# 03 超导数据检索与数据库发现：交互状态与前端逻辑

## React/Vite 落地边界

本文描述检索页面的 React 状态、筛选、排序、选中、跳转、空状态和 Material 反馈。不定义后端查询实现。

## 核心状态

- `searchContext`：元素组合、化学式或检索模式。
- `activeLayer`：当前 demo 层级，取值为 `explore`、`results`、`detail`。
- `filters`：Formula、Tc、压强、年份、超导类型、空间群编号范围、审核状态、`show_in_chart` 等筛选条件。
- `sortState`：当前排序字段和方向。
- `selectedRecord`：当前选中记录。
- `detailSheetState`：详情 Side Sheet / Bottom Sheet 状态；第二层初始为关闭，单击表格行后打开。
- `detailSections`：详情分区展开状态。
- `resultState`：加载中、成功、空结果、失败。
- `snackbarState`：下载、复制、错误等轻量反馈。

## 筛选规则

- Formula 支持模糊搜索。
- 第二层筛选栏必须覆盖以下筛选项：Formula、代表 Tc 范围、压强范围、年份范围、超导类型、空间群编号范围、审核状态和 `show_in_chart`。
- 第二层筛选项全部平铺展示，不再拆分“基础筛选 / 高级筛选”。
- 超导类型、空间群编号范围和审核状态必须使用数据库备选项，不允许手填自由文本。
- DOI / 标题 / 关键词不参与第二层筛选。
- 空间群只支持 `space_group_number` 语义，不支持空间群字符串搜索；范围筛选使用 `space_group_min` 和 `space_group_max`。
- 代表 Tc 筛选和排序必须以后端计算结果为准，避免分页后前端局部排序。

## 行交互

- 单击表格行：触发行 ripple，更新 `selectedRecord`，选中当前行，并打开右侧 Side Sheet。
- 双击表格行：进入详情页；正式路由规划为 `/records/:sourceSystem/:sourceRecordId`，静态 demo 使用 `#detail`。
- 返回列表时尽量保留检索条件、筛选条件和分页状态。
- 复制 DOI、下载 JSON/RIS 成功后使用 Snackbar。

## 三层 demo 跳转

- `#explore`：第一层元素搜索，支持轻量化学式输入、完整周期表选择和 Enter 进入结果层。
- `#results`：第二层 Data Table + Side Sheet，保留第一层选择的元素和筛选模式，点击表格行更新右侧详情。
- `#detail`：第三层详情页，保留第二层选中记录，返回时回到结果列表。
- 刷新页面时根据 hash 恢复对应层级；无 hash 时默认进入 `#explore`。
- 页面顶部不显示 `#explore / #results / #detail` 对应的三段式调试切换 pill；这些 hash 只用于静态 demo 状态恢复。

## 第一层元素搜索交互

- 三种筛选模式和操作按钮必须处于同一工具条，顺序固定为：`选择元素的组合`、`仅包含选择元素`、`包含所选元素`、`进入页面`、`清除选择`。
- `进入页面` 在未选择元素且 Formula 为空时 disabled；选择至少一个元素或输入 Formula 后启用。
- `清除选择` 清空 `selectedElements`、取消所有元素格子的 selected state；如果 Formula 仍有内容，`进入页面` 仍保持启用。
- Enter 快捷键只在第一层 `#explore` 生效；当 `selectedElements` 非空或 Formula 非空时进入 `#results`。
- 元素格子点击后只切换 selected state，不改变元素类别颜色；selected state 通过边框、轻遮罩或描边叠加表达。
- 化学式轻量搜索可以直接进入 `#results`，但不改变周期表 `selectedElements`。
- 主表镧系/锕系入口格点击时按 `La` 和 `Ac` 处理；完整镧系/锕系仍可在下方独立行中逐个选择。

## 页面状态

- 加载中：保留筛选区，表格顶部显示 Linear Progress。
- 空结果：结果 Surface 内展示 Material empty state 和重置筛选按钮。
- 错误：保留用户筛选条件，展示 Banner 和重试按钮。
- 重置筛选：恢复 Formula、范围字段、数据库备选项和 `show_in_chart` 默认值，不清空第一层已选元素。

## 验收标准

- 筛选、排序、选中详情互不干扰。
- 详情字段来自当前接口返回，不需要额外详情请求。
- 空结果、加载和错误状态均可见。

## 旧版设计资产融合边界

- 元素选择沿用旧版状态语义：`selectedElements`、`selectionMode`、进入结果页启用态、清除选择和 Enter 快捷进入。
- 元素类别颜色沿用旧版周期表语义，交互态不得覆盖类别底色。
- `进入页面` 位置沿用旧版操作区语义，必须跟在三种元素筛选模式之后。
- JSON/RIS 导出在 demo 中用 mock Blob 下载，正式实现继续接后端导出接口。
- 图片预览、CIF/3D 查看在 demo 中用详情 Sheet 的可展开区域模拟，不引入后端。
- 不迁移旧版全局函数和内联 `onclick`，正式落地时拆成 hooks 和局部组件状态。
