# 03 超导数据检索与数据库发现：页面结构与内容

## React/Vite 落地边界

本文定义检索页面的 JSX 信息结构、字段和页面内容。接口返回结构以本目录 `API接口调整方案.md` 为准，视觉系统服从根目录 `design.md`。

## 页面承载

- 正式入口规划：`/compound/:elementSymbols` 检索结果页；元素周期表入口仍由 `/elements` 承担。
- 静态示例：`index.html` 单文件三层 demo，通过 `#explore`、`#results`、`#detail` 在元素搜索、结果表格和详情页面之间切换；hash 层级切换只作为 demo 状态，不在页面顶部显示三段式切换控件。
- 页面目标：让用户快速筛选和比较多条超导记录，并查看单条记录的完整科研细节。

## Material 页面骨架

1. Top App Bar：显示当前检索上下文、搜索入口和全局操作。
2. Navigation Rail：当前模块高亮为超导探索。
3. Search Surface：承载 Formula 和元素组合检索；Formula 支持模糊搜索。
4. Filter Surface：筛选本地数据库结果。
5. Data Table Surface：主结果表格。
6. Side Sheet：单击行后展示记录详情。
7. Snackbar：下载、复制 DOI、空结果和失败反馈。

## 页面区块

1. 第一层元素搜索：轻量 Formula 输入、完整 118 元素周期表、已选元素 Chip，以及同一行操作区。
2. 第一层操作区顺序固定为：三种元素筛选模式、进入页面、清除选择。进入页面必须放在“选择元素的组合 / 仅包含选择元素 / 包含所选元素”三个模式按钮之后。
3. 第一层周期表按老版本元素类别颜色区分元素类型，元素格子内容只显示原子序号和英文元素符号；主表中的镧系/锕系入口格只显示 `La` 和 `Ac`，避免 `La-Lu`、`Ac-Lr` 字符串溢出。
4. 第二层结果表格：左侧筛选栏、中间 Data Table、右侧选中结果 Side Sheet、当前筛选结果 JSON/RIS 下载。
5. 第二层筛选栏不再拆分“基础筛选 / 高级筛选”标题，全部筛选项平铺在同一张筛选 Surface 内。筛选项包含 Formula、代表 Tc 范围、压强范围、年份范围、超导类型、空间群编号范围、审核状态和 `show_in_chart`。
6. 第二层不再提供 DOI / 标题 / 关键词筛选。
7. 第三层详情页面：基础信息、超导参数、结构信息、计算与备注、mock 结构预览、mock CIF 展开、单条 JSON/RIS 下载和复制 DOI。
8. 顶部检索上下文：展示当前元素体系、检索模式。
9. 检索范围固定为本地数据库。

## 结果表格列

表格列顺序固定为：年份、体系名称、超导类型、压强、代表 Tc、空间群、数据来源、审核状态、DOI。

表格只展示代表 Tc，不在一行塞入全部 Tc 字段。全部 Tc 字段放入右侧详情和独立详情页。

## 代表 Tc 规则

默认代表 Tc 优先级：`experimental_tc`、`anisotropic_eliashberg_tc`、`isotropic_eliashberg_tc`、`allen_dynes_tc`、`mcmillan_tc`。表格 tooltip 或小标签需要显示代表 Tc 来自哪个字段。

## 右侧详情内容

- 基础信息：Formula、年份、DOI、论文标题、期刊、审核状态、数据来源。
- 超导参数：全部 Tc 字段、lambda、omega_log、N(Ef)、s_factor。
- 结构信息：压强、空间群编号、空间群符号、晶体结构、晶胞参数、体积。
- 计算与备注：计算软件、方法、赝势、交换关联泛函、k/q 网格、能量截断、备注。
- 结构预览：保留 mock preview 与 mock CIF 展开，用于静态 demo 表达未来结构查看入口。

## 验收标准

- 默认只展示本地数据库结果。
- 表格按固定 9 列展示，不使用卡片式结果列表作为主视图。
- 默认按代表 Tc 降序排序。
- 进入结果表格时右侧 Side Sheet 默认不显示；单击表格行显示右侧详情，双击表格行进入详情页。

## 旧版设计资产融合边界

- 继承旧版 SC-explore 的核心入口：化学式检索在上，周期表检索在下，元素筛选模式包含“选择元素的组合 / 仅包含选择元素 / 包含所选元素”。
- 继承旧版周期表的元素类别颜色区分，不把所有元素格子统一成白色或纯 Material 卡片色。
- 继承旧版镧系/锕系独立行展示方式，但主表占位格使用短标签 `La` 和 `Ac`，保证元素格子内文本不溢出。
- 继承旧版操作区语义：进入页面和清除选择放在三种元素筛选模式之后，不放在页面标题区或独立浮层。
- 继承旧版结果页能力：本地数据库检索，RIS/JSON 导出，分页，图片预览，CIF/3D 结构查看和代表 Tc 高亮。
- 继承旧版 SC-share 的下载语义：按当前筛选结果下载 JSON/RIS，以及全库 JSON/RIS 下载。
- 静态 demo 需要能模拟元素选择、模式切换、结果过滤、详情更新、mock CIF 展开和 mock 下载。
