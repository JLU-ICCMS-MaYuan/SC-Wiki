# 03 超导数据检索与数据库发现：后端优化调整方案

## 核心目标

后端需要支持“同一材料体系下本地记录统一展示、筛选、排序和详情读取”。用户从元素周期表或化学式入口检索材料体系后，后端返回前端结果表格使用的摘要行；用户单击或双击某一行时，再通过详情接口读取该记录完整信息。

检索范围固定为本地数据库，不提供数据源切换或跨源聚合。

这里的“展示行”不是新的业务表，也不是把多张表混成一个含糊的数据记录。它只是后端面向前端表格整理出来的统一返回格式。

## 本地数据组成

本地数据库展示行由三类本地数据共同组成：

- `superconductors`：提供体系名称、化学式、归一化化学式、元素组成和材料体系关系。
- `superconductor_records`：提供压强、Tc、超导类型、空间群、计算或实验参数、参数来源标签等具体超导记录信息。
- `papers`：提供 DOI、论文标题、年份、期刊和本地审核状态。

因此，一条本地展示行应理解为“某个材料体系在某个压强和某篇文献来源下的一条可展示超导数据”，而不是单独来自 `superconductors`、`superconductor_records`、`papers` 中任意一张表。

本地 `source_record_id` 建议使用 `superconductor_records.id`。

## 代表 Tc 规则

后端需要统一计算代表 Tc，用于表格展示、筛选和排序。

默认代表 Tc 规则为按以下顺序取第一个非空值：

1. `experimental_tc`
2. `anisotropic_eliashberg_tc`
3. `isotropic_eliashberg_tc`
4. `allen_dynes_tc`
5. `mcmillan_tc`

后端返回摘要行时需要同时返回：

- `representative_tc`
- `representative_tc_field`
- `representative_tc_label`

03 检索页只展示和说明代表 Tc，不允许用户修改 Tc 类型。Tc 类型选择属于 07 图表自定义功能。

## 列表摘要字段

列表接口只返回表格和分页所需摘要字段，不返回完整详情，避免列表接口过重。

摘要字段建议包含：

| 字段 | 含义 |
| --- | --- |
| `source_system` | 本地来源，固定为 `local` |
| `source_record_id` | 来源系统中的记录 ID |
| `year` | 年份 |
| `formula` | 体系名称或化学式 |
| `superconductor_type` | 超导类型 |
| `pressure_gpa` | 压强，单位 GPa |
| `representative_tc` | 代表 Tc |
| `representative_tc_field` | 代表 Tc 对应后端字段 |
| `representative_tc_label` | 代表 Tc 中文或展示标签 |
| `space_group_number` | 空间群编号 |
| `data_source` | 面向用户展示的数据来源 |
| `review_status` | 本地论文审核状态 |
| `doi` | DOI；没有 DOI 时为空 |
| `show_in_chart` | 是否进入默认图表，本地数据可用 |

## 筛选规则

后端检索需要支持以下筛选：

- Formula 模糊搜索。
- 代表 Tc 范围。
- 压强范围。
- 年份范围。
- 超导类型。
- 空间群编号：只支持 `space_group_number`，不支持空间群字符串。
- 审核状态。
- DOI / 关键词。
- 是否进入图表：`show_in_chart`。

空间群筛选只支持编号，避免字符串写法差异造成误匹配。


## 排序规则

默认排序为代表 Tc 降序。

后端需要支持：

- 代表 Tc 升序 / 降序。
- 年份升序 / 降序。
- 压强升序 / 降序。
- Formula 字母顺序。
- 审核状态。

代表 Tc 排序必须在后端完成，避免分页后前端只对当前页局部排序。

## 详情读取

详情接口使用 `source_system + source_record_id` 定位记录，读取本地记录。

### 本地详情

本地详情需要返回完整字段，供右侧详情卡片和独立详情页使用：

- Formula
- 年份
- DOI
- 论文标题
- 期刊
- 审核状态
- 数据来源
- 全部 Tc 字段
- lambda
- omega_log
- N(Ef)
- s_factor
- 压强
- 空间群编号
- 空间群符号
- 晶体结构
- 晶胞参数
- 体积
- 计算软件
- 方法
- 赝势
- 交换关联泛函
- k/q 网格
- 能量截断
- 备注

## 独立详情页支持

后端详情接口需要同时服务：

- `/compound/:elementSymbols` 页面右侧详情卡片。
- 未来 `/records/:sourceSystem/:sourceRecordId` 独立详情页。

独立详情页不要求新增不同的数据模型，可以复用同一个详情响应，只在前端展示层扩展布局。

## 验收标准

- 默认本地结果按代表 Tc 降序返回。
- 列表接口只返回摘要字段，不返回完整详情。
- 列表摘要字段能满足 9 列表格展示。
- Formula、代表 Tc、压强、年份、超导类型、空间群编号、审核状态、DOI / 关键词、`show_in_chart` 均可筛选。
- 空间群筛选只使用编号。
- 详情接口只支持本地记录。
- 本地详情包含全部 Tc 字段、超导参数、结构信息、计算信息和论文信息。
