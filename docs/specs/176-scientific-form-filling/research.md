# 功能内设计决定

- 模型负责判断重复、配对与来源适用性，程序负责有界读源、候选覆盖和结构。依据是已复现的 CaH6 摘要／正文／SI 四条记录；完整身份去重不能解决语义重复。
- 复用现有完整块上下文，不引入向量数据库作为本次前置依赖。短来源目录帮助模型选择后续读取，完整块过大时报告读取限制，不静默截断后宣称已读。
- 组装后接入一个共享整理步骤，以状态身份隔离物相／压力；同一状态多方法可共享参数组。所有输入候选必须有明确去向，合并保留引用。
- 原始候选和响应留在解析产物；失败仅记录问题，不能以空列表覆盖整组。已报告的数值不可静默消失，范围与端点等价需要模型明确映射及同方法／条件检查。
- 其他方法使用既有 method_raw，不新增数据库列。定义仍是 other；用户可自由编辑具体名称。unknown 与 other 不混用。
- 纯文字历史 Tc 使用相同固定布局，保留旧文字说明。只有显式编辑才转换为数值并保存原表达，不在 GET 触发迁移。
- 技术预算采用有限轮数和原文字符预算；每轮必须新增来源或纠正明确格式问题，无新增信息停止。预算不是把不确定科学结论判成失败的依据。
