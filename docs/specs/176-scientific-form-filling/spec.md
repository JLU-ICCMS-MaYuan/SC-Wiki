## 目标与已讨论结论

让 LLM 联合理解原文、整理科学关系并主动查缺；程序检查结构、来源与保存一致性；前端使用固定表单。首先完成 Tc，再按现有科学字段逐项推广和检查，不用“解析完成”代替填写正确。

1. 保持 #94 布局：共同 λ／ωlog 独立行，每种预测方法占一行，方法下拉与该方法的多个 Tc／μ* 组合同排；计算条件独立。不同共同条件分组。
2. 下拉仅含 allen_dynes、mcmillan、isotropic_eliashberg、anisotropic_eliashberg、scdft、other、unknown。other 允许填写并保存具体名称，LLM 有原文依据时同样可用；unknown 不伪装成已确定的方法。
3. 每条预测结果恰属一种方法；同状态允许多方法、多 μ* 点，不默认复制示例值。代表结果仍明确到某方法的某个点，沿用同状态唯一性。
4. “超导转变温度 Tc”不作为 LLM 生成或用户填写的科学字段保存。沿用固定表单，不把错误文本输出解释为切换通用表单的理由。
5. LLM 判断摘要范围、正文单点、表格和 SI 是否描述同一结果；相同结果合并来源而不重复生成结果组，不按数字相等机械删除结果。
6. 缺值、方法不明、参数不完整时主动查找当前论文及 SI 的相关文字、表格、表注和 Methods。没有新证据时停止重复调用，留下具体疑点；不能首次漏提就直接交人，也不能为填满而编造。
7. 暂不从曲线提取 Tc。S19 作为方法对比来源保留；图注方法说明不生成温度结果。
8. 已有 μ* 等字段优先复用，不生成同义扩展输入；合理的新参数保留扩展能力。原始响应、来源和处理关系可追溯。
9. 上传、返修、管理员、超级管理员保持相同填写与保存语义；输入、普通保存不调用模型。保留稳定身份、局部更新、中文输入、并发及失败恢复。
10. 既有历史数据保留；不得读页面就改库、抹去用户修改或伪造人工通过。验证在隔离副本进行。

## 验收标准

- CaH6 150 GPa 的正文结果形成一组共同参数、一个有来源支持的方法行，包含 220 K／0.13 与 235 K／0.1；λ=2.69，ωlog 未报告则空。摘要范围不成为第三份重复结果，S19 不产生文本型 Tc 或读图 Tc，页面没有冗余 mu_star 扩展框。
- 真实多方法资料保留各方法各自结果；other 自定义名称经编辑、保存、重开与导出保持一致。示例数值不能作为论文结果。
- 缺值能够由模型从另一段或 SI 找回；确实未报告、来源冲突和读取失败分别说明。超时、断网不伪装成科学错误。
- 旧错误响应先证明回归能检出，再验证修复；保存并重读字段、所属状态、方法、分组、来源和未处理问题。
- 从原 PDF 的已核对文本重新执行受影响字段的真实 AI 提取与正式后处理，覆盖相邻受影响字段；不复用旧字段答案冒充重提。
- 四类完整宿主回归、test:form-contract、test:form-contract:mutation 及受影响回归通过；新增和历史兼容路径分别检查。
- 记录使用的源码、模型、来源哈希、复用／重跑步骤及失败限制；不能把固定重放当真实提取、字段通过当整篇或全站通过。

## 用户故事与独立验收

### US1：按既定表单查看与填写 Tc（P1）
假如模型返回数值、范围或错误方法文字，当用户打开任何科学编辑宿主，那么布局保持固定；合法值进入对应控件，错误内容保留出处和可理解的处理信息，不变成通用文本型 Tc 表单。选择 other 后可输入具体名称并保存重开。

### US2：得到一组完整、无重复的科学结果（P1）
假如摘要给出范围、正文给出两个 μ* 配对点、SI 给出方法图注，当模型整理全文时，那么判断重复关系并保留各来源；只形成有依据的结果组，不丢失两个配对点，不从曲线生成 Tc。不同方法、压力、物相、近似或共同条件不误合并。

### US3：缺项由模型先查找（P1）
假如首次候选漏掉参数或方法信息，当解析准备填写草稿时，那么模型使用相关原文和附件继续查找；找到适用依据则补齐并保存来源，仍不确定时说明已查什么、缺什么及原因。没有新增证据不能无限重复调用。

### US4：推广一致职责并减少人工负担（P2）
假如当前其他已支持科学记录也存在重复表达或字段归属问题，当应用同一整理原则时，那么仍遵守各自的字段含义与既有表单；缺失、冲突和技术失败分别呈现。逐项记录通过与未通过范围，不能笼统宣称全部字段完成。

## 功能需求

- FR-001：预测 Tc 使用固定分组布局；模型不能生成或改变前端控件。
- FR-002：方法枚举为规定七项；other 接受具体名称并完整保存，unknown 保留未说明语义。
- FR-003：每条结果恰属一种方法；同状态允许多方法和多点，条件不同则分组；代表结果遵循既有唯一性。
- FR-004：共同参数、方法行、结果点与各自来源在提取、保存、重开和导出中一致。
- FR-005：固定标题不作为需要生成、编辑或单独持久化的科学信息；保留必要的已有结构标识及历史可读性。
- FR-006：LLM 可在来源约束下合并重复表达、整理对应关系；每个原候选有保留、合并或排除的去向和理由，不无声丢弃。

2026-11-03 #210修正：此前概述特例未贯穿最终防遗漏门，不能视为FR-006完整落地；当前按已认可方案统一候选去向，合并关系交既有科学核对。原始失败及历史验证保留，详见[210规格](../210-candidate-coverage/spec.md)。
- FR-007：Tc 数值缺失时主动查找；不将方法说明作为温度结果，不从曲线提取 Tc。
- FR-008：查缺读取当前论文和附件的相关段落、表格、表注和 Methods；不从其他论文或常识填入未报告科学值。
- FR-009：每次查缺有明确目标、已读来源和结果；无新证据或任务预算耗尽时停止，技术失败可重试。
- FR-010：区分原文未报告、语义歧义、来源冲突、文字读取失败、模型技术失败；不强迫用户处理伪造的完整结果。
- FR-011：已有字段优先映射，不重复生成同义扩展；保留合理新参数及 other 方法名的自由输入。
- FR-012：整理或恢复仅在解析及明确业务操作时执行；打开、输入、普通保存不得启动模型。
- FR-013：字段与记录稳定身份、原文、旧响应及审计历史保留；迟到结果不覆盖用户新输入，失败不丢草稿。
- FR-014：当前其他已支持科学字段按原有定义逐项推广，检查并移除被替代的重复处理；不新增未要求的模块。
- FR-015：四类科学表单宿主执行既有完整回归门；受影响 PDF 字段保留固定失败重放和原来源真实重新提取两类证据。

## 关键实体

- 科学结果组：同材料状态且共同条件兼容的一组结果，含共同参数与方法行。
- 方法行：唯一方法类型，other 另有具体名称，包含若干独立结果点。
- 结果点：Tc、μ*、限定语和来源；不把方法文字当作数值。
- 来源及候选去向：原文定位、原始输出、合并或排除依据，不能因整理而丢失。
- 缺项处理记录：缺失目标、已读取内容、查找结果、停止原因及待人工疑点。

## 边界与异常

- 原文未明确的 Eliashberg 类型不靠关键词猜；冲突不靠字符串相等解决。
- 同值不同方法、不同条件不是重复结果。材料状态归属仍遵循原有结构优化及物相规则。
- 范围、约数或上下界保留原有科学限定；不能一律改成精确单值。
- 首次失败不清除候选；每次尝试可追溯，停止后保留真实未解决状态。
- 历史错误数据不因读取而改库；在固定布局中保留原内容与恢复入口，不能默默隐藏或伪装通过。
- 删除造成位置变化时不串记录、来源或人工说明；只读与权限约束不变。
