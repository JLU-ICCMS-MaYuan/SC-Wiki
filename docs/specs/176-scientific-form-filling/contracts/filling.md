# 填写与展示契约

## 模型边界

输入：同一篇上传有效正文／SI 的来源目录、可读原块、材料状态及带稳定 candidate_id 的科学候选、字段说明。

输出：读取请求或最终整理。最终整理为分状态结果、每条结果的输入候选与来源引用、共同组／方法行、明确排除、未解决原因。所有原候选必须被覆盖；新补全结果也必须有原文。服务器不接收模型提供的数据库 ID、权限、审核状态或可执行脚本。

## UI 与保存

预测 Tc 始终使用固定共同参数／方法／配对布局。七个方法选项不被数据扩充；other 显示具体名称输入。方法文本不能当作 Tc；旧错误值以说明展示且不能变成代表结果。已有可选空 μ* 不编造，代表结果继续要求明确组合。

普通编辑和保存不请求模型。原文查缺只在解析或明确核对动作中执行；迟到响应遵循宿主版本保护。保存沿用当前接口，不引入全表刷新。

## 失败

模型输出非法、来源无效或候选遗漏时允许有界纠错；仍失败则保留原候选、响应和诊断，不返回虚假通过。取消原样传播。无来源、未报告、冲突、读取失败及技术失败分别记录。

## #210：统一候选去向与科学核对

当前整理复用records.candidate_ids、reason和source_ids；candidate_dispositions保存每条原候选、归属、输出目标和理由。多个重复候选可以映射到同一结果，包括约200 K与详细191–204 K。程序检查候选覆盖完整、目标存在且归属一致，并保留真实原文块；原数字未原样出现不独自构成遗漏。原提取到确定性组装输入的真实漏项保护继续有效。

原候选和理由作为只读organization_context交给既有统一字段科学核对，模型仍须结合双方原文查证压力、方法、配对和关系。映射完整不表示科学通过；错误合并进入不支持或不确定的普通字段处理。逐字段source_ids只选择当前字段的事实及必要范围，不把整理报告整包当作原文展示。

此前7e26744a的candidate_relations/summary_of_range是未贯穿最终门的局部修补，当前由通用去向机制替代；旧协议、数值包含和至少两块来源等限制不再作为当前要求。历史失败响应及原验证边界保留，不改写为新实现通过。详见[本次规格](../../210-candidate-coverage/spec.md)。
