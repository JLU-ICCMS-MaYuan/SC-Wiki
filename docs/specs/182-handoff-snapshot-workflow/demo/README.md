## 打开演示

直接用浏览器打开 [handoff-snapshots.html](handoff-snapshots.html)，无需安装依赖、业务服务或登录，也不读取真实稿件。页面不发送业务 API 或模型请求，不保存数据。

页顶的“入口位置／交接记录／整稿快照”是演示导航，不是计划增加到业务系统的顶栏。

## 已确认的查看路径

1. 在整份稿件的标题操作区放“交接记录与快照”。上传校对、返修、管理员、超级管理员入口各复用自己的标题区域，不增加固定顶栏。
2. 点击后新开整稿交接列表；顶部区分当前公开版、最新交出快照与当前工作稿。
3. 点击某次交接的“查看整稿”，在新标签页打开只读快照。版本信息与该次交接信息分别显示；同一内容快照可出现在多次交接中。
4. 只读整稿仍沿用现有表单分区。点击字段可打开当时的来源、人工记录和 AI 理由；侧栏只含“字段设置／来源核对”，不保留“历史”页签。

## 演示范围和边界

- 全部论文信息、科学值、引句、人员和交接都是模拟数据，不是 La–Sc–H 真实解析、证据或审核结果。
- 示例包含 7 次交接和 6 份快照，展示内容相同复用 S4，不限定 4 份。
- 内容相同指字段值、采用证据、当前采用理由和字段核对结果都未变。理由或字段核对结果单独变化，也在正式交出时新增完整快照；只有交接人、时间及流程决定变化才可仅增加交接记录。
- S4 是当前公开批准版；S5、S6 是修订流程中的版本，尚未替换 S4。
- 示例覆盖按交接查看 S4、以及直接查看 S4，两者可以展示同一内容但不同交接上下文。
- 当前工作稿以退回的 S6 为基础演示；S6 及之前快照均只读。无“直接编辑历史”或自行取回按钮。
- 来源侧栏沿用两个页签、折叠内容区、桌面 480px／窄屏全宽的基本结构。生产组件没有改动，本文件不是逐像素复刻全部现有页面。
- 只呈现代表性表单字段，真实交付要求保存整份表单及随稿证据。没有新增版本比较、恢复、模型核对、编辑或权限接口。
- 实际可见性由后续服务端权限控制。公开页面的访客不因此获得待审版本；本 demo 只示意有权查看该稿件的经手人。
