# 验收步骤

1. 打开含多个材料状态、四类性质模块的上传任务校对页；顶部“返回上传记录”左侧显示两个按钮。
2. 混合展开几个模块，点击“全部折叠”：所有材料状态收起；单独打开一张材料状态，四类模块均收起。
3. 点击“全部展开”：所有材料状态及已有模块展开；关闭一项，再点同一按钮，重新全部展开。
4. 编辑输入但不保存，反复收起、展开，确认输入未丢失、没有额外保存或解析请求。
5. 将模块内部记录手动收起，执行全局操作，确认其内部独立状态保留；晶体结构、论文片段同样保持。
6. 切换英文，键盘Tab及Enter/Space操作按钮；390px窗口下按钮可达、无新增整页横向溢出。
7. 空材料状态时按钮禁用；校验错误定位和任务切换仍按原有行为执行。

自动化命令与实际结果见[验收记录](validation.md)。浏览器若使用隔离夹具，须明确不等同真实账号提交或生产部署。
