# Feature 规格：PDF 解析详情紧凑布局

**GitHub Issue**：[#124](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/124)

**创建日期**：2026-10-09

**状态**：已确认

## 背景与目标

研究者打开 PDF 解析详情并向下校对时，顶部常驻操作栏留白过大，栏与视口之间会露出背后的表单；桌面内容区左右也留有明显空带。目标是让操作栏更紧凑、连续遮挡背后内容，并让展开的解析工作区接近两侧边缘。

## 用户场景与验收

### 用户故事 1：在宽敞且清楚的解析工作区校对（优先级：P1）

研究者点击“查看解析”，向下滚动校对表单时，仍能看到清楚的文件名、解析状态和“收起解析”按钮，同时表单占用更宽的可用区域。

**优先级理由**：直接解决截图中的遮挡和空间浪费。

**独立验收**：在桌面和窄视口打开解析详情、滚动并收起，观察顶部遮挡、左右间隙、按钮可达性和页面溢出。

**验收场景**：

1. **假如** PDF 解析详情已展开，**当** 用户向下滚动表单，**那么** 紧凑的常驻栏贴合视口顶部，文件名、状态和收起按钮持续可见，栏顶和栏内不透出表单。
2. **假如** 桌面视口中的解析详情已展开，**当** 用户查看工作区，**那么** 其左侧与导航、右侧与视口边缘各约有 8px 间隙。
3. **假如** 用户收起解析详情，**当** 页面返回任务列表，**那么** 上传页恢复原有常规横向边距，待上传文件仍保留。

### 边界与异常场景

- 窄视口中的文件名可以截断，状态和收起按钮仍可识别、点击，页面不得新增横向滚动。
- 解析状态加载或缺失时，操作栏仍保持连续背景和可点击的收起按钮。

## 需求

### 功能需求

- **FR-001**：解析详情展开时，常驻操作栏必须紧凑展示文件名、阶段状态和收起按钮，按钮触摸高度不少于 44px。
- **FR-002**：常驻操作栏必须贴合视口顶边且具有连续不透明背景，滚动时不在栏顶或栏内露出背后表单。
- **FR-003**：解析详情展开时，工作区左右间隙应各约 8px；收起后恢复上传页原有边距，不改变其他页面。
- **FR-004**：窄视口中不得因为本次布局调整新增横向滚动或遮挡收起按钮。
- **FR-005**：现有任务切换、收起和本地草稿保留行为必须保持一致。

## 成功标准

- **SC-001**：桌面常驻操作栏高度不超过 56px，滚动后文件名、状态和按钮均可见，表单不会从栏顶或栏内透出。
- **SC-002**：桌面解析详情展开时左右间隙均为 8px，收起后恢复既有 32px 桌面边距。
- **SC-003**：375px 宽视口无新增水平滚动，按钮保持至少 44px 高且可点击。
- **SC-004**：现有上传工作区回归验证通过，切换与收起不清空待上传文件。

## 假设与依赖

- 以当前 `mayuan` 分支的 `AppShell` 和 `UploadPage` 为基线。现有顶部全站 App Bar 已移除，解析栏可贴合视口顶边。
- “窄窄的一条小缝隙”采用左右各 8px 的设计默认值。
- 关联 #48 已实现的常驻收起逻辑；本 Feature 不改变任务状态和 API。

## 范围外事项

- 不调整全站其他页面的边距、导航宽度或表单字段结构。
- 不修改 PDF 解析、任务轮询和提交数据流程。
