# 谱详情数据关系

复用 SpectrumCollection → SpectrumRun，collection.current_run_id 指向当前运行；旧运行和旧拆分/合并集合均保留，不建立新表。

材料状态 + 谱类型形成一个展示组。组内持有当前展示 item 和其他集合，私有历史接口提供每集合旧运行。展示组不是新的科学数据实体，不改变审核归属或数据库唯一约束。

新集合 panel_key 使用稳定语义摘要，旧自由命名 panel_key 原样保留，通过同一展示分组作为历史访问。未归属集合不合并到任何材料状态。

零频缺失是显式数据缺口，频率已定位到 0 不等于幅值已观测。绝对 DOS 模式密度和相对像素幅值不可混算；当前状态变更使历史比较失效。
