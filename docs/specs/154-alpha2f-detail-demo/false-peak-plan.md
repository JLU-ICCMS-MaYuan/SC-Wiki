# 低频伪峰定位与修复方案

## 已证实事实

2026-10-23 只读复查本机业务库：290 GPa 当前 α²F 集合 c340f3c41b144662808c0933d1e75248 仍使用运行 4155b9543bda491ea593efda6c6c8c36。原图 SHA-256 与此前保存图一致。

原频率 1.8979211271 THz 对应原图 y=423。严格 olive 掩膜在该行无点，宽松补读选出 x=642、737、763。642 为实际曲线边缘；737/763 为 λ(ω) 文字棕色抗锯齿边缘。旧代码 coords.mean() 得到 714，按旧幅值轴变成 2.0103357103。前端回绘该存储点，没有生成额外尖峰。

模型 α²F exclude 只含 [674,382,789,402]（α²F 图例），没有 λ(ω) 文字区域；同图累计 λ 的 exclude 已包含该区域。仅在实验副本补入同图累计 λ 的排除框，旧算法也变为像素 642（旧尺度 0.1499078599），说明漏排除是诱因。仅给宽松补读加严格颜色/纯净暗色邻域约束，原模型标定不改也只留下642，说明代码能独立阻断本次伪峰。

## 正式修复

1. 沿用颜色阈值，不通过调幅值大小或按频段特判去峰。宽松颜色候选必须在已允许区域内、邻近严格颜色或色相明确的暗色像素；当前实现采用两像素邻域，不借被排除的图例作为支持。
2. 同一扫描行/列出现多个不相连候选时不直接求全体均值；无法唯一分辨的行标记歧义缺失，不允许重建插值跨越该行。连续真窄峰不因高度或宽度被删除。
3. 逐点记录被拒绝的宽松候选数、候选段数和重建阻断原因；质量汇总与 CSV 保留这些信息，界面显示真实缺失/歧义状态。
4. 模型提示词补充：所有文字及其他颜色图例也需排除，其抗锯齿彩边可能落入本色通道。代码不依赖模型排除框百分之百正确。
5. 算法版本升级 v4，确保正式重提取产生新运行。先完成同图反事实与回归，再仅对本机该290 GPa集合用原标定走现有正式任务函数生成新版本；重新读取当前目标/集合版本及状态，保留旧数值和人工表单，不调用新模型、不触及其他状态。若版本变化则停止写入并重新核对。
