## 数据与职责

- 保留现有 SpectrumCollection / SpectrumRun 所有记录。列表增加运行时间；前端按材料状态及谱类型只组织一个当前入口，在各集合当前运行中优先最新有曲线者，所有旧运行仍保留在历史。当前只表示展示版本，不表示科学采纳，旧集合及运行可从历史入口读取。
- 新发现的面板用材料状态与曲线类型/投影组成稳定 panel_key（同来源内），不再将模型自由命名的 panel_id 当作身份；原标签保留于标定。旧集合通过读取分组汇入历史，不批量改库。
- 增加私有历史运行读取接口，复用目标权限；公开读取不暴露旧的未审核运行。旧运行显示原状态和条件摘要、旧比较不可复用。导出可指定历史 run，图片仍读同集合不可变来源。
- 查看按钮使用原生新标签链接，不触发保存或写 API；未保存的主表单保留，详情明确读取已保存材料条件。标定/归属写操作仍保留版本检查。
- 单图三模式、来源轴向、DOS 分波选择共用独立详情组件；原图覆盖用真实 pixel/axis_calibration，缺数据不连线。点表定高滚动，中文来源状态、幅值绝对差。
- α²F 范围仅取 α²F；累计 λ 只作参考，不扩大主谱范围。展示服务器原积分与同条件参考，缺口/单位未确认或条件失效不伪造比较。
- DOS 新增未归一化的绝对模式数核验，仅已确认原胞 N、完整投影及绝对单位可计算；展示 |积分−3N| 与非负百分比，不给满足判断。

## 零频与科学边界

正式 v3 提取要求显式可辨认零频刻度，以该刻度约束线性轴，延伸 ROI 到原图中的实际零频位置并从图像采样；缺零刻度或出图范围则提取失败，保留来源和原因。不是给旧首点改名；零频幅值不可读保留 missing，不补零。旧 v2 数据保留真实非零起点，并标记零频未覆盖，不能借累计 λ 掩盖。

不把旧 v2 physical_definition_confirmed 当作新的独立 α²F 幅值证据；新标定增加独立幅值依据，缺依据时不输出物理积分。历史数据不自动重算或自动采纳。
