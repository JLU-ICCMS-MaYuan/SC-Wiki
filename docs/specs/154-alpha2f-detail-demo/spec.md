## 用户场景与验收

### US1：从材料状态查看谱（P1）

原材料表单输入备注后点击查看，详情应在新标签页打开，原页输入保留。用户可独立查看来源、结果和数值说明。

### US2：快速核验谱与数据（P1）

切换单图显示方式，查看数值或失败原因，在定高点表内滚动、搜索和选点；不需要翻越重复审核面板。

## 功能需求

- **FR-001**：入口在新标签页打开，原表单及未提交输入保持。
- **FR-002**：材料与来源、原图与提取结果、数值核验、逐点数据四区均有标题。
- **FR-003**：一个图窗提供仅原图、仅提取数据、叠加三种模式；所有模式保持来源图轴向。
- **FR-004**：点表最大宽度 1180px、桌面高度 330px；窄屏高度 300px，双向内部滚动、固定表头。
- **FR-005**：提取范围从 0 开始；展示 λ、ωlog、同条件参考值及绝对偏差，不展示有符号差或百分比，λ 不附单位文字。
- **FR-006**：区分频率、自变量、幅值及累计 λ；标定未知禁用积分，参考缺失/失效/零值分别说明。

- **FR-007**：所有点表与导出从零频开始；幅值差取绝对值。真实零频缺失不得补造；α²F 零频积分须有可靠极限。

## 成功标准

- SC-001：两类入口都新开标签页，原输入不变；不请求业务 API。

- SC-003：切换、搜索、点选、导出和异常场景可操作；数值明确标为合成示例。
- SC-004：正式阶段单独验证真实来源、材料条件、权限和故障边界，Demo 不替代该验收。

## 用户明确追加的三项正式接入约束

以下三项已由用户明确要求纳入，作为正式接入验收条件；本次只是追加需求，不标记实现完成，也不将其等同于整份 Spec 或全部 Demo 的最终认可。

1. **FR-008 / SC-005**：同一材料状态，每种谱只有一个当前入口；旧提取版本保留为历史，可追溯查看。
2. **FR-009 / SC-006**：α²F 的频率范围只依据 α²F 自身数据；即使同集合累计 λ 包含零点，也不得改变 α²F 的范围。
3. **FR-007 / SC-007**：α²F 与声子 DOS 的正式提取均真正从 0 开始；需核对原图零频边界、提取点及导出的一致性，不能只改显示标签或补造零点。缺少真实边界证据时标记提取不完整，不冒充达标。

SC-006 验收：使用“α²F 起点大于 0、累计 λ 有零点”的回归样本，α²F 范围保持自身实际起点，并明确其未满足零频提取要求。

SC-007 验收：真实样本从原图定位到实际零频边界，提取与导出范围一致；历史非零起点数据不能通过改名首点、补造零点或借用其他曲线零点通过验收。
