# 290 GPa α²F 低频伪峰：根因与验证

## 结论

这是模型排除框不完整与确定性提取缺陷串联造成的错误，直接生成伪峰的是提取代码，不是前端绘图，也没有证据表明模型直接编造了数值。

- 实际数据库原运行：4155b9543bda491ea593efda6c6c8c36。
- 原图 y=423，历史频率约 1.897921 THz；真实曲线像素 x=642，RGB=[187,186,143]。
- λ(ω) 文字边缘的 x=737、763，RGB 分别为 [105,89,69]、[162,143,123]，被宽松 olive 色差补读接受。
- 旧代码对三个不相连像素取平均，得到 x=714；该位置 RGB=[255,255,255]，是空白，不是曲线。按历史幅值轴换算成 2.0103357，形成横向尖峰。
- 模型给 α²F 的 exclude 只覆盖其橄榄色图例，漏掉 λ(ω) 黑字。其他颜色/黑字的彩边同样能进入本色通道，不能仅按图例主色排除。
- 前端按原像素回绘该存储点；切换显示模式或裁切不会消除错误数据。

## 反事实实验

固定原图、原模型标定和历史频率轴，离线载入提交 4d875935 的旧提取函数：
1. 原排除框 → 642、737、763 平均为 714，复现存储值。
2. 只补入同图累计 λ 已有的文字排除框 → 仅剩642。
3. 原排除框不改，只使用修正代码 → 仅剩642，两个孤立彩边被拒绝。

2、3 得到同一个真实曲线像素，说明两条原因链均有可复查证据。幅值从旧尺度的 2.0103357 变成 0.1499079，仅用于说明同一标定下的差异，不代表 α²F 独立尺度已经科学确认。

## 修复

- 宽松补读需要严格本色或色相明确的暗色邻域支持。归一化只用于判色，不改图像、坐标或幅值。保留暗色真曲线及真实连续窄峰。
- 多个不相连候选不再直接求均值，无法分辨时保留缺口；重建不得通过插值/边界延续跨过该疑点。
- 逐点与 CSV 记录 rejected_chromatic_pixels、candidate_components、reconstruction_blocked，页面显示多轨迹/彩边证据不足的待核对状态。
- 提示词明确排除所有图例和文字，包括其他颜色图例的文字和彩边。
- 算法版本升级 spectra-production-v4，旧观测不覆盖。

## 实际定向新版本

使用本机原生 127.0.0.1:3307/scwiki，先核验 state-5 仍是 LaSc2H24、290 GPa、classical_static，以及集合版本3和当前目标签名。

通过正式 jobs.enqueue + jobs.run_job 任务函数直接定向生成运行 15974842501e44ecb50fa8b7d495f873，集合升到版本4。复用原标定，无新模型调用，未经过 RQ 调度或 HTTP 认证入口，不重启或部署服务。旧运行结果哈希前后均为 55936e78de67b503f024013b6746f83e8aa5ca2a5e43db2719d1508394ae73a2；其他集合和人工草稿内容未变。

新算法沿用 v3 的真实零频锚点，y=423 对应约 1.944441 THz，因此不能把新旧频率标签的小差异误当作像素位置发生变化；本次消除伪峰的依据是同一源像素行、同一幅值轴下 714→642。新 JSON 与正式 CSV 一致。

## 验证与剩余边界

94 项后端/数学、34 项前端测试及生产构建通过。真实原图固定 SHA 回归覆盖该行、相邻真峰和多候选留空；合成图覆盖坐标转置、纯净暗色、孤立文字彩边、不可跨越歧义和真实窄峰。

另有7个频率采样行（源像素293、294、295、299、301、306、310）有重叠/多候选，保留待核对缺口而不是强行取均值。零频幅值和独立 α²F 幅值依据仍未确认，所以新运行 needs_review，不自动批准或宣称整谱准确。
