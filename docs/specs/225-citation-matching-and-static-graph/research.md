# 技术研究

## 分工

决策：程序优先，LLM2只核对疑难候选，最多16条一批。理由和备选：本地4B批量24错连55漏答，单条约束仍2错连；LLM2批量37168 tokens且无错连漏答。本轮回执见assets/model-comparison.json，拒绝主题相似自动造边。

## 生命周期

缓存键绑定任务/来源、原引文、候选书目身份、算法及LLM2元数据，逐引文保存完整决定和理由。候选身份不包含无关科学内容revision，公开版本筛选继续保留。固定键对象协议防止漏答或额外ID成为#224的成功响应。模型tag进入请求正文，恢复时仍能区分实际LLM2版本，并在调用后恢复外层模型配置。

草稿及独立SQL缓存保存服务器快照，浏览器整体保存不得覆盖；正式引用保存依据，批准后补相关历史关系。源引文使用论文、源版本、原编号及原文签名绑定，目标依论文身份绑定。任务归档后可按正式论文归属读取，GET、自动保存和纯程序重试不发模型。缓存不存密钥。

## 布局

按稳定ID与顺序生成默认网格坐标；新增节点占空位，physics=false、smooth=false，拖动只更新内存。拒绝随机坐标、140轮模拟及刷新后保留临时坐标。

## 旧规则变更

本功能替代#81禁止模型辅助核对和#70空标题默认入图的旧边界；保留原引文、唯一ID、审核/版本以及展开/搜索回退。图谱标题生成策略未决，不改动。
