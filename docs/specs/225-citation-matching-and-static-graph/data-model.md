# 数据模型

`citation_match_cache` 按签名保存已完成决定、理由、模型及算法版本，同时独立持久保存任务快照和失败回执，不存密钥。`PaperReference.match_evidence` 保存来源及候选书目签名、方法和理由；`match_method` 新增 `llm2`，不冒充 `manual`。`PaperReferenceExtraction.matching_snapshot` 保存提交前上下游快照；工作稿根 `citation_matching` 是服务器持有的预览元数据，不属于科学标准字段。普通浏览器保存不能删除或伪造该快照。

生命周期为汇总→匹配/缓存→工作稿保存→用户核对→提交→批准→公开。任务归档后，读取接口按正式论文归属查找提取快照，继续执行原有权限。

决定绑定原引文签名及候选书目身份（规范题名、DOI、作者、年份）。无关科学内容升版不改变目标论文身份；公开查询仍严格要求当前审核版本。源引文按 `(paper_id, paper_revision, reference_index)` 加原文签名核验，不依赖重保存后变化的自增ID。源书目、引文或相关候选身份变化只使相关决定失效；不删除原始引文。有效正式LLM2依据可在后续解析被引论文时复用。

未知和技术失败分开；非法模型结构保持失败。迁移为 `20261106_0225`，父版本为 `20261102_0204`，只在隔离MySQL验证；有匹配依据、快照或失败回执时拒绝破坏性降级。
