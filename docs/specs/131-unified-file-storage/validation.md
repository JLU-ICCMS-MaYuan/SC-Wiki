## 本轮代码路径

- Python `backend/storage/`：文件键校验、FileRef、本地与 S3 读写、冲突保护、摘要校验和临时文件生成。
- Go `goserver/storage/`：相同的私有对象键语义；头像上传、读取、替换与删除接入该存储接口。
- Python 人工证据：私有对象键写入、读取、按需临时文件与原本地路径兼容。公开 DTO 不输出内部存储键。
- 历史文件预检基础扫描：已登记文件的大小/摘要、缺失、符号链接和未分类文件拒绝。
