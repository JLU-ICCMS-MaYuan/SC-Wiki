## 技术与职责

React 19 / TypeScript / MUI；既有 Go Gin 审核 API、MySQL 数据库和 Python 待审快照读取接口。
本次只改前端业务实现，不改后端审核规则与表结构。

新增 `frontend/src/lib/paperReview.ts`，统一三状态、详情和可选快照加载、分类解析与审核载荷。
快速批准点击确认时读取数据；编辑页加载复用相同解析，但批准仍提交当前编辑选择。
待审快照对论文级分类及按既有顺序对应的状态分类回填，保留现有科学数据编辑归一化职责。
新增 `PaperReviewStatusSelect.tsx` 共用选项与排序，提示分别说明各自数据来源。
