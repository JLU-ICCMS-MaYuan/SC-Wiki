# 研究与决策

## 根因

2026-09-02 提交 `e65d38a9` 在 #79 中删除快速审核的 approved 选项；快速审核请求只带状态和意见。
Go 的 `applyPaperClassifications` 要求论文级类型及至少一个材料家族，因此仅补菜单无法恢复批准。
中英文 `editReviewHint` 仍宣称编辑页只能拒绝和退回，与实际三状态控件矛盾。

## 决策

使用编辑页现有已保存数据来源：正式详情和 pending 时的提交快照。快照缺失 404 时回退正式详情，网络、服务和权限错误直接反馈。
共享分类解析和请求构造，编辑页仍保留科学数据表单自己的转换。拒绝和退回不需要分类，不新增请求依赖。
拒绝后端自动推断分类的替代方案：它会引入后端对临时快照的新依赖；本次只修复已存在前端契约。
不删除 Evidence 检查：用户明确暂缓第二个问题。MySQL 验证使用外层回滚事务，发布/清理请求由测试 HTTP 接收端接收，不向真实索引写入。
