# 分类持久化与生命周期

复用既有实体，不增加表、列或迁移。

| 实体 | 本次职责 | 约束 |
| --- | --- | --- |
| `MaterialFamily` / `StructureFamily` | 管理员保存时解析或创建全站目录 | 名称规范化、既有别名、唯一名称/编码；记录创建者 |
| `PaperMaterialFamily` | 当前论文版本的非空材料家族集合 | `(paper_id, paper_revision, material_family_id)` 唯一 |
| `MaterialStateStructureFamily` | 当前材料状态的结构家族集合 | 允许清空，最多一个主家族 |
| `Paper` / `MaterialState` | 当前超导体类别与维度 | 保存、重开、核对和批准读取同一份值 |

普通上传者不创建目录，新候选保留在提交快照。首次待审论文没有正式材料家族关联时回填候选；管理员保存成功后材料家族必定非空，退出回填。结构关联与候选合并时按稳定状态 key 匹配，历史无 key 时仅用双方唯一化学式；无法唯一对应时不按数组位置猜测，需在编辑页确认分类。

管理员创建目录、保存分类及科学图位于同一事务，失败全部回滚。同值保存不重建图、不增加版本；已批准论文分类发生改变时沿用既有升版重审规则。论文级空家族保存仍失败；结构家族清空后不会被旧快照恢复。

快速批准的首次分类保存是批准前的独立步骤；其成功结果保留待审，即使后续证据校验拒绝批准。正式批准事务继续严格检查分类、证据与权限。
