# 实施计划

**输入**：[规格](spec.md)、[研究](research.md)、[数据契约](data-model.md)、[任务](tasks.md)。

1. 汇总后新增专门全文二级分类：复用当前论文及附件解析文本和来源分组，短文一次阅读，长文逐组覆盖并最终综合。专门分类覆盖旧候选摘要的值；失败留空和状态提示。
2. 将服务端分类分析绑定来源摘要、规则与模型，保存在上传草稿及审核产物。草稿保存不能信任客户端写入的分析；人工改值仅保留历史分析，不作为当前依据。
3. 科学来源核对对该字段使用全文归纳类别，校验理由与当前值以及跨内容段落的定位引句；不以 Methods 独立授予 `supported`。侧栏只对该字段更换来源标签与理由兜底。
4. 在任务锁与内容版本保护下，对当前 H3S 草稿定向重跑。比较当前草稿和原 AI 值；仅更新未被用户改动的字段，精确使本字段旧核对失效，再运行字段核对。
5. 隔离测试四类/空值/超长来源/旧草稿冲突，并用真实模型及三入口浏览器验证；回写 Overview、README 影响及 Issue。

不修改 `papers` Schema；不重跑其他论文、不覆盖其他字段已完成的核对。
