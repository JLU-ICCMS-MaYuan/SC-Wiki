# Feature 规格：三组服务独立编排

**GitHub Issue**：[ #132](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/132)

**父 Epic**：[ #130](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/130)

**日期**：2026-10-12

**状态**：规划已确认；未实施、未部署

## 背景与目标

当前生产 Compose 把网站、数据与解析服务一起管理，地址和启动顺序依赖同一个项目。用户先购买一台云机器，之后将数据组和解析组依次迁出。本功能提供可组合但独立管理的三个服务组，以及数据组首次迁出的操作流程。

## 用户场景与验收

### US1：单机组合部署、按组管理（P1）

管理员首次在一台机器准备全部服务，此后只发布网站或重启解析组时，数据服务和存储不被操作。

**独立验收**：记录数据容器身份和数据摘要，发布网站、停止解析组后，两者保持不变。

1. 假如三组同机，当组合启动时，那么使用统一版本与配置通过连接检查。
2. 假如只选择应用组，当停止或升级时，那么不得操作其他组容器、网络或数据卷。

### US2：把数据组迁到第二台机器（P1）

管理员在同云私网新建数据机器，维护窗口内迁移数据并切换连接，网站和解析保留在第一台。

**独立验收**：真实两机环境进行备份恢复、校验、切换及开放写入前回退。

1. 假如目标为空且兼容，当恢复数据并切换配置时，那么无需更改业务源码或重建相同版本镜像即可恢复访问。
2. 假如旧卷归属、目标版本或数据校验不符，当迁移时，那么阻断，不初始化另一份空库冒充成功。

### US3：连接故障可诊断、启动不会改库（P2）

管理员能区分进程启动、服务依赖就绪和业务验收。配置错误时得到有限等待和脱敏失败说明。

**独立验收**：错误端点、认证失败、延迟启动、schema 不兼容以及数据断连场景。

## 需求

- **FR-001**：支持网站、数据、计算三个独立管理单元及单机组合入口，统一复用服务定义。
- **FR-002**：网站与计算生命周期操作不得创建、停止、重建或删除数据组及其持久卷。
- **FR-003**：支持单机、两机、三机配置；服务位置只通过配置变化，不改变业务源码和镜像内容。
- **FR-004**：所有跨组连接端点和认证均可配置；相同数据服务的不同客户端配置一致。
- **FR-005**：同机仅内部容器网络访问数据；跨机只开放指定私网接口和必要来源，管理接口不默认公开。
- **FR-006**：启动必须完成实际认证连接和存储/schema 检查，有限等待后明确失败；不回退默认空库或把进程存活当就绪。
- **FR-007**：schema 迁移必须是显式操作，与发布版本配套；正常启动、状态查询和重启不得自动改库。
- **FR-008**：旧部署存储须按实际身份显式接管；缺少卷、目录、版本或部署身份时拒绝启动而非自动替换。
- **FR-009**：数据组迁移须覆盖四种数据服务及对象存储，停写排空、一致性备份恢复、校验及切换前回退。
- **FR-010**：本地原生部署和热重载保持现有方式，生产命令不复用本地安装器控制远程实例。
- **FR-011**：应用制品、数据引擎与 schema 兼容要求必须可追溯，不使用可变标签作为发布身份。
- **FR-012**：命令范围、失败阶段与服务组状态可观察；报告不泄露凭据，也不替管理员改变云安全组或删除源数据。

## 成功标准

- **SC-001**：单机组合和三组独立启停通过，网站/计算操作前后数据容器身份与持久数据不变。
- **SC-002**：单机、两机、三机配置均可解析且拓扑正确；两机真实运行并完成业务冒烟。
- **SC-003**：错误认证、不可达、依赖延迟、schema 错误均在配置的启动总期限内返回明确失败，未自动改库。
- **SC-004**：两机迁移前后业务表、必要 Redis 状态、图、向量及对象清单一致，切换前回退通过。
- **SC-005**：数据端口未暴露公网，本地原生回归通过，运行制品与版本清单一致。

## 假设与依赖

依赖 [#131](../131-unified-file-storage/spec.md) 的存储契约；[ #133](../133-remote-pdf-workers/spec.md) 负责三机业务与计算迁移最终验收。参考 #112 的备份思路，协调 #14 的健康检查；不重复创建其未完成工作的状态副本。

网站组包含资讯 Worker/调度器；计算组包含上传/核对 Worker 与 GROBID；数据组包含 MySQL、Redis、Neo4j、Qdrant、S3 兼容对象存储。首版同云 VPC，允许停机；实际机器地址和凭据是部署输入，不属于未决架构选择。

## 范围外

Kubernetes、自动扩缩容、高可用数据库、跨云公网访问、零停机迁移、本地运行工具重构。本轮只写文档，不实施生产网络、数据迁移或 schema 变更。
