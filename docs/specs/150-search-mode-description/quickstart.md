# 验收说明：检索方案说明

## 前置条件

安装仓库既有前端依赖，使用本地 Vite 页面；浏览器验证可隔离 API，避免业务数据写入。检索结果数据正确性不在本次改动范围。

## 操作与预期

1. 进入 /search，不选择元素：默认组合方案说明可见。
2. 依次点击组合、精确、包含：文案与 spec.md 表格一致，按钮选中态与说明同步。
3. 选择 La、H，然后清除：已选元素为空，当前方案与说明保持。
4. 再次选择 La、H，分别用三个方案进入结果：请求中 elements 包含 H/La，mode 对应所选方案；返回元素搜索后说明仍正确。
5. 切换英文，重复三种方案检查；切回中文不改变选项。
6. 桌面检查说明位于标题与方案按钮之间；在 1440、1024、768、390、320 像素宽度检查说明和按钮完整换行，无重叠或截断。
7. API 返回错误时回到元素页，说明仍可阅读。

1. “筛选和服务端分页保留参数，结果行仍打开论文及结构”：存在多个名为“下一页”的按钮。
