---

**结论**：方向对——同一份回执、两个消费者（文本模型和视觉模型）是对的；但“视觉模型多一步检查”这句现在的实现方式会失效，因为**它检查的是同一段文字，不是同一张图**。要成立，检查那一步必须回到像素。

## 先纠正一个事实：看图工具返回的并不是“看懂的内容”

我这次用的看图工具，返回值形态是**一段自然语言**：「ScH₆ 绿色柱约 100 K，深蓝柱约 85 K」。没有坐标、没有刻度像素位置、没有置信度。那我是怎么给出 1.35 这个数的？**不是靠工具，是靠我另外写程序解析 BMP 求柱顶、再用正文已知的 λ 值反标定**。工具没给我这个能力。

这一点决定了后面所有设计：**自然语言回执不可校验、不可复现、不可定位**。你说的“发现不对就让工具重新解析”，在自然语言回执上根本无法表达“哪里不对”。

## 模型是怎么处理工具返回的（这决定了反馈能不能建立）

- 工具的返回值进了上下文就是**纯文本 token**，和论文正文没有本质区别，只是我默认给它更高信任。
- 模型**不保留**任何图像表征。第二轮再问，我脑子里（上下文里）关于这张图的全部信息，就是上一轮那几十个字。
- 所以：**错误一旦被压成文字，就再也找不回来了**——这是不可逆的信息损失，不是模型不够聪明。
- 更关键：模型的“检查”没有独立证据源。它检查的是文字的自洽性，不是与图像的一致性。**同一个人把同一段话再读一遍，检出率接近 0。**

这就是为什么“视觉模型多检查一步”单独加上去没用；它有意义的唯一前提是：**检查时允许它重新取一次图**（换裁剪、换 dpi、只问那一处）。

## 所以反馈机制要建在“可定位的中间产物”上

不要反馈“你算错了”，要反馈“第 2 个系列第 1 根柱的 `top_px` 与基线之间没有墨水（`BAR_EDGE_NOT_FOUND`），请只回这根柱的顶边像素和左右相邻两个刻度的位置，配图是局部重裁 x2”。

回执长这样（结构化、可 diff、可重放）：

```json
{"crop":{"sha256":"..","dpi":600,"bbox_page":[..]},
 "axes":[{"id":"y","quantity":"tc","unit":"K","scale":"linear",
          "ticks":[{"px":1453,"label":"100","conf":0.9}],"spine_px":881}],
 "elements":[{"id":"tc.ScH6.mu0.1","kind":"bar","bbox_px":[..],"top_px":1454,"conf":0.8}],
 "unresolved":[{"element_id":"tc.PrH9.mu0.1","reason_code":"BAR_EDGE_NOT_FOUND"}],
 "reader":{"model":"...","prompt_version":"..."}}
```

**数值永远是 `f(axes, elements)` 由程序算**，两个模型都不许直接写数字。这样“检查”才能变成程序判定：

| **reason_code** | **程序判据** | **处置** |
| :--- | :--- | :--- |
| `TICK_FIT_RESIDUAL` | 刻度拟合残差 > 阈值，或刻度数 < 2 | 局部重裁重读刻度 |
| `BAR_EDGE_NOT_FOUND` | 柱内部采样无墨 / 找不到单侧边 | 重裁该柱 + 放大 |
| `AXIS_LIMIT_GUESS` | bounds 与末刻度之间无 headroom 声明 | 要求补轴框与末刻度的相对位置 |
| `OUT_OF_AXIS` | 值落在标定区间外 | 拒绝外推，标未读 |
| `TEXT_CONFLICT` | 与正文/其他图同量冲突（如 150 vs 100） | 记为冲突，不择一 |
| `SERIES_AMBIGUOUS` | 图例色与柱色不能唯一匹配 | 重读图例区 |

重裁顺序固定：**局部重裁（x2 dpi）→ 只含该元素与相邻刻度 → 最多 2 轮 → `unresolved`（fail-closed，不猜）**。

## 你方案里要改的三点

1. **回执必须结构化**，不能是自然语言。否则“重新解析”退化成“重新问一遍”，不幂等、不可审计、失败原因无法定位。
2. **检查者不能是读图者本身**。让视觉模型自检，等于同源自证。有效组合是：程序规则（硬判据）+ 异源复核（换裁剪/换 dpi 的第二遍读，或换一个模型读同一区域）。你要的“视觉模型多一步”，应定义为**它有权重新取图并覆盖回执**，而不是“它再想一想”。
3. **回执是唯一事实来源**。必须明确规定：不在回执里的量一律不许写进字段——否则视觉模型会凭“看过图”的残余印象补出回执里没有的细节，这比文本模型更危险。
