- 同一manuscript_handed_off失权原因在页面标题下只显示一条黄色提示。
- 保留已加载内容和未保存输入。 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../../221-scientific-field-sidebar/spec.md)，本处不再独立维护。

服务端决定写权限；宿主页持有显示状态，子组件报告结构化错误；科学当前值仍由原工作稿持有。
