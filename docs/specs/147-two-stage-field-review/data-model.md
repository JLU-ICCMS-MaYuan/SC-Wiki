# 数据模型

| 实体 | 内容与约束 |
|---|---|
| 字段身份 | 稳定state/module/record/extension身份与现有键；不以数组位置、名称或值作为身份 |
| 字段版本 | 最终值、对应证据版本、必要科学范围；与模型名无关 |
| 字段草稿 | 原始输入、可解析值、说明、预期草稿版本；正式记录不接收未完成数字 |
| 核对结果 | 逐字段状态、原因、证据、方法、版本、时间；通过不能由说明标记代替 |
| 提交版本 | 一次冻结草稿；权限、版本、所有必需字段结论同时成立才提交 |

数据所有权：现有草稿存储保存编辑内容，科学核对表保存历史与结论，后台队列保存进行中任务。字段说明不是科学数据更改；旧结果保留，不能覆盖迟到的新决定。关联上下文可以读取，不意味着共用结果。

管理员暂存使用scientific_review_drafts：paper_id唯一、owner_id、base_revision、base_fingerprint、draft、updated_at；正式论文版本变化时拒绝覆盖。
