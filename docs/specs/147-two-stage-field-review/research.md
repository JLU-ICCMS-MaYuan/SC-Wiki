# 实现决策

- 现状缺陷属于原流程设计不符：编辑、确认、提交复用同一全量快照/历史路径，结果还会按父记录聚合。不能靠隐藏红框解决。
- 复用既有表和队列，独立字段版本以实际内容、证据及必要范围确定；模型切换不改变已通过结果。
- 精简读取使用定向查询与紧凑摘要，完整历史在字段历史页签加载；不把全量历史缓存当作局部接口。
- 程序检查与模型科学判断分别记录来源。人工说明只作为依据，不赋予通过。
- 历史兼容只接纳可证明覆盖的通过；其他记录首次提交补核，不在编辑重验。
- 保持真实来源；用户补充证据标为补充来源，不能替代论文出处。
- 产品边界由最终计划确定；实现细节按KISS选择，不新增跨字段包、服务或无关抽象。

- 管理员原保存接口直接重写正式图，无法容纳未完成输入；增加scientific_review_drafts作为管理员暂存，上传/返修继续复用原草稿。管理员审核通过后在单一事务写入正式数据和批准状态。迁移只新增表，不清空旧记录。
