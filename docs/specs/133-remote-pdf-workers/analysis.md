## 关键一致性检查

- Redis 仍管理队列和公开运行态；MySQL 执行头只证明当前执行权与持久提交，不新增所有读取请求的数据库兜底。
- 完成顺序为产物保存校验 → 业务结果与执行标记同事务 → Redis 投影；恢复 committed 不重跑模型。
- 所有中间写入在 T001 审计，候选结果必须隔离；仅在外围加锁不足以满足 FR-003/FR-004。
- 超时、租约、有限传输重试与显式重新解析互相区分；不声称消息 exactly-once。
- 网站证据区域渲染继续由 API 按需读取，不与“后台解析迁出”矛盾；资讯仍在网站组。
- #131 决定文件键与清理，#132 决定端点与发布，本 Feature 不另建存储协议或迁移入口。
