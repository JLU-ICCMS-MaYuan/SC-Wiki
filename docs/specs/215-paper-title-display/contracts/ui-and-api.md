# 界面与接口契约：审核列表标题自适应宽度并支持悬停全文

## 用户可见行为

- 标题占满该列可用宽度，年份、状态和操作区域保留必要空间。
- 标题保持单行，确实超出可用宽度才省略；截断时悬停显示可换行的完整题目。
- 管理员、超级管理员及嵌入审核列表使用同一展示规则；不改变论文标题数据或审核流程。

## 事实来源与约束

完整标题仍由论文数据提供；是否溢出属于标题组件的临时显示状态，不持久化。

## 实现边界

PaperTitle测量自身文字和容器宽度，通过ResizeObserver更新溢出状态，按真实溢出启用Tooltip；AdminPage明确保留元信息列宽。
此处记录原实现契约，没有新增接口或数据结构。与其他子项共用的接口参数、组件及返回值继续由原代码掌管；本项范围外行为见spec.md。
