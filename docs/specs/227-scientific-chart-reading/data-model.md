# 读图事实的数据所有权

## 现有契约保持

科学值仍为现有记录及参数，约数通过`value_raw`表示；标准键及摘要不变。论文误差条按原科学含义处理，像素读数精度不写入测量`uncertainty`。材料状态、方法和系列由现有关系及字段来源绑定，模型不生成数据库ID、权限或人工决定。

## 来源事实

DocumentIR新增的读图来源块仍属于原PDF的file_id、SHA256与真实PDF页；`source_kind=vision`，metadata声明`chart_reading`及版本。块文字明确标注“原图标定读数”，保存材料/条件/系列、报告数字或约数、单位和精度说明，不能冒充印刷原句。metadata保留图号/面板、裁剪框、像素/归一化位置、坐标轴/色标标定、原数值标签、逐点去向及读数算法版本。原图和原文字块保留。

来源块经既有IR、科学上下文、字段引用、保存及正式paper_chunks/document_blocks链传播；持久化审查须证明metadata与读数文字均未丢失。传输可无损去重，不能用过程摘要替代这些事实。源值或标定变化参与既有来源版本失效，普通读取和保存不调用模型。

## 数值

有标签时复制标签实际报告值；无标签时由程序依据AI识别并可重放的刻度、数据位置或色标计算。实际图像像素分辨率是精度下界；刻度定位残差、数据点/柱边界范围、色阶跨度都参与读数精度说明。对数轴先在对数域标定。缺轴、冲突刻度、颜色非唯一或无法归属时留下未读/不确定，不能宣称完整提取。

三图型读数只是来源事实，不自动授予科学支持或批准。多系列共享原图，但各点仍有稳定来源身份和实际条件；共同概述与分材料详细读数合并或分开由原有科学核对判断。
