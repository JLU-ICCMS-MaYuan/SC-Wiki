# 实施计划

## 已有路径与所有权

MaterialStatesEditor为四宿主材料状态入口，父级普通保存拥有当前草稿。规范结构仅在state.structure；物性和共同参数归property_modules及其metadata。字段核对和选定依据由现有EvidenceWorkflow及来源存储拥有，不改写审核缓存。空间群由现有标准表映射，不新增科学键。

## 实现

在规范结构与物性共存的材料卡提供入口。独立对话框只保存预览的原卡稳定键及单卡内容快照、原物性目标空间群。确认按最新statesRef查找原键并比较单卡快照，权限及对象变化则拒绝；不保存旧全表。一次emitStates更新原卡、转移结构并追加空物性新卡，复用newStableKey。保留原物性对象和所有其他卡的对象引用，changedScientificFields只失效真实变化。新卡复制材料、压力、结构优化等真实共享身份字段及相关原依据，不复制属于原物性相的结构家族标签；结构来源与哈希不变。

预览取消不调用onChange；重复确认关窗且以最新单卡快照拒绝。不会在拆分动作中发起模型或网络保存，父级现有自动保存/立即保存继续生效。最终以普通网页保存重开验收。

## 验证与安全

先写四宿主交互回归检出无入口，再实现。覆盖数据源完整性、依赖失效、取消、只读、陈旧预览、原状态删除、邻卡变化及一次性确认。执行字段契约、完整表单契约与12变异、TypeScript/构建及受影响测试；以同草稿实际网页验证来源和值。未改后端接口或数据定义，不迁移、不推送、不部署。
