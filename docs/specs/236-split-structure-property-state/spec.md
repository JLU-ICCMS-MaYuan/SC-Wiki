## 背景与目标

同一化学式和压力不证明同物相。现有一张卡同时存有规范晶胞及物性记录时，操作者须能修正混挂，保留完整科学数据、来源和稳定身份。操作只改当前草稿，沿普通保存及审核链流转。

## 用户场景与验收

### US1：预览并拆分（P1）

可编辑材料卡含规范晶胞和物性时，操作者打开拆分对话框，填写保留物性的原卡空间群，预览两张卡并确认。原卡保留原state_key、全部原物性模块、方法、共同参数、记录键、来源和非结构字段；晶胞整体移到新建结构卡，新卡无物性记录，不复制笼型等只支持原物性相的标签。拆分操作不代表科学审核通过。

独立验收：网页保存后重开得到两张预览所示卡，结构正文、哈希及来源相等，原物性记录键和所选来源不变，其他材料状态保持。

### US2：取消、只读与并发（P1）

取消无写入。预览后若原材料卡内容变化或删除，拒绝陈旧确认；其他卡编辑不被覆盖。只读/权限收回时不能确认。失败保留当前草稿，不靠新上传或后台改值恢复。

## 功能需求

- FR-001：入口仅对可编辑、稳定身份且同时具有规范结构和物性记录的卡提供；不能批量拆分其他卡。
- FR-002：先展示原物性卡和新结构卡的化学式、压力、物相、记录数量和结构去向，再显式确认。
- FR-003：原state_key及物性module_key/record_key和全部数据、所选依据保持；新结构卡获得新稳定身份，晶胞对象完整转移，不转成手工上传来源、不丢原文定位。
- FR-004：由操作者选择原物性卡的报告空间群，按现有标准表同步群号和晶系；程序不替操作者判断科学物相。新结构卡保留原报告物相与结构身份，不借用其他压力或材料数据。
- FR-005：当前值与来源变化及时显示，只有受影响字段和真实依赖失效；无关卡不重绘、重扫或重跑核对。
- FR-006：四宿主共用行为，沿用当前版本、保存、权限和返修规则；不引入新API、数据库结构或科学标准键。
- FR-007：取消或陈旧预览无写入；只读状态无法调用；同一次确认仅生成一张新结构卡。
