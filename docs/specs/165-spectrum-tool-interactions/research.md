# 调研与设计决策

## 当前事实

- SpectrumManualEditor默认tool='select'、linked=true；工具按钮重复点击只重复设置同一值。add按钮校验必须唯一选点。右侧linked复选框提供已有单点/联动能力。
- SourceCanvas在add状态下寻找tail或唯一selected作为anchor；只有目标和parent都存在才进入插点/补接，其余调用appendPoint。仅放宽按钮校验不能完成先选工具后选起点。
- engine.snapTarget阈值SNAP_RADIUS_PX=8，换算屏幕尺度，只查当前曲线；prepareMove使用既有连接和权重。
- Canvas工具变化已有tail/drawing/snappedEnd/snapId/pendingAdd清理；gesture/preview与pointer capture也必须在退出路径检查，防止中途切换后提交旧手势。
- theme.ts的primary.main当前为#4f46e5、contrastText为#ffffff；既有编辑器.active样式为浅色，不满足用户选中深色要求。主题值以实施时实际token为准。

## 决策与理由

1. 两个并列按钮直接选中不同拖动工具。linked由工具身份派生，删除重复开关，避免工具和开关状态冲突；拒绝保留一个按钮再二次切换模式。
2. 明确idle状态。idle左键可选点查看，不开始拖动/加点；滚轮和已有导航快捷手势不变。工具选择不进入Document.operations或撤销历史。
3. 增加点分为等待起点和已有起点两种交互阶段。无唯一有效点时只允许点击吸附已有点作为起点；已有唯一点沿用。选择起点不调用appendPoint或joinExistingPoint。
4. 复用8屏幕像素吸附。没有候选时保持等待，不全图吸附，不选其他分波。
5. 统一切换函数处理工具及标定取点身份；同一工具/同一标定槽再次点击退出，另一个槽切换目标。完成单次取点、结束加点、切换曲线等路径统一进入idle。
6. 退出保留已完成的本地修改、保留仍有效的点选择；清除临时尾点/描线会话/吸附/未完成手势。重新进入由当前选择建立新的加点会话，不延续旧绘制基线。
7. 持续工具单独使用主题样式：未选中采用主题浅底/主题文字与边框，选中采用主题主色实底/contrastText，悬停保持可辨认深浅；焦点和禁用态沿用项目规则。实现中通过主题读取并传给局部CSS变量或MUI样式，不修改全站主题、不覆盖所有.active类。
8. 保存、撤销、删除等立即动作不参与工具切换；方向模式是互斥参数，显示开关继续切换显示值。

## 备选与边界

不修改联动权重、不建立新的曲线算法、不同步独立Demo、不更改后端存储。按钮浅/深色属于本需求必要实现；完整视觉验收在业务实施后进行，本轮不将源码调研冒充渲染验证。
