# 编辑器交互状态

本Feature只涉及前端临时状态；业务Document、点ID、连线和历史保存格式保持原样。

| 状态 | 含义 | 生命周期 |
|---|---|---|
| 当前工具 | idle、select（选点）、dragLinked（批量拖动）、dragSingle（单点拖动）、pan（移动）、add（增加新点）、box（批量框选）、calibrate | 默认idle；同钮退出；异钮切换 |
| 标定取点目标 | 频率/幅值轴及0/1刻度槽 | 仅calibrate期间有效；同槽退出、异槽切换 |
| 选中点ID列表 | 当前曲线中的有效选点 | 切换工具保留有效选择，切换曲线清除 |
| 加点起点/尾点 | 当前连续加点的唯一锚点 | 进入时沿用唯一有效选择，或等待点击；退出清除会话 |
| 吸附候选 | 当前曲线8屏幕像素内最近点 | 鼠标移动更新；离开工具/曲线清除 |
| 临时手势/预览 | 拖动、框选、平移过程 | 完成按原规则提交；取消/退出清除未完成预览 |
| 已完成编辑历史 | 已发生的点/连线变化 | 切工具不修改；撤销/重做和保存沿用现有行为 |

一致性约束：同时最多一个持续工具。按钮高亮、aria-pressed、指针行为只反映该状态。联动布尔由拖动工具身份派生；单点拖动时不能残留联动权重。标定工具还比较取点目标身份。仅模式变化不进入操作日志或产生dirty。

2026-11-05：按钮列表与快捷键共享顺序；select 与 idle 均不能移动谱点，select 有选中高亮。工具列布局、显示开关位置和右侧读数精简属于视图状态，无新持久字段。
