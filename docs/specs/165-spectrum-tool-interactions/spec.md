## 背景与目标

2026-10-27 已将原统一拖动入口拆为两个工具，支持先选加点工具和持续工具反选退出。2026-11-05 用户在实际人工调整页面进一步要求：明确六工具分类、改为左侧竖排并加入快捷键、调整显示开关位置和精简右侧栏；沿用既有主题及编辑和保存机制。

### 需求结论与变更取舍

2026-11-05 后续要求取代旧的五按钮名称及横向排列：六个工具按选点、移动、批量拖动、单点拖动、增加新点、批量框选在画布左侧竖排，不透明度在其下；Alt+1～6 按同一顺序选择。新增选点只选择，不拖动点。显示其他分波与原图开关位于适应窗口左侧；右侧使用确认坐标，隐藏图 3 像素卡和状态说明。图 4/5 核实后用户选择保留方向切换、隐藏联动说明，单曲线隐藏编辑曲线、多曲线保留切换。


此前已采用直接把两个拖动模式做成独立按钮的纠正，本次仍保留两个独立工具入口。用户明确只有持续工具采用选中/退出机制，保存、撤销、删除等立即执行操作保持。按钮选中深色、未选中浅色是本次明确需求。

## 用户场景与验收

### US1：独立选择批量与单点拖动（P1）

用户看到“批量拖动”和“单点拖动”，直接点击对应按钮后在图上选点拖动。
优先级理由：操作入口直接体现是否牵连邻点。
独立验收：同一曲线中，单点按钮只移动目标点，联动按钮按现有权重移动邻点，其他分波不变。
场景：无工具激活时点击单点按钮并拖动，只有目标点改变；切到联动按钮拖动，附近相连点按现有规则跟随。

### US2：先选增加新点工具，再选择起点（P1）

用户没有选点时也可先激活增加点，靠近已有点看到吸附提示，点击确定起点，再继续新增。
优先级理由：取消必须先选点再选工具的绕行。
独立验收：首次点击吸附候选后仅改变选中状态，点数/坐标/连线不变；下一次点击新增位置才增加点。
场景：已唯一选中有效点时可直接作为起点；无选中或多选时等待用户点击当前曲线的已有点。未靠近任何点时不创建新起点。

### US3：统一持续工具退出与视觉状态（P1）

点击工具进入，再点同一工具退出；点击其他工具切换，深浅颜色始终对应当前操作。
优先级理由：可辨认且能直接取消，减少误加点和误拖动。
独立验收：持续工具逐个测试进入/再次点击退出/Esc退出，选中深色、未选中浅色，退出后画布不残留原工具操作。
场景：退出增加点后已完成编辑保留；再次进入时按当前有效选点决定是否等待起点，不延续旧吸附目标或临时手势。

### US4：竖排工具与精简侧栏（P1）

工具按 FR-001 顺序在左侧竖排，通过 Alt+1～6 直接选择，不透明度在六工具下方。显示开关集中到适应窗口左侧；坐标区保留可编辑数值与确认坐标。保留方向切换，仅同文档多曲线显示编辑曲线。
独立验收：桌面和390px窄屏工具可达、无横向溢出，实际开关、选点、方向限制、坐标确认及保存回读符合 SC-007～009。

## 边界与异常场景

- 只编辑当前分波，其他分波不作为吸附目标或拖动对象。
- 保持8屏幕像素吸附范围及缩放一致性，不把远处最近点强行吸过来。
- 空曲线或附近无候选时，等待有效起点，不凭空生成起点。
- 切换曲线退出工具并清除失效起点；退出工具保留已完成编辑，不自动保存、不撤销。
- 原图失败、正在保存、历史只读和版本冲突沿用既有限制。
- 中途退出或切换工具清理未完成手势/预览，已提交到本地编辑历史的点保留；一次完整拖动仍对应一次撤销记录。
- 保留原直连线段插点、未连接点补接、普通连续加点和已有结束方式；已有结束回调返回无激活工具状态。
- 普通浏览导航（滚轮缩放、既有右键/Alt平移等）保持，未激活拖动工具时不能移动谱点。

## 功能需求

- **FR-001**：六个工具名称、顺序为选点、移动、批量拖动、单点拖动、增加新点、批量框选；后五项复用原有平移、联动拖动、单点拖动、增加点和框选，保留现有联动参数。选点只选择当前曲线点，不拖动数据。
- **FR-002**：持续工具单击激活、再次点击当前按钮退出、点击其他按钮互斥切换；视觉状态与实际操作一致。
- **FR-003**：进入编辑器及退出工具后为无激活工具状态；可选点查看坐标，不可左键拖动谱点或增加点；单纯切换工具不修改曲线或生成撤销记录。
- **FR-004**：增加点无预选要求；没有唯一起点时预览附近已有点，点击只确定唯一初始点；已有唯一有效选中点可直接作为起点。
- **FR-005**：复用当前8屏幕像素吸附规则，只在当前曲线找候选；未命中不增加点，缩放和平移后吸附行为一致。
- **FR-006**：起点确定后的连续新增、原直连线段插点和未连接点补接继续有效；再次点击增加新点退出并保留已完成编辑。
- **FR-007**：选点、两种拖动、增加新点、移动、批量框选、标定取点统一切换/退出；退出和Esc清理吸附及临时手势。同一个标定取点槽再次点击退出，另一个槽直接切换取点目标。
- **FR-008**：保存、撤销、重做、删除、恢复、应用坐标等保持立即执行；拖动方向设置、显示开关和曲线切换保持各自语义。
- **FR-009**：持续工具未选中为浅色，选中为深色，使用SC-Wiki主题颜色及清晰可读的文字；退出恢复浅色，切换时新工具变深、原工具变浅。禁用态和焦点可辨认，按钮aria-pressed与实际模式一致。

- **FR-010**：六个工具在画布左侧竖排，不透明度竖条在六个按钮下方；窄屏保持相同顺序，必要时工具列独立滚动，不覆盖画布。
- **FR-011**：Alt+1～6 按 FR-001 顺序选择工具，快捷键与按钮高亮及真实模式同步，不改文档或撤销历史；重复快捷键保持选中，按钮仍按 FR-002 再次点击退出。支持 macOS Option 数字键；保存中、未保存离开弹窗内和中文组合输入中不触发。
- **FR-012**：显示其他分波和隐藏原图／显示原图紧邻适应窗口左侧；维持参考分波和原图显示语义，隐藏原图时禁用不透明度。
- **FR-013**：坐标应用按钮名为确认坐标；不展示图 3 的原图像素 X/Y 卡和点状态／换算说明，频率及幅值编辑、坐标确认与保存行为保持。

- **FR-014**：保留只改幅值／自由移动方向切换，标题为拖动方向，隐藏联动范围及其说明；编辑曲线区仅在当前文档有多条曲线时显示，顶部独立分波切换保持。

## 关键实体

当前工具、当前选中点、增加点起点、吸附候选、临时手势、未保存编辑历史。仅前端交互状态，不新增业务数据库字段。详细生命周期见[data-model.md](data-model.md)。

## 成功标准

- **SC-001**：批量拖动、单点拖动分别可用；单点模式其余点坐标不变，联动模式遵守当前权重和连通边界，其他分波不变。
- **SC-002**：无预选可激活增加点；选起点时点数、坐标和连线不变，随后新增动作只增加预期点。
- **SC-003**：所有持续工具通过进入/再次点击退出/切换/Esc测试，无残留动作，已完成编辑保留。
- **SC-004**：插点、补接、撤销/重做、保存刷新、权限和版本限制通过回归；不修改Demo和用户联动参数。
- **SC-005**：α²F/DOS、频率横/纵轴、不同缩放和窄屏下按钮状态与画布行为一致。
- **SC-006**：默认、选中、悬停、焦点与禁用态清楚；未选中浅色、选中主题深色，计算样式和aria-pressed均与工具状态一致。

- **SC-007**：桌面和390px窄屏中六工具自上而下顺序正确，不透明度位于其下，画布与页面无横向溢出；各 Alt 数字键选择正确工具且不产生编辑记录。
- **SC-008**：显示开关位于适应窗口左侧且交互有效；选点拖动不改坐标；确认坐标实际修改所选点并可撤销保存；图 3 内容不再出现。

- **SC-009**：方向切换实际约束拖动轴，当前标定频率方向保持正确；单曲线不显示编辑曲线，多曲线仍能切换且不误改其他曲线。
