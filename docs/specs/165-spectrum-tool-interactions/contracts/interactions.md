# 工具与画布交互契约

## 持续工具

| 按钮 | 激活后 | 再次点击 |
|---|---|---|
| 选点（Alt+1） | 点击选择点，拖动不改变数据 | idle |
| 移动（Alt+2） | 左键移动视口 | idle |
| 批量拖动（Alt+3） | 选择并拖动点，邻点按既有权重跟随 | idle |
| 单点拖动（Alt+4） | 选择并拖动点，仅目标点改变 | idle |
| 增加新点（Alt+5） | 等待起点或从唯一有效点开始后续加点 | idle，保留已完成编辑 |
| 批量框选（Alt+6） | 框选当前曲线点 | idle |
| 标定取点 | 点选指定轴/刻度槽 | 同槽退出，异槽切换 |

未选中浅色、选中深色；新工具激活时旧工具恢复浅色。状态通过aria-pressed暴露；键盘Enter/Space与点击一致。保存等禁用条件继续生效。

## 增加点

1. 无唯一有效选择：移动到当前曲线候选点附近显示吸附；点击只选该已有点作为起点，数据不变。
2. 不在吸附范围：保持等待，不生成点，不选择远处或其他分波。
3. 有唯一有效起点：后续点击沿用appendPoint、原直连插点、未连接点补接逻辑。
4. 退出/换工具：保留已完成点与连线，清理临时会话和预览，不自动保存。
5. 原直连插入完成、双击结束等已有终止事件改回idle；不新增环或重复点。

## 其他按钮与边界

保存、撤销、重做、删除、恢复、确认坐标/应用标定等立即动作保持；拖动方向/显示开关不作为持续编辑工具。切曲线清理失效选择与锚点。原图失败、保存中、权限/版本限制继续沿用。

不新增HTTP接口、数据库字段或权限。读取/保存仍使用已有manual接口；工具切换和起点选中不得发送业务写请求。
