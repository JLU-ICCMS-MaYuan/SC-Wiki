# 方法字段与兼容契约

新记录按 data-model.md 写入命名明确的计算字段及method_scope；具体值、阶段、适用关系和逐字证据共同决定可用性。保存/读取沿原草稿与论文接口，不增加模型自动调用。科学字段审核保持原权限和版本门。

结构优化接口支持四类新目标及历史sscha值；详情是可空状态JSON，原子平均位置、体积和晶胞形状分别表达。Python/Go详情和导出保留同一对象。旧值读取不改库、不触发重新提取。

历史 payload.approximation 不能自动解释为电子理论。明确错类继续返回可操作的核对问题，正确电子数值和其他独立字段不被清除或一起失效。新结果生成不传播状态级近似，候选不覆盖人工已填值。
