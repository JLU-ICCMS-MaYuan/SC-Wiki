# 实施方案

依据[规格](spec.md)与[调查](research.md)，沿用既有字段、来源和持久化职责。

1. 固定共享 mayuan 基线，建立旧结构优化响应重放及错误类别/作用域反例。
2. 删除状态到所有物性的近似广播；扩展结构目标与几何详情的提取、验证、模型/数据库、Python保存导出及Go读取。
3. 明确电子理论、声子技术、振动层与作用域的字段语义；同步提取/整理/条件关联/核对，明确历史混装字段边界。
4. 保持稳定身份、单字段保存及真实依赖。 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../221-scientific-field-sidebar/spec.md)，本处不再独立维护。
5. 运行失败重放、隔离持久化、真实PDF字段重新提取、四类完整宿主、正式表单双门及相邻科学回归；独立基线判别已有失败。
6. 使用Overview维护流程回写事实、字段映射、HTML规则库和README；精确提交，不推送部署，不修业务历史数据。
