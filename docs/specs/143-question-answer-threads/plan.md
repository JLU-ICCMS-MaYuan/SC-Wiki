Go 负责公开读取和首答治理；Python 负责问题创建、逐题队列、追加及追加编辑。复用 #142 的社区条目与独立 RQ。

新增模型卡映射、回答请求、追加段及追加修订四表。首答仍为 community_entries，不复制；卡按问题与 config_hash 唯一。请求在问题行锁下分配序号，Redis 只投递各题队首；任务开始才读取前文，发布时重查快照与来源。监督周期恢复中断任务及投递遗漏。凭据在入队时保存，TTL24小时；失败不影响下个请求。

请求上下文只永久保存标识、版本、正文哈希及引用依赖，完整正文在执行时取出传给模型。来源依赖包含全部读过的前文引用；公开读取及上下文构造排除失效内容。生成期间手工修改/下架使快照校验失败。

手动提问只写问题；AI 提问批次只保存一个提问模型，不派生回答。旧重生成 API 返回 workflow_changed，防止旧客户端覆盖。
