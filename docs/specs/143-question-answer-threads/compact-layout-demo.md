## 原始需求记录

> 我希望在选择生成答案的按钮旁边就是选择模型的按钮，而且能选择多个模型，而不是先点击生成答案后，再弹出选择 模型的按钮。
>
> 使用 issue 和 spec 完成，你可以先做一个 demo，我来看看。

## Demo 与审阅重点

[打开独立 Demo](assets/compact-answer-demo/index.html)。它不依赖 React 服务，不访问业务 API，不使用真实模型或写入任何讨论记录；刷新恢复示例状态。

1. 默认阅读列最大宽度 680px，顶部可切换 800px 比较；这一选择器仅用于审阅，尚未决定放入正式产品。
2. 每模型默认是一条紧凑卡片：模型身份、两行摘要、回答次数和展开按钮。展开后在同一卡片中阅读首答与追加；不删改正文。
3. 模型选择直接紧挨生成按钮，无弹窗。Demo 默认同时选中 DeepSeek/OpenAI，可逐个取消或选择，无选择时禁止提交。
4. 模型按勾选顺序排队；按钮显示所选数量，下方明确顺序。一次点击可以加入多项，等待期间可再次提交；同模型仍只追加在原卡片内。
5. 窄屏上控制区自然换行，选择和生成仍直接可见；不出现水平滚动。

680/800宽度、默认两行摘要、默认选中两个模型和按勾选顺序属于本次可逆的原型提案，不能在用户认可前写成正式已确认规则。示例文字仅供展示，未作为项目科学事实或正式答案。
