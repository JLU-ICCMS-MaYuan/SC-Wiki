# 设计依据

独立模型卡映射保存稳定配置身份，避免 LLM1 改型号后混入旧卡。首答使用现有条目，追加独立存储以避免复制和覆盖。每题行锁协调入队和发布；全局容量保持两槽，阻塞不占用后续同题任务执行。

已有回答映射由旧任务 config_hash 回填，不修改正文。无匹配历史任务的 AI 条目保留但不冒认当前模型。引用前文的 A 标记与文献 S 标记区分；完整输入仅受显式上游上下文限制，不静默截断。

本功能有同题依赖，不能沿用 #142 并行全模型队列。只给各题队首投递 RQ，成功或失败后再投递下一项；监督回收负责恢复中断的投递，避免进程退出后卡住。

实际模型复验要求后续答案必须包含真实前文标识；完全重复或未回应时带反馈再试一次，仍失败不发布。新生成时间显式写UTC，历史时间不回填。本机旧任务收敛后已启用143，数据不变。
