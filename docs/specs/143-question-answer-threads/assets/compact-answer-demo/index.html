零电阻首先证明存在一条连通的低阻路径。少量超导细丝或表面层也可能让测量电阻降到分辨率以下；判断体超导，还应结合磁响应和独立的热力学证据。

初始回答 #1

四探针测量中的“零电阻”，是指电压已低于测量分辨率。只要存在贯通的超导路径，就可能出现这一信号，因此它本身不能确定样品中有多大体积进入了超导态。

  • 输运测量判断是否存在贯通路径。
  • 磁化测量提供屏蔽与磁通排斥的信息，需要考虑形状和磁通钉扎。
  • 比热等热力学证据可帮助判断是否存在体相变。

补充回答 #3

认同 OpenAI 对屏蔽与磁通排斥的区分。补充一点：比较不同测量时，还应核对样品条件、测量灵敏度与转变宽度，不能只比较曲线上的单个温度值。

初始回答 #2

我认同前面强调独立热力学证据的方向。需要补充：薄的超导外壳也可能产生较强屏蔽信号，而场冷磁化又可能受磁通钉扎影响。一个看似很大的屏蔽率，并不能直接换算成可靠的超导体积分数。

没有分辨出比热异常也不能直接否定体超导，还要考虑异常幅度、测量分辨率及相变展宽。结论应由多种实验的相互印证建立。
