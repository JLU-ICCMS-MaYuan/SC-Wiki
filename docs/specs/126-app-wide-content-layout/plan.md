# 实施计划：全站页面主体窄边距布局

**GitHub Issue**：[#126](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/126)

**日期**：2026-10-09

**Spec**：[spec.md](spec.md)

## 摘要

在 `AppShell` 一次性设置全站主体的 8px 水平边距，移除上传页的负边距特例及各页面根容器最大宽度。局部固定列数按断点重排，保留内容卡片、阅读文字和弹层内部宽度规则。

## 技术上下文

- **语言与版本**：React 19、TypeScript 5.6。
- **主要依赖**：MUI 7、Vite 5。
- **数据存储与接口**：不涉及。
- **测试体系**：Vitest、Testing Library、生产构建和浏览器视口检查。
- **目标平台**：所有由 `AppShell` 承载的桌面和窄屏浏览器页面。
- **性能目标**：不新增网络请求或页面数据处理。
- **约束**：保留上下留白、侧栏宽度和现有交互；不提交其他任务的工作区改动。
- **规模范围**：公共壳层、少量整页限宽和多列布局入口。

## 源代码结构与职责

- `frontend/src/components/AppShell.tsx`：全站唯一页面主体外边距来源，水平 8px、竖向沿用原值。
- `frontend/src/pages/UploadPage.tsx`：移除展开态负边距，复用现有常驻栏。
- 各页面根容器：清除账户、公开主页、社区讨论、系统页、管理工作台及管理员论文编辑页的整体限宽；知识图谱页清除重复水平内边距。
- 对话页：当前重写采用全屏根容器和 `m: { xs: -2, md: -4 }`，且与另一任务的大量未提交改动同文件。由 `AppShell` 仅在 `/rag` 路由覆盖直属页面根容器的横向负边距，保留竖向全高和内部 820px 阅读宽度；不修改或暂存另一任务的 RAG 文件。
- Tc 估算和管理员论文编辑页：仅调整必要的固定网格列数。
