# UI 契约：全站页面主体边距

- **生产者**：`AppShell` 主内容区域。
- **消费者**：全部应用路由页面，包括访客、用户、管理员和超级管理员界面。
- **外侧水平间隙**：页面主体距导航右缘与视口右缘各 8px，允许 1px 浏览器取整误差；不因上传解析展开状态改变。
- **竖向间隙**：维持当前 `xs: 16px`、`md: 32px` 的普通主内容内边距。
- **整页宽度**：主要页面根容器不施加居中最大宽度；局部文字、空态、对话框、抽屉和菜单可保留既有约束。
- **窄屏**：页面级宽度不得超过视口，确需横向滚动的表格、图表仅由其内容容器承载。
- **常驻栏**：保留上传解析已有页面级顶部常驻栏的贴顶、不透明背景与收起行为；不新增其他栏。
