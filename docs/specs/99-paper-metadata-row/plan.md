# 实施计划

**Issue**：[ #99](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/99) · **规格**：[spec.md](spec.md)

## 技术上下文与职责

React 19、TypeScript 5.6、MUI 7 表单；Go Gin/GORM 提供管理员更新和详情；Python FastAPI/SQLAlchemy 负责解析和提交；MySQL 保存正式论文，Redis 保存上传草稿。

新增 `PaperMetadataRow.tsx`，只负责六个具名插槽的顺序、比例和横向滚动。两个页面保留各自受控字段、校验及保存回调，避免复制布局或引入额外表单状态。

`papers.issue_number` 是正式数据来源。Alembic 新增可空 `VARCHAR(100)` 列，Python 与 Go 同步模型；Go 更新白名单与详情 map、Python 归一化及创建论文显式包含该字段。解析提示与分段合并同时补齐书目字段。既有导入导出保留期号。
