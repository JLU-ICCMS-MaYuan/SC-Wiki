# 设计决策

## 期号独立保存

决策：新增可空文本 `issue_number`。理由：用户明确区分年份、期号、卷号；期号可能为增刊或合刊文本。拒绝复用卷号或使用整数。证据：现有 `Paper` 只有 journal、year、volume、pages，Go 管理更新使用白名单，Python 草稿归一化也显式选择字段。

## 布局共享，表单状态各自管理

决策：使用具名 ReactNode 插槽共享 CSS Grid；比例 4:1:1:1:1:4，内部最小宽度 1080px，外层横向滚动。理由：短字段需要显示中文标签，两个页面的字段大小与错误提示不同。拒绝复制两份 CSS，也不抽象保存逻辑。

## 保留页码兼容

决策：只把编辑标签改为“起始页码”，仍写 `pages` 文本。理由：旧值可能为 `100-108` 或文章编号，用户未要求转换历史数据。

## 验证边界

决策：用现有前端回归验证字段事件和 DOI 错误定位，新增期号往返测试；用当前 MySQL 外层回滚事务执行真实提交函数及 Go 管理更新/详情 handler。理由：单纯 Mock 无法证明跨语言字段不会丢失。浏览器验收使用运行中的开发服务，测试数据仅在可回滚范围写入。
