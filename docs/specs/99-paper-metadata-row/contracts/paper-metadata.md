# 书目信息契约

## 用户界面

上传和管理员编辑共有一行：期刊名、年份、期号、卷号、起始页码、DOI。六列可分配宽度为 4:1:1:1:1:4，间隙单独计算。小于内部最小宽度时书目行横向滚动，字段不换行。DOI 保留 `paper.doi` 错误锚点。

## 草稿与正式论文

既有草稿保存接口的 `paper.issue_number` 和管理员论文更新的顶层 `issue_number` 均为可空文本，最大长度 100。上传表单限制输入长度；沿用现有保存错误反馈和权限校验。未提供字段时不改变管理员数据，显式空文本或 null 允许清空。详情响应新增 `issue_number`，旧论文为 null，不更改其他字段类型。

解析不得以年份或卷号推断期号。草稿归一化、Redis 往返和提交保存均保留期号。已有导入导出接口中的论文对象可选包含该字段。API 无版本升级，无新权限或外部请求。
