# 导航与结果页契约

关联：[Spec](../spec.md) FR-001、FR-002、FR-009、FR-012～019。

## 地址

拟采用 `/search?elements=H,La,Sc&mode=elements_exact_search&view=papers&paper_page=1&state_page=1&structure_page=1`。化学式使用 `formula`；筛选使用既有字段的明确键，不存浏览器组件对象。

- view只接受papers／states，缺省和非法值为papers；默认页码1。元素顺序规范化且去重，不改既有匹配语义。
- 独立的paper_page／state_page保留各视图位置；切换在同一标签页更新地址，保持查询。查询变化重置相关页码，实际总数变化时纠正越界。
- 同页用户操作应形成合理浏览器历史；地址变化必须同步宿主状态，不能只在useState初始化时读取一次。迟到请求忽略或取消。
- 搜索按钮和显式详情链接采用原生新标签语义及noopener noreferrer；不要把视图切换写成window.open。

## 返回

详情入口携带编码后的合法站内 `return` 地址；新标签首次载入和刷新仍可用，不依赖React Router临时state或window.opener。

只接受同源已知业务路径，拒绝外部scheme、`//host`、反斜线绕过、控制字符和嵌套解码绕过。保留允许的查询与片段；认证return不混用为科学详情return。

搜索来源文案为“返回检索结果”，保留view和页码。其他来源按合法来路；直接访问无来源使用稳定站内兜底，不依赖history.length猜来源。不得为了返回操纵或关闭任意其他标签页。

## 点击矩阵

完整矩阵在Spec的US4；侧栏“通知”新开，与通知列表的“打开”维持当前页严格区分。管理员编辑／返修仍沿原未保存保护，不扩大编辑权限。结构详情中的下载按钮执行下载，打开结构页面的入口才新开。

## 退役评论

移除论文、搜索详情、图表弹窗、问题／回答下的评论与回复区域及体系讨论入口；保留AI问题和答案导航及论文引用。识别旧客户端kind=comment、id读取／编辑／回复操作并返回明确不可用结果，不以空列表伪装未退役。

保存既有历史数据；不做数据库删除。历史评论通知可提示目标不可用，不返回评论正文。管理员论文审核意见、字段证据理由不属于社区评论，不退役。
