# Feature 规格：检索双视图与详情导航

**Issue**：[＃178](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/178)

**创建日期**：2026-10-29

**状态**：已获“开始实现”授权并在本地实现；实际验证及既有基线失败见[验收记录](validation.md)，远程链接待授权推送后核验。

## 背景与目标

当前元素选择和结果共用 `/search` 的组件临时状态，离开再返回不能恢复检索。结构区插入旧两列网格后，Tc 明细表落到下一行左列。旧表按物性记录展示，不能直接表达“找到几篇论文／几个材料状态”。

用户要求以论文和材料状态两个单位展示同一查询，默认论文；通过新标签页阅读详情并恢复检索，同时保留未详细研究但有完整模型的伴随材料的独立发现能力。PDF 解析表单的数据要求不自动构成搜索界面的布局要求。

### 需求结论与变更取舍

- 最新补充明确：右上方提供可选展示方式，同一结果页切换，默认按原始论文；切换不另开标签页。
- 最初用户询问为何有两个结构入口，后明确主动保留两者。采用后者，不删除结构入口。
- 最初只调查 Tc 记录能否点击，后明确退役旧搜索 Tc 表格；移除表格及其局部记录详情，不删物性数据或论文详情。
- 化学式、压强、报告空间群号、优化条件共同辨别状态；沿用已保存稳定身份，不以这些显示字段新建全局唯一约束。
- 同一论文的多个状态均可链接到同一来源论文。无状态的独立模型单列，不能虚构状态。
- 删除 #56 强制返回上传页约束；其他返回／取消仍维持原设计。侧栏账户／通知／社区管理的具体新标签要求优先于“其他业务导航维持原设计”。
- #142 的“关闭发布、保留历史评论浏览”不满足当前要求；本 Feature 移除社区评论／回复功能，历史数据不做物理清理。审核意见、证据人工理由不是社区评论，不受本次删除影响。

## 用户场景与验收

### 用户故事 1：同页选择论文或状态视图（US1，P1）

研究者从选好的元素进入新结果标签页，默认看到匹配论文，可在右上方切换为状态列表。

**优先级理由**：这是本次明确采纳的主路径。

**独立验收**：固定 H-La-Sc 样例为 1 篇论文、8 个状态；切换不打开新页，移除旧 12 条 Tc 记录表。

**验收场景**：
1. 假如输入元素或化学式，点击进入／搜索，则原页保留输入，新标签页默认按论文。
2. 假如同一论文有8状态、12条Tc，切换为状态，则只显示8状态，切回仍是1论文。
3. 假如一个状态有多条测量／预测物性，则只显示一次；压强相同但优化条件不同的两个状态分开。
4. 假如查询有多页，则服务端先匹配／去重／计数，再按展示单位分页，跨页不漏项或重复。

### 用户故事 2：发现状态与伴随独立结构（US2，P1）

研究者在结果中能看到无 Tc 状态和无状态的完整模型，分别找到来源论文和结构。

**优先级理由**：避免旧 Tc 主体丢失可用科学资料。

**独立验收**：无Tc状态仍能命中；无状态模型单列、其来源进入论文列表，状态数不凭空增加。

**验收场景**：
1. 假如论文只给出伴随材料完整模型，没有该材料Tc／状态，按自身元素检索仍可展示模型和论文。
2. 假如已有状态关联模型，则结构入口属于该状态，不再在独立区重复。
3. 假如仅有晶格或坐标不完整，则不显示完整结构入口，不复制其他压力／优化方式模型补缺。
4. 假如论文有匹配状态与匹配模型，则论文仍只出现一次；同一状态的多个来源不增加状态数。

### 用户故事 3：新标签阅读并返回原检索（US3，P1）

研究者打开论文或结构后，可继续原结果，或恢复原来的筛选、展示方式和页码。

**优先级理由**：直接修复截图中的丢失来路与错误上传返回。

**独立验收**：覆盖新标签、地址直达、刷新、浏览器前后退、详情返回和非法返回地址。

**验收场景**：
1. 假如按状态第2页打开论文，则原结果页保留；详情返回可恢复同一条件、状态视图和第2页。
2. 假如从搜索进入论文，则不显示固定“返回上传列表”；从其他来源按合法来路返回。
3. 假如传入外站、协议相对或非法返回地址，则拒绝该地址并回退合法站内默认入口。
4. 假如快速改变筛选／视图或浏览器后退，则旧响应不得覆盖新条件的结果。

### 用户故事 4：统一既定导航并退役评论（US4，P1）

按下列矩阵调整入口，保留 AI 问答浏览，移除社区评论及体系讨论入口。

**优先级理由**：用户已逐项决定，不能用“所有按钮统一新开”覆盖例外。

**独立验收**：逐项检查矩阵，旧客户端不能继续读取／发布／编辑评论与回复；AI 问答、引用和非评论通知正常。

### 边界与异常场景

- 空结果清楚显示按当前单位计数为0；加载失败显示可重试错误，不能以空结果掩盖错误。
- 只包含独立模型时：论文视图可有论文，状态视图主列表为0，但独立结构区域仍可见。
- 访客及普通用户检索限当前已批准 revision；管理员／超级管理员可按审核状态检索当前 revision，见 FR-022～023。旧 revision／排除模型不泄漏。
- 元素精确／组合／包含与化学式模式沿既有含义，不顺便改成新的化学式计量匹配规则。
- 材料条件在同一状态或结构上成立；不能从一状态取化学式、另一状态取压强拼成命中。
- 论文年份等论文级条件作用于来源论文；用户实际使用 Tc／图表过滤时按已有适用范围处理，有无Tc和独立结构的范围必须明确提示，不借本次重构偷偷改变筛选科学语义。
- 页码越界按真实总数纠正并同步地址；非法展示参数回到按论文。两种视图分别保存页码，条件变化重置相关页码。
- 390px窄屏、长标题、中文、键盘操作都可使用；不存在原左侧窄列结果表。
- 历史评论通知的失效目标显示清楚不可用反馈，不泄漏退役评论正文；一般通知“打开”与自动跳转保持原设计。
- 无新增科学表单入口或保存逻辑；涉及共享编辑宿主时必须执行 #174 完整合同与回归。

## 需求

### 功能需求

- **FR-001**：元素进入及化学式搜索必须新开结果标签页并保留原选择。
- **FR-002**：结果页右上方必须可同页切换“按论文／按材料状态”，默认按原始论文；切换保留检索条件。
- **FR-003**：论文视图每篇匹配来源论文一项，同时匹配状态和模型不得重复论文。
- **FR-004**：状态视图每个匹配稳定状态一项，物性条数不改变状态数。
- **FR-005**：沿用论文revision内状态身份，显示化学式／材料名、压强、报告空间群号／符号和优化条件；不跨论文合并。
- **FR-006**：删除旧搜索Tc明细表及其局部记录详情切换，保留论文物性和社区图表。
- **FR-007**：没有Tc的状态也可被元素／化学式及适用条件匹配，不要求完整模型才展示状态。
- **FR-008**：完整独立结构按自身组成单列；来源论文参与论文视图，模型本身不虚构状态；已关联模型不在独立区重复。
- **FR-009**：保留来源论文与结构下载两个入口，均新标签；无完整模型不显示可用模型入口，不跨条件借用结构。
- **FR-010**：按真实论文／状态单位匹配、去重、计数及分页，不能对一页Tc明细去重冒充完整结果。
- **FR-011**：保留既有元素匹配模式、论文审核边界及真实字段归属；同一候选须满足相应材料条件。
- **FR-012**：查询、筛选、展示模式及分页可由地址恢复；刷新／前后退读取最新数据，原页可继续使用。
- **FR-013**：详情按合法来源返回，取消必须上传页的要求；搜索来源不展示固定上传返回，非法来路有站内兜底。
- **FR-014**：US4矩阵指定的新标签入口必须逐项实现，保持键盘和浏览器原生链接能力。
- **FR-015**：US4矩阵中的现有导航、通知打开、下载、弹窗／侧栏／图谱及自动流程例外必须保留。
- **FR-016**：移除社区评论／回复及体系讨论入口，退役评论读取与写入操作；保留AI问题、答案、引用及治理边界，不物理删除历史数据。
- **FR-017**：不改变公开论文权限和结构revision边界；新标签页沿用既有认证同步。
- **FR-018**：桌面主结果位于筛选栏右侧，窄屏可操作；空、加载、失败、重试反馈真实。
- **FR-019**：地址更新、快速切换及请求取消不得出现旧响应覆盖当前结果。
- **FR-020**：本功能不重解析PDF、不修改科学数据、不隐式保存或调用模型；不扩大部署／推送权限。

### 关键实体

论文是来源归并单位；材料状态是某论文revision下的稳定科学对象；物性记录属于状态、可多条；完整结构可关联状态或作为独立资料，不自动等于一个材料状态。检索上下文属于浏览器可恢复导航，不是业务库科学事实。

## 成功标准

- **SC-001**：隔离固定样例默认显示1篇论文，同页切换8状态，再切回1论文；全程不因切换增加标签页，旧12条Tc表不可见。
- **SC-002**：无Tc状态及无状态完整模型均能命中；模型来源论文计入，模型不增加状态数，已关联结构不重复。
- **SC-003**：多论文、多页、多物性用例与未分页参考集合一致，无跨状态拼接命中或去重丢项。
- **SC-004**：全部新标签入口与全部保留例外通过逐项行为检查，原页输入和选择保持。
- **SC-005**：新开、直达、刷新、前后退、详情返回均恢复查询／视图／页码；非法return不能跳外站，迟到响应不污染当前结果。
- **SC-006**：两种300GPa状态可区分，仅确有模型者可查看结构；独立伴随结构可单独访问和下载，来源论文正确。
- **SC-007**：评论／回复界面和体系入口均不可用，旧客户端评论读写退役；AI问题／答案／引用和非评论通知通过回归。
- **SC-008**：1400px及390px真实路由浏览器无原窄列挤压和新增整页横向溢出，键盘可切换视图、打开详情。
- **SC-009**：相关服务查询／权限集成、前端宿主行为、认证及适用表单合同检查通过；静态字符串不能代替真实行为证据。
