# 既有接口与状态约束

不新增API。本文件记录本次修复必须保持的边界。

| 入口 | 输入及权限 | 应有输出或错误 |
| --- | --- | --- |
| `POST /api/upload-tasks`及文件PUT | 用户明确main/SI角色，沿已有身份和上传规则 | 正式HTTP/RQ解析，完成状态不伪报成功 |
| `POST /api/rag/evidence/summary` | 当前有权访问的upload/paper等目标 | 摘要不含完整历史/结构输入；与当前派生结果一致；当前版本优先 |
| 现有提交与批准服务 | 既有权限、审核、来源、版本及事务规则 | 复用有效结果；缺失/失效依据仍报错；不重新调用科学核对模型 |
| `POST /api/upload-tasks/batch-delete` | 既有任务所有者及清理检查 | 清理对应工作稿和使用关系，正式论文和共享不可变来源保留 |
| 谱任务入队/执行 | 当前模型配置、工作稿及预期版本 | 同一持久版本可继续；真实修改仍产生版本冲突；质量限制独立记录 |

技术错误的完成状态使用`automatic_review_incomplete`，保留具体原因和已有内容；不会给全部未完成字段授予人工通过。原错误权限、迟到结果、人工内容保护和只读规则保持。

审核模型收到完整结构的临时输入不作为用户可编辑字段，也不进入标准字段清单。程序不通过关键词相等重新裁决科学含义；现有确定性结构、类型和来源身份检查保留。
