# 数据所有权与生命周期

本次不新增表、不迁移数据库、不修改`scientific_form_contract.v1.json`及锁。

| 对象 | 当前事实来源 | 本次修复边界 |
| --- | --- | --- |
| 原PDF、原表和来源 | 既有文件存储与解析制品 | 原文件不改，规范化只供内部读取，不伪造原文 |
| 材料状态 | 当前持久工作稿及正式材料状态 | 归属前补空身份，保留非空身份；研究材料列表派生自这些卡片 |
| Tc共同组和点 | 现有tc_group及各记录 | 服务器装配组/方法/点身份；μ*不是共同组身份 |
| 规范结构 | 每卡`S.structure` | 原子文件、原胞/惯用胞及格式派生仍属于一份规范结构 |
| 临时结构核对输入 | `_structure_model_input` | 只为所选结构的模型请求提供文件；保存、公开和交接剥离 |
| 字段核对 | `ScientificEvidenceCheck`与既有来源目录 | 当前版本有效结果复用，保留独立字段身份，不复制永久大对象 |
| 工作稿 | `ScientificWorkDraft` | 删除upload任务同时清理对应body和来源使用关系 |
| 不可变来源 | `ScientificSourceItem` | 不因删除一个工作稿而删除共享来源 |
| 独立谱运行 | `SpectrumCollection`、`SpectrumRun` | 首次入队从持久body计算版本；不新增谱状态或曲线算法 |

## 状态与失败恢复

整理未完成或字段核对有技术错误时，保存failed、原因及已有预览和结果；自动流程正常结束才发布ready。科学不确定性仍走原字段流程，不用技术完成状态授予人工批准。

未报告的可选值可以为空；结构参数仅在对应当前文件通过后按确定性派生显示通过，文件真实变化仍使依据失效。整数与小数同值比较不放宽实际数值变化。

## 清理、提交与历史

清理仅针对获授权的未提交解析稿及其当前使用关系，不删除正式论文、冻结交接历史或下载目录原PDF。提交在原事务中保存科学实体和来源；#207的来源转存规则继续有效。完整提交验证使用外层回滚，不把测试生成的论文编号写作真实送审成果。

## 持久版本一致性

MySQL JSON往返可能改变浮点末位表示；首次谱入队先重读新工作稿，再计算版本，使执行时读取同一事实。真实压力等内容变化仍改变版本，不对所有科学数值或全局指纹统一舍入。
