## 用户场景与验收

### 用户故事1：解析完成状态可信（P1）

用户从正文及SI重新上传后，可以知道自动整理、自动核对是否真的完成。

**优先级理由**：错误显示成功会把系统未完成的工作转给用户。

**独立验收**：正常新任务结束为ready；注入整理或核对技术失败时显示failed并保留已有内容。

1. **假如** 软件添加了合法Tc分组，**当** 检查模型字段，**那么** 不把服务器标签误认成模型越界字段。
2. **假如** 合法空软件组需要补值，**当** 继续核对，**那么** 正常补空且不覆盖其他软件或非空内容。
3. **假如** 自动整理或核对技术未完成，**当** 结束任务，**那么** 不显示完成，不丢预览和已保存结果。

### 用户故事2：结构、字段与页面审核一致（P1）

用户能看到有来源的规范结构，页面与核对读取相同的当前材料和结构内容。

1. **假如** PDF以三列晶胞参数和Wyckoff坐标报告结构，**当** 提取，**那么** 保留原表并完成既有组成、对称及几何检查。
2. **假如** 材料卡片尚无编号，**当** 结构归属，**那么** 先形成稳定身份；已有身份不替换，重复身份不猜测。
3. **假如** 模型核对结构，**那么** 能读取当前完整坐标；文件通过后，晶胞、体积和原子数遵循原有确定性派生规则显示。
4. **假如** 材料卡片更新，**那么** 页面与核对使用当前汇总，不让模型另写一份独立材料清单。

### 用户故事3：保存、清理和入库不改变已核对内容（P1）

用户删除解析稿后不再读到残留表单，提交时复用有效核对与来源。

**优先级理由**：保存和清理是完整流程的收尾，不能只验前端。

**独立验收**：真实提交和两类管理员批准在外层回滚事务中保存、重读通过；正式数据不变。

1. **假如** 已审核的数值为150.0，**当** 模型使用150表达相同数值，**那么** 不生成无意义的改值请求。
2. **假如** 提交大型结构表单，**那么** 审核摘要可读取，全部已核对物性引句保留，不额外调用科学核对模型。
3. **假如** 删除未提交任务，**那么** 清理对应工作稿和来源使用关系，保留共享不可变来源与正式论文。
4. **假如** 首次谱任务入队，**那么** 与执行时读取同一持久工作稿；真实内容改变仍被识别。
