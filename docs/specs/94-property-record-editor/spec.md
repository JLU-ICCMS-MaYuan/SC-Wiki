# 物性记录表单简化

关联 [Issue #94](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/94)；依赖已实现的 #90 模块化表单。

## 用户故事与验收

- **US1（P1）清晰标题**：用户查看或添加记录时只看到类型和方法；“测量 Tc · resistivity”不含模板版本号。
- **US2（P1）自由描述实验条件**：用户打开测量 Tc 后，在一个多行框查看和修改完整实验条件。论文报告两条同状态测量结果时，AI 分别保留各自条件，不相互覆盖。
- **US3（P1）独立折叠**：用户将第一条记录收起时，第二条状态不变；再次展开，编辑内容仍在。只读页面也能折叠，不能编辑。

## 功能需求

- **FR-001**：记录标题、只读标签、记录定义及添加记录选项均移除模板版本后缀；内部定义版本保留。
- **FR-002**：所有测量 Tc 的实验条件只提供一个多行框，不显示六个固定字段或补充实验条件编辑器。计算条件和参数表单不变。
- **FR-003**：AI 以样品、制备方式、测量方法、测量装置、外场和压力不确定度为描述方向，根据原文填写连贯文本；不强求齐全，不猜测缺失信息。条件属于每条 Tc，不能仅保存为材料状态共享条件。
- **FR-004**：实验条件文本经保存、读取、复制和校验后保持原文及换行；已有结构化条件可读，编辑时不静默删除原字段和 Evidence。
- **FR-005**：每条物性记录可独立折叠，覆盖同状态下的多条测量 Tc、预测 Tc 与自定义性质；默认展开。折叠摘要含类型、方法及可用的名称/值，键盘可操作。
- **FR-006**：折叠状态不进入科学数据；修改、增加、复制、删除其他条目不重置现有折叠状态。只读态可折叠但不能修改，收起时仍能看到服务端校验或定义加载错误提示。

## 成功标准

- **SC-001**：编辑态、只读态和添加菜单中的记录名称无版本后缀，提交仍带原定义键和版本。
- **SC-002**：仅有一个实验条件多行输入；两条测量记录的不同条件通过真实归一化、校验和数据库往返后仍各自完整；未填写内容可为空。
- **SC-003**：多记录独立折叠、编辑、复制、删除测试通过，既有计算条件/参数回归通过。

## 假设、边界和非目标

- 新增与已有记录默认展开，用户按需收起；共用组件内的其他物性记录复用同一交互。
- 六方面只约束 AI 描述方向，不做六个必填校验。生成文本遵循现有英文生成规则，人工输入语言不限。
- 已有结构化条件只在展示层转换；若用户填写 description，该文本是当前展示来源，旧字段作为原始信息保留。
- 同一状态、相同方法仍可有多条记录，用稳定记录键区分。
- 不改权限、计算公式、定义治理、已发布 Schema、数据库结构或 #93 论文历史命名。

- **FR-012**：预测 Tc 的 λ、ωlog 移至名称前；其余参数、补充参数与计算条件仍可编辑，常用区不得出现重复入口。测量 Tc 不新增理论参数。

### 范围与设计结论

在用户认可的 US6 样式基础上，制作电子性质、动力学性质、热力学性质和超导性质四模块 Demo。统一的是控件排布、补充字段新增/删除、单独成行和自动宽度；各记录保留自身科学含义及数据契约。模块切换仅用于本轮 Demo 中比较四种样式，不代表已决定改造生产页面的模块导航。

- **FR-022**：四类性质的常用字段紧凑单行排列；不使用重复左竖条、嵌套标题或多余缩进。补充参数与计算条件均采用独立“新增字段”入口，每条新增字段另起一行；初始宽度约为 ωlog，随内容自动扩宽。
- **FR-023**：非 Tc 记录保留现有名称、值类型、原始值、对应规范值和单位的含义，不因视觉统一而合并或丢弃数据。超导预测记录继续使用已认可的 λ/ωlog 前置与两组 Tc/μ* 同色无边框配对；不为其他三类性质增加这些专用字段。

## 2026-10-15：谱解析详情入口与分解稳定性（US8，设计草稿）

### 最新需求结论

用户希望声子态密度解析结果属于动力学性质，谱函数解析结果属于超导性质，点击进入独立页面查看。热力学示例从德拜温度改为目标化合物相对于分解路径的稳定性，以及不稳定时的 above-hull 数值。

热力学新场景以 FR-028～030 取代 US7 的德拜温度及该示例通用数值行；其他记录的既有数据契约与统一排版继续保留。

已询问原话中的“室温”含义；用户进一步明确应依据论文的 convex hull 判据，区分 0 K 形成能、0 K 形成焓和含温度的形成吉布斯自由能，并核对零点振动能是否计入。因此不将室温或 300 K 固定为产品口径，也不把“论文未说明 ZPE”改写成“未计入 ZPE”。

### 拟议需求与验收

- **FR-026**：动力学模块显示当前材料状态的声子 DOS 解析结果摘要，超导模块显示当前材料状态的 α²F 谱解析结果摘要；摘要包含来源、频域和解析/核对状态，提供“查看详情”。混合谱集合按曲线类型引用，不复制一份持久化谱数据，也不把已提取等同于已采纳。
- **FR-027**：点击摘要进入独立谱详情页面，提供返回原模块的入口，保留主表单试填。详情按当前曲线显示材料状态、来源、频率与幅值单位、提取曲线及逐点原图/重建值和点来源。后续实施继续复用 #137 的图像、质量、候选和导出能力及其权限边界；不在列表内堆叠完整详情或用弹窗代替所要求的页面。
- **FR-028**：热力学模块记录凸包依据（形成能 ΔE、形成焓 ΔH、形成吉布斯自由能 ΔG、论文未说明）、相对于分解路径的稳定性（稳定、不稳定、未判定）和分解路径。按用户本次明确口径，ΔE/ΔH 记录为 0 K，ΔG 按论文记录实际温度，同时保留压力及来源条件；不得自动假定 ΔG 的温度为 300 K。
- **FR-029**：不稳定时提供对应判据的 above-hull 数值和明确单位；按 ΔE/ΔH/ΔG 显示对应标签，不把不同判据的数值当作同一结果。更换判据不默认沿用另一判据的稳定性、数值或条件；Demo 分别保留各判据的试填草稿，具体持久化模型需在实施 Plan 中确定。
- **FR-030**：零点振动能使用“已计入／明确未计入／论文未说明”三态，按原文记录；稳定性、above-hull 数值、温压、ZPE、分解路径及证据属于同一化合物和同一计算口径。未知数值不当作零，也不依据示例数值自动生成真实稳定性结论。
- **SC-016**：动力学的 DOS、超导的 α²F 摘要可分别打开对应独立详情视图，曲线、来源与逐点数据匹配，并能返回原模块；其他模块不出现错误类别的谱入口。
- **SC-017**：在 ΔE/ΔH 下显示 0 K，在 ΔG 下可填写实际温度；切换判据不会把 ΔH 的 above-hull 值冒充 ΔG，返回时相应试填保持。
- **SC-018**：稳定/不稳定切换控制 above-hull 输入显示；ZPE 三态可分别选择，缺少说明保持未知。以上 Demo 验证不等于业务 API、路由或数据迁移已实现。
