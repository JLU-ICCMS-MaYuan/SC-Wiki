# 物性记录表单简化

关联 [Issue #94](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/94)；依赖已实现的 #90 模块化表单。

## 用户故事与验收

- **US1（P1）清晰标题**：用户查看或添加记录时只看到类型和方法；“测量 Tc · resistivity”不含模板版本号。
- **US2（P1）自由描述实验条件**：用户打开测量 Tc 后，在一个多行框查看和修改完整实验条件。论文报告两条同状态测量结果时，AI 分别保留各自条件，不相互覆盖。
- **US3（P1）独立折叠**：用户将第一条记录收起时，第二条状态不变；再次展开，编辑内容仍在。只读页面也能折叠，不能编辑。

## 功能需求

- **FR-001**：记录标题、只读标签、记录定义及添加记录选项均移除模板版本后缀；内部定义版本保留。
- **FR-002**：所有测量 Tc 的实验条件只提供一个多行框，不显示六个固定字段或补充实验条件编辑器。计算条件和参数表单不变。
- **FR-003**：AI 以样品、制备方式、测量方法、测量装置、外场和压力不确定度为描述方向，根据原文填写连贯文本；不强求齐全，不猜测缺失信息。条件属于每条 Tc，不能仅保存为材料状态共享条件。
- **FR-004**：实验条件文本经保存、读取、复制和校验后保持原文及换行；已有结构化条件可读，编辑时不静默删除原字段和 Evidence。
- **FR-005**：每条物性记录可独立折叠，覆盖同状态下的多条测量 Tc、预测 Tc 与自定义性质；默认展开。折叠摘要含类型、方法及可用的名称/值，键盘可操作。
- **FR-006**：折叠状态不进入科学数据；修改、增加、复制、删除其他条目不重置现有折叠状态。只读态可折叠但不能修改，收起时仍能看到服务端校验或定义加载错误提示。

## 成功标准

- **SC-001**：编辑态、只读态和添加菜单中的记录名称无版本后缀，提交仍带原定义键和版本。
- **SC-002**：仅有一个实验条件多行输入；两条测量记录的不同条件通过真实归一化、校验和数据库往返后仍各自完整；未填写内容可为空。
- **SC-003**：多记录独立折叠、编辑、复制、删除测试通过，既有计算条件/参数回归通过。

## 假设、边界和非目标

- 新增与已有记录默认展开，用户按需收起；共用组件内的其他物性记录复用同一交互。
- 六方面只约束 AI 描述方向，不做六个必填校验。生成文本遵循现有英文生成规则，人工输入语言不限。
- 已有结构化条件只在展示层转换；若用户填写 description，该文本是当前展示来源，旧字段作为原始信息保留。
- 同一状态、相同方法仍可有多条记录，用稳定记录键区分。
- 不改权限、计算公式、定义治理、已发布 Schema、数据库结构或 #93 论文历史命名。

## 2026-09-16：Tc 紧凑布局（US4，P1）

用户确认常用区直接编辑当前 Tc；后续明确取消独立原始记录，修改后的值是唯一有效数据。兼容 [#103 核对流程](../103-property-evidence-review/spec.md)。

- **FR-007**：测量与预测 Tc 的名称、值类型、Tc 值（框内 K）和代表复选框紧凑排列；容器宽度至少 640px 时单行，400–639px 两列，更窄时单列。实验条件独占一行。
- **FR-008**：Tc 只维护当前值，移除原始记录、原始值与原始单位输入；新建记录只填一次值。既有 value_raw、unit_raw 列作为兼容表示随当前值同步，不再独立保存旧值。
- **FR-009**：数值支持连续小数、科学计数法、清空与粘贴，零值有效。临时非法输入不回填旧值，保存被阻止；清空当前值同时清空其兼容表示。
- **FR-010**：范围、文本及布尔仍有对应输入；类型切换清理不适用的规范值字段。Tc 折叠摘要使用当前规范值；代表标记沿用同状态、类型、方法唯一约束。
- **FR-011**：共享布局覆盖上传、管理员及只读入口，保留字段和稳定记录键；核对标签可打开侧栏，数字可直接编辑，完成后关闭及位置保持不退化。
- **SC-004**：真实浏览器在三种容器宽度验证行列、无溢出、实验条件整行，编辑和只读均无原始记录区域。
- **SC-005**：实际输入与保存请求验证数值、零值、临时输入、范围、当前值同步、代表标记、重新加载和多记录独立性；旧 raw 内容不能阻止新值保存或覆盖当前值。
- **SC-006**：人工核对、共享表单回归、TypeScript 和生产构建通过；使用隔离数据，不修改论文 #29。

## 澄清记录

- 用户进一步确认不需要保留初次录入或提取的错误值，用户和管理员修改后均以新值为准。
  本次修改测量/预测 Tc 的双值设计；不清理既有论文版本、修改审计历史、论文文件或 Evidence，
  不扩大为压强及其他物性字段改造，也不执行真实数据批量改写。
