## 需求结论与 AI 提案

用户明确要求收起简洁、展开详细；未明确要求改变初始展开状态。本 Demo 推荐默认收起，与下面的物性模块一致，作为待评审选择，不写成用户已确认需求。

- **FR-066（拟议）**：收起仅显示箭头、“晶体结构”和简短状态，同相邻物性模块标题行对齐；移除折叠态灰色大容器、重复材料名/状态编号及大面积空白。当前材料归属由外层状态卡提供，不删除数据归属。
- **FR-067（拟议）**：上传按钮、无结构提示、文件信息、模型、晶格参数、矩阵与原子坐标都位于展开内容内；收起隐藏这些详细内容。未解决问题使用单行状态入口，收起时仍可查看来源，不通过隐藏问题营造已完成状态。
- **FR-068（本轮边界）**：原生独立折叠保留 DOM 和本地选择，不影响其他模块的展开/输入；只读可折叠、查看来源及切换坐标视图，不可上传或编辑。Demo 的模型及两处位置是布局示例，不代表论文结构或真实解析/几何转换。
