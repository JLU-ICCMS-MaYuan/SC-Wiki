## 需求结论与 AI 提案

用户明确要求收起简洁、展开详细；未明确要求改变初始展开状态。本 Demo 推荐默认收起，与下面的物性模块一致，作为待评审选择，不写成用户已确认需求。

- **FR-066（拟议）**：收起仅显示箭头、“晶体结构”和简短状态，同相邻物性模块标题行对齐；移除折叠态灰色大容器、重复材料名/状态编号及大面积空白。当前材料归属由外层状态卡提供，不删除数据归属。
- **FR-067（拟议）**：上传按钮、无结构提示、文件信息、模型、晶格参数、矩阵与原子坐标都位于展开内容内；收起隐藏这些详细内容。未解决问题使用单行状态入口，收起时仍可查看来源，不通过隐藏问题营造已完成状态。
- **FR-068（本轮边界）**：原生独立折叠保留 DOM 和本地选择，不影响其他模块的展开/输入；只读可折叠、查看来源及切换坐标视图，不可上传或编辑。Demo 的模型及两处位置是布局示例，不代表论文结构或真实解析/几何转换。

## 场景与成功标准

- **SC-053（Demo）**：初始结构与三类物性模块都收起，四行等高；无结构时收起不显示上传按钮/空态。展开后显示上传入口及空态，重新收起恢复一行。
- **SC-054（Demo）**：有结构布局展开显示模型和详细数据；切换分数/直角坐标后收起重开保留选择，其他模块的输入及折叠不受影响。待核对入口在收起时可打开来源，不改变折叠状态；只读禁用上传而保留查看。
- **SC-055（阶段门）**：桌面、390px 与键盘交互无溢出；先展示完整 Issue 追加草案及 Demo，由用户决定样式和默认展开行为，取得实际答复后才更新远端 Issue 或设计正式实施。当前未获该版确认。

## 设计与实施安排

独立 HTML [Demo](assets/structure-collapse-demo.html) 复用物性模块的分隔线/箭头/同高标题视觉。结构内容与标题分开，标题只显示简短状态；动作属于展开体，来源问题保留紧凑入口。暂无结构／有结构布局／待核对三个场景与只读切换仅在本页执行，不调用业务 API、AI、文件读取或持久保存。

本轮 T068～070：T068 留存原话、原图、历史核查及草案；T069 制作并验证 Demo，保存截图与观察；T070 展示完整追加草案并等待确认。正式组件、结构解析、3Dmol、几何确认、数据模型、API、数据库及 Overview 不修改；后续落地任务在用户决定后建立。
