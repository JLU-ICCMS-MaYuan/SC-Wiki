## US17：评审记录复制入口与同行删除

复用 #94，保持 OPEN 和唯一 `type:feature`；不新建 Issue 或父子关系。本段为拟追加正文，尚未写入 GitHub。

### 原始需求记录

> 我观察到解析数据表单记录里面有一个“复制记录”按钮，那是干什么的了？感觉没什么用，我也平时从来不用。你来判断一下是不是有必要保留这个功能按钮？
>
> 另外我觉得那个“删除记录”按钮应该放到和一行数据相同水平的位置
>
> 你使用 issue 和 spec 来实现，先看看有没有可以复用的 spec 和 issue，如果没有再新建。然后做好 demo 再决定要不要落地.

### 调查与建议

复制会新增一条独立记录，完整复制字段、条件、参数和证据，不是复制到剪贴板。可用于补录相似结果；但当前解析校对场景收益有限，历史备份中已有相同 DOS 副本，也没有全体用户频率统计。AI 建议取消逐条复制，保留添加独立结果，把删除放在本条常用输入行右端，等待用户评审。
