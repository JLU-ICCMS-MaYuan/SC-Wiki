# 快速验收

## 自动化

```bash
npm --prefix "frontend" run test:upload-ui -- --maxWorkers=2 --minWorkers=1
npm --prefix "frontend" run build
```

## 浏览器验收

1. 访问本地 `/news`，确认顶部栏已消失，SC-Wiki 与七个导航顺序正确。
2. 在展开与收起状态分别点击每个图标，检查路由、当前项、提示与键盘焦点。点击 SC-Wiki 回到 `/news`。
3. 从预测下方空白后的模型入口打开原配置弹窗，检查默认模型、供应商选择、掩码与取消；测试配置保存/清除使用隔离浏览器数据，不发送真实计费请求。
4. 从模型下方切换中文/英文，刷新确认语言偏好保持，折叠时也可打开语言菜单。
5. 以三种角色分别从侧栏末项进入 `/account`，再按角色进入工作台；从头像菜单退出，访客可从登录入口打开登录/注册。
6. 上传选择本地文件、预测选择 CONTCAR/PDOS 或输入表单后，收起/展开侧栏，确认文件与输入仍在。检查上传解析详情悬浮操作及其收起行为。
7. 在桌面、390px 窄屏与低高度窗口中检查导航内部滚动、菜单位置和正文空间。侧栏不盖住正文，低高度时可滚动到登录或账户菜单。

折叠选择保留在当前页面会话内；重新加载时按屏幕宽度采用默认状态。业务表格自身可横向滚动。
