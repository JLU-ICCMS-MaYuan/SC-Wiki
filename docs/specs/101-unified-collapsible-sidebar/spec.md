# 功能规格：全角色统一可收起侧栏

**GitHub Issue**：[#101](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/101)

## 背景与目标

按用户提供的两张页面截图，将顶部品牌、个人模型配置、语言切换和账户菜单迁到左侧，为正文释放完整空间。用户、管理员、超级管理员与访客共享设计。

## 用户故事与验收

### US1：统一功能入口（P1）

假如访问任意页面，当查看导航，那么 SC-Wiki 在热点上方，点击回到默认热点页；其后依次为热点、探索、脉络、社区、上传、对话、预测。空白后依次为切换模型、中文/英文、角色入口，访客末项为登录。

### US2：按需收起侧栏（P1）

假如正文已有文件选择、未保存输入或会话，当收起、展开侧栏，那么正文宽度随之改变，内容和请求状态保留；全部入口可通过图标、提示与键盘访问。低高度视口可滚动到全部入口。

### US3：保留身份与配置功能（P1）

假如以三种角色之一登录，当操作底部入口，那么仍进入用户中心，并从原有工作区进入对应工作台；头像菜单可退出。展开和收起时都可打开原模型配置、切换语言；访客可登录、注册。

## 功能需求

- **FR-001**：所有页面移除全宽顶部栏及正文顶部占位；品牌入口回到 `/`，继续重定向 `/news`。
- **FR-002**：导航顺序固定，七个业务功能、模型、语言与每种角色均有明确图标。
- **FR-003**：侧栏可展开或向左收起为窄图标栏；正文占据剩余宽度，不被侧栏覆盖。
- **FR-004**：主导航与底部配置组间保留空白，模型和语言紧邻角色入口；低高度时入口可滚动访问。
- **FR-005**：底部角色标签仍进入 `/account`；头像退出、访客登录注册、工作台入口和路由权限保持现有契约。
- **FR-006**：复用现有模型配置弹窗及语言上下文，保留当前模型显示、保存、测试连接、清除、密钥掩码和语言偏好。
- **FR-007**：侧栏操作不重挂载正文、不清空文件/表单/会话；更新依赖旧顶栏高度的悬浮布局。
- **FR-008**：全部图标按钮有双语可访问名称与焦点反馈；折叠图标有提示，活动导航可识别。

## 成功标准

- **SC-001**：三角色与访客均通过导航顺序、品牌回首页、登录/退出、角色访问矩阵验证。
- **SC-002**：展开与收起都能操作模型和语言；输入与正文状态在切换侧栏后保持。
- **SC-003**：在 1440×900、1366×768、390×844 与低高度视口检查宽度、滚动、菜单、弹窗和正文，无新增框架遮挡。
- **SC-004**：前端全量测试与生产构建通过，真实浏览器验证导航、配置与工作台可达性，记录验证边界。

## 假设、依赖与范围外

- 展开宽度 216px，收起宽度 64px；小于 900px 默认收起，用户可主动展开。折叠偏好保留在当前页面会话，不新增持久化键。
- #40、#43、#44 的用户中心与工作台契约继续有效。#48、#73、#74 中的顶部栏位置与高度由本规格替代，业务契约继续有效。
- 不改后端、数据模型、业务 API、权限、审核与发布流程，不触发外部模型计费调用。
- 历史页面内部已有窄屏布局问题不据此改写为本次全部修复；记录实际浏览器证据。
