## 范围与行为

- 任务主模型使用起始模型快照，左侧已有选择为入口；不新增每步模型选择，不在反馈、重试或恢复中更换主模型，不做多模型投票。
- 统一工具回执包含原文件摘要、页、区域、图像摘要、观察/元素身份、刻度及位置、程序读数、精度、未读原因和读取器/提示版本；自然语言解释可保留但不能代替这些事实。
- 纯文本主模型接收可读的同一结构化结果及上下文；已验证视觉主模型接收同一结果并额外接收实际图片像素，路径或图片编号不冒充已读图。
- 图像解析、主模型收到文字、主模型实际收到像素分别记录；调用失败、截断、未传图片不标记已读成功。
- 能力检测针对实际模型/端点身份，基础读图探针不等于科学图表准确率；503/超时为未知服务状态，不能宣称不支持。
- 文字、表格、公式保留专用读取工具；标量、谱、结构、字段核对仅共用取源/图像工具及反馈，核对按需查图，不全表重新数字化。
- 坐标/柱高/色标换算、曲线数字化、积分、几何校验和结构展开由现有程序负责；数字标签允许识别后校验。材料/条件/系列及结构归属仍需模型理解。
- 所有图像候选必须绑定本次实际来源；正文/表格等其他合法证据继续有效，不把工具回执当唯一科学真值，也不凭模型残余印象补字段。
- 首个独立视觉后端及其部署并未在前文选定；提供明确的解析器适配边界，未配置/不可用时报告真实未读，不以假数据模拟能力。Qwen3-VL、本地4090、PaddleOCR、DeepSeek-OCR-2均先记录为候选。
- 复用既有权限、严格工具参数、来源白名单、模型调用用量及运行器；不接受任意文件路径/公网URL，不暴露密钥或绕过内容版本。

## 验收

- 同一份工具结果分别进入隔离文本/视觉主模型路径；每个任务模型固定。
- 文本路径不直接发送图片给不支持的模型；视觉路径确有像素输入证据。
- 工具回执能够定位到同一元素并保持原模型、来源与提示版本。
- 标量、谱、结构和按需核对保留原有专用计算及科学字段契约。

不推送、不部署、不批量修改历史数据或标准字段。尚未选定的图像后端及4090部署另行记录，不把接口存在当真实图表通过。保留原主模型选择、科学数值、权限、四宿主契约及#224重试规则。
