# 数据模型与所有权：统一固定视觉主模型的看图工具回执与实际图片传递

依据：[spec.md](spec.md)、[接口契约](contracts/tool-and-source.md)。本文件为待实施内部协议，不新增科学标准字段。

### 主模型身份

沿用任务模型快照，身份包含模型、服务提供者/端点、接口协议及模型配置版本的安全摘要；密钥不进入回执或快照正文。无需第二视觉配置。基础探测和科学验收结果分别保存，503/超时不写成“不支持图片”。

### 统一回执

内部回执包括`receipt_id`、协议版本、来源/区域引用、图片清单、对象和元素、观察、坐标轴/刻度、程序计算、未读及限制、父回执、动作、工具/算法/提示版本。图形元素可以尚未完整解析，缺值说明原因；主模型下一轮观察仍引用本回执和图片，并交程序验证。

### 图片传输

图片清单持久部分只保存图像摘要、宽高、定位/渲染参数和缓存引用；实际字节/data URL只在本次传输中装配，供应商file_id按既有安全范围使用。记录已生成、已发送、完成读取，不存内部完整思维链或额外调用模型编造过程。

### 动作及来源

每个动作绑定当前任务的file_id/page/region_id/element_id，参数不能引入任意路径、端点或另一个模型。表格、文字、公式可返回其专用结果，并保持同一来源身份；计算候选不自动成为业务字段。
