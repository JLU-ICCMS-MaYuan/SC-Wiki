# 状态与数据所有权

当前仅迁移文档，不修改持久模型。侧栏沿用原宿主当前值、稳定字段身份、字段内容／来源／人工资料版本、核对结果与候选，不产生另一份正式科学值。

设计区分四类状态：未保存／保存中／已保存／部分失败；尚未核对／处理中／科学结论已返回／技术未完成；当前值与尚未应用候选；当前工作稿与冻结历史。保存按钮、结论显示和标红资格分别由对应事实驱动。颜色条件只见 #220。

过程投影应绑定当前 target/item_key 与任务身份，只报告真实阶段及可公开简短摘要，终态停止更新；不得用模型内部推理、候选文字或本地颜色授予后台通过资格。具体接口扩展实施前按原字段契约细化并验证，无自造标准科学键。
