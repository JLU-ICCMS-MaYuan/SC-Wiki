# 默认能力与正式接入的数据边界

问题、答案、版本及部分完成状态只由[目标三数据模型](../239-field-human-question-queue/data-model.md)定义，本单元不再复制实体或状态枚举。

## 配置与任务策略

拟增加服务端配置upload_human_questions_enabled，环境名称UPLOAD_HUMAN_QUESTIONS_ENABLED，默认true。新任务创建记录本次功能策略和协议版本，API与Worker一致；已有问题是否可读/可答不能只取当前全局开关。

关闭后的新任务不生成新队列，执行原有保护；已接受问题按当前队列继续，旧方向和证据仍有效。当前已有待答且继承启用策略的任务需要完成其局部恢复，不通过切换开关清空任务。无既有队列的历史任务缺功能元数据时按旧逻辑读取，不自动重新解析或批量回填。

## 公开状态

任务公开DTO仅扩展功能能力、待答数量、队列revision和当前是否等待人工的摘要。完整题目和证据按目标三接口读取，避免每2秒轮询携带大队列/整篇图像。paused/pause_reason沿目标三协议，现有大状态与五阶段编号保持；waiting不是failed，也不提前ready。

## 科学值与展示

新模块不持有另一份current_value，不从待答计数计算审核资格；#220/#221继续控制标记和合法操作。普通表单输入不调用模型，人工回答触发的是先前暂挂工作的有界恢复，当前工作稿及真实依赖版本仍需核验。
