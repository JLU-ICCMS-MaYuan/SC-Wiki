## 故障证明与修复

旧代码新增场景 1 项通过、8 项失败，其中包括四宿主漏标；缺少新增仓库方法的 TypeError 不冒充业务缺陷证明。初版管理员夹具使用 change，而原生文本路径按 input 通知，已改为真实 input；不增加生产绕过。正式 Chrome 独立旧源码四宿主都重现原免审项填写不红，修复后四宿主均红且保存后保持；mutation 再分别注入渲染及漏标回退证明检查有效。

过程中相邻回归发现新提醒优先级掩盖技术失败；按 #191 原要求恢复技术失败优先，四宿主技术失败仍显示 failed。多原因测试最初定位在外层节点，改用真实字段标签验证。null 与空文本依照既有规范化等价，输入后清空恢复原免审，不新增伪通过。上述失败均未被放宽断言或增加超时绕过。
