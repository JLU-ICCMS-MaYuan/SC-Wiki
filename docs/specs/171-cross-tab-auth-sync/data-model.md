# 会话状态与存储

## 共享存储

| 键 | 内容 | 所有权 |
| --- | --- | --- |
| auth_token | 现有 JWT 字符串 | 登录/邮箱验证写入，退出或明确认证失效移除 |
| auth_user | 现有用户 JSON | 登录结果或当前会话身份核验更新 |
| auth_session_revision | 不含凭据的随机世代标记 | 每次成功建立会话及主动/有效失效退出更新 |

旧版本没有世代标记时按空字符串处理；不迁移数据库，不新增账号信息，不记录凭据到日志。

## 页面内状态

当前 token、revision、user 作为一组视图，loading 表示身份恢复中。异步核验记录请求代次，写回前比较当前共享 token/revision。退出后新世代仍保留，防止未登录时发出的迟到登录响应复活已取消的会话。

## 不变量

- 界面展示的用户来自当前会话成功认证或对应 /me 响应。
- 核验不得重新写回 token。
- 旧会话的资料修改与核验响应不得改变新会话。
- 监听其他页面变化只采用当前共享值，不直接重放旧事件携带值。
