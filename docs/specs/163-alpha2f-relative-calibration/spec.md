## 用户指定的实施 Prompt

> 对于 α²F：用 ωlog 的对比看谱形是否吻合，用论文已有的 λ 确定幅值缩放；对比结果只供参考，不作为任何操作的通行条件。
>
> 具体流程是：
>
> 先从像素曲线独立计算 ωlog。
> 不需要先确定 α²F 的绝对幅值，再与同条件论文中的 ωlog 对比，显示计算值、论文值及相对偏差。
>
> 再使用论文已有的 λ，确定幅值系数 C。
> 假设像素曲线为 \(p(\omega)\)，先计算：
> \[
> I_{\mathrm{像素}}=2\int\frac{p(\omega)}{\omega}\,d\omega
> \]
>
> 然后：
> \[
> C=\frac{\lambda_{\mathrm{论文}}}{I_{\mathrm{像素}}},
> \qquad
> \alpha^2F(\omega)=C\,p(\omega)
> \]
>
> 例如像素积分为 100，论文 λ 为 2，那么 C 就是 0.02，用它把像素幅值换成 α²F 幅值。
>
> 取消 λ 的独立准确度校验。
> λ 在这里是确定刻度的输入。缩放后积分得到相同的 λ 是必然结果，不能再拿它证明解析准确。结果应注明“依据论文 λ 归一化”。
>
> ωlog 偏差无论多大，都只展示，不拦截。
> 不设置“偏差超过多少就不允许计算、保存或继续操作”的门槛。由你查看结果后，自行决定是否继续编辑。
>
> 这里的 ωlog 对比是谱形吻合程度的参考指标，不能单独证明整条曲线准确；但这个科学边界也不成为系统卡住你的理由。

## 背景与目标

现有逻辑把绝对幅值说明与 λ、ωlog 的可计算性绑定，导致像素曲线不能独立提供 ωlog。用户改为使用 ωlog 的论文对比作为谱形参考，使用论文 λ 确定幅值倍率，并取消根据偏差大小限制操作。

### 需求结论与变更取舍

本 Feature 使用本侧对话中用户最新确认的方案：论文 λ 是归一化输入，不再是独立校验目标；ωlog 的偏差只展示。该结论替代此前不使用论文 λ 反推倍率的讨论结论，不改写旧 Issue 的历史记录。完整追加用户关于“幅值标定依据”的补充，不引入替代的必填说明或确认节点。

## 用户场景与验收

### 用户故事 1：独立查看 ωlog 和参考偏差（US1，P1）

用户保存或编辑 α²F 后，点击“重新计算”，无需绝对幅值刻度和幅值依据文字，即可查看有数学定义的 ωlog。
优先级理由：先解除可独立计算结果被幅值要求连带隐藏的问题。
独立验收：使用有效像素曲线，缺少论文 λ 也能得到 ωlog。

1. 假如像素曲线有效、幅值依据为空，当用户重算，那么显示 ωlog 计算值。
2. 假如已有同条件论文 ωlog，当重算完成，那么显示论文值、绝对偏差和相对偏差。
3. 假如偏差很大，当用户编辑、保存、重算或继续其他操作，那么系统不按偏差设置门槛。

### 用户故事 2：通过论文 λ 确定幅值倍率（US2，P1）

用户通过当前材料状态已有的同条件论文 λ，将像素曲线转换为归一化 α²F，并能查看倍率与来源。
优先级理由：在无绝对幅值刻度的条件下提供明确的幅值来源。
独立验收：给定有效曲线和论文 λ，倍率能复现该归一化目标。

1. 假如像素加权积分为 100、论文 λ 为 2，当重算，那么 C 为 0.02，结果注明“依据论文 λ 归一化”。
2. 假如像素幅值统一乘以 2，当以同一论文 λ 重算，那么 C 减半、ωlog 不变，归一化后的幅值一致。
3. 假如论文 λ 缺失，当重算，那么说明 C 暂无输入，仍显示可计算的 ωlog。
4. 假如曲线编辑后再次重算，那么以当前源像素曲线重新计算，不能反复乘用上次 C。

### 用户故事 3：无需填写幅值说明（US3，P1）

用户在 α²F 和声子 DOS 正式编辑器中调整点或标定，无需填写“幅值标定依据”。
优先级理由：落实用户新增要求，前后端行为一致。
独立验收：两类谱的有效编辑均能在未提供该说明时保存；可计算数据的重算不因说明为空失败。

1. 假如进入任一正式谱编辑器，那么不展示该文本框，也不以另一输入项替代它。
2. 假如旧记录该说明为空或新请求没有填写该说明，当保存有效调整或计算有效数据，那么不以缺少说明拒绝操作。
3. 假如旧版本已有说明，那么保留历史记录，不要求用户重新填写。

### 边界与异常场景

- 缺少论文 ωlog：仍展示计算值，对比项留空并说明未提供参考。
- 缺少、非有限或不适用于当前条件的论文 λ：不能生成相应归一化结果，但不连带取消 ωlog 或限制编辑保存。
- 同条件存在多个不同参考值：不以“最接近结果”为理由挑选；说明当前参考未确定，不隐藏独立结果。
- 像素加权积分为零、积分发散或数据无效：分别说明对应结果为何无定义，不制造数值、不强行补点，也不阻止编辑和保存。
- 论文参考为零时，相对偏差若无定义应明确展示，不能生成无穷大或让整次操作失败。
- 幅值说明为空本身不是无效数据；不新增高频末端核对或准确度阈值。
- 既有权限和版本冲突保护继续有效，避免覆盖其他人已保存的修改。

## 需求

### 功能需求

- **FR-001**：α²F 的 ωlog 必须从当前曲线的频率和相对像素幅值独立计算，不依赖论文 λ、绝对幅值刻度或幅值说明。
- **FR-002**：像素幅值必须表示相对于当前零幅值基线的距离，不能把图片全局坐标直接当作幅值；不得借累计 λ 的轴刻度冒充 α²F 幅值。
- **FR-003**：ωlog 对比必须分别展示计算值、同条件论文值、绝对偏差和相对偏差；缺少参考时保留计算值。
- **FR-004**：系统必须使用同条件论文 λ 和像素加权积分计算 C：C = 论文 λ / 像素加权积分；α²F = C × 像素幅值。
- **FR-005**：归一化结果必须展示论文 λ、像素加权积分和 C，注明“依据论文 λ 归一化”；不得继续展示 λ 的独立准确度对比或通过／不通过结论。
- **FR-006**：任何 ωlog 偏差大小都只能作展示，不能成为计算、编辑、保存或其他操作的拦截条件。
- **FR-007**：α²F 与声子 DOS 正式共用编辑器必须移除“幅值标定依据”输入项；前后端不得因该说明缺失或为空拒绝有效保存或计算，也不得增加替代的必填说明或确认节点。
- **FR-008**：当前曲线、参考 λ、倍率、归一化结果及参考来源必须能对应到同一计算版本，源像素点和既有历史记录必须保留。
- **FR-009**：再次重算必须使用当前源像素曲线与当前适用参考，不能在旧归一化幅值上重复缩放。
- **FR-010**：各结果必须独立报告可用性和失败原因；缺少一种参考、C 不可计算或一种结果无定义，不能连带隐藏其他可计算结果。
- **FR-011**：原图无 α²F 幅值刻度时不要求用户补造刻度依据，不新增高频末端核对，不按对比偏差赋予或撤销科学采纳。
- **FR-012**：本次修改必须限于正式谱路径，保持声子 DOS 的积分与 3N 公式、Demo 和无关功能不变。

### 关键实体

- 源像素曲线：带频率映射、零幅值基线和连接关系的当前点集。
- 论文参考：与当前材料条件对应的 λ 或 ωlog 及其既有来源。
- 重算结果：像素加权积分、独立 ωlog、参考偏差、C、归一化 α²F、可用性和原因。
- 版本关系：计算结果关联其输入曲线及参考，历史结果保持可追溯，旧说明只作为历史信息保留。

## 成功标准

- **SC-001**：有效像素曲线在绝对幅值刻度缺失、幅值说明为空、论文 λ 缺失的组合下仍能独立给出 ωlog。
- **SC-002**：同一像素曲线统一放大 2 倍后，ωlog 相对变化不超过 0.000001%，C 在相同容差内减半，归一化幅值一致。
- **SC-003**：给定论文 λ 的有效案例中，归一化 α²F 的积分与输入论文 λ 的相对差异不超过 0.000001%；详情不展示该差异为独立准确度证明。
- **SC-004**：ωlog 相对偏差超过 100% 的有效测试案例仍可完成编辑、保存与重算，无偏差拦截。
- **SC-005**：α²F 与声子 DOS 正式编辑器均无该文本框，未填写该说明的有效请求通过前后端保存及计算路径。
- **SC-006**：缺失参考、零积分及数值无定义分别有明确结果状态；刷新可恢复已保存结果，历史结果不被覆盖。
- **SC-007**：完成公式测试、正式 API 保存重算测试和浏览器操作验证；验证覆盖新旧记录及两类谱共用编辑行为。
