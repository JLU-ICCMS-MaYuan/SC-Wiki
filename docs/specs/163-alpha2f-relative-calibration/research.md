# 技术决策

1. ωlog采用相对像素p的加权对数平均，统一幅值倍率抵消；像素先相对当前幅值零基线，不使用图片全局坐标。旧α²F与累计λ共享刻度的比例不参与新C。
2. 论文λ作为归一化输入，C=λref/Ip；归一化候选与源曲线分开，防止重复乘C。Ip=0、发散或数值无效有独立状态；缺λ仍显示ωlog，缺ω参考仍显示计算值。
3. 使用幅值缩放改善求积数值范围，所有有效输入均不以结果偏差设门槛。归一化λ为0时C=0有定义，ωlog仍来自相对谱；负/非有限λ不生成物理归一化。
4. 频率定义/绝对幅值旧确认标志可能混合了未标幅值的判定，不作为新相对计算的文字通行证；按当前已保存频率标定进行计算，不新增确认节点。
5. references_for保持兼容，新增参考诊断区分缺失与歧义，不修改现有材料表单或根据结果选参考。当前300GPa材料只读查询可取得λ=3.34、ωlog=968K，均来自已有同条件记录。
6. 初始自动结果与人工重算共用相对算法；原有零基线/联合重建只保留诊断候选，不用其λ对比作为准确度验收。独立ωlog同样只作谱形参考。
7. 编辑器说明字段不再展示或必填。旧字符串可留在历史JSON，不做迁移。选定单位/两个标定数值仍用于坐标换算，DOS的3N公式不改。

实施中用户将正式联动edgeWeight与minWeight同时改为0.1，旧校验阻止模块加载。保留其数值，将等号解释为核心区最外点保留、外部全部截断，仅修正校验与注释；提交只包含此逻辑修正，不包含用户数值变动。
