## 背景与目标

让访客在独立、安静的科研主题页面完成邮箱登录或注册。先用无真实认证副作用的 Demo 评审视觉和交互，再进入正式集成。

### 需求结论与变更取舍

采用 SVG 科学插画，依照 2026-10-23 反馈增加更写实的材质、冷雾与点击交互；默认仍安静循环。用户明确授权代码绘制，因此此次不依赖生成图片。所有入口统一仅在第二阶段实施。抗磁性与磁通钉扎说明是已批准方案中的科学表达边界。

## 用户场景与验收

### 用户故事 1：预览页面与动画（US1，P1）

访客从 Demo 入口进入白色全屏登录页，左侧超导体绕轨道悬浮运行，右侧可操作表单。独立验收：预览链接加载、返回入口、语言切换和动画暂停均可操作；正式侧栏不变。

### 用户故事 2：体验邮箱认证流程（US2，P1）

访客使用演示账号登录，或填写注册信息后验证邮箱。独立验收：模拟成功、错误、加载、未验证邮箱恢复、验证码重发均有明确反馈；网络中没有认证 API 请求，不修改正式登录会话。

### 用户故事 3：正式入口统一（US3，P2，尚未授权实施）

Demo 满意后，侧栏和上传页进入 /auth；登录及验证成功返回合法站内来源。无来源时登录进入 /news，新注册进入 /account。独立验收：真实现有认证链路及来源页回跳；不得用 Demo 成功代替。

### 边界与异常场景

- 短屏允许纵向滚动，手机优先显示表单；中文、英文不得横向溢出。
- 错误邮箱、用户名格式冲突、短密码、错误或过期验证码可恢复；提交中禁用重复操作。
- 未验证邮箱登录可进入验证码步骤，重发倒计时不因切换语言重置。
- 系统减少动态效果时默认静止，允许显式播放；后台暂停、回前台不跳帧补跑。
- 演示状态仅保存在内存，刷新即重置，不写认证 token，不请求 SMTP。

## 需求

- **FR-001**：独立 Demo 入口与正式页面隔离；第二阶段才统一全部登录入口。
- **FR-002**：白底、桌面约 60/40 分栏、右侧约 380px 表单，顶部品牌、返回及语言切换，窄屏上下布局。
- **FR-003**：SVG 科学插画轨道、悬浮间隙、投影、前后层次、少量磁场线、T < Tc，默认约 12 秒一周；点击加速有上限，停靠后重新点击从低速出发。
- **FR-004**：暂停/继续、减少动态效果及页面不可见暂停；动画不抢焦点、不遮表单。
- **FR-005**：邮箱密码登录；用户名、邮箱、至少 10 位密码、可选实名注册；密码显隐及既有用户名规则。
- **FR-006**：6 位验证码、重发冷却、加载/失败/成功反馈、未验证邮箱恢复，完整模拟而无真实认证副作用。
- **FR-007**：中英文、键盘可操作、明确字段标签、状态播报及可见焦点。
- **FR-008**：科学说明明确概念示意；稳定沿轨运行通常涉及磁通钉扎，不把完全抗磁性当作全部稳定机制。
- **FR-009**：正式接入沿用既有 API，限定站内来源地址，完成后更新 Overview；无新增数据库结构。

## 本轮需求结论（2026-10-23）

后来的六点反馈覆盖最初的“密码找回范围外”和 16 秒匀速要求，原文保留。本轮继续修改 Demo，尚未批准生产接入。

- **FR-010**：移除桌面动画与表单之间的竖线；提高黑色超导圆片的材质层次、边缘、颗粒及凝霜细节，加入液氮冷却产生的白雾示意。
- **FR-011**：默认 12 秒一周，每次推动速度乘 1.35，上限 1 秒一周；上限后点击不再加速。鼠标悬停为手型，按下呈抓握反馈，键盘也可推动。
- **FR-012**：点击磁轨设置停靠点，沿当前方向运行到该处精确停下，不瞬移；新点击替换旧目标。点击已停圆片以 20 秒一周重新出发，继续点击可加速；暂停、减少动态和后台暂停继续有效。
- **FR-013**：仅点击登录页“忘记密码”后，依次展示邮箱 → 邮箱验证码 → 新密码及确认 → 成功并返回登录。模拟验证码校验成功前不能改密码，重置码与注册验证码分离，验证码和重置凭证过期或消费后不可复用。
- **SC-006**：浏览器实际指针点击验证加速上限、轨道坐标换算、到点停靠、慢速重启；桌面和手机截图确认白雾与材质可见、竖线消失。
- **SC-007**：忘记密码完成后新密码可模拟登录、旧密码失败；错误/过期/重发/确认不一致可恢复；不请求真实 API、不修改生产存储。

上述数值为本轮可调演示默认值，不是物理参数。白雾表现冷空气凝结的小水滴，不宣称氮气本身为白色。

## 第三版需求结论

- **FR-014**：速度上限改为每秒一圈；默认 12 秒和低速重启 20 秒不变，上限后不可继续加速，最高速仍能停在所选轨道位置。
- **FR-015**：依据论文突出理想迈斯纳态的抗磁性：蓝青色磁场线在样品两侧弯曲并局部变密，线连续且不穿过样品内部；另一颜色表示表面屏蔽电流；图例明确这是理想迈斯纳态示意，实际轨道实验磁通钉扎不等同于整个内部 B=0。
- **FR-016**：参考视频约 13.683、25.250、46.283 秒画面，白雾形成比圆片大数倍的浓雾团，沿轨道铺开并向外下沉；保留部分圆片轮廓和可点击轨道，不遮登录表单。白底下用白色核心与淡冷灰边缘表现体积，不能仅提高旧薄雾透明度。
- **SC-008**：真实浏览器测得最高速约 1 秒完成一圈且不会越过速度上限；高速停靠和低速重启回归通过。
- **SC-009**：视频抽帧与实现截图并排检查雾团覆盖尺度；磁场线显著可见且不穿过样品；暂停、减少动态效果、后台暂停和表单流程保持可用。

## 正式实施基线

用户已确认第四版 Demo 并授权正式落地，解除先前“只做 Demo、正式集成待确认”的阶段门。当前视觉以 FR-017/018 为准；早期磁场图层不恢复。

- **FR-019**：独立 /auth 页接入现有登录、注册、邮箱验证和用户名可用性；侧栏及上传页入口统一跳转，记住来源，保留查询参数和锚点。拒绝外站、协议相对、反斜线、控制字符与认证页自身回跳。无来源时登录进入 /news、新注册完成进入 /account。
- **FR-020**：忘记密码实现真实邮箱验证码→一次性改密授权→新密码确认；验证码与注册/已登录改密完全隔离，5 分钟有效、最多 5 次错误，60 秒发送冷却及既有邮箱/IP额度；凭证仅存前端内存，5 分钟有效、一次性使用。改密成功递增 session_version，旧 JWT 失效，返回登录而非自动登录。
- **FR-021**：未验证、封禁、注销或不存在的账号不能完成找回；请求验证码显示统一受理信息，不直接透露账号是否存在。SMTP/Redis/数据库故障明确报错，不能显示虚假成功。密码使用现有 bcrypt，满足至少 10 字符且不超过 72 UTF-8 字节。
- **SC-011**：正式前端与真实 Go 路由、隔离数据库/验证码缓存/邮件捕获完成注册验证、登录、找回、错误恢复、旧会话撤销及来源回跳；浏览器不使用 mockAuth；隔离 SMTP 通过不宣称公网邮箱实际投递。

无数据库迁移，不改变账户中心已登录改密功能。不推送或部署远端；远程 Spec 链接和外部 SMTP 收信若未验证，明确保留边界。

## 注册字段命名与防重核验

- **FR-022**：正式注册页和共享 Demo 的字段标签由“公开用户名”改为“用户名”，英文同步为 Username；不改变已有账号展示范围、真实姓名提示或用户名格式。
- **FR-023**：核验现有失焦可用性检查、注册提交查重与数据库唯一索引；完全相同的用户名不可重复。沿用当前 ascii_bin 大小写敏感规则，Alice 与 alice 可不同，不新增迁移或修改历史账号。
