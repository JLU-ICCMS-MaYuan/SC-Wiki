# SC-Wiki 独立登录页：先交互 Demo，后正式接入

## 设计方案

已确认：**极简科学插画、SVG 动画、安静循环、所有登录入口统一**。

- 全屏白色背景，隐藏业务侧栏。顶部保留 SC-Wiki 标识、返回入口和语言切换。
- 桌面采用约 **60% 动画区 / 40% 表单区**，右侧表单宽约 380px，直接排在白色页面上，避免厚重弹窗感。
- 沿用网站紫色 `#4f46e5`，配深灰文字、浅灰输入框和充足留白。
- 窄屏改为上下布局：缩小插画，优先保证表单完整、易操作。

## 动画与表单

**左侧动画**

- 使用本次已获选择的 SVG 方案，绘制透视环形轨道、悬浮超导圆片和少量磁场线。
- 圆片约 16 秒绕行一周，通过悬浮间隙、投影和前后遮挡体现空间关系；标注 `T < Tc`。
- 提供暂停/继续；遵循系统“减少动态效果”设置，页面不可见时暂停。
- 简短说明这是概念示意：抗磁性与实际稳定沿轨运行涉及的磁通钉扎分别表述，不宣称物理仿真。

**右侧表单**

- 默认展示“欢迎回到超导维基”，支持登录/注册切换。
- 登录：邮箱、密码、密码显隐。
- 注册：用户名、邮箱、至少 10 位密码、可选真实姓名，保留现有校验规则。
- 注册后进入 6 位邮箱验证码步骤，支持重发倒计时、错误提示和成功反馈。
- 仅提供邮箱渠道，沿用现有中英文能力。
