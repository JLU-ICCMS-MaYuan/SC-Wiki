# Demo 状态与生命周期

- 页面状态：入口预览、登录、注册、验证码、成功；当前语言复用站点偏好。
- 表单：邮箱、密码、公开用户名、可选实名、验证码；密码只在当前页面内存中保存。
- 内存账号：规范化邮箱、用户名、密码、已验证标记；两条固定样例分别用于成功登录和未验证恢复。注册新增账号只对当前页面生命周期有效。
- 验证状态：发送时间、60 秒后可重发、5 分钟后过期、错误次数；重发更新计时与次数。
- 登录成功进入演示完成态，不写 token 或生产会话；返回仅进入 Demo 入口，不假装真实登录。
- 切换登录/注册清除错误；离开验证或成功后可返回登录；刷新重置模拟账号。
- 动画状态：运行/暂停、用户显式选择、系统减少动画、页面可见性、已累计运行时间。隐藏或暂停时不累加时间。
- 本阶段无数据库表、持久化迁移或新的生产实体。

## 本轮新增状态

运动状态为 angle、speed、target；与界面暂停、后台可见性分别管理。target 是当前运动方向的角度目标，跨目标时 speed=0；推动清空 target。白雾用独立累计时间，暂停和隐藏期间不累加。

重置挑战独立存储邮箱、发送时间、错误次数及验证后的短期改密授权。验证成功消费验证码；新密码符合至少 10 位且两次一致后消费改密授权，不登录、不改变邮箱已验证状态。离开找回流程清除表单与临时授权；刷新后全部模拟账号重置。
