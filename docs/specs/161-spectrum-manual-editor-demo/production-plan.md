## 数据与接口

- 复用SpectrumCollection/SpectrumRun的JSON字段，无新表或迁移。GET /api/rag/spectra/{id}/manual?kind=alpha2f|phonon_dos 返回有权限的当前运行编辑文档列表，每条曲线使用自己的标定，避免混用分波尺度。
- POST同路径携带target、expected_version、expected_collection_version、base_run_id和document。一次保存一条曲线；锁集合并核对来源、材料及运行版本，创建不可变新运行，合并保留其他曲线并撤回旧采纳。
- 服务端校验来源/曲线身份、像素范围、标定与零频确认点，重算THz/幅值和零频报告；不信任浏览器指标，不沿用旧积分/比较/候选。原观测留在旧run，人工点不标为自动观测。
- 非单值、缺口或幅值证据不足的描线可保存待核对，不自动开放积分。公开接口继续只返回已采纳曲线，并移除内部编辑文档，防止附属字段泄露未采纳点。

## 界面职责

- 正式组件放在frontend/src/components/spectrumEditor，两种谱共用。Demo作为已认可交互参照保留；正式路径不依赖固定图片/假数据/localStorage草稿。
- 详情增加编辑入口，已归属、有编辑权、非历史且未过期的记录可编辑。不同分波独立保存，切换未保存曲线有保护。
- 保留坐标/零频核对、联动、平移缩放、透明度和撤销重做。API失败保持工作副本，成功后更新列表与路由版本，回到数据库的新结果。
- 只显示真实运行的识别刻度，未知幅值保留相对像素，不借累计λ刻度。正式联动使用用户当前2/.3/1/.1配置值，Demo原文件保持不变。

## 指定起点描线

点增加可选connectTo字段指向同曲线前面的稳定点ID，新点追加到数组并breakBefore=true，不改变旧边。绘图显式绘制父子边；联动由已存边建立线性邻接，遇分叉停止扩散。后端校验前驱存在且在该点之前，禁止跨曲线/自环/环；回读和CSV保留前驱，公开裁剪遇丢失父点则断开。

SourceCanvas在add工具中用click事件处理，detail>=2仅结束、不加重复点；dblclick退出，新增成功自动选中末点。右键平移和滚轮不结束链，表格改变选择会重启需明确起点；双击不触发API保存。Demo和正式编辑器同步行为，用户调参文件不动。

## 正式末端吸附

Point.joinTo可选字段表示尾点到已有目标的附加边，不复制或重新排序目标。吸附查找是当前曲线一次O(n)平方距离比较，屏幕阈值8px换算到源像素；鼠标预览只在目标变化时更新状态，点击重新求值避免旧缓存。点击吸附后锁定终点直到双击/退出，不继续误追加。服务端二次校验ID范围和自连；绘图/联动/删除/公开过滤/CSV同步joinTo。Demo实现和数据均不修改。
