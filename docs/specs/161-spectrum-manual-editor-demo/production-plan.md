# 人工编辑器正式接入方案

## 实施基线

用户原话：可以！开始落地把。

本轮将已认可Demo接入正式详情与数据库，取代此前仅Demo的范围；保留所有旧原话。不推送、不部署、不批量重提取，原Demo调参文件不修改或夹入提交。

## 数据与接口

- 复用SpectrumCollection/SpectrumRun的JSON字段，无新表或迁移。GET /api/rag/spectra/{id}/manual?kind=alpha2f|phonon_dos 返回有权限的当前运行编辑文档列表，每条曲线使用自己的标定，避免混用分波尺度。
- POST同路径携带target、expected_version、expected_collection_version、base_run_id和document。一次保存一条曲线；锁集合并核对来源、材料及运行版本，创建不可变新运行，合并保留其他曲线并撤回旧采纳。
- 服务端校验来源/曲线身份、像素范围、标定与零频确认点，重算THz/幅值和零频报告；不信任浏览器指标，不沿用旧积分/比较/候选。原观测留在旧run，人工点不标为自动观测。
- 非单值、缺口或幅值证据不足的描线可保存待核对，不自动开放积分。公开接口继续只返回已采纳曲线，并移除内部编辑文档，防止附属字段泄露未采纳点。

## 界面职责

- 正式组件放在frontend/src/components/spectrumEditor，两种谱共用。Demo作为已认可交互参照保留；正式路径不依赖固定图片/假数据/localStorage草稿。
- 详情增加编辑入口，已归属、有编辑权、非历史且未过期的记录可编辑。不同分波独立保存，切换未保存曲线有保护。
- 保留坐标/零频核对、联动、平移缩放、透明度和撤销重做。API失败保持工作副本，成功后更新列表与路由版本，回到数据库的新结果。
- 只显示真实运行的识别刻度，未知幅值保留相对像素，不借累计λ刻度。正式联动使用用户当前2/.3/1/.1配置值，Demo原文件保持不变。

## 指定起点描线

点增加可选connectTo字段指向同曲线前面的稳定点ID，新点追加到数组并breakBefore=true，不改变旧边。绘图显式绘制父子边；联动由已存边建立线性邻接，遇分叉停止扩散。后端校验前驱存在且在该点之前，禁止跨曲线/自环/环；回读和CSV保留前驱，公开裁剪遇丢失父点则断开。

SourceCanvas在add工具中用click事件处理，detail>=2仅结束、不加重复点；dblclick退出，新增成功自动选中末点。右键平移和滚轮不结束链，表格改变选择会重启需明确起点；双击不触发API保存。Demo和正式编辑器同步行为，用户调参文件不动。

## 正式末端吸附

Point.joinTo可选字段表示尾点到已有目标的附加边，不复制或重新排序目标。吸附查找是当前曲线一次O(n)平方距离比较，屏幕阈值8px换算到源像素；鼠标预览只在目标变化时更新状态，点击重新求值避免旧缓存。点击吸附后锁定终点直到双击/退出，不继续误追加。服务端二次校验ID范围和自连；绘图/联动/删除/公开过滤/CSV同步joinTo。Demo实现和数据均不修改。


## 主动重算实施（已确认）

FR-050至054/SC-028至030：新增独立recalculate模块与POST /{collection_id}/recalculate。复用manual.current/assert_latest完成鉴权、行锁、材料及版本验证，来源是当前run.result_json；按稳定ID恢复显式连线图，只有一个无分支/无环的连续单值频率路径可进入积分。按频率方向遍历而不改动原始点数组，不跨缺口排序拼接。
复用spectral_integrals的分段线性精确积分；λ/ωlog状态独立，幅值依据来自当前manual_documents（优先）或初始calibration。相对谱依据须描述零基线及统一倍率，物理频率定义继续沿用已确认来源，不能由普通文本自动改变。DOS按各曲线自身网格积分，完整范围一致才合计；3N比较另检查原胞证据，不要求网格采样点完全一致。
结果写新SpectrumRun，copy原曲线/标定，quality记录每种谱的recalculation来源run/时间/操作者；新运行清除审核，不自动采纳。人工save既有quality重置行为自然使重算失效。公开受限频段过滤不得泄漏全谱结果。
前端页面持有忙碌锁和请求目标，POST成功replaceListing并导航新run/version；结果组件只展示服务端状态。零频详情compact模式仅一条摘要和未完成分波，编辑器维持原检查组件默认行为。删除仅详情的旧解释组件与逐点表。


## 计算异常定位设计

FR-055/057→独立topology模块构建稳定ID邻接表并迭代遍历连通分量/DFS回边，O(V+E)；connected_samples复用同一图，诊断与积分不采用不同连接规则。断片列各片段真实端点，孤立点独立列出；闭环列实际回边两端，分叉列中心及邻点。像素优先保存的frequency_pixel/amplitude_pixel，缺失时由当前标定换算；无有效像素不提供可点击定位。旧自动点ID使用与manual.editor_document一致的curve:p索引。
FR-055→重算quality.trace_diagnostics[kind]存报告，原run不修改；新失败和成功重算均生成诊断，人工save质量重置使旧诊断失效。旧重算结果没有诊断时通过现有重新计算入口更新，不增加迁移或后台业务写入。公开结果剥离该内部诊断，避免暴露未采纳点。
FR-056→SpectrumMetrics传curveId/pointId到页面openEditor，沿用GET manual版本核对并确认点存在。editor初始选点传给SourceCanvas一次性定位，初始化fit/ResizeObserver完成后将点置于图窗中心并适度放大；之后用户自由缩放/平移，不随每帧拖动重新居中。坐标与点表使用现有selected同步。
FR-057→前端每页12条诊断，仅渲染当前页；坐标和文案不复制到λ/ωlog两个参数中。SC-031/032→拓扑单元测试、正式HTTP保存/重算、当前MySQL保护和浏览器点击/删除/撤销/版本冲突/窄屏证据。


## 材料状态重新核对恢复

FR-058→listing增加stale_reasons（historical/source_changed/state_missing/state_changed），前端在02/03操作区域显示具体禁用原因。老响应缺字段时仅显示材料/来源待核对，不猜已满足恢复条件。
FR-059/060→POST /{collection_id}/revalidate复用权限、集合锁、内容版本/集合版本/基础run校验，唯一例外为允许state_signature不一致；仍要求同state_key存在、来源文件哈希有效、当前同类最新集合，必须confirmed=true。按当前ctx state_signature更新集合，新建immutable run，复制全部点/标定/编辑文档/操作，不重新提取。派生质量清理与manual.save共用，零频按保存文档重建；旧采纳和候选清除。顶层state_revalidation记录来源run、旧/新签名、作者、时间及当前材料摘要；公开过滤移除。
FR-061→前端确认对话框读取当前材料摘要及原图caption，复核提示只能说明原记录和当前条件，不能伪造旧条件快照。提交携带已展示listing.version/state_key，成功替换listing并导航新版本；随后可继续点击编辑。取消不发写请求；失败保留详情。编辑原因另补原图/材料加载原因，不将幅值警告混作编辑门槛。
SC-033/034→正式HTTP/当前MySQL并发、浏览器复现state_changed且source有效、取消不写、恢复后编辑/重算、来源变化拒绝、历史和材料删除拒绝、公开字段过滤与Demo保护。用户真实谱保持只读。


## 统一预检查与末端策略

FR-062→diagnose在既有O(V+E)拓扑图上增加样本/路径和端点诊断，不因首个异常就停止后续检查。数值积分仍拒绝不安全输入；诊断独立于幅值依据，因此幅值未确认也能先处理形状。
FR-063→Document.highEndpoint可选{pointId,x,y,frequencyTHz,evidence}，服务器校验来源/曲线身份和有限快照；当前最高频点及快照匹配才有效。高频目标若在图框内且已显式确认，采用实际点频率作为积分上限；未确认且未达图框高端时发high_endpoint，不构造边界幅值。图框本身只作为“覆盖到图框上限”的一种可检验边界，不能强迫用户把真实端点移到上沿。
FR-064→prepare_repairs对人工文档中的开放片段端点用精确位置/数值键分组，唯一配对且一个为高端、另一个为低端，连接不会形成分叉/环/频率回折时添加joinTo；使用并查集跟踪片段合并，避免全点两两计算。只复制工作payload，在新run及manual_documents操作中记录，不覆盖父run。不删除任何点、不合并近似坐标。积分遍历只折叠具有显式边且原图/数值完全一致的连续重复样本。
FR-065→删除SpectrumMetrics中的时间/参考JSON渲染；仍保留quality.recalculations/comparisons后台数据。TraceDiagnostics扩充问题类型与参考边界读数，已自动处理项另列。
SC-035至037→数值/自动修复正反例、proof失效、HTTP持久化/公开过滤、当前MySQL保护与浏览器定位→证据确认→保存→重算、窄屏和Demo哈希。

补充：用户显式撤销的自动连接记录具体端点ID，再次重算跳过该对端点，尊重人工修订；不同真实截止的DOS分波在每条末端均已独立核对时按各自区间积分相加，不补零，返回component_intervals。
