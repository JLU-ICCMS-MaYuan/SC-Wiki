# 新增点坐标与识别坐标轴验收

日期：2026-10-26。对应 FR-021 至 FR-024 / SC-014 至 SC-016，范围为 #161 独立 Demo。

## 实现与来源

- 普通加点或零频加点/替换后自动选中，右侧顶部显示频率、幅值、源像素X/Y及距当前零频线距离；连续加点仍可用。
- 标记零频线后可直接核对像素、频率及与原识别零刻度的差；只是标定依据，不自动科学采纳。
- 蓝色当前标定轴、灰色已有识别刻度、棕色λ参考、人工零频线及选中点投影共用SVG坐标变换；辅助层不拦截点击，可隐藏。
- 频率识别源像素435/311/188/65对应0/20/40/60 THz，来自已有标定记录。原记录与图像哈希保存在 demo/src/recognized-axes.json，已重新核对。
- 当前等分刻度明确是当前标定生成的，不称为AI识别。λ的0–4只作参考，PhDOS无数字幅值刻度不伪造；当前相对幅值轴放上边以区分原图λ轴。
