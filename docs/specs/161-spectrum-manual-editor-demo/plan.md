# 实施方案

## 基线

对应 [#161](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/161) 与 [Spec](spec.md)。用户已明确请求实施完整五节方案，所有设计围绕 FR-001 至 FR-013，不新增生产范围。

## 结构与数据流

- 隔离 React + TypeScript + Vite Demo，使用仓库 frontend 已有依赖；独立构建目录，不修改生产路由。
- engine.ts 保存轴映射、点片段、约束位移和历史；SourceCanvas.tsx 负责原图像素坐标与屏幕映射、SVG/指针交互；App.tsx 负责详情、表单和保存。
- 固定图像/点快照 → 不可变初始文档 → 工作副本与操作历史 → 本机已保存草稿 → 详情图表。localStorage 仅由显式保存操作写入。
- 保存键包含 Demo 版本与示例 ID。恢复时校验来源身份、尺寸、标定、点 ID、片段及有限数值，异常不静默覆盖。
- 保留 source 绝对像素坐标；视口可裁切，但不重写点位置。

## 核心行为

- 轴以两点线性映射，频率轴 x/y 可切换。幅值未知时用像素相对值；物理标尺由用户明确启用且有说明。
- 标零频时平移频率标定使选中位置为 0，保留斜率和像素点；清除之前的零频选点确认。补选零频点必须在标记线附近实际点击，频率像素取已标零线，幅值取点击位置，不默认零幅值。
- 点按频率有序，采用显式 segment；删除产生新片段，新增点只连接所选片段内部，缺口中的新点单独成段。
- 联动权重为半径内 (1-(d/r)^2)^2，中心为 1；按拖动起点快照计算，避免逐帧累加。二维移动对全部受影响点的越界及频率交叉统一约束位移比例。
- 图中点采用恒定屏幕命中半径，鼠标中心缩放；SVG client CTM 反变换得到源像素。
- 一次完整指针操作记录一次历史；标定、增加、删除、数值编辑和恢复各记录一次。取消指针操作恢复起点。
- 详情原图、数据、叠加模式；表格固定高度滚动，编辑器侧栏可滚动。小屏上下布局。
- 所有人工修改保留来源和操作记录，不自动设置 scientific accepted 或 human_confirmed。

## 验证与交付

engine 单元测试 → TypeScript 与独立构建 → Playwright 实际指针操作、保存恢复、失败、桌面/窄屏、网络边界 → 记录 validation.md 与截图。确认所有 FR/SC 有任务和测试映射，再按 AGENTS.md 精确暂存并提交；不推送、不部署。

## 技术上下文

- TypeScript 5.6、React 19、Vite 5.4；依赖复用 frontend/node_modules，不修改前端依赖或生产路由。使用 Vite 自带 JSX 转译，Demo 无须 Fast Refresh 插件。
- 桌面 Chrome 和 390px 窄屏；每个示例数百个固定谱点，SVG 命中半径按实际 CTM 缩放。逻辑测试使用 Vitest，真实浏览器使用 Playwright + Chrome。
- 存储仅 localStorage；公开运行接口是 127.0.0.1:5187，不访问数据库、模型或业务 HTTP API。无后端迁移或部署。

## 阶段依赖

T001 文档和需求核对 → T002 固定样本 → T003 编辑核心与测试 → T004/T005 画布与界面 → T006 保存恢复 → T007 浏览器实操 → T008 文档与提交。纯数据逻辑共用，避免为两类谱复制两套编辑器。

## 必要复杂度

显式片段用于保证删点后不自动跨缺口连线；统一位移限位用于保持联动形状与频率顺序；不可变初始结果和历史用于撤销与来源追溯。拒绝全局曲线平滑、直接改正式 calibration API 和新建后端表，因为它们不能满足本次隔离 Demo 的边界。
