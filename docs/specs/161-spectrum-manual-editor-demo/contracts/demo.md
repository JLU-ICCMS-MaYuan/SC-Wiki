# Demo 交互契约

不新增 HTTP API，不请求业务 API。唯一网络读取为本机静态页面、图片和开发资源。

- 保存：校验工作文档 → localStorage.setItem → 更新已保存状态及详情。失败保持编辑器和历史。
- 刷新：读取对应 schemaVersion + 示例 ID 的草稿；校验通过才恢复，否则提示且禁止静默覆盖。
- 未保存返回：继续编辑、保存调整、放弃修改；浏览器刷新使用 beforeunload。
- 未知幅值：使用像素相对刻度，人工填写物理尺度必须提供依据；不自动调用积分。
- 数值输入仅修改选中点，拖动按联动设置；一次操作对应一次历史。
- 标零频和补零点各是独立操作；标定变化使已确认零频选点失效。

## 连线与联动更新

人工补点连到同曲线的频率前后邻点，删除断边仍保留；再次补点只解除当前位置的断边。连线不插入数值数据。联动按两侧各5邻点明显变化、外侧指数衰减；不跨未连接边。旧草稿恢复只补充人工点标记，不清空或覆盖用户坐标。

## 本轮二维编辑契约

默认 free；幅值锁定模式仍可选。拖动保持描线顺序，不用相邻频率夹住点；补点位置原样保留，插在几何最近线段内或延伸开放端点。新增点可见两条相邻直线，但不能强制把用户点投影到旧直线或删除原点。旧错误连线由显式“重新连接人工补点”作局部相邻修正，可撤销，坐标不改，点击保存才持久化。

## 新增点与轴叠加契约

加点成功后保持加点工具、自动选择刚增加或替换的点。右侧坐标区优先展示；标记零线清除旧点选择并展示该线位置。刻度叠加是只读辅助层，显示当前标定、已有识别、独立λ参考与选中点投影；隐藏辅助层不删除标定或点，仍保留显式人工零线。

## 零频保存与检查

保存成功才返回详情并检查保存快照；不完整不阻止保存。未成功写入时保留编辑，不更新已保存检查结果。加载旧草稿重新检查，已有标零和补点证据无需重复确认。普通0点只提示候选；用户明确确认现有零线/点后才记录依据，且不改坐标。PhDOS检查全部分波，不随当前图层筛选省略其他分波。
