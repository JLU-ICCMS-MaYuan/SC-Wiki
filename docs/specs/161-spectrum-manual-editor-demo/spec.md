# Feature 规格：a2F 与声子 DOS 人工调整编辑器 Demo

**Issue**：[#161](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/161)
**创建日期**：2026-10-26
**实施基线**：用户明确要求实施已完整展示并再次贴出的五节方案；本文件将其转写为可追踪需求，不把方案授权记录为用户另行确认过本文件。

## 背景与目标

自动提取可能混入图例、累计 λ 和其他曲线，也可能漏掉零频和密集尖峰。提供基于来源图像的人工修订工具，先验证独立 Demo，再考虑正式数据库接入。

### 需求结论与变更取舍

采用最新编辑按钮入口，取代早期点击图片入口。一个 Feature 和共用编辑器覆盖两类谱。独立全屏 Demo，默认 X/Y 自由拖动的局部联动；按最后答复取消导出。保存仅是本机 Demo 草稿，不是数据库保存或科学采纳。

## 用户场景与验收

### US1：从详情进入并修正谱点（P1）

用户在任一谱详情点击编辑，放大密集点，选中并拖动或输入数值，删去误识别，补选漏点，保存后回到详情核验。
优先级理由：这是直接解决误识别的核心旅程。
独立验收：a2F 与 PhDOS 各完成一次增删改、保存、返回，图和表一致。

### US2：校正标定及零频位置（P1）

用户选择频率轴方向，用图上的两对刻度完成标定；标记真实零频线后另行在曲线上补点。
优先级理由：错误坐标会影响全部谱点。
独立验收：标定不移动像素；只标零频不消除缺失；未知幅值仍可相对编辑。

### US3：局部调整形状（P1）

用户拖动一个峰，同一连通曲线中两侧各 5 个邻点明显跟随、更远点指数衰减；可切换单点或二维模式。
优先级理由：避免逐点修复造成锯齿。
独立验收：中心点完全跟随、范围外和其他分波不变，频率不交叉，不跨缺口联动。

### US4：保留与恢复调整（P1）

用户可撤销、重做、恢复初始数据、保存本机草稿并在刷新后恢复；放弃未保存改动不影响此前保存结果。
优先级理由：防止误操作和试用数据丢失。
独立验收：各操作可往返恢复；存储异常保留编辑且提示错误。

### 边界与异常场景

- 图片加载失败：保留编辑草稿，提示重试，禁用图上选点而不伪造背景。
- 轴标定两点重合、非有限数值、零值跨度：拒绝应用并保留原标定。
- 修改坐标或二维拖动超出图框、频率顺序交叉：限制有效位移，不自动交换点身份。
- 删除中间点：形成显式断边；后续在该处人工补点时，按最新 FR-014 连接前后邻点。
- 当前曲线删空：仍可添加新点；无数据范围不能显示为零频达标。
- 存储被禁用、草稿损坏或版本不匹配：说明原因，不静默覆盖或误报保存成功。
- 未保存时返回、切换示例或刷新：给出退出保护；刷新使用浏览器原生未保存提示。
- 缺刻度、零频证据或积分边界依据：保持待核对；不自动批准科学数据。

## 功能需求

- **FR-001**：两类详情提供编辑按钮及独立全屏工作区，保留原有分区视觉。
- **FR-002**：保持来源比例和轴向；支持指针中心缩放、平移、适应窗口及固定屏幕点击范围。
- **FR-003**：每轴两点线性标定，支持频率横/纵轴、刻度、单位及零点位置，像素点不因标定改变。
- **FR-004**：未知幅值使用相对像素且标明待核对；a2F 不借用累计 λ 的标尺。
- **FR-005**：图表同步选点并查看数值、像素及修改状态；支持拖动、输入、增加、单点及框选删除。
- **FR-006**：删除保持显式断口；人工新增点按 FR-014 连接两侧邻点，联动不跨未连接边。
- **FR-007**：PhDOS 单条分波可编辑、其他仅参照；累计 λ 不进入 a2F 编辑对象。
- **FR-008**：默认按两侧各 5 个邻点为主要影响区，外侧指数衰减，极小影响截断；支持单点及二维模式，保留图框限位，拖动不重排描线顺序（FR-015）。
- **FR-009**：零频线标定与真实曲线零频点补选分开，不改首点标签、不补造零幅值，不自动批准积分或科学采纳。
- **FR-010**：全部数据修改支持撤销/重做，一次拖动为一个操作，保留不可变初始数据。
- **FR-011**：保存更新详情并持久化本机 Demo 草稿；刷新恢复、失败保留内容、未保存退出保护。
- **FR-012**：示例来源和人为错误注入可追溯；无导出、业务写入、AI 调用和正式部署。
- **FR-013**：内部草稿保留来源身份、尺寸、标定、稳定点 ID、像素坐标、片段和人工操作记录。

# a2F / PhDOS 人工调整交互 Demo

## 1. 目标与交付边界

先制作独立可操作 Demo，复刻现有详情页，在“02 · 原图与提取结果”标题旁新增“编辑”按钮，进入全屏编辑工作区。

本次覆盖坐标标定、点的增删修改、缩放选点、附近点联动及保存后预览。最终产品目标是将人工修订保存进 SC-Wiki 数据库；本次 Demo 使用本机草稿验证操作流程，不调用业务写入接口，不提供下载或导出按钮。

已确认的选择：

- 独立交互 Demo。
- 全屏编辑工作区。
- 默认联动调整幅值，另提供自由移动模式。
- a2F 与 PhDOS 共用编辑能力，分别提供示例。

## 2. 编辑交互

**工作区布局**

- 顶部：返回详情、撤销、重做、恢复原始提取、保存调整。
- 中央：保持原图比例的大图，默认叠加数据点和曲线。
- 右侧：曲线选择、坐标标定、选中点坐标、联动设置。
- 支持滚轮缩放、放大/缩小按钮、平移和适应窗口；缩放围绕鼠标位置，点的点击区域保持屏幕尺寸。

**坐标标定**

- 支持频率在横轴或纵轴，首版采用线性坐标。
- 每根轴通过两个图上位置及对应数值标定，支持调整刻度范围、单位与零点位置。
- 修改标定时保留数据点在原图上的位置，重新换算数值；不自动移动曲线去匹配新刻度。
- 幅值刻度未知时允许按相对像素编辑，明确显示“幅值刻度待核对”；α²F 不借用累计 λ 的刻度。

**点编辑**

- 点击选点，查看频率、幅值、像素位置与修改状态；图中选点与定高数据表同步。
- 支持拖动、输入坐标、点击原图增加点、删除单点及框选删除。
- 增加点归入当前曲线；删除区域保留缺口，不自动补点或跨缺口连线。
- PhDOS 可查看全部分波，每次只编辑一条明确选中的分波，其他分波作为参照。
- a2F 中累计 λ 仅作为原图参照，不参与目标曲线的编辑和联动。

**附近点联动**

- 默认开启“只改幅值”的局部联动，可关闭为单点编辑，也可切换为二维自由移动。
- 影响范围按频率距离设置，默认当前频率跨度的 5%；图上高亮将受影响的点。
- 使用平滑衰减权重：中心点完全跟随，距离越远移动越小，范围之外不变。
- 仅作用于同一曲线、同一连续片段；不跨缺口、不影响其他分波。
- 自由移动不得造成频率次序交叉或点移出图框；越界操作限制到有效范围。
- 一次拖动作为一次撤销操作，避免逐帧形成撤销记录。

## 3. 零频与保存语义

- 分开提供“标记原图真实 0 频率位置”和“在曲线上补选零频数据点”。
- 仅标定零频位置不能解除数据缺失提示；必须在当前曲线的真实位置补选或修正数据点。
- 不自动将第一个点改成零频，不自动补造零幅值；零频率不等于零幅值。
- 原图看不清或缺少幅值依据时保留待核对状态；人工编辑不自动代表科学采纳，也不自动开放 λ、ωlog 等积分结果。

Demo 保留不可变的初始提取数据和独立编辑草稿。“保存调整”更新 Demo 详情的叠加曲线、点表及实际频率范围，并保存本机草稿；刷新后可恢复。退出未保存编辑时提供继续编辑、保存和放弃操作。本机保存失败时保留编辑内容并显示错误。

内部草稿包含来源图标识与尺寸、曲线身份、标定、稳定点 ID、源像素坐标、连续片段及人工修改记录。两类谱共用该模型，为后续数据库接入保留明确的数据边界；本次不新增正式 API 或数据库表。

## 5. 验收标准

- 两种谱均能从详情按钮进入编辑器，保存后返回并显示修改结果。
- 放大密集尖峰后能准确选点；不同缩放和平移下，拖动与数值输入映射一致。
- 联动范围可视化，中心与邻点平滑移动，范围外、其他分波和缺口另一侧保持不变。
- 可删除图例误识别点、补选真实曲线点；删除后不自动填补缺口。
- 标定零频位置但未补选数据时，仍显示零频提取不完整。
