# 指定起点连续加点与积分说明验收

## 交互与数据

普通加点只接受单个已有起点，连续点击显式记录connectTo前驱；原边保留，不执行最近邻自动连接或多边形闭合。双击新位置只添加一次最后点并结束，双击当前末点直接结束；结束后普通点击不继续加点，不发保存请求。Escape/切工具保留已加点，逐点撤销/重做有效。删父点切断该处引用，其他子链继续保持。联动不穿过分叉扩散到其他支线。

正式保存/读取、数值点和CSV保留前驱；服务端拒绝不存在/自环/跨曲线前驱。公开限定频段移除父点时清除悬空边，不泄露或改接隐藏点。分支描线不是已经通过科学审核的单值谱。
