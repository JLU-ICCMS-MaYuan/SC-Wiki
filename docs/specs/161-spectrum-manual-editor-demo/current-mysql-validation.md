- 21项正式HTTP与MySQL测试全部通过：新运行持久化/会话重读、旧运行不变、409版本冲突、403权限拒绝、11种非法请求回滚、频率单位换算、其他曲线保留、公开过滤、零频确认/失效、CSV来源、返修身份重绑定。
- 两个线程/会话同时提交相同基础版本：一个200、一个409，只产生一个新运行；旧运行不变，集合版本只增加一次。
- 首轮20通过/1失败来自测试构造使用Python UTC，而MySQL DATETIME为本机SYSTEM时间。改为在数据库旧created_at上加一分钟构造新记录，复验通过；没有修改MySQL时区或生产算法。
