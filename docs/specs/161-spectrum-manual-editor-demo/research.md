# 设计依据与取舍

## 正式接入后的有效边界

用户已认可Demo并要求落地。正式实现位于 frontend/src/components/spectrumEditor，不从docs读取示例数据或本机Demo草稿；下文早期“只复刻隔离Demo”保留为历史取舍，由 production-plan.md 和 contracts/production.md 取代。

正式编辑文档由权限/版本受控接口构造。每条分波使用自己的标定，单次保存只替换该曲线，其他分波仍作为参照。新run复用现有JSON存储，不重新提取、不新增表。服务端换算数值并撤回旧积分、候选和采纳，零频记录只证明位置一致性。频率重复或回退的人工描线可以保存，但不能直接采纳为单值谱。

公开过滤移除内部编辑文档，限定频段保留断边。正式联动配置复制用户2/.3/1/.1，不触动Demo原文件。Demo草稿没有真实集合/版本身份，不自动迁入业务库。

- 正式详情入口在 frontend/src/pages/SpectrumDetailPage.tsx，图像面板在 SpectrumDetailView.tsx；本次只复刻隔离 Demo。
- SpectrumFigure.tsx 已使用 SVG 与来源像素保持比例。继续使用 SVG，便于精确选点和共享变换；不引入大型绘图库。
- PropertySpectrumPoint 的 frequency_pixel/amplitude_pixel 提供来源坐标；既有 calibration PUT 会重提取，不能拿来实现本次手动点保存。因此 Demo 不调用该接口。
- #137 首版明确不提供逐点编辑；#161 是新增能力，不改变 #137、#154、#155 的旧验收。
- α²F 既有样本 amplitude 标尺可能来自 λ；恢复像素只使用 snapshot.amplitude_pixel，绝不据此宣称 α²F 幅值已标定。Demo 初始幅值采用相对像素。
- PhDOS 使用同一真实来源图的固定示例点，构造图例误识别与零频缺失练习；并记录取点算法和注入位置，不能当作真实重新提取验收。
- 最新联动采用按邻点序号的核心区与指数尾部，见下方修订；不使用全局样条或整体平滑。
- 最新默认联动允许 X/Y 自由拖动；只改幅值作为可选模式，数值输入用于精确修改当前单点。
- 删除显式断边；人工补点按频率插入并连接两侧相邻点，不插值增加数值点。
- 本机存储仅用于 Demo 草稿；未来数据库契约另行设计。保留来源、原始结果、改后点和编辑记录，为后续设计提供实际样例。

## 本轮连线与联动修订

旧的“缺口补点单独成段”和“频率半径紧支撑权重”由 FR-014 至 FR-016 取代。点增加 manual 标记，后点 breakBefore 显式保存删除断口。相邻边连通条件为：没有 breakBefore，且同 segment 或任一端为人工补点。插入人工点时只解除其后邻点的该条断边；不改其他边。旧草稿通过初始样本点 ID 集识别新增点，已有 status 不可靠（拖动会改为人工调整），因此不只凭显示状态推断。

权重按点的序号距离 d：d≤5 时 w=1−0.08d，第五点为 0.6；d>5 时 w=0.6 exp(−(d−5)/2)。w<0.001 截断为零，即每侧最多 17 点。权重表只生成一次；拖动开始准备排序、邻接连通区和 ID 权重映射。每次移动复用快照，保持一次拖动一次撤销；SVG 每条路径一次生成，白色底线与彩线复用同一路径。不使用样条、空间树或全点对搜索。

## 二维与回折问题诊断及修订

只读获取 127.0.0.1:5187 的已保存 α²F 草稿（399点、43操作）；源 JSON SHA-256 见 free-drag-diagnosis.json。两个点击日志的 y 差0.06像素足以改变按频率排序的先后，这是回折原因。当前草稿已包含后续删改，局部复现明确使用点击日志坐标，不把历史截图冒充最终快照。

改为 Curve.pathOrdered 标明 points 数组是描线顺序；每点 breakBefore 显式描述前一条边是否断开。旧格式首次使用时按旧频率顺序冻结现有连接，不改数值；新增点比较到现有相连线段的投影距离与开放端点距离，端点优先处理外延，内部插入保持折线路径。仅点击时 O(n) 扫描，无全点对算法。拖动只受图框限位，沿描线而非频率排名联动；数值表可独立排序，重复/回退频率不当作已验证科学谱。旧错误连线通过显式可撤销“重新连接人工补点”修复；用户原始保存文件不改写。

实际草稿视觉复核排除了整段移除再插入人工点的方案，因其可能跨过相邻窄峰。最终显式重连只在人工点参与、频率像素差不超过0.5的相邻点对上，比较局部两侧总线长；仅在长度严格减少时交换，固定两遍 O(n)。不交换两个人工以外的原有点，不跨断口，不改变任何坐标。新点可插入最近的已连线段、相邻断口或延伸开放端点；只改变插入处的边。

## 已有识别与当前标定的事实来源

旧 SourceCanvas 均匀分5档显示频率，数字并非AI识别刻度。false-peak-fixture.json 保留频率刻度 [[435,0],[311,20],[188,40],[65,60]]。本Demo当前两点标定为435→0、65→60，两者中间可能有亚像素差，应并列显示而非互相覆盖。旧 amplitude_ticks 的0–4为原图累计λ轴，已在前轮判明不能代用α²F幅值，因此只画成有明确标签的λ参考。PhDOS与α²F同图使用共用频率轴识别；PhDOS幅值数字刻度无可核对记录，显示缺失。

参考坐标定义放独立只读JSON，记录文件与图像哈希；不改变 source 对象以免旧草稿校验失效。新点自动选中使用稳定ID；零频替换旧ID时按该点的源像素幅值位置查回，不能误选另一个分波的零点。辅助图层 pointer-events:none，渲染使用同一 SVG CTM；刻度数有限，无逐点轴搜索。

当前幅值轴放在图框上边，避免与原图底部累计λ刻度混淆；频率轴显示当前标定与已有识别两组位置，颜色与图例区分。测试发现 Chromium 指针事件的单精度位置经过逆矩阵后可产生约1.2e-5像素边界噪声；只对1e-4源像素以内的越界噪声夹回边框，0.01像素图外点击仍拒绝。该处理不移动已有点、不把近零历史数据改成零点。

## 手动调参入口

用户最新要求将5邻点改为3。参数集中在 demo/src/dragInfluence.ts：核心区 w=1−(1−edgeWeight)·d/coreNeighbors；外侧 w=edgeWeight·exp(−(d−coreNeighbors)/decayLength)。按 minWeight 生成有限权重表，不再硬编码数组长度，避免改参数后界面与实际行为不一致。

## 零频检查的完成条件

旧 zeroCovered 只能识别 pointIds，普通手动加到0的点不会成为确认记录；旧详情持续使用笼统提示。改为检查人是否显式确认零频位置、确认点是否仍存在且位于该线；数值近零不自动批准。直接复用 zero.pixel/pointIds，不增加服务端或“human_confirmed”字段。位置容差仅1e-4源像素（处理指针舍入），不能把0.01像素或更大的缺口当作已覆盖。各分波共享位置但各自确认数据点。候选点可明确确认，原坐标不变；结果从保存快照导出，不保存会过期的完成标记。

## 原图透明度入口

正式 SpectrumDetailView.tsx 保留“叠加强度”，独立Demo此前没有该控件。本轮按用户要求控制原图本身透明度，与既有曲线叠加强度区分。使用原生纵向range与SVG image opacity，不增加图像处理或点数据转换；共享页面状态避免进出编辑器丢失调节值。

## 遮挡与粗步幅原因

旧SourceCanvas initial使用固定源像素边距，而轴标题用固定屏幕字号，窗口/缩放变化会造成标题超出边缘；absolute工具栏、图例与底部说明还会覆盖图形。改为布局隔离，并按屏幕像素边距计算完整fit。旧按钮倍率1.35，改为1.05；滚轮灵敏度由0.0015降为0.00035，按delta累积而非固定档位，不人为制造突然跳变。详情早期 !editing 返回阻止了平移，改为先处理导航手势再限制点编辑。

视觉检查发现窄图窗中当前标定的横轴辅助标签可能互相挤压，因此按屏幕间距选择可读标签，优先保留零点、边界和中间值；已有识别刻度不省略。浏览器fit验收同时检查当前横轴标签不重叠。

## 加点与积分说明修订

用户要求显式选择前驱，取代普通加点的几何最近边插入。用connectTo表示分支边，保留旧点和旧边；不复制锚点、不用浮点坐标猜连接、不关闭多边形。用户双击解释为结束描线并保留工作副本，真正入库仍使用保存调整；已在实施说明中告知。

只读核对当前290 GPa α²F集合c340f3c41b144662808c0933d1e75248，版本11，零频pixel435已确认，幅值pixel[637,790]→[0,153]、amplitudeEvidence为空；旧α²F/λ标定候选均为0–4，不能据此证实α²F绝对尺度。服务端manual.save对人工谱统一停用旧积分，不会自动重算，必须如实说明实现边界。ωlog若只缺统一正倍率且频率、基线、完整性可靠，该倍率在归一化对数平均中抵消，不应宣称它一概需要绝对尺度。

## 吸附连接的表示

原connectTo表达新点到较早父点，不能拿它覆盖目标已有的父边，也不能添加重复节点来闭合。使用尾点joinTo引用任意同曲线既有ID，保留两端原坐标及所有旧边。已存在的无向边不重复添加，单个尾点已有不同终点时拒绝覆盖，需新开描线。只在当前曲线找最近点，8px屏幕半径，候选并列按已有稳定顺序选择；放大后自然缩小源像素搜索范围。环中联动使用visited保护，每点至多赋权一次，中心保持1。


## 主动重算决策依据

FR-050至054/SC-028至030：新增独立recalculate模块与POST /{collection_id}/recalculate。复用manual.current/assert_latest完成鉴权、行锁、材料及版本验证，来源是当前run.result_json；按稳定ID恢复显式连线图，只有一个无分支/无环的连续单值频率路径可进入积分。按频率方向遍历而不改动原始点数组，不跨缺口排序拼接。
复用spectral_integrals的分段线性精确积分；λ/ωlog状态独立，幅值依据来自当前manual_documents（优先）或初始calibration。相对谱依据须描述零基线及统一倍率，物理频率定义继续沿用已确认来源，不能由普通文本自动改变。DOS按各曲线自身网格积分，完整范围一致才合计；3N比较另检查原胞证据，不要求网格采样点完全一致。
结果写新SpectrumRun，copy原曲线/标定，quality记录每种谱的recalculation来源run/时间/操作者；新运行清除审核，不自动采纳。人工save既有quality重置行为自然使重算失效。公开受限频段过滤不得泄漏全谱结果。
前端页面持有忙碌锁和请求目标，POST成功replaceListing并导航新run/version；结果组件只展示服务端状态。零频详情compact模式仅一条摘要和未完成分波，编辑器维持原检查组件默认行为。删除仅详情的旧解释组件与逐点表。
