# 本机运行

在仓库根执行 `npm --prefix docs/specs/161-spectrum-manual-editor-demo/demo run dev`，打开输出的 127.0.0.1 地址。Demo 仅监听本机，不启动正式服务。

默认地址为 [人工调整 Demo](http://127.0.0.1:5187/)。端口已占用时启动失败，不自动切换到不明地址。可在命令后加 `-- --port 5188` 指定另一个本机端口。

运行依赖复用 `frontend/node_modules`。首次使用仓库时按前端既有方式安装依赖。

浏览器测试使用当前环境的 Playwright 和本机 Chrome；可通过 `CODEX_RUNTIME_NODE_MODULES` 指向包含 Playwright 的 node_modules，`PLAYWRIGHT_CHANNEL` 指定浏览器 channel，`SPECTRUM_DEMO_URL` 指向实际 Demo 地址。测试使用独立浏览器上下文，不读取或覆盖用户日常浏览器的草稿。

## 建议试用顺序

1. 点击“编辑”，默认进入原图叠加和 X/Y 自由移动。选中一个峰并拖动，观察橙色邻点随动。
2. 滚轮放大或使用按钮；右键、Alt 拖动或“平移”工具移动视口，“适应窗口”恢复。
3. 框选右下方演示图例误识别点，点击“删除选中点”；撤销可恢复。
4. 用“增加点”点选缺失区域；坐标输入只调整当前点，联动沿描线顺序作用于拖动，默认两侧各 3 个邻点明显变化，外侧指数衰减。
5. 先点“标记原图 0 频率位置”，在底部真实零频边界点击；再选“补选曲线零频点”，在对应曲线位置点击。只标线不会解除缺失提示。
6. 展开“坐标标定”，通过靶心按钮选择刻度位置并填写对应数值，点击“应用标定”。源像素保持不变，未应用标定会阻止保存并受退出保护。
7. 点击“保存调整”，回到详情并刷新，查看本机草稿是否保持。PhDOS 可切换 La/Sc/H，每次只编辑当前选中分波。

零频选点完成只记录人工依据，幅值、积分及科学采纳仍待核对。固定样例频率沿竖轴；编辑核心支持频率横轴，误把当前竖轴图改为横轴可能产生重复频率，需先核对原图，不能绕过数据校验。

`npm --prefix docs/specs/161-spectrum-manual-editor-demo/demo test` 运行逻辑测试；`npm --prefix docs/specs/161-spectrum-manual-editor-demo/demo run build` 执行类型检查和隔离构建；`npm --prefix docs/specs/161-spectrum-manual-editor-demo/demo run test:browser` 验证运行中的 Demo。

保存只写当前浏览器本机草稿，不写 SC-Wiki 数据库。调整原图定位不代表科学采纳。恢复原始提取可撤销；清除浏览器站点数据会删除 Demo 草稿。

## 本轮试用说明

人工补选点会自动连到同曲线前后邻点；只画折线，不插值补点。删除仍留下断口，再次补点才连接该处。已有本机草稿的人工散点（包括已拖动过的补点）恢复时自动补充连线标记，坐标不变，只有点击保存才写回。更新前请先保存当前未保存修改；无需清除浏览器数据。

## 二维移动与旧连线修正

默认“自由移动（X / Y）”允许两个方向移动，不再被相邻点的频率夹住；需要锁定频率时可选“只改幅值”。新点按图上的邻近线段或端点连接，不按频率强制重排。三点本身不共线时仍会保留正常折角，不会擅自把你的点击投影到直线上。

已保存草稿加载时保留现有点坐标和连线。若旧图有局部回折，点击“重新连接人工补点”；只调整局部相邻连线，可撤销，满意后再保存。没有符合条件的回折时会明确提示，无须恢复原始提取或清空草稿。描线可暂时含重复或回退频率，仍待科学核对，不据此开放积分。

## 坐标与零频核对

普通加点或零频补点成功后会自动选中，右侧顶部显示频率、幅值、原图像素X/Y，以及到当前标定零频线的像素距离。新增工具仍可连续使用，不必先切回选点。标记零频线后会显示标记位置、换算频率、已有识别零刻度及位置差。

图上“轴与刻度”按钮可隐藏/恢复辅助层：蓝色为当前标定（相对幅值轴在上方），灰色为已有识别频率刻度，棕色为累计λ参考，橙线为人工标记零频线。选中点投影与图像共用缩放平移。已有识别不因人工改标定或单位而被覆盖。PhDOS没有数字幅值识别记录，当前只用相对像素；α²F不能借用λ的0–4幅值尺度。

数字相符只说明标定一致，不代表原图零边界或科学数据已确认。显示功能不重提取、不清空本机草稿。

## 手动调整联动幅度

编辑 `demo/src/dragInfluence.ts` 顶部的 `DRAG_INFLUENCE`：`coreNeighbors` 是每侧主要邻点数（默认3）；`edgeWeight` 是最外核心邻点跟随比例（默认0.6，改0.3会减弱附近与尾部）；`decayLength` 是外侧指数衰减长度（默认2，改1收敛更快，改4更慢）；`minWeight` 是极小影响截断（默认0.001，增大后影响更局部）。选中点始终100%跟随。

先保存页面里未保存的选点，再保存代码文件并刷新 Demo。无需重提取或清空草稿；修改配置只影响之后的拖动。界面邻点数同步配置。参数合法范围见代码注释，错误值或过大范围会明确报错。

## 保存后查看零频检查

保存成功返回详情后，查看“零频位置核对”结果；PhDOS逐分波显示。未完成也会保存草稿，并提供继续核对按钮。若已有0点，不必删掉重画：先对照原图确认蓝色零频线，再确认选中的现有零点，保存后即可重新检查。原来通过图上标记和零频补点完成的记录无需重复操作。

移动、删除零点或修改标定会使相应结果在下次保存时重新判定。仅数值接近0不能自动通过，检查也不会自动改变点。调参方法已同步到 [Overview](../../overview/01_Decentralized_Uploading_of_Superconductivity_Data/spectrum-manual-editor-demo.md)。
