# 设计依据与取舍

1. 不能把公开papers改成rejected来显示返修按钮，否则现有搜索、统计与详情公开读取会下架旧批准版。选择派生workflow_status，列表及筛选一致，正式公开状态保持权威。
2. 不增加公开科学数据的第二份可修改副本。已有修订送审暂存与批准事务可以复用；首拒已批准稿需允许其他合法审核员作拒绝，随后归属严格沿原工作稿规则。
3. 标题溢出测量只观察自身尺寸，避免对整张表或科学表单全量扫描。
4. 检查页复用同一组件，个人页3条和独立页20条显式传参；底部分页置于滚动容器外。收录列表维持现有20条，此次3条只适用于检查区。
5. 权限错误按code识别，不按翻译后字符串去重，不隐藏不同错误。
6. 大纲用报告空间群，沿用#94事实来源；不从结构模型推测。界面折叠不入库，不改变字段核对。原本研究材料按名称分组的展示改为逐状态导航；研究材料汇总本身仍由原逻辑掌管。

公开匿名列表和非本人普通用户的行不读取私有交接状态；仅本人或管理员的私有行批量读取交接头。状态SQL用MAX事件ID定位，避免携带大JSON的filesort；实际1MiB快照与32KiB会话排序缓冲测试通过。
