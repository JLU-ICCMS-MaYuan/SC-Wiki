# 本地实现与验收

日期：2026-11-04。Issue：[#213](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/213)。

## 实现结果

六个已确认目标均已实现：仅拒绝触发返修、旧批准版持续公开；标题充分利用列宽且截断悬停全文；个人页检查区每页3篇无内部滚轮、独立区每页20篇并滚动分页；三角色收录贡献名称统一；失权一条警告且禁写；右侧可折叠材料大纲稳定定位。

公开数据继续由papers批准状态与当前科学图掌管，workflow_status只从交接头派生。没有新增数据库迁移或科学标准键；旧审核和批量接口不能下架批准稿，已进入交接的正式内容不能被普通PATCH覆盖。规范正文与当前工作稿由原服务持有，不创建第二套可修改科学值。

- 定向前端：4个文件20项通过，包含3/20分页、历史/待检查承接、拒绝、标题提示、删除前项后的大纲定位、压力更新及工作稿更新。
- 定向Python：29项通过；无MySQL时15项集成场景跳过，随后在隔离MySQL实跑，结果另列。
- 隔离MySQL：公开稿拒绝→作者修改→送审→再次拒绝→再次送审→批准，以及两会话RR并发共3项通过。仅测试预置当前审核结果，不调用模型，不代表论文科学内容已验收。旧公开标题、公开指针、冻结稿及私稿权限分别重读核对。
- Go新增实际请求回归通过；隔离MySQL以1MiB整稿快照及32KiB会话排序缓冲验证最新状态投影与筛选，拒绝/待审/批准不改变公开原稿，无filesort大JSON问题。

## 固定失败回放

1. 大纲四类完整宿主修改前4失败、修改后通过。
2. 仅把原有正式approved当处理状态，独立HEAD的真实Go私有筛选请求返回total=0；修复后已拒绝/待审/批准与私有返修入口一致，公开状态保持。
3. 新增SQL回归发现拒绝时若内容摘要不同，会覆盖旧公开快照指针；修复为已有公开引用仅在approve时切换，幂等及旧快照读取通过。
