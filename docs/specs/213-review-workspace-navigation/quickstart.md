# 使用与验收

1. 管理员列表找到已通过论文，点击审核小锤子，选择拒绝并确认；原上传者在用户中心按“已拒绝”筛选后进入“修改并重新提交”。旧公开内容持续；新版批准后切换。交接列表仅查看。
2. 两角色长标题占满标题列，缩窄时省略，悬停显示全文；三角色详情入口与收录列表名称一致。
3. 个人页检查区两页签各3条，通过底部分页查看；打开工作区承接当前页签，各20条，列表滚动、底部分页。
4. 交出后的旧编辑页只一条权限警告，不能写；其他错误不隐藏。
5. 五类入口通过右侧三角折叠/展开大纲并定位；修改压力标题更新，删除前项后跳转正确；窄屏及来源侧栏无遮挡。
6. 执行字段契约、表单门、变异门、受影响Vitest/Python/Go、生产构建和浏览器检查，记录实际边界。
