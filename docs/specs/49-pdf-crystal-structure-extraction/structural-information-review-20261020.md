## 核查结论

### 1. LaSc₂ 数据足够建模，错误在提取与保存流程

补充 PDF 第 8 页 Table S1 明确报告：300 GPa、Fddd，a=4.248 Å、b=6.845 Å、c=7.682 Å、α=β=γ=90°；La(8b)=(0,0,0.500)，Sc(16f)=(0,0.843,0)。这是完整的“晶格＋空间群＋独立 Wyckoff 位点”证据，可以对称展开。

本次用当前解析器从原 PDF 重新提取，得到有效 LaSc₂ 候选，惯用胞 24 个原子；同时得到 LaSc₂H₂₄ 的 27 原子派生候选。LaSc₂ 不依赖现有超导材料状态才能进行几何构造。它是不是主要研究对象，也不影响这些数据的真实性或保留价值。

实时读取原上传任务 `c16cc627a0c04dc8ad4289624d1da80a`，状态仍为 ready、revision=6，保存的仍是第 8／9 页及正文第 3 页的三条旧 blocked 候选。因此新截图中的错误提示来自旧草稿，并不代表当前解析器重新运行仍然提取不到晶胞。此前的代码修复没有自动改写该任务。

但只更新草稿也不足以满足本次需求：未分配区当前只显示参数、引句和分配控件，没有完整三维预览；正式 `structure_models` 又要求 `material_state_id` 非空，提交器只采集关联 `material_states[N]` 的 confirmed 候选。单独保留 PDF 附件不能代替可查询、可导出、可重新打开的结构模型。

### 2. Table S2 应保留八条几何参数观测，不能制造八份原子结构

补充 PDF 第 9 页 Table S2 报告 P6/mmm-LaSc₂H₂₄ 的晶格参数和 H–H 距离，没有原子坐标。表中的 a=b、c、单位、压力、Harmonic／Anharmonic 分组及每行 H–H 距离都应保留。

相同 300 GPa 的两条 S2 数据不能互相覆盖。Table S1 的 LaSc₂H₂₄ 又是 a=4.712 Å、c=3.236 Å，与 S2 两行都不同；不能仅凭化学式、空间群和压力相同，就把 S1 分数坐标复制到 S2 晶格并称为作者报告结构。

根据明确的 P6/mmm 常规六方设置，可提供 b=a、α=β=90°、γ=120° 的对称性派生说明；这些值须与表格直接打印值分开。即使六项晶胞参数都已具备，仍因没有原子位置而不能生成真实原子模型。Harmonic／Anharmonic 按原文保存，不仅凭该标签就自动指定 `structure_optimization=sscha`。

上一轮修复正确地阻止 S2 生成假完整模型，但当前结构提取器没有输出独立的晶格观测记录；领域提取契约还把晶格／坐标列为 `out_of_model_scope`。这些内容有审计或原文来源并不等于已经具备正式结构化存储、展示和导出。这个缺口必须补齐。

### 3. 只有材料／空间群描述的正文不应进入结构模型列表

正文第 3 页的相关引句说明 LaSc₂H₂₄、P6/mmm 和稳定压力，缺乏可构造晶胞与原子位置的数据。它可支持材料身份、空间群或研究结论等字段，不应仅因包含 `space group` 就生成一个“缺少晶胞”的结构候选。

旧规则先以空间群／晶格关键词触发，再统一检查六个晶胞参数，混淆了“发现真实结构数据”“数据足够建模”“提取失败”三种情况。当前代码已收紧模型候选触发条件，但尚未建立本次所需的结构资料分级与完整保存流程。

## 已明确的需求

1. 完整结构只要有可靠证据就可以建模、查看和导出；建模不能依赖是否已匹配现有材料状态。
2. 本文实际报告的伴随材料结构也应保留。LaSc₂ 不能因为不是主要超导对象而被自动排除。
3. 有价值的部分几何信息须结构化保存，即使不能生成原子模型，也可随论文保存、重开、核对和导出。
4. 不具备结构几何证据的描述不能进入结构模型列表；保留原文及其实际支持的字段。
5. 原文没有报告坐标与解析器没有读到坐标，必须使用不同原因与补救动作。
6. 原始数据、对称性派生结果、人工修改与模型采用状态保持可区分；不能用补猜坐标消除错误。
7. 元素搜索 La–Sc 时应能找到来源于该论文的 LaSc₂ 结构，即使它没有 Tc 记录。搜索结果清楚区分“论文提供的结构”与“已记录的超导性质”，不能为使它可检索而填造 Tc 或暗示它已被证实超导。

## 建议的分级处理

| 信息类别 | 进入条件 | 保存与展示目标 | 建模与导出 |
| --- | --- | --- | --- |
| 可建模结构 | 完整周期晶胞＋完整坐标，或明确空间群＋可展开独立位点 | 真实模型、原始证据、派生链、条件及确认状态 | 三维预览，具备条件时提供 CIF／POSCAR 及原胞／惯用胞 |
| 部分几何观测 | 明确晶格、体积、键长或其他几何量，但缺完整原子位置 | 逐来源行保留原值、单位、条件、缺失字段和原因 | 展示参数，结构化 JSON／CSV；不导出冒充完整原子结构的文件 |
| 材料描述证据 | 只有化学式、空间群、相名或研究描述 | 关联实际支持的字段，并保存排除结构候选的理由 | 不生成模型、不出现“结构校验失败” |
| 提取失败／冲突 | 原文存在数据，但列关系、字符、位点或占位无法可靠恢复 | 保留已识别内容和明确失败原因，提供原页核对／定向重提取 | 未通过校验前不生成可采用模型 |

这是处理分类，不要求用一个互斥枚举承担全部状态。几何可用性、状态关联和人工确认分别判断：允许“可建模＋未关联＋待确认”，也允许“晶格完整＋未报告坐标＋有价值的观测”。

## 建议的解析与 Agent 职责

1. **发现与定位**：以页、图表、表格行／单元格和正文块为定位单位，先识别结构资料，不按整页生成一个候选。
2. **逐项抽取**：读取表头、单位、合并单元格、跨页续表、材料、空间群、压力和原文近似分组，保留来源哈希及坐标；不可读与原文未报告分别标记。S2 的 Harmonic／Anharmonic 位于合并行组中，文字在视觉上居中；转换后的纯文本可把组名放在部分数值行之后，不能按组名出现先后顺序给后续行贴标签，必须核对表格区域、行分隔及组的实际覆盖范围。
3. **跨块关联**：仅依据明确表题、交叉引用或同一结构身份结合晶格和位点；保留关联证据。相同化学式／压力本身不足以授权拼接。
4. **几何验证**：代码检查必需字段、晶胞体积、坐标类型、占位、多重性、化学计量及来源一致性；ASE／pymatgen 构造与重新读取。模型输出的置信度不能替代这些检查。
5. **覆盖核对**：每个实质结构表行必须有观测或明确排除／失败记录。S2 验收要求 8 行全部保留，300 GPa 两种近似不串行；有疑点的行不能当作已成功覆盖。
6. **版本与补救**：修复解析器后展示旧草稿解析版本与重解析差异；优先复用可用文本／表格和原 PDF，必要时由 #136 的互补工具补强局部，不默认重跑全文、调用模型或覆盖人工确认。

现有职责继续复用：#49 承接结构资料与模型；#114／#122 提供来源和覆盖契约；#136 提供文档布局与局部补强；#139 的条件关联负责相应条件证据，但不把晶格值硬塞入 Tc 参数。

## 数据保存与界面：根据明确使用目标提出的设计

推荐建立论文 revision 下的“结构资料集合”，材料状态关联可选。集合包含完整结构与部分几何观测，已关联状态可展示同一来源引用；未关联或伴随材料仍可以单独核对、保存、预览及导出。确认保存结构与采用为某状态规范几何是两个动作。

这样可继续保持“每个材料状态一份当前规范几何”的既有约束，而不通过创建虚假的主要研究状态来保留 LaSc₂。来源归属已明确是本文，只是尚未关联现有材料状态，界面应表达这一区别。

另一方案是给 LaSc₂ 自动新增材料状态。当前研究材料由全部状态汇总，采用这一方案会改变论文研究材料展示及后续统计语义；而且单纯新增状态仍不能解决只查 Tc 的搜索限制。用户已经明确不需要决定内部存储办法，关心的是搜得到结构及来源。因而由工程方案负责实现这个目标；“论文结构资料集合、材料状态关联可选”仍是拟议实现，最终 Spec 评审前不冒充用户已批准的数据库模型。

确认数据归属后，再细化以下交互：完整结构列表有“查看模型／下载／保存”入口，状态关联是可选操作；部分几何观测按材料、原文近似和压力分组展示，缺坐标说明清晰可见；材料描述不出现在结构列表；被排除或旧版本的依据仍可追溯。

还需在正式 Spec 中明确：未人工确认资料的保存层级及公开条件、部分观测与已采用几何的引用关系、删除状态后的资料保留、返修／revision 复制、权限和完整导出、来源变更与人工值保护。这些不在当前尚未确认的草案中冒充已落地设计。

### 搜索必须包含无 Tc 的结构资料

实查 `goserver/handlers/papers.go` 的 `SearchRecords`／`approvedRecordSearchQuery`，当前以 `property_records` 为主体，要求 `property_code=tc` 并关联材料状态；没有 Tc 的 LaSc₂ 不会自然进入结果。不能只保存模型就宣称元素搜索已经满足。

拟议用户体验是在现有元素搜索页直接展示“相关结构资料”结果，保留原 Tc 记录列表，结构查询本身不要求存在 Tc。LaSc₂ 条目至少显示化学式、Fddd、300 GPa、完整／部分几何状态、来源论文标题与 DOI、原文页码／表号，并提供模型与文件入口。条目根据 LaSc₂ 自身元素组成匹配 La–Sc，不能仅因为论文主材料 LaSc₂H₂₄ 含 La／Sc 就把整篇论文的所有结构一并挂到二元结果。

精确、组合、包含三种元素模式复用既有语义；在二元精确模式下，LaSc₂ 可命中，LaSc₂H₂₄ 不能误入。结构缺少 Tc 时保持缺失值，不写成 0 K，也不进入 Tc 统计图。Tc 数值和代表点筛选对 Tc 列表生效，不能在没有明确说明时让独立结构资料悄悄消失；对应说明和各类结果数量须在实现契约中明确。

公开结构搜索继续遵守论文当前已批准版本的可见性，待审资料只走原有上传者／审核者权限。修改、排除和返修后，结构检索结果与缓存同步反映当前有效来源，不展示已失效版本冒充当前事实。

### 拟新增功能需求（待最终草案确认）

- **FR-024**：完整、有效的结构在未关联材料状态时也须支持模型预览和结构文件导出。
- **FR-025**：论文实际报告的伴随结构须能确认保留、随论文保存和提交后重开；不得因为非主要研究对象或缺少 Tc 而丢失。

- **FR-030**：既有元素搜索入口须提供无 Tc 的结构资料结果，按该资料自身化学组成匹配，显示模型、条件和来源论文；不得填造 Tc、暗示已证实超导或纳入 Tc 曲线。
