# 结构资料保存与检索实施基线

用户在完整三类处理及“元素搜索找到 LaSc₂ 并显示论文来源”的说明后回复“开始”。本轮按这些明确目标实施，不再要求用户选择内部表结构。

## 设计与契约

- 新增论文 revision 下的结构资料记录：稳定来源键、材料化学式及元素集合、压力、空间群、资料类型、保留决定、来源和内容。完整几何保留既有候选及派生表示；部分观测保存晶格、原文近似与键长。可选材料状态引用不作为资料保存前提。
- 资料确认保留与采用为状态规范几何分离；继续保持每状态一份规范几何。没有 Tc 不创建假 Tc，不将伴随结构冒充已证实超导体。
- 资料随正式科学草稿在同一事务保存；读取、修改、返修保留当前 revision 的资料及决定。公开查询仅返回当前已批准 revision 中确认保留的记录。
- 元素查询使用资料自身元素集合，复用精确、包含与组合语义。按压力／年份／关键词过滤，单独分页；Tc 和图表筛选只影响既有 Tc 区域，页面明确说明。
- 重提取只读原始附件、校验摘要并返回差异预览；应用发生在编辑器内，用户保存主表单后持久化。已确认或人工编辑的旧资料保留，不自动删除或覆盖。
- S2 抽取按表格行和几何分组；原文没有坐标时记录 not_reported，不生成原子结构。正文描述不生成资料记录，原始证据仍保留。
