# 进度接口契约
summary、jobs、submit-check的请求增加可选progress_id（32位十六进制）；原响应和科学校验保持。无标识的调用不写进度状态。
GET /api/rag/evidence/preparations/{progress_id}：当前认证用户命名空间内读取{percent,cancelled}，不存在返回404；非法ID返回422。不返回科学内容。
DELETE 同一路径：原子记录取消，即使请求尚未注册也保留墓碑。返回cancelled。取消只终止对应准备请求后续动作，已完成科学结果不删除。
准备写入阶段边界检查取消；排队前、排队后都检查，竞态创建的任务立刻按既有cancel_job清理，不能因前端关闭自动提交。
前端每秒最多一次状态查询、单次不重叠；查询未注册/暂时失败保留最后进度，主请求错误决定失败。主请求结束即停止查询。
运行身份阻止迟到响应、完成提示和finally关闭覆盖后续运行。技术失败可重试，重试从0开始。旧客户端兼容不影响真实科学规则。

准备请求最长等待1800秒，超时按取消处理；任务状态GET使用原任务截止时间和AbortSignal，取消或离页可立即终止浏览器等待。完成态立即填满进度条并停留400毫秒，避免动画未结束即关闭。
