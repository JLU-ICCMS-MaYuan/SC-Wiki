# 实施计划：晶系未知联动

**Issue**：[#105](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/105)；**日期**：2026-09-17；**规格**：[spec.md](spec.md)

## 技术上下文

- React 19、MUI 7、TypeScript 5.6；两入口共用 `frontend/src/components/MaterialStatesEditor.tsx`。
- 现有 Python 上传归一化、科学数据重写与 MySQL 字段；不迁移，不新增 API。
- Vitest/Testing Library、Chromium 浏览器、pytest 与隔离 SQLite 验证。

## 实现方式与职责

在共享组件中增加晶系选择处理器，用一次完整状态更新同时写三字段。
普通选择由 Select 的 onChange 处理；值未变化的“未知”菜单项额外处理激活事件，避免 MUI 不发出 onChange。
仍使用最新 `statesRef`、统一 `emitStates` 和现有只读保护，实际改变的字段由现有核对通知识别。
空间群控件保持受控同步，验证本地文本与失焦提交不能复活旧值。

生产者为用户选择事件，事实来源为当前材料状态，消费者为两个宿主的现有保存接口和核对流程。
上传归一化对空符号不产生群号，科学保存保留显式 null；先测试这一边界，只有发现违反契约时才修改对应保存代码。
不把“unknown 总是清空”放入服务端归一化，避免破坏解析时由合法群号推导晶系的既有规则。
