# 功能规格：晶系设为未知时同步清空空间群

**GitHub Issue**：[#105](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/105)

**创建日期**：2026-09-17

## 背景与目标

选择晶系“未知”后，空间群符号与编号目前仍会残留，保存时还可能据此重新推导晶系。
用户需要用一次选择表达“当前材料状态的晶系和报告空间群均未知”。

## 用户场景与验收

### US1：清空当前状态的晶体分类（P1）

上传者和管理员均可通过选择晶系“未知”同时清空报告空间群，无需分别删除两个字段。
优先级理由：消除互相矛盾的表单值。独立验收：两入口选择、保存、重新加载后均保持未知。

1. 假如当前状态为立方、Fm-3m、225，当选择未知，那么晶系显示未知，空间群符号和编号为空。
2. 假如晶系已为未知但仍有空间群，当再次选择未知，那么空间群仍会清空。
3. 假如符号输入框刚输入了文本，当选择未知、失焦、保存和重新加载，那么旧文本不回填。
4. 假如有多个材料状态，当清空其中一个，那么其他状态、物性与结构附件保持不变。

### 边界与异常

- 鼠标和键盘均能选择；只读页面不改数据。
- 再选有效标准符号或填写合法群号，按原规则联动晶系与另外一个空间群字段。
- 保存失败保留当前编辑，沿用现有错误提示与重试行为。
- 打开历史记录不自动清理；选择其他已知晶系的既有行为不变。

## 功能需求

- **FR-001**：上传草稿和审核编辑中，选择未知必须同时清空当前状态的空间群符号及编号。
- **FR-002**：已为未知时再次选择也必须生效，鼠标及键盘行为一致。
- **FR-003**：清空值必须参与保存，失焦及重新加载不得恢复旧值。
- **FR-004**：不得自动修改其他材料状态、结构附件、物性记录或打开时的历史内容；只读不修改。
- **FR-005**：后续明确输入有效空间群时，继续保留原有正向联动。
- **FR-006**：审核必须识别实际字段变化，不能把旧值的确认自动认定为新值的确认。

## 关键实体

材料状态承载晶系和报告空间群，仍以现有稳定键定位；结构附件的空间群为独立事实，不属于清空对象。

## 成功标准

- **SC-001**：两入口的选择、保存和重新加载场景全部通过，三字段保持一致。
- **SC-002**：重复选择、键盘、失焦、多状态隔离、只读及正向联动回归全部通过。
- **SC-003**：相关核对回归、类型检查和生产构建通过，验证不修改真实论文 #29。

## 假设与依赖

- 沿用 [#53](../53-upload-form-refinements/spec.md) 正向联动和 [#103](../103-property-evidence-review/spec.md) 核对流程；无新增父子 Issue。
- 空的空间群表示未知，不使用 0 或“未知”字符串代替空编号。

## 范围外

不做历史批量清理、数据库迁移、结构附件对称性修改或新接口，不更改非未知晶系之间切换的规则。
