## 用户场景与验收

### US1：独立生成论文向量（P1）

用户从受控客户端调用服务器，为中文问题和英文论文生成向量，无需百炼凭据。

**优先级理由**：独立调用是本次部署的直接价值。

**独立验收**：实际 GPU 推理，单条、批量、2560/1536 维、中文问题检索英文片段冒烟。

1. 假如服务已启动，当有效客户端提交中英文文本，那么按输入顺序返回对应向量。
2. 假如请求缺少有效密钥，那么受保护的接口拒绝访问。
3. 假如服务重启，那么重新加载相同权重并恢复调用。
4. 假如 SSH 通道可用，那么外部客户端可通过该通道调用相同接口。

### US2：本地与阿里云复用固定外部接口（P1）

用户先在本地测试，以后正式部署的阿里云 SC-Wiki 使用同一台 4090 的固定映射接口。

**独立验收**：从机器外通过 HTTPS 和访问密钥调用所选模型；后续阿里云接入沿用同一服务，不将未来接入写成已经完成。

**验收场景**：假如平台已提供固定映射，当本地客户端通过 HTTPS 和密钥调用，那么由这台 4090 完成推理；请求不发送给百炼。

### 边界与异常场景

- 模型名错误、空输入或非法维度不得返回伪成功；错误不输出密钥。
- 超长请求按运行时长度上限拒绝，不以静默裁剪冒充完整编码。
- 初期限制并发和最大长度，为 24GB 显存留余量；启动失败不回退到付费 API。
- SSH 网关不支持转发时，记录平台端口映射依赖，外部访问验收保持未完成。

## 需求

- **FR-001**：仅运行所选 Qwen3-Embedding-4B，并可追溯权重、依赖、启动源码身份。
- **FR-002**：提供可重复调用的单条和批量向量接口，返回稳定索引和有效向量。
- **FR-003**：支持原生 2560 维及至少 1536 维输出，缩短后重新归一化。
- **FR-004**：访问受密钥及受控网络通道保护，凭据不提交到 Git。
- **FR-005**：服务在退出 SSH 后继续运行，异常后自动恢复，并提供启停和日志方法。
- **FR-006**：交付外部调用方法和实际验证结果，不将独立部署写成网站已切换。

- **FR-007**：外部映射入口必须使用 HTTPS、密钥和嵌入接口路径限制；先供本地验证，后续可供阿里云使用，原生推理端口不直接暴露到公网。

## 成功标准

- **SC-001**：真实 GPU 下三条固定中英文输入返回三个对应向量，维度正确、数值有限、L2 范数接近 1。
- **SC-002**：无密钥和错误密钥请求均被拒绝；记录实测状态码。
- **SC-003**：固定中文问题对相关英文片段的相似度高于无关片段；仅证明冒烟场景，不等于全库质量验收。
- **SC-004**：重启后健康与向量调用恢复；记录服务自启配置、常驻显存和响应延迟，不预设未经测试的吞吐承诺。
- **SC-005**：至少一个机器外客户端完成真实调用，或明确列出平台网络阻塞并保持对应验收未完成。

- **SC-006**：外部入口证书验证开启，未授权请求和非嵌入路由被拒绝；记录地址、端口映射和适用消费者，不将本地验证等同于阿里云上线。
