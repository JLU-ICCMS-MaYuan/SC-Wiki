# 数据与制品所有权

本服务没有业务数据库、文献库或向量索引。所有权如下：

| 数据 | 所有者 | 持久化及约束 |
| --- | --- | --- |
| 固定模型清单 | 仓库部署材料 | HF 仓库、revision、各文件大小与 Git/LFS 哈希 |
| 模型权重 | 服务器用户 | /home/singeuser/qwen3-embedding/model，仅校验通过后启动 |
| Python 环境 | 服务器用户 | 独立 .venv，安装后 freeze |
| 访问密钥 | 部署用户 | config.env 0600；不进入 Git、Issue、日志或命令行 |
| 启动配置与版本 | 仓库及部署实例 | 源码 SHA/哈希、模型身份及依赖 freeze 可交叉检查 |
| 请求文本与输出 | 调用者 | 不落业务库；禁用访问/请求内容日志，调用者决定后续存储 |
| 原有 Qdrant 数据 | SC-Wiki 业务实例 | 接入时只读导出，原集合保留；新模型写入独立集合，核验后切换本地配置 |

最新接入授权后，本地原集合 `paper_chunks` 作为只读迁移来源，保存原始 ID、payload 和向量到权限 0600 的私有备份；新模型写入独立命名集合。切换只更改本地配置的物理主集合，源集合不删除、不更新。重建工具逐条校验 payload 和 ID，并比较源集合前后摘要，发现源变化或模型失败时不切换。这里不改变科学数据实体、字段或审核状态。
