# 界面与接口契约：统一拒绝返修流程，保持旧批准版公开

## 用户可见行为

- 返修统一由合法管理员选择“拒绝”触发，移除交接记录与快照中的独立返修按钮及写接口。
- 原上传者只能从当前归属允许的已拒绝论文进入长期返修稿，送审后恢复只读；自审与越权继续禁止。
- 拒绝、修改、重新送审及再次拒绝期间，旧批准版继续公开；新版合法批准入库后才在事务中切换公开科学图与批准引用。
- 私有列表、筛选及返修能力使用相同工作稿处理状态，普通PATCH及旧审核接口不能绕过交接改写公开内容。

## 事实来源与约束

papers的批准状态和当前科学图决定公开版；最新handoff.holder仅派生私有workflow_status；PaperRevisionDraft/ScientificReviewDraft持有工作稿，正式快照不可变。

## 实现边界

沿用review-commit，在论文行锁内执行拒绝交接并建立作者返修稿；私有列表批量投影交接头，SQL用MAX事件ID定位，公开查询不引入无关私有读取；批准事务才替换公开图。
此处记录原实现契约，没有新增接口或数据结构。与其他子项共用的接口参数、组件及返回值继续由原代码掌管；本项范围外行为见spec.md。

## 验证对应

FR-001～FR-004对应US1与SC-001/002，实际案例及原运行边界见[验收记录](../validation.md)。
