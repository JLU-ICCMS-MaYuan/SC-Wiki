# 使用与复查：统一拒绝返修流程，保持旧批准版公开

## 操作与预期

1. 已批准稿被其他合法审核员拒绝后，原上传者在“已拒绝”找到返修，公开值保持。
2. 修改→送审→再次拒绝→再次送审期间旧版不变；新版批准后切换，旧快照仍可读。
3. 自审、旧周期写入、重复请求及事务失败不越权、不重复交接、不丢稿。

## 复查既有证据

1. 阅读[本项验收](validation.md)和[证据清单](assets/evidence.json)，核对本项案例及代码范围。
2. 必要时按plan.md列出的真实测试文件和validation.md的案例筛选进行复测；MySQL仅使用显式隔离库。
3. 阅读[共用验收](../213-review-workspace-navigation/validation.md)中的已知失败和发布边界，不能把历史通过记录当成本轮新运行。
4. 本地文档未推送，Issue保持开放；不据本说明操作业务数据或发布环境。

## 复查本轮单条跟踪

1. 管理员或超级管理员拒绝同一论文；当前记录显示已拒绝，作者可返修。
2. 作者重新提交；已检查／已拒绝列表不再保留这篇，待检查仅有一条，筛选及总数一致。
3. 再次拒绝、送审与批准，仍只跟踪同一论文ID；原拒绝意见在文章内部交接历史可查。
4. 作者与审核员详情显示当前状态，旧批准版继续展示时有明确说明；公开访客仍看批准版。
5. 详情底部不再显示独立的化学式和关键词卡片；各材料状态和正式关键词数据保持。
