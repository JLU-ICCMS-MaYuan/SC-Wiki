# 依据与取舍

#205仅提供工具名称，模型猜figure_id；实际inspect_figure要求block_id且只返回IR块。review适配器将来源窗口建立为paragraph，不能宣称具备figure块读取。本轮隔离验证漏传manifest，既有read_original_page未启用，生产功能是否可用不能由该遗漏推出。

采用现有只读工具的严格函数参数限制，最终科学结果继续沿原协议，不重写整个审核结构。工具定义与本地执行匹配；无实际图块时不暴露inspect_figure。真实图像复用read_original_page，不能将文本页读取标成看图。

原生工具调用必须带回接口返回的调用编号与对应结果，而不只是把观察结果塞进新提示。初次真测重复读图后补齐标准回执，最终两次调用完成。只保留最近一次工具调用/返回配对，已读取来源仍由既有目录维护，避免无限累积历史。

模型文本不能伪造内部_tool_call回执；本地结构门拒绝未知参数或工具，不额外调用模型纠错。PDF原页不存在或文件完整性错误仍失败；没有文字块的真实PDF页可以返回图像，但不会伪造文字来源。
