## 实现

image_catalog.py集中选择当前原始块和完整图片对象。当前选择之外的块及图表派生事实继续留在IR；图片入口仅登记当前原始内容。同页父表bbox完整包含单元格且父表入口可用时共用整表入口；孤立、越界或父表不可用的单元格保留。按TableIR/parent_block_id建立索引，避免逐单元格重复扫描整份表。

图片反馈目录和严格read_complete_object枚举使用同一集合。原文/OCR回执按当前原始块选择，PDF真实文字层保持。reader.source_context_version=current-original-context-v2及动作缓存身份防止复用旧原文回执；旧状态格式、历史回执和区域定位保留。文件/块身份、全文、图片、科学值、工具能力、科学字段及96000预算均未改，未新增模型核对或人工步骤。
