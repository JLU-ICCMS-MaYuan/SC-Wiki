# 工具与来源契约：以可定位证据驱动同一主模型自动重读和修复

依据：[Spec](../spec.md)与[数据模型](../data-model.md)；本契约是未来实现约定，不宣称现已注册新工具。

## 可定位反馈

输入：当前回执/来源/区域/元素身份、具体问题、原因代码、动作、参数、核验条件。输出：实际执行的方法、原/新图像关联、观察/计算变化、新证据、仍未解决原因。身份及错误码由程序登记，模型不能临时生成可执行命令。

## 原因与动作示例

| 原因 | 可核验事实 | 可选择动作 |
| --- | --- | --- |
| 柱边未找到 | 指定柱内部采样为背景/追踪失败 | 包含标签/基线的局部重裁、重新定位/追踪 |
| 刻度标定存疑 | 刻度位置/值不一致或残差与精度不符 | 单独读刻度、回完整轴、OCR或原图重新检查 |
| 系列不明确 | 图例文字/颜色与元素无法唯一对应 | 取得完整图例与目标区域并重新解释 |
| 数据越界 | 数据位置确实在声明轴范围外 | 重查轴与位置，无法标定保留未读；不外推 |
| 图文分歧 | 同材料同条件的量存在不一致来源 | 补读正文/SI，区分概述/详细点并保留真实冲突 |

代码命名在实现的统一协议中登记，表中并不规定主观阈值。末刻度不在框端不自动错误；两点拟合残差为零不构成独立准确证据。

## 退出与恢复

有新依据继续；无进展不原样重复，按已有动作预算处理；原来源确无足够信息则保留缺失结论。技术服务故障复用#224有限重试与暂停；原用户恢复时仍沿原模型和原来源。不能把预算/服务错误改写成论文未报告。

## 写入边界

反馈只修订观察/候选。正式科学写入沿既有填写、来源校验、字段核对及版本事务；人工最终审核权限继续存在，自动读图修复不额外增加强制人工逐图环节。
