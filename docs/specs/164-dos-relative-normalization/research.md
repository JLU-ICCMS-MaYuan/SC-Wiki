# 研究与设计决策

- 当前 recalculate.dos_integrals 在积分前检查绝对单位；保留其绝对模式检查语义，新增独立 calculate_dos 供重算和首次提取共用，避免 α²F 变化。
- 既有v4相对路径复用 relative.pixel_curve 的零基线换算，并主动去掉纵轴倍率；原始点不写回，频率已规范THz。本轮已认可的后续修订改为优先使用当前可信纵轴标定，任意单位照常按刻度积分，无可用刻度时才复用像素路径。原始绝对密度积分继续沿原单位独立处理。
- 每条曲线先按所选幅值依据求有序样本和梯形面积。总量条件失败不丢独立面积；面积占比仅共同比例且完整集合可用。
- 原胞 N 继续使用 context.primitive_for 的结构证据；元素比例优先当前 material 的可解析化学式，缺少化学式时使用结构计数，不推导原胞 N。化学式无法明确解析则不可用。
- 标准投影沿用 physical_definition_confirmed；按用户最新要求删除 frequency_range_confirmed 和高频边界记录的检查，仅保留独立的已记录裁峰检查。旧标定在模型输入时丢弃退休字段，其余未知字段仍拒绝；新存储不再生成该字段，不批量迁移旧数据。
- 归一化按每条曲线自身网格，不插值跨缺口。候选单独记录 curves，包含每条 frequency_thz、幅值基线依据和模式密度；保留共同系数及结构依据，不生成无依据的合成点。
- 历史记录通过方法版本区分；旧绝对结果仍显示，旧候选不冒充本次计算。手动保存的 invalidate_derived 已清空 quality/candidates。
- 公开访问只保留已完整采纳曲线的独立面积；只要存在隐藏或限定频段分波，就移除全部依赖总量的占比、归一化和旧归一化质量结果。
- 不采用分别归一化元素、按频率全局排序、未经证据的插值补齐或默认猜测完整频段。

- 面积比例比较选取化学计量最小且面积为正的元素为共同参考（同计量按元素名排序），参考元素归一为1；零面积元素保留0。接近程度使用与参考元素无关的最大占比差（百分点）。化学式与结构冲突时比例明确以化学式展示，3N 归一化仍阻断。

- 方法更新为 dos-relative-v2、重算版本同步升级；旧方法报告提示重新计算，以免数据库保存的旧 reason 继续展示。CSV 兼容读取两版相同的候选结构。

## TDOS 独立路径

仅 projection 明确为 total（兼容 TDOS）且标准物理定义已确认的单条声子谱，才能跳过元素门槛。单线数量和 ID 含 total 均不构成来源证据。discovery 提示明确要求依据图注/坐标识别总谱，不能把缺失分波当总谱。总谱不需要跨曲线尺度比较，但仍需要频率标定、幅值零基线、正有限面积与可信 N。总谱和分波混合、隐藏提取失败仍阻断。元素与结构计数一致性保持原约束。

TDOS 的 shares 不提供百分比或元素比，normalization 单独可用；UI 根据服务器 spectrum_type 显示总谱并隐藏逐元素归一化表。独立绝对积分对已确认 TDOS 同样免除元素条件，但仍要求原始绝对单位和原有每原胞比较依据。新报告采用 dos-relative-v4，避免旧失败提示继续充当当前规则；历史记录保持原样。

## 纵轴刻度优先的取舍（已确认，待实施）

刻度已存在却统一退回像素，不影响同一线性倍率下的最终归一化形状，但让来源数值积分缺席。后续优先沿用当前有效标定及已保存样本；人工修改标定后使用当前值，不回退到旧识别刻度。只有没有可用纵轴刻度时才使用距零基线的像素高度。面积沿真实连线积分，不重画曲线，不用单位是否为绝对密度作为一般数值积分的通行条件。

任意单位·THz可显示为来源积分，其物理幅值尺度仍未知；确认标准TDOS和可信N后，可另给3N归一化候选。真正的绝对密度刻度继续独立积分并按已有条件比较3N，不强制改成21。共同尺度和数据可见性规则保留，防止混合单位相加。

固定描线示例在原标定下积分6.308648445665745，C=3.32876370919475；像素面积2596.0318316798316，C=0.008089269069713752。两种归一化谱点最大绝对差8.881784197001252e-16，仅验证同一描线的倍率等价，不证明描线准确。
