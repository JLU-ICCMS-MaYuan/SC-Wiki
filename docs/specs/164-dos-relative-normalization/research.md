# 研究与设计决策

- 当前 recalculate.dos_integrals 在积分前检查绝对单位；保留其绝对模式检查语义，新增独立 calculate_dos 供重算和首次提取共用，避免 α²F 变化。
- 相对像素复用 relative.pixel_curve 的零基线换算；原始点不写回。坐标已规范 THz，不二次转换。绝对密度沿原始单位积分。
- 每条曲线先求有序样本和梯形面积。总量条件失败不丢独立面积；面积占比仅共同比例且完整集合可用。
- 原胞 N 继续使用 context.primitive_for 的结构证据；元素比例优先当前 material 的可解析化学式，缺少化学式时使用结构计数，不推导原胞 N。化学式无法明确解析则不可用。
- 标准投影沿用 physical_definition_confirmed；按用户最新要求删除 frequency_range_confirmed 和高频边界记录的检查，仅保留独立的已记录裁峰检查。旧标定在模型输入时丢弃退休字段，其余未知字段仍拒绝；新存储不再生成该字段，不批量迁移旧数据。
- 归一化按每条曲线自身网格，不插值跨缺口。候选单独记录 curves，包含每条 frequency_thz、幅值基线依据和模式密度；保留共同系数及结构依据，不生成无依据的合成点。
- 历史记录通过方法版本区分；旧绝对结果仍显示，旧候选不冒充本次计算。手动保存的 invalidate_derived 已清空 quality/candidates。
- 公开访问只保留已完整采纳曲线的独立面积；只要存在隐藏或限定频段分波，就移除全部依赖总量的占比、归一化和旧归一化质量结果。
- 不采用分别归一化元素、按频率全局排序、未经证据的插值补齐或默认猜测完整频段。

- 面积比例比较选取化学计量最小且面积为正的元素为共同参考（同计量按元素名排序），参考元素归一为1；零面积元素保留0。接近程度使用与参考元素无关的最大占比差（百分点）。化学式与结构冲突时比例明确以化学式展示，3N 归一化仍阻断。

- 方法更新为 dos-relative-v2、重算版本同步升级；旧方法报告提示重新计算，以免数据库保存的旧 reason 继续展示。CSV 兼容读取两版相同的候选结构。
