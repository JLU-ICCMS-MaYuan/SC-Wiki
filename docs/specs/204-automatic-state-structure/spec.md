## 已审定目标

模型联读原PDF正文、SI、表头、结构表、压力和结构优化方法，判断结构所属材料状态；程序校验原文定位、完整几何及每卡一份规范结构。依据充分、归属唯一且没有覆盖冲突时自动填入S.structure，继续原有字段核对和提交审核。

分别识别静态、准简谐、SSCHA结构优化；同材料同压力不同真实几何分别建卡。同一几何的原胞/惯用胞、CIF/POSCAR是派生表示。无Tc的完整伴随结构可有材料卡，不生成假Tc。

已有人工内容保护；查源后仍不确定或校验失败，已知归属进入结构字段来源侧栏，无法定位使用既有兜底。不能只藏日志，不增加独立诊断面板。来源、校验、派生表示和人工备注随规范结构承接。

新生产流程和正式草稿退出根级structure_candidates、structural_observations。解析内部可以有临时候选，原始产物保留；完整链路就绪前不得先删旧容器。历史读取保持有界，不改冻结快照。
