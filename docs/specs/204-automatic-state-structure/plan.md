依赖：依赖#203，正式结构统一S.structure。

1. 模型输出结构到稳定状态身份的关联及原文来源；程序检查身份、来源、几何和冲突。
2. 有来源且唯一完整的结构自动写S.structure；其他情况保留可达字段核对问题，不伪造确认或审批。
3. 同几何多表示保留；不同真实几何分状态；无Tc完整结构建立真实状态，不造Tc；人工结构受保护。
4. 上传、读取、查看/下载、核对、快照、返修、导出和谱结构指纹统一读取S.structure；新保存退出根候选及观测容器。
5. 将可确定旧候选转为结构，失败项保留原始产物与现有可达问题；冻结快照旧版读取，不改历史。

## 结构源头内容识别

新PDF原生文字按实际页及位置形成只读来源目录；AI使用既有受限文档工具联读原页和表头，输出固定内部几何描述。程序校验来源身份、读取回执、原数值、类型、坐标行、完整性、化学计量和几何；不猜基底、不用空间群更改报告坐标。规范结构仍由原归属/保存主链生成，失败保留具体原因及原来源。旧非PDF调用继续原有有界解析。新读取输出、原响应、工具调用和图像实际接收分别归档，不把渲染算成模型已读。

AI识别在前；原有完整坐标和Wyckoff确定性几何解码继续保留作后处理，不能作为新PDF识别的前置词形门。归属读取将结构化IR展开成原文块，并按块身份保留重复单元格；原生坐标来源与归属来源共同保留。科学疑点按结构进入原侧栏/未定位兜底，不抛成整文件技术失败，不修改矛盾坐标或猜测基底。

### 第七轮读取回归

结构原页工具内部的文本读取属于同次原生行动，删除重复consume；累积原生assistant/tool配对回执，输入按实际图片附件顺序列文件、PDF页及摘要，沿用当前图像接收审计。不改DocumentTools的12行动上限、科学完整性或整任务失败策略。T013对应原SI八调用固定重放、前轮回执及图片身份、13次请求停在原有上限三个反例，再从原PDF真实读取并完成既有后处理/归属/隔离存取与网页重跑。
