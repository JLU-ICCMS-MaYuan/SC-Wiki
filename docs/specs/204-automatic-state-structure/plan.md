## 结构源头内容识别

新PDF原生文字按实际页及位置形成只读来源目录；AI使用既有受限文档工具联读原页和表头，输出固定内部几何描述。程序校验来源身份、读取回执、原数值、类型、坐标行、完整性、化学计量和几何；不猜基底、不用空间群更改报告坐标。规范结构仍由原归属/保存主链生成，失败保留具体原因及原来源。旧非PDF调用继续原有有界解析。新读取输出、原响应、工具调用和图像实际接收分别归档，不把渲染算成模型已读。

AI识别在前；原有完整坐标和Wyckoff确定性几何解码继续保留作后处理，不能作为新PDF识别的前置词形门。归属读取将结构化IR展开成原文块，并按块身份保留重复单元格；原生坐标来源与归属来源共同保留。不抛成整文件技术失败，不修改矛盾坐标或猜测基底。 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../221-scientific-field-sidebar/spec.md)，本处不再独立维护。

已验证的原PDF坐标行若同时列出位点多重性，直接适配到已有Wyckoff解码；不要求原文使用固定表题。负号和上划线编码仅作同一报告符号的比较归一。解码用的内部规范化文本不得充当原文引句；报告坐标、真实行来源、模型读取说明及派生晶胞参数分别保留，原有几何、组成及多重性校验继续执行。


### 第七轮读取回归

结构原页工具内部的文本读取属于同次原生行动，删除重复consume；累积原生assistant/tool配对回执，输入按实际图片附件顺序列文件、PDF页及摘要，沿用当前图像接收审计。不改DocumentTools的12行动上限、科学完整性或整任务失败策略。T013对应原SI八调用固定重放、前轮回执及图片身份、13次请求停在原有上限三个反例，再从原PDF真实读取并完成既有后处理/归属/隔离存取与网页重跑。

### 结构请求的重复表示压缩

同一已读来源的完整原行只由本次sources提供；source_index对已读项仅保留source_id和页码，未读项继续提供原定位及预览。原生工具历史保留全部assistant/tool消息和调用编号：只有工具返回的block_id、页码、原文与本次已提供来源完全一致时，才将重复块替换为来源引用；不可解析或未匹配来源不作科学推断。原始工具返回在raw_tool_history完整归档，与实际发送的tool_history区分。当前sources全文、原页图片、服务端完整catalog、严格枚举、数值/几何校验、行动上限及科学契约不变。实现对应FR-007/SC-005，防止重复目录及观察量把结构请求放大；科学分段48000窗口仍属于后续独立步骤，不能代替该修复。
