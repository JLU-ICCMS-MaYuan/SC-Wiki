# 重算与撤销交互

沿用POST /api/rag/spectra/{id}/recalculate，权限/目标版本/集合版本/base_run保护不变。按当前kind执行精确端点连接、受限频率修正、诊断、积分、保存新run。
详情直接显示修正后的当前曲线与计算结果；不显示已处理修正的摘要/坐标列表/分页，也不在只读详情绘制自动修正标记。仅未修正原因及实际问题定位保留。进入编辑器后仍可查看高亮和撤销。
编辑器显示最近批次摘要和“撤销自动频率微调”按钮；后续频率修改/标定变化/点删除时禁用直接撤销，不覆盖新数据。撤销是未保存编辑，保存调整才入库，也可使用现有撤销/重做历史。
连续重算不累积修正，用户撤销后直接重算不自动重做；再发生实际人工编辑才重新考虑。限额超出保持诊断，不生成成功标签或以3N总和验证准确率。
