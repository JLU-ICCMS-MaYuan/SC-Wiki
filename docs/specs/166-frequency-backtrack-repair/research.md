# 研究与实现选择

- 既有samples.connected_samples沿实际连线遍历并要求严格递增。preflight.prepare_repairs只连接完全相同的端点，不处理微小回折；新功能单独实现，不混淆两类修正。
- 使用频率增加方向的原图坐标t=sign(slope)*pixel。先用非降PAVA识别连续冲突块（相等也归块），正常单点块保持。候选在块均值附近加入最小正向间隔，间隔=max(1e-6原图像素,64*坐标量级ULP)，只作数值约定。
- 每块的中心在所有逐点±0.5像素区间、源图框、固定点、相邻原始端点及相邻PAVA块均值分界的交集中取距均值最近值。分界和原始邻点双重约束确保相邻块即使一块拒绝也不引入新回折；该选择保守，可能拒绝存在其他复杂解的情况。拒绝时不挪点。
- 原图两端点、已确认零点及数值零点固定；α²F在距0频率≤1原图像素的样本也固定，避免低频权重敏感区域被自动挪动。保护只限定自动修正，不增加手工编辑/积分门槛。
- 显式相连且像素和数值完全相同的重复表示复用coincident语义分组，组内同步修改，不删除原点。连续回退超过位移限额不会因相邻差值小而放行。
- 只修正有匹配manual_document的曲线。像素、方向、标定、点身份必须一致，频率重算同步写入曲线与文档。幅值、其他轴、点ID及所有边不变，自动修正状态明确标为自动。
- 批次按最多4000字符分片写Document.operations；详情报告来自仍与当前坐标匹配的批次。重复重算若最后操作仍是自动修正或撤销则不再修正；用户发生新的实际编辑操作后才重新考虑。
- 编辑器只撤销最近未撤销批次，且所有目标点当前频率坐标与修正后完全相同、标定未变。否则禁止直接撤销，防止覆盖后续人工频率调整；幅值编辑保留。撤销记录批次ID，下一次重算尊重该意图。
- 重算创建新run并保留原run；无需新接口，撤销后仍通过既有manual保存。公开接口移除内部报告/操作；状态文字可说明自动调整，但不能泄露其他分波。

- 按后续反馈，将后台修正历史与详情主结果分开：已应用修正不再作为常驻提示渲染；不删除服务端审计、不修改数值，不新增确认应用动作。当前及旧报告均不展示成功修正清单。编辑器的追溯和撤销保持，未处理原因仍展示。
