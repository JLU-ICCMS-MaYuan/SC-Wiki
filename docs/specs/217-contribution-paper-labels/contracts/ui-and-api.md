# 界面与接口契约：统一收录贡献名称，消除作者身份歧义

## 用户可见行为

- 用户、管理员、超级管理员的共享收录入口及列表标题统一为“他帮助 SC-Wiki 收录的论文”。
- 列表加载失败、空态及英文文案统一表达收录贡献，避免“我的论文”造成作者身份误解。
- 检查贡献继续使用独立名称；不修改实际提交归属、作者字段或审核历史。

## 事实来源与约束

界面名称由中英文词典掌管，实际归属仍由上传者与既有列表接口决定。

## 实现边界

沿用共享PaperEditView/MyPapersList及AccountPage入口，统一paperDetail词典中的myPapers、loadMyPapersFailed、emptyMyPapers，不通过改数据解决显示问题。
此处记录原实现契约，没有新增接口或数据结构。与其他子项共用的接口参数、组件及返回值继续由原代码掌管；本项范围外行为见spec.md。

## 验证对应

FR-001～FR-003对应US1与SC-001/002，实际案例及原运行边界见[验收记录](../validation.md)。
