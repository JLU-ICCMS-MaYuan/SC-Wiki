# 实施方案
## 既有约束审计
#205允许候选或空值并解释；#204只允许真实不同状态建卡；#176原填写器锁住原状态，因此需在进入填写器之前完成状态规划和候选归属；#137谱独立存储/审核不变；#170的解析运行计时包含自动谱阶段；#174禁止全表重绘/无意义请求，科学审核不能靠清空状态规避。

## 数据所有权与顺序
1. 共用原IR来源目录，模型在科学组装阶段给出材料状态清单和原候选去向，程序生成稳定身份、校验来源及全候选守恒。结构表/谱图证明的状态可无标量物性，未知归属候选复用实际状态并形成字段问题。
2. 结构归属写每状态唯一S.structure，不为未知记录复建卡；填写器继续保护固定字段和数值守恒。
3. 谱发现先筛候选，再读图识别目标面板和材料归属，随后独立标定/数字化。识别资料不依赖曲线非空校验，非目标不生成collection。
4. 黑灰通道只采原图像素，排除图框、文字、其他轨迹；同色多轨迹可用原图观察锚点约束分支，锚点不是模型生成的数值曲线。保持缺口与质量报告。
5. 上传Worker在草稿写入后、ready前执行自动谱任务，手动API保留独立任务。使用正式服务/数据库，完整处理结束才发布终态并结算耗时。
6. 同目标刷新保留旧列表，终态停止请求；目标失败身份供模块导航，不显示表单末尾空记录。

## 验证和清理
先增加可失败的回归证明当前错误，再修改。定向后端/谱算法、前端完整宿主、field/form/mutation、构建。用原PDF真实模型重提核验，保留失败及成功记录。隔离验证后清理CaH6旧任务并全新上传，不影响H3S。实际环境沿用当前本机原生源码运行服务，仅刷新本次受影响且可确认归属的进程；不发布其他环境。
