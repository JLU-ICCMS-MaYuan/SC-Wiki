# 调查与设计理由
## 根因与原要求
- CaH4未知压力DOS先建state-4，结构表另建50 GPa，后续原页核对补50但不重排归属。#205候选语义没有接入建卡流程。
- Fig.S6被文字覆盖标为out_of_model_scope；谱流程只匹配已有状态，因此150 GPa缺卡。状态建立不能仅看标量记录或完整坐标表。
- 标定PanelCalibration要求非空曲线，黑灰曲线被拒后连state_key一起丢失；issues同时容纳非目标排除，discover把所有无panel的issues变成空集合。
- PropertySpectra固定间隔读取，每次listing=null造成卸载；upload_jobs先complete_parsing_state才enqueue_upload，ready/耗时提前。
## 方案取舍
先统一状态并分配结果，避免事后按相同压力合并不同真实几何。谱身份和数值标定分开，允许无曲线失败结果仍有类型和归属。黑灰取数不按论文答案调参；不可分辨的同色交叉保持未知。复用既有服务、谱表、来源侧栏与状态，不增加第二套持久业务容器。
## 新问题处理
每个新增故障先检索全仓文档/代码、读相关原Issue/Spec/Overview，登记原要求、实际分支和重现证据，再修改。不得静默重录科学契约摘要或放宽来源/数值检查。

## 实测后补充追溯
- 空间群旧OCR表达与规范符号不能简单按字符串认定不同物相；依据#194/#199允许模型查源纠正无法识别的表达，已有合法不同群仍阻断。
- 材料状态规划只建立已有标量候选、完整结构或目标谱明确报告的条件，不把结构搜索网格或一般电子图说明展开成空卡；存疑标量所引用原页在同一规划调用实际传图。
- #195只读预览在正式草稿不存在时不应请求谱列表。完整宿主先证明额外谱请求能被测试检出，再限制为正式草稿/冻结谱读取；预览布局不变。
- #183要求真实来源身份。Worker交接状态规划必须使用form_sources的原IR块，不可把Markdown临时块编号当成原PDF块；共享工作区该交接修正与独立回归已经出现，后续以实际Worker证据验证，保留其他任务文件归属。
- #137与本次彻底删除要求：整份上传草稿清理同步删其SpectrumRun/Collection，保留其他任务谱和共享图片；独立SQLite回放证明CaH6删除、H3S保留。

## 边界刻度与中断的实际回归
- 原图叠加发现α²F上下边框的少量刻度被当成观测。依据#137 FR-012/015，补充黑灰边框/刻度连通性排除；保留真正延伸进图内的曲线，无法分辨处不插值。回放与独立合成像素测试均验证，不靠论文λ调参。
- 本机服务停止后，上传任务failed但自动发现run仍running，#91的父任务恢复没有覆盖新合并的子运行。执行归属绑定到父job，失败与重试遵守所有权；迟到回调不覆盖新轮次。
- #170的retry=True是状态机参数而非保存标志；新轮次计时从extracting入口建立，不能直接跳summarizing导致零耗时。
- 最终完整验收采用固定的当前整合源码、只绑定127.0.0.1的临时API及专用RQ队列；科学提取、模型、MySQL和文件存储均真实，不Mock科学路径。仅路由到专用队列。原Marker/llama依赖通过只在副本内建立资源路径复用，不安装或修改全局依赖；完毕清理临时进程与副本。

## 固定字段补空旁路
实际补查出现条件类型错误。对照#203/#205及parameter_paths，每个固定空参数本来都有独立核对键。当前_form_contract_version=1的review_draft不再开启condition_additions，通过自己的final_value补空，额外整包响应明确拒绝。历史无固定契约的兼容保持有界。此处收敛现有字段所有权，不改变参数类型或契约摘要；网格仍允许已登记数组/文本，数量对象只接受已登记的value_kind。

## La-H引用图物理量与错误初猜固化

两轮真实原始响应均把LaH10的10.0 states/Ry放在300 GPa，并同时引用正文DOS段及图6页。图6实际展示能带和声子谱，不是电子DOS；SI图S3才给出电子DOS，并明确LaH10为250 GPa。旧规划只为压力None附图，且整卡分配后将任何非空压力当成已证实条件；混在300 GPa候选中的真实Tc与存疑DOS因此不能分别归属。

FR-002已经要求不将宿主压力当成记录事实，并在查图后调整该记录，因此修复原实现遗漏，不新设科学判断规则。新增的是受限控制协议中的逐记录去向，不是新的业务数据容器；保留真实不同条件保护与后续模型核对。测试跨另一材料同样成立，代码没有论文/图号/压力特例。
