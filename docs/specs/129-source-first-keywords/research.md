# 研究与决策

## 决策 1：关键词来源优先级

- **决策**：当前主文明确作者关键词栏 > 当前论文全文 AI 提炼 > 空值待人工核对。
- **理由**：原列关键词由作者提供，不能被模型改写；无列表的期刊论文仍需提炼。
- **备选方案**：始终让模型自由生成。它无法保证作者原词优先，也容易将摘要句误标为原列。
- **证据**：`upload_jobs.py` 的汇总提示词现要求根据标题、摘要与内容提炼；`_fill_missing_keywords` 只再次读取标题、摘要、概要。

## 决策 2：来源身份

- **决策**：独立保存关键词分析的类型、值、状态、证据、规则与来源摘要；字段核对仅在分析值等于当前值时采用。
- **理由**：`field_evidence` 可承载引句，但单独的引句不能证明列表是作者原列，也不能说明全文是否读完。用户改值后必须使旧身份失效。
- **备选方案**：仅修改侧栏文案。文案无法区分真实作者列表与模型提炼。
- **证据**：现有 `keywords_tags` 为 `SYNTHESIS_FIELDS`，核对侧栏可依据定位到的摘要句显示“原文直接记载”。

## 决策 3：中文作者词

- **决策**：有定位的作者原词豁免生成字段英文校验；AI 提炼词仍须英文。
- **理由**：“直接采用”要求保留作者原文，翻译会改变原词并失去直接来源属性。
- **备选方案**：全部翻译。翻译结果是 AI 改写，不能称为作者原列。
- **证据**：`language_contract.py` 当前对所有 `keywords_tags` 拒绝中日韩字符。
