# 来源定位的数据与接口

## 所有权

原件沿既有文件服务及权限保存；字段只引用当前文件、摘要、版本、页码、块和已有区域。没有新增科学表单键或数据库表，没有持久化截图副本。

## 按需读取

现有`POST /api/rag/evidence/region`请求不变。结果增加`context_text`、`source_sha256`和`text_locator`。后者包含源文本SHA256、`char_interval`与`match_kind`；区间为原始Unicode字符的左闭右开位置，前端先转成字符数组，不能当作UTF-16索引。

匹配只在已经限定的来源块中进行；精确、排版空白等价、重复和未定位分别表示，后两者区间为空。它不增加模型调用，也不能授予科学支持。原文件摘要、页面几何、权限与版本仍经原服务核验。

图中点位只使用已标定来源元数据内的坐标，完整图框作为上下文；表格有可信父表框时保留原表区域。缺少可靠位置时不从字段值猜坐标。标记开关仅改变本地覆盖层，不重新请求、不改字段或审核结论。
