## 技术上下文与职责

React 19 / TypeScript / MUI 7；Python FastAPI、SQLAlchemy；Go Gin/GORM 审核事务；MySQL 持久数据；Redis/RQ 运行任务。测试使用 pytest、Go testing、Vitest、现有 MySQL 回滚事务及真实浏览器。

Python 统一构建科学核对项，覆盖论文科学叙述与分类、材料状态、模块记录和结构；以 state_key/module_key/record_key、结构身份和字段标识定位，字段路径仅用于界面锚点。记录事实和条件按最小依赖形成摘要，附件元数据不冒充论文引句。已有多证据保留与确定性引句定位继续复用。

新增通用 MySQL 核对表保存所有结果及裁决草稿，新增永久来源关联、结构提交来源及受保护上传快照。RQ 完成前先持久化；Redis 仅运行态。预检查按当前快照恢复并合并有效结果，旧版本单独显示失效。草稿生命周期保留必要来源，提交后按稳定身份转接。

Go 批准事务调用 Python 只读准备接口，检查当前快照完整性，写正式证据和来源、审核历史并清理临时项。不再按 PropertyRecord 数量短路。批准携带分类必须等于已核对的实际值。编辑页保存成功后才核对。

共享前端工作流管理核对、恢复、重试和裁决；共享字段标记按稳定身份与当前路径映射。MUI temporary Drawer 从右侧覆盖显示，不改变页面宽度。核对运行不占数据库长事务，离页不自动续提。

结构来源由服务端根据认证用户和真实输入记录；程序校验附件结构参数。有论文支持优先使用引句，无论文支持且来源可追溯时要求人工理由，永久保留限定。RAG 发布及引用携带来源说明。
