## 已确认的布局与编辑方式

| 内容 | 位置 | 行为 |
| --- | --- | --- |
| 研究材料 | 论文基本信息之后 | 从材料状态汇总名称、化学式与状态链接，修改材料名后同步更新；不新增独立研究材料输入框 |
| 材料关系 | 研究材料之后 | 展示论文与材料的研究关系，逐行选择材料、编辑描述、增加或删除；长文本完整换行 |
| 材料状态类型 | 各材料状态的基本信息区 | 实验、理论、理论与实验、未知四个选项；与常规／非常规超导体类别分别展示 |
| 晶体结构与晶格参数 | 对应材料状态的结构附件区 | 左侧交互晶体模型，右侧依次显示晶格参数、晶格矩阵与原子位置；更换示例结构时一起更新 |
| 来源核对 | 字段标签或结构标题 | 点击或键盘打开右侧面板，展示归属、当前值、核对状态和示例来源，不在页尾输出原始 JSON |

三个视图共享一份内存草稿：上传校对与审核编辑允许修改，论文详情只读。
所有材料状态默认展开，可折叠并通过研究材料链接重新定位。
核对问题解决后字段仍显示；相同状态类型通过材料归属区分。

## 演示的数据与交互边界

- 使用 Sn、Pb、SnHg 三个材料状态；Sn 和 Pb 提供示例结构，SnHg 初始无结构。
- 更换结构通过选择内置示例文件演示，3Dmol 解析同一份示例 CIF 生成模型、晶格参数、矩阵与原子位置；不提供任意文件上传。
- 保存仅更新当前页面内存中的快照；取消恢复快照，刷新恢复初始示例，不使用本地持久化或网络请求。
- 上传视图可采纳、撤销示例建议；审核视图另外允许填写非空理由并人工确认。AI 通过、人工确认及建议采纳分别显示。
- 修改相关字段使先前结果失效，清除旧人工理由的生效状态。结构核对按材料与结构身份定位。
- 关闭或确认侧栏后返回原入口并保持阅读位置。详情不提供编辑或裁决操作。
- 原型只演示本轮字段；既有论文、物性与完整审核功能由生产组件负责，不将原型直接替换为生产编辑器。

## 晶体结构左右布局补充

用户要求保留已有的三维晶体展示，并将结构区分为左右两半。桌面采用等宽双栏，
宽度不超过 850 像素时改为上方模型、下方数据，三种页面视图保持一致。

- 左侧复用生产查看器同版本的 3Dmol.js，显示球棍模型、晶胞边界、a/b/c 轴和元素图例。
  支持鼠标拖动、缩放，以及旋转、放大、缩小和重置视角按钮；每个材料保持独立视角。
- 右侧按晶格参数、晶格矩阵、原子位置顺序明确展示，默认不折叠。
  长度使用 Å，角度使用度，体积使用 Å³；矩阵按 a、b、c 晶格向量逐行排列。
- 原子位置默认显示沿晶格向量的分数坐标 u、v、w，可切换为直角坐标 x、y、z（Å）。
  坐标换算使用 3Dmol 的矩阵与向量 API，不把非正交晶胞的分数坐标误写成 x/a、y/b、z/c。
- 示例原子位点逐一列出并以 P1 解析，避免按空间群重复展开；这些位点不代表原论文提供了结构证据。
- 模型与数据表都读取同一个已解析模型；更换结构、取消修改、切换视图后保持一致。
  无结构时明确显示未知，不生成推测矩阵或原子位置。
- 查看器按材料复用，切换页面或保存不累积 WebGL 上下文；折叠后重新展开时调整画布尺寸。

## 后续正式接入要求

3. 验证上传保存、提交、管理员保存与详情重载；研究材料保持服务端汇总语义。
4. 多结构独立定位，排序后仍按稳定身份匹配；未定位项进入核对区的紧凑清单，不丢弃也不输出页尾原始数据。
5. 正式页面交互与读写链路验证后再更新 Overview。本次不关闭 #103，不把 Demo 验证当作真实服务验收。
6. 正式结构区保留现有三维组件，同步展示对应晶胞表示的参数、矩阵和原子坐标；
   当前结构摘要仅含晶格参数，矩阵与位点须从同一结构解析结果提供，不另建可独立编辑的数据副本。

## 浏览器验证

使用 Chromium 直接通过本地文件加载演示，覆盖 1440 × 1000、390 × 844 和 320 × 740 视口。

- 三视图数据一致，详情无编辑控件；保存、取消、刷新边界正确。
- 关系新增、改归属、编辑、删除和取消恢复；用户文本按纯文本显示。
- 上传建议采纳与撤销；管理员理由必填、确认关闭、修改使旧决定失效。
- 结构更换与新增同步更新参数，不影响其他材料；取消恢复原结构。
- 展开／折叠、材料跳转、视图键盘切换、侧栏 Escape 关闭、焦点及滚动恢复。
- 手机页面与侧栏无横向溢出，长关系文本随内容增高。
- 浏览器无脚本错误，零 HTTP／HTTPS 请求。
- 结构区桌面等宽双栏、手机上下排列；画布像素检查确认非空、模型未裁切。
- 旋转、拖动、缩放与重置改变实际模型视图；更换结构和取消同步更新模型及数据表。
- 参数、按行矩阵、分数坐标与直角坐标核对；额外使用非正交晶胞验证矩阵方向与正反坐标转换。
