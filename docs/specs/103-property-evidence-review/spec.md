# 物性证据保留、自动补证与人工裁决

关联 [Issue #103](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/103)，2026-09-11 用户确认并授权实施。

## 用户故事
- US1（P1）：上传校对保留来源；核对成功自动提交，有出处但存在疑点携带疑点待审，无出处保留草稿并定位问题。
- US2（P1）：两个管理员工作台共用核对；成功自动批准；有效出处的疑点允许逐条说明理由人工裁决；退回与拒绝不调用模型。
- US3（P2）：取消、离页、并发变更不继续旧操作，错误明确区分数据与服务问题。

## 需求
- FR-001：解析、编辑、复制、保存、落库保留多证据；以材料状态、模块、记录联合定位。
- FR-002：仅当前论文及附件；确定性核对来源和引句，保留真实页码，定位失败不得静默丢弃。
- FR-003：需要模型时可取消三秒倒计时，使用发起用户配置；核对材料、物性、数值、单位和条件，不擅改科学数据。
- FR-004：核对结果绑定内容、来源摘要及规则版本；内容不变复用，改变则失效。
- FR-005：支持结论自动续提；语义疑点允许上传待审，批准必须人工理由；无来源不能提交或批准。
- FR-006：服务端验证任务归属、角色、自审、版本和幂等，不能信任前端通过标志。
- FR-007：取消或离页停止续提；任务未应用不写正式数据；模型失败独立提示，可重试。
- FR-008：显示记录、原文、原因和修正入口；人工裁决进入审核历史。
- FR-009：证据的搜索、选择和关联由系统完成，不要求用户选择 chunk、来源文件或编辑引句。找到的原文默认折叠供查看；重新查找必须实际重新核对未解决记录，不能只返回旧疑点缓存。人工仅裁决科学结论的疑点。
- FR-010：等待后台核对时显示进度条、当前阶段和已等待时间；已知总量时显示实际完成组数及百分比，排队或尚未取得总量时显示动态等待条，不伪造进度。

## 验收标准
- SC-001：#29 SnHg 4.29 K 测量温度不被自动当作 Tc；Pb 7.19 K 与约 6 K 冲突可见，原值不变。
- SC-002：倒计时取消零模型调用；成功一次续提；无出处、服务错误、并发变化不批准。
- SC-003：现有 sc-wiki MySQL 回滚事务验证证据流转、同键隔离、权限、历史和三种状态；真实页面验证上传及两角色。
- SC-004：上传与审核均无片段选择器或引句编辑框，不展示内部文件或片段编号；疑点保留自动找到的原文。重试经可取消倒计时创建新任务，找到支持证据后自动续提。
- SC-005：共享核对界面在排队与运行期间始终显示进度条；后台完成一组原文后推进计数，等待时间持续更新，取消和自动续提保持有效。

## 已确认边界
仅当前论文及附件，已有证据也核对；人工可凭有效出处说明理由裁决，上传疑点可进入待审。不全库回填，不自动改值，不使用临时数据库，不自动推送。
