# 演示设计依据

- 已读取 AccountPage、AdminPage、SuperAdminPage、SuperAdminGovernance、theme 和角色治理 Overview。
- 现有紫色主色 `#4f46e5`，白色卡片和左侧导航保留；原型调整密度、字号层级及边框，减少持续表单感。
- 资料只读用文本，不使用一排灰色禁用输入框；编辑草稿与当前值分开，支持取消。
- 原工作台入口先 setTab；原型用带 view 的独立 URL 表示直达目标，验证新标签页体验，不改真实路由。
- 已检查记录和待检查队列分开，避免贡献数量误计。示例论文题名是真实文献，用户与论文的贡献关联是虚构示例。
- 工具不可用时不伪称内置 Browser 验证；本次经用户允许使用 Playwright 与本机 Chrome 无登录的新上下文。

## 改密验证

以旧密码和绑定邮箱为发送前置条件，而非在输入验证码后才验证身份；保持两步操作，降低表单密度。原型显示专用示例凭证和模拟发送文案，避免误导用户输入真实密码。重发和过期只是流程演示，不作为生产安全实现。
