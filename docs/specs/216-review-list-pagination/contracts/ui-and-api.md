# 界面与接口契约：检查列表分页与独立工作区

## 用户可见行为

- 个人页检查区的已检查记录、待检查每页均为3篇，仅支持底部分页，没有内部纵向滚轮。
- 保留打开检查工作区，独立页面每页20篇，支持列表内滚动和底部分页。
- 独立工作区保留两个页签，并承接个人页当前页签；搜索、筛选与页码对应实际请求，旧响应不能覆盖新结果。
- 本人检查历史与待检查队列分开；收录贡献列表不因本项自动改为每页3篇。

## 事实来源与约束

已检查记录按本人不可变审核事件读取，待检查复用审核队列；页码、容量和页签由对应界面掌管，不新增科学数据。

## 实现边界

AccountReviews显式区分紧凑/完整模式；MyPapersList和AdminPage接收pageSize/scrollable；AdminWorkspacePage路由壳选择完整工作区，查询参数review_tab承接页签，避免组件循环承载。
此处记录原实现契约，没有新增接口或数据结构。与其他子项共用的接口参数、组件及返回值继续由原代码掌管；本项范围外行为见spec.md。
