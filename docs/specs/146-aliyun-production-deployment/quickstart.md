# 操作与验收指南

正式命令以实施后的 scripts/deploy.py --help 为准。本文件当前记录验收步骤，不表示已部署。

1. 核对发布 SHA/digest、私有配置、部署身份、源端版本和备份清单。
2. 显式初始化新目标，启动数据组，隔离恢复验证后执行最终维护窗口迁移。
3. 检查 schema 并显式执行必要迁移；启动解析与网站。
4. 从外网访问 https://www.sc-wiki.com，并核验 HTTP/裸域名跳转和授权 API。
5. 记录数据容器 ID，停止计算组，验证登录/检索/已有文件；更新网站后重新比对 ID。
6. 重建应用容器、验证数据和证书持久化，执行隔离恢复演练。
7. 保留源数据和备份。恢复前核对目标为空与新增写入保护；禁止直接覆盖上线后的数据。

实际命令、备份位置和结果写入 validation.md；该文件不得保存秘密或用户科研正文。
