# 研究与决策

## 三项目而非单项目 profiles

沿用 #132：网站、数据、计算使用独立 Compose 项目和固定部署身份。同机共享显式 external 网络；跨机通过配置私网地址，不幻想 bridge 跨机器。停止一组不会删除共享网络或其他组存储。

## Garage 与版本

沿用已迁移本机业务的 Garage，替换 #132 旧文档中 MinIO 默认。必须保留 S3 sha256 元数据，否则当前 describe/head 失败。Redis 源端可能高于旧 Compose 7，使用实际版本兼容验证，拒绝格式降级。

## 上线和镜像

Caddy 自动 TLS，前端仍用 Nginx。仅 Caddy 发布 80/443；数据服务只在内部网络。镜像固定 digest，Hub 不可达时转运同一制品而非改用未知镜像。生产需要固定依赖的真实认证与 schema 检查，不将 /health 当业务成功。

## 迁移

允许维护窗口，先演练再最终冻结。MySQL 逻辑备份、Neo4j dump、Qdrant 快照、必要 Redis 业务状态、S3 对象加清单；不把运行中的数据库裸目录作通用备份。目标只允许空身份。过期时间绝对化；不恢复临时模型密钥或旧锁。源端全备另行私密保存。

## JSON 浮点精度实测

同版本 MySQL 8.4.2 的演练恢复发现谱线 JSON 中少量数值变化一个 double 末位。
在目标直接对比 CAST(JSON文本 AS JSON) 与 JSON_OBJECT(...,CAST(原值 AS DOUBLE))，
后者能保留源值。因此冻结时附带 JSON 原文，只在隔离恢复目标通过事务定向修复相邻 double
解析误差，结构/字符串/整数/较大数值差异均拒绝；修复后仍逐字段原文及整库摘要完全比对。
不引入业务运行时容差，不修改源库，不重算科学结果。

## text-embedding-v4 兼容性

2026-10-21 使用用户配置、仅发送合成短文本实测：默认返回 1024 维，显式 dimensions=1536 返回 1536 维。选择显式维度适配现有集合，避免重建数据存储。
批量上限按百炼文档采用 10，作为可配置的 Embedding 参数；不改变聊天模型选择逻辑。模型、维度需在索引与查询间一致，将来更换模型即使维度相同也不能混用旧向量。
