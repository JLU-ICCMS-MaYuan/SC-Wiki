## 转运与候选检查

阿里云直连Docker Hub出现超时或连接重置，因此通过Actions导出固定版本的amd64原版镜像。
前端、Go及Python最终均从GitHub制品直接下载到阿里云；Python完整制品约4.74GB，
采用分段下载，下载、摘要核对和解包共约465秒。没有在本机保存该完整镜像。

每份GitHub制品先核对完整ZIP摘要与大小，再检查归档及元数据校验清单；
导入后核对源码SHA、平台、镜像配置及完整文件层，并与成功构建任务输出的Hub digest一致。
Docker导入后的本地镜像ID可能不同于配置JSON摘要，发布清单使用实际镜像ID。
候选部署通过现有存储身份、真实依赖和schema检查后才进入维护窗口。
