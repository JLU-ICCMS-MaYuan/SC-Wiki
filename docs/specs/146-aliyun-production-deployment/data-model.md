# 部署与迁移记录

不新增业务表。发布记录保存 deployment_id、source_commit、各镜像引用与内容身份、引擎版本、schema heads、配置文件摘要（不含值）。

迁移清单保存 backup_id、源版本、冻结时间、对象键/大小/sha256/Content-Type/元数据、业务表行数与内容摘要、Redis 状态原绝对期限、Qdrant 集合和别名、Neo4j 统计、文件引用转换。秘密配置独立保存，公开日志不含记录正文。

状态顺序为：已盘点 → 已冻结 → 已导出 → 已校验 → 已恢复 → 已验证 → 已开放。失败保留当前阶段和证据，不跳步。公开写入之后禁止无新增数据保护的回退。
