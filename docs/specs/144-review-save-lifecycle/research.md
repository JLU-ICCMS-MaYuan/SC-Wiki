# 设计依据与取舍

依据：[investigation.md](investigation.md)的只读复现及用户认可的Tc依赖分离规则。

- 采用明确字段可空规则和value_kind检查，不给所有字段统一nullable，不通过补0/假单位绕过保存校验。
- 已报告的共用条件事实由材料/相/软件/阶段/用途/原文范围决定。结果数字属于结果归属定位，不应成为同组条件身份的一部分。
- 旧版兼容限定为可验证的完整历史claim与有效规则证据；必须同时校验来源覆盖、事实值、软件及范围。拒绝只比字段名或重新盖hash。
- 仍保留有依据的冲突撤回，不采用无条件supported优先。技术失败与有效反证必须分别记录。
- 历史行不删除、不迁移整库；读取时验证后投影，正常保存使用当前合同。未知版本拒绝兼容，规则语义变化不能自动套旧许可。
- 浏览器场景须实际执行编辑器和核对标记。为保护用户草稿，优先使用真实草稿副本与MySQL外层事务回滚桥；若HTTP/身份采用夹具必须明确，不能称作真实登录生产端到端。
- 不默认页面跳动和SSCHA红框同根；分别收集焦点、滚动、URL、请求顺序证据。

- 用户单独授权后，前端共用字段按稳定组身份寻找新承载记录；父级记录变动通知以实际字段差异判定，不能再次按父路径把全部子项置stale。Tc/μ*结果字段仍依原点身份，跨组不能借用。
