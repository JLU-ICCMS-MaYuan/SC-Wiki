# 实施方案：切回提示后载入

依据[规格](spec.md)、[调查](research.md)、[数据模型](data-model.md)及[接口合同](contracts/workflow.md)。

## 数据所有权与实现

以已保存工作稿修订号按需检查，不在后台轮询或读取整稿。focus和visibilitychange合并同一轮检查；发现变化只提示，不替换表单。
点击载入时才读取同一工作稿的完整资料；主表单、人工说明、证据／候选待保存均需保护。确认替换后取消未发出的本地说明保存；已有写请求或提交在途时禁用载入，不额外自动保存来同步。载入期间有新编辑则丢弃迟到响应并再次提示；成功后一次切换值、当前依据和有效结果。
冻结快照不参加更新检查；已结束工作稿或不同租约不能通过载入恢复旧页写权限。保留原保存间隔和其他布局。

## 跨功能依赖

183与185提供字段资料、局部写入基础；189在其上提供共同资料目录；192消费这些规范合同并冻结／交接；187消费相同工作稿修订号且不替换快照。186独立评估，不混入尚未确认的性能重构。

## 需求／设计／任务／证据映射

FR-001～004→按需检查和提示；FR-005～008→未保存和迟到保护；FR-009～013→四宿主、冻结隔离和零模型。任务按下方Tasks执行，证明信号为真实读写／权限／完整宿主／持久化结果，不以文件存在或字符串检查替代。

## 执行质量门

先加入实际故障和边界测试，再实施；有PDF字段或证据处理变化时定向真实重提。最终执行科学表单双门、受影响回归、独立既有失败基线与候选构建。未推送的远程链接仍待验证，不据此关闭Issue。
