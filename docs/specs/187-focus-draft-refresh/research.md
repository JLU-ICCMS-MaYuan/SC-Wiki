# 技术调查与决策：切回提示后载入

以已保存工作稿修订号按需检查，不在后台轮询或读取整稿。focus和visibilitychange合并同一轮检查；发现变化只提示，不替换表单。
点击载入时才读取同一工作稿的完整资料；主表单、人工说明、证据／候选待保存均需保护。确认替换后取消未发出的本地说明保存；已有写请求或提交在途时禁用载入，不额外自动保存来同步。载入期间有新编辑则丢弃迟到响应并再次提示；成功后一次切换值、当前依据和有效结果。
冻结快照不参加更新检查；已结束工作稿或不同租约不能通过载入恢复旧页写权限。保留原保存间隔和其他布局。

## 兼容与边界

只复用当前有效稿与当前核对，不把任意旧中间结果恢复作为承诺。新协议接口带明确版本与写租约；旧格式只在边界读取，不能越过当前归属。业务库迁移、真实数据回填、历史删除、推送及部署不执行。共享源文件按依赖串行修改，不并行混改。

## 本轮实现收敛

当前结果复用 ScientificEvidenceCheck 的工作规则行；旧版本行保留。正式交接复用不可变 PaperHistoryEvent 的 JSON 元数据，只有首次引用保存完整内容，后续记录只引用快照身份；不新增重复的 Workflow／FieldState／Snapshot 表。ScientificWorkDraft 与来源目录／使用关系分别承担权威工作稿和采用资料。

内容规范化忽略内部编辑标记、处理时间及可选 null 元数据的省略差异，保留真实零值与缺失语义。新模型结果的 Tc—μ* 对应由结构化 point_binding 合同核验，来源定位不能代替科学对应。原始科学值仍在稿件中，不以引用层另存一套可修改数值。

## 最终权威对象与外部谱资料

上传稿的科学值由 scientific_work_drafts.body 持有；返修和审核复用既有 paper_revision_drafts／scientific_review_drafts 作为唯一正文，该表在这些入口只保存经手人、周期和修订号，不另存第二份科学值。

谱曲线属于整稿资料。审核工作稿使用私有谱命名空间，原公开谱在新批准前保持。交接冻结当前曲线、当时决定与标定，以及独立原图引用；不复制编辑器中间文档或历史运行列表。冻结表单复用原摘要和绘图组件，关闭当前谱刷新与活接口。

当前人工资料按工作稿在经手人之间转移，旧提交行保留。当前操作者与每项证据原提供者分开；仅修改理由不重建未改证据。Tc 的必要依赖参与单字段令牌，μ* 的配对 Tc／方法参与令牌，无关背景仍按既有单字段合同保留。
