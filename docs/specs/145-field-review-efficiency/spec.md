## 背景与目标

单字段保存/完成目前经过整篇草稿保存、全量preflight与当前决定写入；内部又重复构造快照与读取历史。“不调用LLM”不等于操作轻量。先逐项解释，再落实用户明确的“未修改不保存、单字段操作不全量刷新”。

### 需求结论与取舍

- 已确定：未修改的科学数据不重复保存；只改理由/新增附件仍须保存对应内容。
- 已确定：单字段保存或完成不刷新整篇核对状态，不因此启动LLM。
- 待讨论：每种字段改变后是否需模型或程序核对。不能把批评过度设计解释成免除权限、并发或真实冲突检查。
- 历史保留用于追溯，但不等于每次遍历；旧证据重验仅在相关版本变化或有效性缺口发生时有必要。
- 科学数据、人工说明和核对决定是不同对象，保存其中一个不应无条件重写另外两个。

## 用户故事与验收

### US1：逐键看清现状（P1）

**价值**：让用户逐项判断检查是否必要。

**独立验收**：每个当前核对单元及可编辑入口能定位，显示键值、归属、两条路径、方法、模型/程序次数及边界。

1. 假如查看标题、作者、超导类型或主要发现，当切换字段，那么显示该字段的修改/未修改流程，不能只给通用方框。
2. 假如查看N(EF)名称、值、单位，当查看次数，那么明确它们当前共享整条物性审核单元，不把一次单元调用重复累加。
3. 假如查看计算条件或Tc/μ*，当检查依赖，那么区分共用事实和结果归属。
4. 假如计数来自一次preflight，当显示次数，那么不能冒充点击完成的全部次数、字段终身次数或历史LLM请求次数。

### US2：无变化不写，单字段不全量刷新（P1）

**独立验收**：请求/数据库日志证明未改科学值时零科学数据写入、单字段完成零全量preflight。

1. 假如值、依赖、来源、规则未变，当点击完成，那么只保存新的确认决定（若有）和必要版本/权限校验，科学数据写入0、LLM请求0。
2. 假如仅理由改变，当保存人工记录，那么只保存该记录；理由/附件也未变时幂等返回，不重复历史。
3. 假如有科学值修改，当保存，那么只保存变更与必要原子更新范围，更新当前字段及真实依赖，不能无条件重核整篇。
4. 假如发生并发相关修改，当提交旧决定，那么拒绝过期确认，不能为性能跳过版本保护。

### US3：历史与证据按需处理（P1）

**独立验收**：当前资格不加载整篇历史；旧版恢复和新反证测试都通过。

1. 假如当前结论仍有效，当重复保存，那么复用它，不逐字扫描旧证据。
2. 假如缺少当前有效结论，当需要恢复，那么仅读取本项必要历史，原文重验成功后产生可复用的当前结论。
3. 假如来源/规则改变或有新反证，当读取资格，那么撤回受影响支持并说明原因，历史仍保留。

### 边界与异常

- 未修改科学值但理由、新附件或待完成保存有变化，不等于无操作。
- 缺失与解析失败不等于未报告，沿用#139/#144规则。
- 显示格式变化与科学语义变化须按合同区分，不能仅比较屏幕文字。
- 页面自动任务、显式重核、完成、最终批准分别计数；模型重试/纠正和长文分窗单列。
- 结构资料、贡献者来源、确定性推导与当前实例不存在的模块单列，未知次数不填0。

## 功能需求

- **FR-001**：逐字段目录列键、截短值、状态/模块、审核单元与编辑入口，能对应当前实现。
- **FR-002**：可交互图按修改/未修改分支展示现状和建议，覆盖论文信息、材料状态、物性、条件、结构。
- **FR-003**：核对方法按用途分类，区分LLM、程序与人工；计数注明场景/版本/口径，未知不填0。
- **FR-004**：未变科学值不重复写；理由、附件、决定独立保存且幂等。
- **FR-005**：单字段保存/完成不全量刷新，局部返回当前项及真实依赖，其他项保持。
- **FR-006**：正常读取当前资格不遍历整篇历史；历史保留并字段级按需读取，旧版恢复有界且审计。
- **FR-007**：同一有效版本不重复全文证据扫描；相关值、依赖、来源、规则或有效反证变化才重新判断。
- **FR-008**：保存/完成/人工说明不启动模型；首次自动任务、显式重核与管理员全量任务单独记录。
- **FR-009**：按钮链验收含请求数、读写范围、响应大小、耗时、LLM调用数，不只统计单元测试。
- **FR-010**：与用户逐字段审查删减并记录意见；未讨论项不能统一取消检查。
- **FR-011**：权限、并发、科学冲突、人工身份与整篇最终批准保持；不删历史、不伪造人工确认。

## 关键实体

科学字段、共享审核单元、当前核对凭证、历史、人工说明、模型任务、一次按钮操作轨迹。一个输入框未必对应一份独立核对结论。

## 成功标准

- **SC-001**：当前447个核对单元、518个可编辑入口全部可定位，普通物性共享单元明确；动态定义中的非当前实例另标。
- **SC-002**：未改科学值的确认/说明保存，科学数据写入0次、完整状态刷新0次、LLM请求0次。
- **SC-003**：单字段操作的核对/历史查询不返回无关item_key，不携带整篇历史，必要权限/当前版本信息除外。
- **SC-004**：相同有效版本重复完成不重复全文定位或生成重复记录；来源/规则/冲突变化反例仍拒绝。
- **SC-005**：真实页面无修改、改单字段、仅理由、附件、并发、初读、显式重核及批准有独立轨迹；延迟目标待逐项审查确定。
- **SC-006**：图能切换全部字段，明确现状/建议与已测/未测，窄屏可读；方法有源码依据。
