# 为超导快讯与最新文献增加自动分类标签

## 目标与已确认规则

对新闻、科研报道、预印本、期刊论文自动打标签，覆盖已有条目和后续新增条目。只根据现有标题、摘要判断，不下载全文，不提供人工编辑。

| 分类维度 | 标签规则 |
|---|---|
| 研究类型 | 实验、理论、综述，按主要贡献单选；判断不出则留空 |
| 理论子类 | 计算类、方法类、理论与机制类，单选，仅理论类型展示 |
| 材料家族 | 从数据库现有材料家族目录选择，允许多个；判断不出则留空 |

综述仍可带材料家族，例如“综述 · 铁基超导体”。新闻报道按其介绍的研究内容判断；普通产业资讯无法判断研究类型时不强行分类。

已核对相关历史需求：#63、#88 未包含这组标签；#79 的材料家族目录及 #128 的理论子类定义可复用。

## 分类与后台处理

- 使用现有 LLM 配置生成结构化分类，读取数据库当前材料家族及别名；不硬编码目录、不自动新增家族。
- 沿用现有理论子类含义：使用既有方法得到材料结果属于计算类；方法本身创新属于方法类；模型推导或机制解释属于理论与机制类。仅出现 DFT、软件名等不足以判类。
- 分类独立于采集事务，在采集成功后异步处理。复用资讯调度与 Worker，以短批次处理，避免历史回填长期占用采集任务。
- 保存分类结果、状态、输入指纹、规则版本、模型和简短判断依据。标题、摘要或分类目录变化后重新判断；输入不变时复用结果。
- 写回前核对输入指纹，防止旧任务覆盖更新内容；合并重复条目后，以保留条目的当前内容重新判断。
- 无依据时保留空值；模型失败记录失败并有限重试。分类失败不删除资讯、不影响采集成功状态。
- 历史条目分批补齐，支持中断后继续；优先处理新增和更新条目。仅写资讯分类数据，不改正式论文或科学审核结果。
