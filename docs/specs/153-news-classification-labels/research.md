# 设计依据

2026-11-02：自然周适合周报归档，不适合作为持续资讯流的默认截断。周一刚收录但周日发表的论文仍应可见，改为全库按发表日期连续倒序。最近七天仍会在低频来源中产生空列表，故不引入另一个时间窗口。日期精度与后台采集状态继续保留，列表有内容不代表采集正常。

- 正式论文具有现成三种类型、理论子类及家族目录；快讯独立储存，故仅共享分类语义，不导入全文审核流程。
- 复用资讯 Worker，单批三条，调度每分钟追加一批；已有采集任务先入队，避免历史回填长期占用。
- 分类前持久化尝试次数，RQ 超时也计入三次预算；五分钟领取租期，失败一小时后重试。内容或目录变化可重新尝试。
- 分类结果单独保存，不增加资讯主表解析负担；资讯合并删除时级联清理，保留行的旧结果由指纹判定是否可用。
- 前端按实际可用宽度折叠家族标签，而非固定数量；抽屉全部展示。
- 迁移接在现有 20261022_0147b 分支，不擅自合并另一并发迁移头；部署仍使用仓库多头迁移约定。
