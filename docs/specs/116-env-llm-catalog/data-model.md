# 配置实体

- **目录项**：稳定 ID（如 `LLM3`）、显示名、API URL、型号、密钥。四字段非空；正整数编号可不连续；按编号排序。同服务商可有多个项。
- **公开目录项**：仅 ID、显示名、型号。禁止输出密钥、掩码、URL。
- **浏览器选择**：个人配置沿用旧字段；服务端选择只保存 ID 与显示元数据。不是账号跨设备配置。
- **执行配置**：复用 `LlmConfig`，新增可选目录 ID/显示名，保留个人来源标记。
- **任务快照**：独立短期 Redis 键保存实际执行配置；公开任务状态中的来源 ID 用于识别必须拒绝的快照缺失，不将密钥混入业务状态。

无 SQL 迁移。目录来自部署配置，不从业务包导入。删除并重用编号视为部署配置调整；已经入队的任务沿用入队快照。
