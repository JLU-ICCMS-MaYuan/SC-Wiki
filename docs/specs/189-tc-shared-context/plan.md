# 实施方案：共同计算资料只存一次

依据[规格](spec.md)、[调查](research.md)、[数据模型](data-model.md)及[接口合同](contracts/workflow.md)。

## 数据所有权与实现

复用PropertyModule.metadata_json的版本化tc_contexts目录保存明确组与方法的共同资料；不再逐点存共同parameters／calculation_conditions／method_code／method_raw。点保留Tc、µ*、代表标记、独有覆盖和稳定组／方法引用。SQL点的科学方法由引用读取，现有definition_key仅作为表单定义引用保留；读适配恢复原前端形状，不改变共同参数区或方法／点排列。
工作稿JSON及快照使用相同压缩表示，API及前端读取按引用投影视图。共同字段修改更新其目录一次，点修改不改目录。只共享已明确声明的稳定组及真实相同资料，不因同名／同压或软件自动合并；未声明的旧记录只读兼容，读取不写库。
SCDFT可空µ*，显式mu_star_status区分unknown/not_reported/not_applicable/reported；真0保留为0。特殊实现有报告值时照原文保存。状态通过原控件占位与已有设置表达，不另建表单。

## 跨功能依赖

183与185提供字段资料、局部写入基础；189在其上提供共同资料目录；192消费这些规范合同并冻结／交接；187消费相同工作稿修订号且不替换快照。186独立评估，不混入尚未确认的性能重构。

## 需求／设计／任务／证据映射

FR-001～007→真实去重和完整往返；FR-008→µ*语义；FR-009～014→原设计、只读、冻结与兼容。任务按下方Tasks执行，证明信号为真实读写／权限／完整宿主／持久化结果，不以文件存在或字符串检查替代。

## 执行质量门

先加入实际故障和边界测试，再实施；有PDF字段或证据处理变化时定向真实重提。最终执行科学表单双门、受影响回归、独立既有失败基线与候选构建。未推送的远程链接仍待验证，不据此关闭Issue。


## 2026-11-04：方法身份修复的当前实施基线

本节修订上文将全部 method_raw 视为共同资料的旧决定：标准方法代码与必要的共同方法名称归方法目录；既有 method_raw 继续表达每个结果的原文写法，逐点保存。共享方法与逐点原文不再逐字等同。

新写入的 tc_contexts 目录使用版本 2，tc_context_ref 保持组／方法寻址协议版本 1，并以 method_raw_owner=point 明确原文归结果所有；读取同时支持旧目录版本 1；旧版本的共同原文名称按旧含义展开，不在读取时写库。版本 2 保留逐结果 method_raw。方法行归属使用既有 group／method 与程序分配的稳定编号；解释写入已有 reason，逐结果原文与引用继续使用 method_raw 和来源记录。此前新增模型 method_name 的做法已撤销，不能以关系元数据名义扩大固定字段。历史共同名称仍兼容读取，不新增 unknown 的表单编辑框，不自动清理已有资料。

集中方法语义函数供模型整理、Tc 集合校验、存储及核对依赖复用。具体名称参与其他／未知方法语义；标准方法原文可有不同写法。变更显式方法身份／具体方法名进入方法及结果的必要核对输入。普通保存维持现有本地校验、修订及租约规则，不发起模型。冲突信息包含组、方法编号及两条记录。

FR-015～019／SC-009～012 → 集中方法语义、版本化存储、字段依赖、现有共享编辑器 → T005～T009 → 失败固定重放、无损往返、反例、真实来源重提及完整宿主回归。原失败数据只在隔离环境使用；旧快照及原任务不改。

标题使用真实Tc点数形成统一格式，单点、多点、范围端点共用同一计数，方法名称不因数量切换。验证器接入main/supplementary实际IR来源；隔离保存前显式采用正式读取投影建立空metadata容器，其余原文、关系、数值和来源继续全文严格比较。原任务前后快照与固定重放、新模型调用分别留证。

历史实现曾在 unknown 方法旁显示“方法描述”，这超出了固定字段和原页面要求，现已撤销。other 保留原有“具体方法名称”；其余解释通过已有 AI 理由及来源记录保留。


## 2026-11-05 当前约束修订

以 [Spec 的固定字段纠偏](spec.md) 为准：撤掉 unknown 的方法描述输入，不再允许 AI 输出 method_name；解释使用既有 reason，原文及来源使用已有字段。既有 group／method 标签只表达明确归属，程序分配原有稳定编号；不得按枚举相同自动合并。保存不因同一显式方法行的原文写法不同而拒绝；语义真伪仍经过既有来源核对。历史 method_name 只兼容已有资料，不作为新增模型字段或表单输入；不回填、删除或覆盖业务草稿。
