# 提取、建议与表单契约

**适用范围**：#139 的模型输入／输出、现有上传 Worker 和 JSON payload 边界。没有新增公共 HTTP 路由。

## 版本、来源与输入

- 保持当前领域 `extraction_version=1` 和科学草稿顶层版本；增加的 `payload.source_associations` 按内部 `version=1` 解释。新增字段及读写兼容必须测试，不改已发布定义校验和。
- 每次模型调用使用上传任务当前模型及已有服务端调用配置。PDF 输入来自有效 main／supplementary 的选中 IR 块；TXT/MD 在已有来源转换边界生成同义上下文。普通附件、引用工作和外部知识不能作为本文共用设置。
- 表格输入携带表头、行列、单位、分组、表题、脚注、延续块及原定位；Methods 输入携带所有读取窗口的原文和状态，不只给论文概要或关键词。
- 超预算时按完整块及行组分窗；不能剪断引句、漏读未声明区域或用模型摘要冒充逐字来源。每窗最多一次重试，取消即时检查；失败窗口标缺口。

## 领域提取输出

继续生成 `material_states[].property_modules[].records[]`。每个直接事实均有当前来源中的逐字证据；论文级叙述汇总不得重写科学值。λ、ωlog、μ* 使用规范参数名，单位明确时转换并保存原始表示。表头／脚注作为上下文仍需被覆盖账本登记，不能用“表注”作为忽略科学参数的排除理由。

表格一行可产生一个范围结果或多个明确配对的标量结果，但必须保存共同原始行身份。服务端核对 8 个逻辑行，而非用记录条数替代覆盖正确性。

## 共用关系候选输出

模型仅输出目标记录引用、允许的 `target_path`、报告值／单位、阶段、作用域及例外、`basis_kind`、事实引文、范围引文和简短说明。完整字段见[数据模型](../data-model.md)。目标引用用现有记录身份和科学指纹共同验证，不接受模型自创的数据库 ID 或通过数组位置绑定另一条记录。

- 作者明确指定范围的同一计算条件可联合引文为 `paper_quote` 候选。
- 依赖全文理解的共用关系为 `paper_inference`，其数值必须仍是原文报告值；不能生成未报告的数值。
- 关系未定不得标记为全篇共用；模型声称已读全文不能代替窗口阅读账本。

## 建议阶段集成与写入规则

在 `upload_jobs.py` 现有最终直接 Claim 检查之后、保存草稿之前，复用 `generate_upload_suggestions` 与证据建议规则完成关系补空。共享上下文提供关联证据；补空必须按叶子字段工作，不能因为 payload 已存在就跳过全部空条件，也不能用新 payload 覆盖旧 payload。

补空前检查目标内容、来源指纹及已有值，精确地合并允许路径和阶段扩展，执行记录及元数据校验；只写可采用的候选，所有人工值和局部明确条件受保护。写入推断时沿用 `uncertain`、推断说明、内容／来源 hash 和后续人工复核；不降低 `validate_claim` 的直接证据要求。

重试采用同版本同内容的幂等键。Methods、表注、模型或提示词变化使上下文缓存失效；旧分段缓存也要包含上下文版本／hash，不能只重跑汇总。

## 表单及证据显示

- 保持现有 λ、ωlog、Tc–μ* 和计算条件控件，使用现有 schema 表单及扩展列表；无布局重设计。
- 计算阶段在补充条件名称和来源说明中可见。主阶段不确定时，不把其他阶段参数填进平面槽位。
- 明确反向配对使用现有 `mu_star` 范围；未配对范围只显示为补充参数及待核对原因，两端 μ* 留空。
- `source_associations` 在现有来源／AI 理由入口展示关联说明及分别定位的表行、表注和 Methods；附加元数据不作为普通科学参数编辑控件。
- 编辑后解释绑定失效，保存／重开不能恢复已清空值或旧核对状态；所有返回、提交、返修和导出保留附加元数据。

## 权限、错误和降级

沿用当前上传任务、草稿、论文修订及导出的所有权和版本检查，不增加新权限通道。客户端元数据不能指定自己的 validated／supported 状态，权限或内容指纹失配遵循既有拒绝路径。

内部缺口原因采用明确分类：`source_missing`、`context_incomplete`、`quote_unlocated`、`scope_ambiguous`、`condition_conflict`、`unit_unknown`、`pairing_unknown`、`target_stale`、`generation_failed`。这些是拟新增审计原因，不是已发布 HTTP 错误码。

直接事实或覆盖检查失败仍遵循原任务失败／人工复核边界；不得用空候选跳过。单个推断未能补足则保留原有科学记录、空值和原因；不宣称该项已完成。无来源、未读窗口、单位不明、配对歧义均不得用软件默认值填补。

## 验证边界

契约回归覆盖双入口、真实生产者消费链、payload 深合并、配对方向、空值、阶段、局部例外、伪造引句、取消、重试、缓存失效与来源变更。模拟模型响应只能证明机械转换，真实模型与原 PDF、浏览器和 MySQL 验收分开记录。
