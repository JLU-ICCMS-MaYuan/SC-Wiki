# 行为契约

- 稿件重建：同内容、同来源、同范围在交接和返修中产生相同字段版本；真正变化失效。
- 来源展示：evidences为当前字段明确相关依据；旧整包legacy_evidences不可作为缺省显示。支持与反证均可关联；共同依据保留每次使用的对象和范围。
- AI理由及人工操作原位保留。真实失败、重试及只读保持。 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../../221-scientific-field-sidebar/spec.md)，本处不再独立维护。
- 核对：原有单字段主动入口保存后读取完整正文、SI和必要人工材料，结果绑定当前字段；查看与保存不自动核对。
- 提交：有效结果复用，必需未通过阻断；不恢复#207已取消的入库逐字科学裁决。
- 清理：只执行用户确认的本机对象，全新上传不复用旧提取；不代办真实最终批准。
