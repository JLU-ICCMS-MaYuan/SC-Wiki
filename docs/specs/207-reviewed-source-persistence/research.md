# 设计依据

#194的source_catalog从模型阅读副本去除HTML注释，原始Markdown未删；旧#103入库调用locate_with_reason比较连续文字。只改清洗虽可修本例，却保留两套审核标准，不符合最终澄清。

采用来源身份解析：文件/块/片段身份确定资料存在且可读；已审核引用按原样保存，归纳文本不必逐字出现在原文。科学判断仍走原模型流程，不新增自动通过入口。

版本转接沿用source_transfer_matches比较文件正文及角色，验证迁移没换资料，不判断资料是否支持字段。外部题录、人工材料保持身份，不硬塞成本文PaperEvidence；人工决定不强求伪造原文。

未经审核的自由引句保存不借此获得通过；已审核却缺来源身份应报告关联缺失。原人工决定下无法定位的旧引用仍可归档，不冒充论文支持。不批量改用户数据。
