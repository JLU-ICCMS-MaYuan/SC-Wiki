## 2026-11-03 既有失败保留语义补齐

H3S 黑盒测试发现，核对结束时程序对所有不可复用结果统一写成“依赖变化”，连真实技术失败也被覆盖；其原错误类型无法从最终字段结果追查。按 FR-003 补齐：技术失败继续保持未核对和 `human_confirmed=false`，保留真实原因、原请求版本及成功结果；当前版本重新绑定只供错误展示与重试，不能成为科学通过。只有没有技术错误、确因内容或真实依赖变化失效的已完成结果，才使用依赖变化提示。不增加自动通过或无限重试。
