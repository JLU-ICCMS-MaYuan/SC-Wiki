# 论文总结增量实施计划

关联 [Issue #120](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/120) 与 [Spec](spec.md) 的 FR-015～018。
现有 [实施计划](plan.md)聚焦材料家族，本文件记录总结增量；共用 `paper.summary` 和既有字段来源结构。

## 生成与校验

全文汇总 LLM 从本文各分段候选及摘要生成 3–5 条编号英文单句结论。原摘要达到 70 词时，总结应略长于摘要且不超过约 1.5 倍；短摘要不机械凑字数。抽取阶段的回退总结使用相同规则；两条路径在草稿归一化前共用格式、长度和摘要重复校验。若不合格，只针对总结用本文来源重试一次；仍不合格时置空并禁止通用字段建议自动回填总结，保留其他已提取字段并提示人工核对。原摘要保持原文，不参与改写。

## 来源与界面

`paper.summary` 使用既有 `paper_synthesis` 来源类型及 `check_mode=synthesis`。模型核对的理由和已定位引句绑定当前字段值与来源版本；聚合后保存完整核对理由，侧栏显示该理由而非直接记载的固定回退文案。仍以实际引句作为 `supported` 的必要条件，人工修改后只读保留旧理由。

## 旧草稿与验证

对唯一 H3S 上传任务核对文件身份、草稿版本、总结生成来源及人工改写记录，保存私有快照；只在未改写且版本一致时重算并保存总结及对应核对。记录摘要与结论对照、可定位引句、侧栏展示、更新前后草稿差异；无法满足前置条件时保留原值并报告。详见 [验收记录](summary-validation.md)。
