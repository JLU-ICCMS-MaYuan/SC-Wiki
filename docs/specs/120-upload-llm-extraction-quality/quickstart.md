# 材料家族分类验收步骤

## 自动验证

1. 运行 `scripts/run-tests.sh backend tests/01_decentralized_uploading/test_issue120_material_family.py`，检查目录匹配、证据、失败和版本边界。
2. 运行相关上传与来源核对回归；前端运行材料家族控件测试与构建。
3. 使用固定模型响应分别经过默认和 #114 可选汇总分支，确认二者生成相同的论文级选择结构。

## 真实 H3S 草稿

1. 在有权访问的本机环境核对唯一 H3S 任务的标题、正文与补充材料身份，读取当前分类、证据、草稿版本和人工修改；先存私有快照。
2. 使用当前目录与实际论文来源执行定向重算，核查“氢基超导体”目录 ID、代表性本文引句和简短理由。若值已正确，保持原值；只刷新旧的材料家族核对。
3. 重新读取草稿和核对，比较除材料家族与对应核对外的字段；在页面确认当前材料家族可见、错误的不一致提示消失。若版本已变化，停止写入并重新取当前值。

真实模型输出用于单篇验收，不代替多家族、新体系与异常路径的确定性回归。

## 材料家族 AI 理由增量验收

1. 读取 H3S 当前有效核对：`reason` 已说明富氢材料到目录 ID 1 的归类，而 `ai_reason` 为空；打开侧栏后须把具体判断显示在“AI 理由”，不显示固定直接记载文案。
2. 分别检验新分类、旧结果缺理由、用户改选、引句失效及上传转论文；旧理由只作历史，不覆盖当前草稿的其他字段。
3. 总结字段保持已有全文归纳说明；按 [#109 共用侧栏契约](../109-field-evidence-and-ai-suggestions/contracts/api.md) 检查新旧结果的一致性。

本轮 H3S 上传页已实测目录 ID 1、“氢基超导体”、第 4 页本文引句和具体 AI 归类理由；只读真实模型重核也返回同一分类及判断桥梁。定向后端 63 项、前端侧栏及总结 40 项与前端构建通过。正式转接和管理员重读尚未完成，T025、T028 不提前勾选；完整测试边界见 [#109 验收记录](../109-field-evidence-and-ai-suggestions/quickstart.md#本轮实测)。
