# 上传任务独立解析页交互 Demo

关联 [Issue #140](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/140)。本目录只保存交互原型与验证记录；不作为已经确认的 Spec 或已实现产品功能。

## 本轮用户原话

> 你可以先做一个 demo，我看看好不好，再来决定是不是要完善 spec

## 体验路径

1. 打开 `index.html`，点击任务条框的文件名、状态或空白区域，进入 `detail.html?task=...` 独立页面。
2. 在详情顶部点击“返回上传记录”，回到任务列表。列表不显示内联解析区域，也没有“查看解析／收起解析”按钮。
3. 第一条任务提供等待校对示例：可修改论文标题并保存演示草稿，刷新可恢复；有未保存修改时，通过页面入口返回会弹出保留提示。
4. 第一组材料状态默认展开，四类性质各自折叠，声子 DOS 放在动力学性质，谱函数说明放在超导性质。本原型没有加载曲线或接入谱详情。
5. 第二条任务展示处理中页面，第三条展示失败页面。多选框、取消、清理和批量删除独立操作；可通过“重置演示”恢复全部样例。

## 启动

在仓库根目录运行以下命令，再打开 <http://127.0.0.1:18440/index.html>：

```bash
python -m http.server 18440 --bind 127.0.0.1 --directory "docs/specs/140-upload-task-detail-page/assets/navigation-demo"
```

只依赖浏览器与静态文件服务，没有外部脚本、字体或业务 API 请求。

## 演示边界

- 所有任务、文件名对应关系、状态和材料数据均为界面样例，不是对真实论文的提取结果。科学标量使用“待核对”，不填造数值。
- 保存、取消、清理及批量删除只修改浏览器中专属的 `scwiki-140-navigation-demo-v1` 数据。上传不可用；提交审核只显示演示反馈。
- “重置演示”恢复初始任务与标题；已有产品数据和其他页面存储不受影响。
- 本轮未修改 Spec、Plan、Tasks 或正式前后端代码；用户查看反馈后再决定是否完善 Spec。
- 页面返回入口的未保存提示已验证；浏览器原生前进后退、刷新未保存时的系统提示及完整可访问性未作验收。

## 已执行验证

2026-10-16，使用 Codex 内置浏览器实际操作：

- 复选框选择只改变选择状态，地址保持列表页。
- 条框空白区域可进入正确的 La–Sc–H 任务详情；顶部返回入口可回列表。
- 键盘 Enter 激活第二条任务链接，进入对应处理中页面。
- 修改标题、保存、刷新后，演示草稿保留；未保存修改返回时出现三个选项，放弃修改后回到列表。
- 清理第三条演示任务后，任务数从 3 变为 2，地址保持列表页；重置后恢复 3 条任务。
- 实际浏览器日志未发现页面错误；`node --check demo.js` 通过。

窄屏完整交互、取消确认、批量删除全流程和真实业务集成未完成验证，不据此声称 Feature 验收通过。Spec 保持原有草稿状态。
