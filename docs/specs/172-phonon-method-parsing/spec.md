## 背景与目标

CaH6 正文与补充材料在第 3 步失败。Worker 日志、保存的模型响应及离线重放确认：#139 的提交 a2c74489 新增条件清理时，把分组对象当成记录列表读取，触发 `'str' object has no attribute 'get'`。

正确提取、保存和展示声子方法，并保留无原文依据的计算条件不得补猜的检查。名称和格式是两个问题；去掉名称前缀不是已证实的崩溃修复，也不是用户命名导致程序错误。

## 需求与取舍

- FR-001：面向用户统一称“声子方法”，不加“电声耦合的”前缀；位于材料状态“超导性质”的相关计算条件中。
- FR-002：声子方法与电子结构理论、软件、泛函分开，保留原文、材料及计算阶段归属。用户名称简化不删除后台归属信息。
- FR-003：新提取结果采用一致的数据结构；有界处理本次含义明确的分组写法，不因格式读取崩溃，不静默丢弃声子方法。
- FR-004：含义不明或仍不合格的数据按现有流程报错；不新增重试次数、不扩大自动纠错机制、不吞掉全部异常。
- FR-005：QE 泛函未报告留空，明确报告保留，不能由 VASP 泛函推算。
- FR-006：修复 PDF 字段相关代码后，沿真实解析流程对受影响字段重跑，不只检查已整理表单。
- FR-007：把字段重跑验证要求写入 AGENTS.md，Spec 留存具体方法及证据。

1. 从原 PDF 正文、补充材料及必要上下文开始，不使用最终已填答案作为输入。

3. 受影响字段重新调用 AI 提取及正式后续处理，不复用该字段旧结果冒充重跑。
4. 检查值、名称、位置、来源、保存和重读；共用处理改动覆盖相邻受影响字段。

6. 在隔离副本验证，保留用户草稿；明确复用和重跑步骤，不称为整篇验收。
