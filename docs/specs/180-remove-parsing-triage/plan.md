# 精确撤回实施方案

依据 [Spec](spec.md) 与 [调查](research.md)。数据事实来源仍是原文件、IR、草稿科学值与审核记录。

## 执行顺序与职责

1. 固定当前分支与共享工作区基线；添加能在完整宿主复现误增入口的行为回归，先确认失败。
2. 删除独立前端分类组件、快照、翻译与宿主入口；账本类型迁回通用草稿结构，不读取历史分类。
3. 删除后端附加分类及专用重建脚本；保留原账本生成、出版年份处理和草稿版本锁。题录验证脚本移除分类步骤。
4. 完整 Worker 隔离保存路径验证新账本不生成 triage、原文保留； 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../221-scientific-field-sidebar/spec.md)，本处不再独立维护。
5. 正式表单双门、受影响科学回归及候选构建通过后，回写 #172 历史撤销关系、Overview、HTML 与字段规则库；只提交本次增量。
