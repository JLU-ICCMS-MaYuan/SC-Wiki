## 材料小组连续处理补充

- FR-005：材料表单按小组串行处理，默认每组2个材料状态。完成本组填写、来源检查、核对与保存后，才进入下一组；不先填写全部再统一核对。
- FR-006：模型填写只接收本组候选及必要身份和原文；核对只处理本组字段，优先读取本组来源，其他原文仍可定向查询。超限不能退回发送全稿，仍沿现有96k预算及每候选四轮填写/三轮核对上限。

- FR-008：进度显示当前组、总组数、当前填写/核对/保存动作及已完成材料数，不把部分完成标为整稿可送审。
- SC-004：5个状态必须按填1/核1/存1、填2/核2/存2、填3/核3/存3顺序执行；非首组全局身份不漂移；本组失败后组零请求；同源同模型续跑复用前组；来源/模型/输入变化使检查点失效。
- SC-005：同源真实制品验证实际请求只含本组候选/字段，核对不再默认携带无关原文；超限停止或缩小本组，不扩大预算。真实网页黑盒与隔离实验分别记录。
