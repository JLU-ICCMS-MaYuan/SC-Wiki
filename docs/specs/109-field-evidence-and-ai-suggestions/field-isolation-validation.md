# US11 字段影响隔离：实现与验证

## 实现范围

对应 FR-038—043、SC-027—031、T054—T059。用户实施授权原话：

> 开始落地

实现、测试及文档提交：`ba96f8d`。GitHub #109 已追加该提交的修复与验证进度并回读核验，原话、旧内容、唯一 `type:feature` 与 OPEN 状态保留；本地 Spec/图片未推送，远程链接仍待验证。

共享影响计算复用已有 `dependency`、稳定字段身份和当前值读取。程序派生项不再因同状态任意上下文编辑全部失效；已知旧记录缺依赖字段时，按其确定性规则读取输入。工作流在 React 完成当前事件后合并通知、比较实际值，只有受影响项清除旧确认及说明；同值、重复事件和无关记录保留。删除前项使用稳定身份定位，不把旧数组位置当成新位置的修改。

服务端的群号、晶系和单位换算断言明确包含实际输入；材料身份仍保留，压强等无关字段不进入这些派生项自己的摘要。物性记录的真实科学条件仍在原断言中，未关闭跨字段失效、样式标记或提交门禁。

## 依赖与责任矩阵

| 项目 | 实际影响来源 | 无关变化的处理 | 事实与实现位置 |
| --- | --- | --- | --- |
| 元素种类数 | 自身值、化学式、材料身份、输入的有效核对 | 核处理、独立压强或空间群编辑不触发前端整组失效 | `state_records`、`apply_derived`、`evidenceFieldAffected` |
| 标准映射群号、晶系 | 自身值、报告空间群符号、材料身份、输入的有效核对 | 核处理不影响；压强不改变派生项自身摘要；输入来源真正失效仍遵守 `apply_derived` | 同上 |
| 单位换算值 | 自身值、对应原始数值、单位、材料身份及输入有效性 | 其他条件不进入本项确定性计算摘要 | `converted_state_value`、`state_records` |
| 普通材料字段 | 自身值、材料身份及服务端断言上下文 | 不能只因同卡片编辑而清空前端核对 | `field_records`、`currentEvidenceField` |
| 物性记录 | 当前记录、材料身份及其科学条件 | 其他记录的修改或排序不串项；核处理、压强等真实条件变化仍失效 | `record_claim`、稳定状态/模块/记录键 |
| 论文级字段 | 当前字段值及既有明确联动 | 其他字段编辑不全页失效；作者角色继续归入作者断言 | 共享工作流、字段锚点 |
| 结构来源 | 稳定结构哈希及明确结构编辑通知 | 只读浏览、折叠不发起编辑失效 | 既有结构入口与共享工作流 |

同值比较沿用稳定键忽略排序和纯证据字段，并将空字符串与空值视为相同空字段。材料名/化学式改变仍按既有身份规则影响本状态断言。前端不会把“值未变但真实输入来源已失效”伪装成有效支持。

## 浏览器与真实存储证据

`evidence-field-isolation-browser.mjs` 使用 Chromium 加载正式页面组件；`evidence-isolation-storage.py` 使用真实 MySQL、新 Session、`ScientificUploadDraft`、核对快照和持久结果读取。整个存储桥持有外层事务，每次写入使用保存点，退出回滚；目标为随机 UUID，不读改真实论文。

| 入口 | 组件与视口 | 观察阶段 | 结果 |
| --- | --- | --- | --- |
| 上传 | 正式 `UploadTaskEditor`，1440px | 初始、编辑后、等待、首次保存失败、重试成功 | 3 项无关字段边框与标签均不红，原说明可读 |
| 返修 | `revisionPaperId` 正式保存路径，390px | 同上，自动保存等待超过 5 秒 | 同上 |
| 管理员 | 实际管理编辑路由，1440px | 同上，点击保存及重试 | 同上 |
| 超级管理员 | 同路由、超级管理员夹具身份，1440px | 同上 | 同上 |

共 20 个观察点通过，保存后从 MySQL 读取到 `sscha`；拒绝首次保存时数据库仍为 `classical_static`，无关字段仍保持有效。重开元素数来源侧栏能读到原人工说明；截图与结构化结果保存在 `/tmp/scwiki-evidence-isolation/`。

浏览器 HTTP 路由和角色身份由夹具适配，权限本身未重验；核对结果与草稿持久化不是前端内存 Mock。自动核对任务请求仅返回已有快照，不调用模型。没有执行真实上传解析、正式返修提交、管理员批准、推送或部署，不用本轮结果关闭 #109 其他验收项。

运行方式：

```bash
cd frontend
npm run test:upload-ui -- tests/01_decentralized_uploading/evidence-field-isolation.test.tsx

```

浏览器脚本在仓库根运行，设置本机 `PYTHON_BIN`、`PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`FRONTEND_URL` 和显式 `SCWIKI_CURRENT_MYSQL=1`。存储桥从本地 `.env` 读取数据库连接，不输出凭证；外层事务退出回滚。

## 当前边界

本次收窄了部分派生项的内容摘要；先前按旧断言摘要保存的核对可能需要一次重新核对，不自动把旧人工决定授予新摘要，也不批量改写旧记录。符合当前摘要的结果在无关编辑后保留；输入值、来源或规则真正变化仍按版本失效。权限、历史恢复、真实模型准确性和 #109 其余未完成工作不因本专项通过而视为验收。
