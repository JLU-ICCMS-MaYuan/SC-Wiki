# 实施计划：社区 Tc 双图固定 4:3 比例

**GitHub Issue**：[#111](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/111)

**日期**：2026-09-19；**规格**：[spec.md](spec.md)

## 技术上下文

- TypeScript 5.6、React 19、MUI 7、Recharts 2.15、Vite 5。
- 仅涉及 `frontend/src/components/ChartScatter.tsx` 与 `frontend/src/pages/share.tsx`。
- 使用现有 Vitest、Python 契约测试及独立 Chromium 浏览器脚本；不新增依赖。

## 实现方式

1. `ChartScatter` 统一提供 `CHART_ASPECT_RATIO = 4 / 3`，绘图父容器使用 CSS 比例，`ResponsiveContainer` 填满该容器；移除误命名且实际固定高度的 `minHeight` 属性和两个调用参数。
2. 加载占位复用同一比例。图表仍由 Recharts 根据新尺寸重新绘制，不缩放字体、点或 SVG 图片。
3. 控件保持现有标准宽度并限制不超过卡片宽度，允许按可用空间换行；两图共用布局规则。字段提示使用单行省略并提供完整标题，避免不同字段名称改变绘图区位置。
4. 图例保留最低高度并允许增长，取消裁切；家族文字允许断行。网格卡片拉伸到同一行高度，绘图区仍保持相同尺寸。
5. 坐标域与业务回调不变。若窄屏刻度/标签重叠，只调整标签排版或刻度密度，不改变数值含义。
6. 数据散点直接绑定 `Scatter.onClick`，修复旧整图事件没有 `activePayload` 导致点击详情不可达；背景不绑定。浏览器验证悬浮与详情真实请求。
