# Feature 规格：社区 Tc 双图固定 4:3 比例

**GitHub Issue**：[#111](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/111)

**创建日期**：2026-09-19

## 背景与目标

当前图表宽度随窗口变化、高度固定，导致宽屏下过于扁长。用户确认两图采用宽∶高 = 4∶3，固定形状并保留响应式尺寸。

## 用户场景与验收

### US1：不同窗口下保持图表形状（P1）

访问者调整窗口或侧栏后，仍能看到形状一致、可比较的两张图。

**独立验收**：真实浏览器测量五种窗口宽度下的绘图容器。

1. 假如打开 `/share/charts`，当窗口宽度为 375、768、1440、1920、2560px，那么两图宽高比均为 4:3。
2. 假如桌面两图并排，当收起/展开侧栏或选择不同字段、家族，那么两图等宽等高，绘图区上下边缘对齐。
3. 假如窗口变窄，当两图变为单列，那么筛选器与图例可以换行，页面不横向溢出。

### 边界与异常

- 无数据和筛选后无点仍显示坐标轴、背景、参考线及空提示。
- 独立加载、请求失败和重新选择字段仍按既有逻辑工作。
- 家族数量增多和中英文长名称不能使图例被固定高度裁切。

## 功能需求

- **FR-001**：两图包含坐标轴的绘图容器统一保持 4:3；标题、筛选器、字段提示和图例不计入比例。
- **FR-002**：随可用宽度计算高度，保留宽屏双列与窄屏单列，并排时绘图区上下对齐。
- **FR-003**：控件和图例随空间换行，文字与散点正常绘制，不整体拉伸、不产生横向页面滚动。
- **FR-004**：保持字段/家族独立筛选、背景、参考线、空状态、悬浮提示和论文详情点击行为。
- **FR-005**：只改变前端展示，不改变 API、数据、坐标域、存储和个人偏好；不新增比例设置。

## 成功标准

- **SC-001**：五种窗口下容器高度与宽度乘 3/4 的差不超过 1px，桌面侧栏切换及持续缩放后仍满足。
- **SC-002**：并排时两图宽、高及上下边缘差均不超过 1px；窄屏无横向溢出，控件、轴标签及图例可见可操作。
- **SC-003**：有数据、空数据、筛选、悬浮和论文详情通过浏览器验收，相关回归与前端构建通过。

## 假设与依赖

- 比例固定于绘图容器，不要求扣除坐标轴边距后的网格也严格为 4:3。
- 复用 #30、#72 当前代码；无新增前置依赖。
- 浏览器布局验收使用隔离 API 夹具，不将其表述为生产数据或部署验收。

## 范围外事项

后端修改、数据库迁移、数据源修复、全站侧栏重设计及生产部署。
