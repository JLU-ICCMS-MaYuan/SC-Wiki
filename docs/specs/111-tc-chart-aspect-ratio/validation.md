## 验证结果

- 真实 Chromium 浏览器 26 组布局测量通过，使用真实 AppShell、Recharts、ResizeObserver，只隔离 API 数据。
- 五种宽度各覆盖中英文；另覆盖连续缩放、1199/1200px 断点、侧栏收起/恢复、不同字段、无数据、失败恢复和家族选择。
- 每组测量 4:3 容器、并排图与网格上下边缘、轴标签与参考线标注边界、刻度重叠、控件/图例裁切及页面横向溢出。
- 真实散点悬浮和点击通过；详情请求 `/api/papers/99111` 后显示夹具论文。没有浏览器异常，所有夹具 API 请求均为 GET。
- `community-charts.test.tsx`：20 项通过，包含新增的真实散点事件回归及背景点击不打开详情。
- 本次布局契约与统一坐标域：2 项 Python 检查通过。
- `npm --prefix "frontend" run build`：TypeScript 与 Vite 构建通过。仍有既有的 3Dmol eval 与大体积 chunk 提示。

## 基线与发现

- 改动前，浏览器在 375px 窗口测得 247×390px，4:3 断言失败；改动后为 247×185.25px。
- 浏览器发现纵轴标题边缘越界，已增加 8px 左留白；英文参考线标注统一为 12px，避免越过纵轴。
- 原有整图点击事件不提供预期散点 payload，无法打开论文；改绑实际 Scatter 点事件后，浏览器与组件回归均通过，原因见 [研究](research.md)。
- 旧 `test_issue30_tc_chart_preferences.py` 改动前为 13 项通过、7 项失败。本次更新布局断言后为 14 项通过、6 项失败，无新增失败。
- 剩余 6 项均在修改前已失败：3 项后端旧表/字段/缓存键断言，3 项前端旧硬编码文案断言。实际代码已改为版本化物性记录或翻译键，本次未扩大到这些历史测试的修订。
