# 界面契约：Tc 双图尺寸

- 页面入口仍为 `/share/charts`，宽屏在现有 `lg` 断点双列、窄屏单列。
- 图表内部移除 `minHeight` 参数；两个现有调用方同步移除，统一采用导出的 `CHART_ASPECT_RATIO = 4 / 3`。
- 比例容器包含坐标轴、网格、散点、背景和参考线；字段提示、控制区和全部图例不计入。
- 所选 Tc 字段、家族、坐标域、点点击回调及错误处理保持既有契约，API 和存储格式不变。
- 同宽两图等高；字段名以单行提示显示，完整名称可通过标题及选择器读取。
- 控件可换行，图例完整展示；加载占位使用相同比例，失败仍显示独立错误提示。
