## 交互设计

- 每组谱先绑定材料状态，卡片标题显示化学式、空间群和压力；计算近似在每组谱摘要中单独显示。
- 声子 DOS 位于动力学性质，α²F 与累计 λ 位于超导性质。摘要只保留类型、曲线数量、来源、近似、频域、核对状态和明确的查看按钮。
- “查看声子 DOS”“查看 α²F”分别链接独立详情页 detail.html，携带材料状态与谱类型；详情显示来源图位置、提取曲线、质量、数据预览与下载，支持返回原状态。
- 150 GPa 状态无已归属谱时使用明确空态与禁用入口，不借用 300 GPa 谱。
- 无法确认归属的谱放在单独区域；“核对归属”也进入详情页。手动确认演示仅写当前会话 sessionStorage，返回后归入相应卡片，可重置；不自动猜测压力。

## 使用方法

打开同目录 index.html，或使用本机 HTTP 静态预览。无第三方依赖、无业务 API 请求；本地文件可以预览入口和详情，会话归属操作建议使用 HTTP 预览。

## 演示数据与边界

本原型的归属、数量、曲线与质量数值是明确标记的界面样例，曲线由函数生成；不是 La–Sc–H 的真实数字化结果。来源面板也标为示意来源图，不冒充论文原图。CSV 文件标记 DEMO-ONLY。入口位置和跳转交互供用户评审；未修改生产前后端、已有上传任务、科学记录或其他任务的未提交文件。
