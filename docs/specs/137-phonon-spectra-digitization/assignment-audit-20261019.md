## 已实现修复

- 结构解析统一识别普通及 PDF 私有区 α／β／γ；坐标表题支持句点和常见完整表题。按材料、空间群、压力拆分，检查位点覆盖、多重性及展开后的化学计量；候选身份区分不同条件。
- Markdown 已丢失坐标列关系时，从原可搜索 PDF 读取行布局；已有完整逐行坐标时保留 Markdown，不从拆散的列猜测坐标。上传处理把原 PDF 路径交给该解析器。
- 结构自动归属在原空间群／压力唯一匹配基础上核对化学式。失败候选不因归属成功变成可采用结构。
- 未分配结构卡片提供已提取参数、文件页码和原文引句；失败候选也可明确排除，不提供采用入口。
- 只有曲线或真实标定的集合计入“待确认归属”；无数值且无标定的集合放入默认收起的“谱提取记录”，保留失败原因和独立详情入口，不删除数据库记录。
- 空记录详情明确显示“谱提取记录”，不要求用户为不存在的数值指定材料；保留原图失败提示与原始原因。
- 已保存且无待处理人工依据的主表单可以直接打开谱；有改动时先保存，失败则在入口显示具体后端错误并保留输入。
