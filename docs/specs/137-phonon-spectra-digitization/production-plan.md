# 正式接入实施计划

# #137：将谱提取与质量核验整合到 SC-Wiki

## 目标与已确认选择

把 demo 算法接入正式上传、存储、审核、论文详情及导出流程，在材料状态的“动力学性质”中展示谱数据和提取质量。

- 上传时全自动发现、标定、提取，之后允许人工校对。
- 使用当前上传任务的模型，先验证读图能力；不支持时保留待处理原因，其他解析继续。
- 首版支持线性坐标的彩色 DOS、α²F、累计 λ；其他图型保留来源并说明限制。
- 每条谱独立审核，不因谱质量问题阻止整篇论文提交。
- 公开详情只展示已采纳或限定频段采纳的谱，同时公开质量指标和限制。
- 人工校对修改图框、刻度、颜色、图例排除区和材料归属，再重新提取；首版不提供逐点手改。

## 自动提取与校对流程

1. 将 demo 数学及提取算法移入后端共享模块，demo 改用同一模块，避免两套实现漂移。
2. 从正文和补充材料的 Document IR 图块、图注及原 PDF 获取谱图。优先保留内嵌原图；矢量图和扫描图按固定分辨率渲染，记录像素与 PDF 坐标变换。
3. 模型识别面板、谱类型、曲线颜色、坐标刻度、单位、图例及材料条件，只输出结构化标定建议。服务器校验标定后，确定性算法生成数值序列。
4. 根据材料、物相、压力等条件关联材料状态；无法唯一关联的候选进入“待分配”，不猜测归属。论文 λ、ωlog 必须关联相同状态和计算条件的具体来源。
5. 在既有异步任务体系中执行谱提取，独立显示进度、失败和重试状态。按源文件哈希、图框、标定及算法版本缓存，重试不重复生成同一结果。
6. 修改标定或材料条件后生成新版本，重新计算指标并使旧采纳状态失效；保留原始观测和此前版本。

缺刻度、单位不明、长缺口、裁边、模型不支持读图等分别记录。只有 DOS 时仍能提取；只有 α²F 时仍可积分；没有累计 λ 时不生成联合重建或留出验证。

## 存储、接口与界面

- 新增独立谱集合与提取运行表，不将数组塞进现有标量 `PropertyRecord`。谱集合关联上传草稿或正式论文 revision、材料状态；运行保存标定、原始点、候选序列、质量报告和算法指纹。
- 数值及质量报告保存于 MySQL JSON；原图与派生图片使用现有文件存储抽象。草稿提交时在同一事务内绑定正式论文、文件和材料状态，保证保存重开、返修及 Redis 丢失恢复均不丢谱。
- 增加谱列表、异步提取/重提取、标定修正、运行状态、逐谱审核和 JSON/CSV 导出接口。所有修改携带预期版本；服务器重算质量指标，不接受浏览器提交的指标作为事实。
- 审核状态为待核对、已采纳、限定频段采纳、排除；限定采纳须记录有效频段和理由。公共读取同时检查论文已批准 revision 与谱采纳状态。
- 上传校对、管理员审核和论文详情共用谱组件：原图与数值曲线并排，支持缩放、轨迹叠加、原始/候选切换、逐点来源、质量展开及下载。只读详情仍允许查看、缩放和切换。
- 扩展材料状态导出，包含谱版本、来源、单位、质量指标、掩膜和审核范围；单谱 CSV 保留逐点来源及候选列。
- 已有论文可由有编辑权限者显式启动提取，沿用现有编辑或返修流程；不批量改写历史数据。

## 质量指标与展示规则

使用分项指标，不生成掩盖问题的统一“准确率”。

| 指标组 | 展示内容 |
|---|---|
| 原图一致性 | 原图叠加、标定点及残差、幅值像素包络、观测覆盖率、补读/插值/推断比例、最大缺口和裁边范围 |
| λ、ωlog 对照 | 原始重建、零基线候选、联合候选的计算值；同条件论文报告值及来源；有符号差、绝对差、相对偏差 |
| 累计 λ 核验 | 终值对照、每 5 THz 贡献、真实像素支持范围及相容状态；虚线插值不作为精确真值 |
| 联合重建 | 拟合点和留出点数量、RMSE、最大像素偏差、零轴调整与遮挡掩膜 |
| DOS 约束 | 原胞模式数依据、共同归一化因子、元素面积及条件目标偏差 |
| 稳健性 | 低频截断敏感性、一像素幅值扰动、未覆盖频段和不可分辨幅值范围 |

- λ、ωlog 与正文的比较标为“相对论文报告值的偏差”，不能直接称整条谱的真实误差；参考缺失或条件不一致时显示“无法比较”，参考为零时不计算百分比。
- 单位转换保留原单位和规范单位；DOS 密度同步转换雅可比。α²F 单位或频率定义不能确认时，不给出伪物理积分。
- DOS 仅在原胞和投影条件具备时提供共同归一化候选，不分别缩放分波凑目标。
- 联合重建满足积分关系属于约束结果，不能自证准确度；裁边候选不声称恢复唯一峰顶。
- 指标不自动批准谱。缺失值、未知误差和不可计算项保留原因，不显示为零。
