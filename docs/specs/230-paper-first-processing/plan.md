# 实施计划

## 职责与接口

从原文提取填写论文级字段并保存核对结论，再判断专用流程并提取材料状态、填写核对。有效论文结果复用；材料发现差异只记录对应字段冲突，不覆盖已核对值。真实阶段和失败停点分别显示。

## 默认选择

来源标记可开关，按需读取上下文和原件。前文目标2000字符，必要完整块/表头表注仍保留。分段并发默认2，受进程共享额度限制。论文核对结果保存成功后交接，后阶段只处理材料字段并保留论文所有权。

依赖：#227图源、#229分段服务于#230流程；#228展示复用来源，不建立新科学值来源。无循环依赖。共享文件串行修改。


## 端到端保存触点

material_state_contract.research_materials_for_save统一规范化值选择；上传PUT沿已有稿继承漏传值，创建Paper保留显式值/空值，返修同样保留当前稿；C1仅保存科学数据，不改写论文级清单。正式创建的已核对名称和空列表反例先在旧行为失败，修正后由正式MySQL事务创建并新会话读取，外层回滚临时业务行。旧请求缺字段的兼容和新绑定缺字段分别测试。
