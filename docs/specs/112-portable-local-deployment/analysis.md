## 已消除的设计冲突

| 原风险 | 收敛方式 |
| --- | --- |
| 把 Redis 当纯缓存会丢草稿，原样迁移又会带凭据/队列 | 只迁移上传状态/草稿并重建业务索引，排除执行与认证数据。 |
| 自动迁移可能触发旧分支破坏性升级或单头错误 | 打包要求源码/库兼容；导入只核验；空库按显式头集合初始化。 |
| 新机器没有环境却先要求旧 `.env` | 系统 Python 引导环境，目标自动生成配置。 |
| 复制源码不能证明对应数据库版本 | 干净 HEAD 源码包、revision 集合和真实结构摘要共同绑定。 |
| 重跑按旧行数核对会把目标新增数据误判为损坏 | 行数只用于首次导入验收；成功后的重跑只检查服务/schema。 |
| `.env` 排除后运行配置仍可能含 API Key | 同时排除运行时模型 JSON 和 Redis 模型凭据键。 |
| 目录提升后进程中断可能再次导入 | 数据目录完成标记与本机阶段记录共同判断，不重复导入。 |
