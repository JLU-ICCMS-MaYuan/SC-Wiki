# 数据事实来源：只覆盖实际变化

当前经手人的工作稿、实际叶子变化与稳定数组操作。

数值、证据、理由分别更新。普通值修改不使用整稿版本或旧值作为同项覆盖拒绝门，但稳定对象不存在、工作稿失权和真实科学核对版本仍检查。
有稳定身份的数组以增加／删除／调整顺序操作表达，不整数组覆盖其他页面的新数据。点重排只改变仍存在的目标顺序，未见过的新对象保留；不按数组位置重建删除对象。新字典只合入本次实际键，已有对象的变化按叶子展开。人工说明保存携带明确变化掩码，未改证据／理由不回写。
新增可锁定的权威工作稿行与内容修订号；开启新协议后数据库工作稿为事实来源，Redis仅兼容旧任务数据。权限交接采用独立写租约，不用内容版本拒绝合法同项后保存。

科学值由权威工作稿或已批准图持有，字段资料只保存定位及采用关系，不保存另一份可修改科学值。临时视图可展开共享引用，持久化、冻结与导出必须回到同一规范合同；旧数据不在读取时自动回填。
