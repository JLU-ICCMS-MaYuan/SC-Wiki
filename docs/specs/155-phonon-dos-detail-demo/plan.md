## 最新 DOS 展示规则（优先于下方历史记录）

仅显示全部分波积分、3N、绝对偏差、非负相对偏差百分比；移除满足判断与容差。缺失数据/依据不计算偏差，零目标不计算百分比。α²F 展示不变。

## 2026-10-23 第二轮设计要求（取代初版对应展示）

- 02 只有一个图窗，三种模式为仅原图、仅提取数据、原图与数据叠加；全部模式保持来源轴向。
- DOS 可选全部分波或单独某一分波；03 对全部分波积分后比较 3N，与图中当前选择无关。
- 两种谱都从 0 THz 开始提取，点表与导出也包含零频；未真实覆盖到 0 的正式结果只能标记不完整，不能伪造数值。
- α²F 比较表只显示积分值、参考值和绝对偏差；λ 不附“无量纲”。逐点幅值差取绝对值。
- DOS 的 N 必须是原胞原子总数，分波需完整、互不重复、同绝对尺度；缺数据或归一化依据时显示无法核验。

界面仅使用一个 Plot；分波选择仅控制绘图，独立 DosQuality 读取全体分波。复用原组件与科学核验函数，无新业务依赖。

## 技术路径

复用 #154 下独立 Vite/React 原型。按 page=alpha、page=dos 分开渲染。材料入口用原生 target=_blank 与 noopener noreferrer。不导入正式 API 客户端，演示状态仅驻留内存。Canvas 只绘制可复算的合成科学数据，用户原图单独查看，绝不将生成图冒充论文图。

## 职责与复用

Plot 负责绘图与轴向；Comparison 负责有条件的指标对比；Detail 负责单页分区；Entry 负责入口。共用组件与表格样式避免两份布局漂移，科学差异在独立分区表达。符合 KISS、DRY；不引入后端、持久化或正式审核流程。
