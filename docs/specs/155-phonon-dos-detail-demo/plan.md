## 技术路径

复用 #154 下独立 Vite/React 原型。按 page=alpha、page=dos 分开渲染。材料入口用原生 target=_blank 与 noopener noreferrer。不导入正式 API 客户端，演示状态仅驻留内存。Canvas 只绘制可复算的合成科学数据，用户原图单独查看，绝不将生成图冒充论文图。

## 职责与复用

Plot 负责绘图与轴向；Comparison 负责有条件的指标对比；Detail 负责单页分区；Entry 负责入口。共用组件与表格样式避免两份布局漂移，科学差异在独立分区表达。符合 KISS、DRY；不引入后端、持久化或正式审核流程。
