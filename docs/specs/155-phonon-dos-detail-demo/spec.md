## 原始需求记录

我希望尽可能的再优化一下α²F 谱函数解析详情页面的展示和查看声子 dos 详情页面的展示。

1. 点击“查看a2F” 后跳转到一个新的标签页，不要在当前标签页调转。“查看声子 dos”也同理。
2. α²F 谱函数解析详情页面点开之后最明显的缺点就是不清楚各个区域的功能。你需要先做好分区，写好标题各个位置都是展示了什么
3. 谱曲线和谱候选这两个我感觉没必要展示。因为一个材料状态只会对应一个a2f谱和一个声子 dos 谱。
4. 原始重建也很莫名其妙，我当时的设计是把它放到最右侧，可以点击选择是否展示它在原图上的覆盖情况还是单独展示提取之后的数据的情况。
5. 下面的提取质量与比较也看不到什么有用信息。我觉得你可以展示你取的频率区间是多少，用提取出来的谱函数积分计算得到的 lambda 和 wlog 是多少，对比原始的数值，误差是多少，误差百分比是多少。
6. 这里的原图叠加、标定校对与逐谱审核和前面的内容几乎都重复了。我觉得可以删除。
7. 最后的逐数据点的校对我希望做成固定宽度表格内，用滚动方式展示，不然平铺开实在是太大了。
8. 特别注意的是 a2f谱函数的因变量坐标单位是频率（图中的竖轴，有时候也是横轴，你要加以区分），自变量a2f的坐标单位是什么？我并不清楚，我希望你能调研一下告诉我。但是其自变量坐标刻度绝不是 1,2,3。这是 lambda 的刻度。lambda 没有单位。

10. 我希望能建立 2 个 issue，然后把 dos 的设计和 a2f的设计分开做。先做 demo.

## 用户场景与验收

### US1：从材料状态查看谱（P1）

原材料表单输入备注后点击查看，详情应在新标签页打开，原页输入保留。用户可独立查看来源、结果和数值说明。

### US2：快速核验谱与数据（P1）

切换右侧显示方式，查看数值或失败原因，在定高点表内滚动、搜索和选点；不需要翻越重复审核面板。

## 功能需求

- **FR-001**：入口在新标签页打开，原表单及未提交输入保持。
- **FR-002**：材料与来源、原图与提取结果、数值核验、逐点数据四区均有标题。
- **FR-003**：右侧提供原图覆盖与独立数据切换，删除谱选择和候选选择及重复审核区。
- **FR-004**：点表最大宽度 1180px、桌面高度 330px；窄屏高度 300px，双向内部滚动、固定表头。
- **FR-005**：La、Sc、H 是一组 DOS 的投影图例，独立显隐，不擅造总 DOS；缺失点保留。
- **FR-006**：显示频段、幅值单位与缺口；正常、失败、重试、空态可演示。真实 HTTP 500 另验。

## 成功标准

- SC-001：两类入口都新开标签页，原输入不变；不请求业务 API。
- SC-002：1440px 和 390px 下无页面水平溢出，点表内部可滚动且表头固定。
- SC-003：切换、搜索、点选、导出和异常场景可操作；数值明确标为合成示例。
- SC-004：正式阶段单独验证真实来源、材料条件、权限和故障边界，Demo 不替代该验收。

## 关键实体

材料标签、谱类型、频率与幅值点、来源谱/提取谱、参考可用状态；仅内存示例，不建立业务存储。
