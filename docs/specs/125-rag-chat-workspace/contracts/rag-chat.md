# 接口与交互契约：RAG 对话工作区

**依据**：[Spec](../spec.md) · [数据模型](../data-model.md)

2026-10-12 润色修订已实现并通过本地边界测试；真实模型及人工评审、登录浏览器验收范围见[验证记录](../quickstart.md)，其余工作区能力保留原验收边界。响应保留项目现行 `{ "ok": true, "data": ... }` 包装；错误码按 API 实际规范映射，不回显内部异常、模型凭据或未批准文献内容。

## 会话 API

所有 `/api/rag/conversations` 路由必须校验有效登录，并从令牌确定所有者。

| 操作 | 请求 | 成功响应 | 错误 |
| --- | --- | --- | --- |
| `GET /api/rag/conversations` | `limit`（1～50）与 `offset`（从 0 开始） | 本人会话 `id/title/updated_at/last_sequence`，按最近活动排序 | 401 |
| `POST /api/rag/conversations` | 可选标题 | 新会话摘要 | 401、400 |
| `GET /api/rag/conversations/{id}` | 会话 ID | 有序完成轮次、来源摘要与版本 | 401、404 |
| `DELETE /api/rag/conversations/{id}` | 会话 ID | 204 | 401、404 |
| `POST /api/rag/conversations/import` | 有界的旧本地会话、`source_local_id` | 导入后的会话 ID 和是否已存在 | 401、400、413 |

不属于当前用户的会话返回 404，避免通过 ID 区分资源是否存在。列表不得包含其他账号数据。导入同一个账号和 `source_local_id` 重试返回同一会话。

## 问答流

保留 `POST /api/rag/chat/stream` 的 SSE 事件与访客旧请求兼容。登录云端模式在请求中增加 `conversation_id`、`request_id`、`expected_last_sequence`。服务端按会话 ID 校验所有者，并从云端读取轮次作为上下文；该模式忽略客户端自报的 `history`。新完成轮次须在最终 `done` 事件发出前提交，`done` 返回 `conversation_id`、`turn_id`、`sequence` 及现有答案、引文和灵感结果。服务端不保存失败或未完成的回答。

同一 `request_id` 的重试必须幂等；`expected_last_sequence` 过期返回 409 并让前端刷新，不覆盖另一个设备新增的轮次。无会话 ID 的访客请求保留现有行为。无权会话返回 404；无效登录返回 401。SSE 错误事件需给出稳定错误码，前端保留问题和重试入口。

## 提示词润色

`POST /api/rag/prompts/polish` 保留请求与响应形状，不增加会话历史或模式字段。

```json
{"draft":"我想知道目前设计低压氢化物超导体的思路都有哪些。"}
```

成功响应仍为 `{"ok": true, "data": {"suggestion": "优化后的提问正文"}}`。

| 项目 | 契约 |
| --- | --- |
| 输入 | `draft` 长度 1～1000 Unicode 码点；纯空白无效，保留既有请求校验 |
| 输出 | 非空完整正文，长度不超过 1000 Unicode 码点，与问答发送上限一致；不返回分析过程、解释或确认问题 |
| 内容 | 保留原意、语言、科学符号、数值、单位、否定条件及占位符；按需完善提问，不回答、不虚构背景或具体条件 |
| 生成校验 | 超长、截断、缺少正常结束标记、空正文、拒绝/工具调用或关键原文内容丢失均不返回成功结果；不得裁剪后回填 |
| 错误 | 保留 HTTP 422 的 `POLISH_INVALID` 用于服务层输入/输出无效；请求结构错误沿用 FastAPI 422；模型、认证及超时沿用现有错误映射，不回显上游原始异常 |
| 模型 | 使用现有请求级选择与凭据，30 秒读取超时，温度 0.2，生成额度 4096 tokens；不新增业务层重试或自动切换模型 |
| 数据 | 不创建会话、不发问答、不检索、不读取历史、不持久化输入输出；正文不含凭据，身份与模型配置继续走现有请求头依赖 |

前端响应处理必须使用当前引用中的请求序号、草稿版本、会话与账号身份，不能只判断发起请求时闭包中的会话 ID。仍有效时直接回填并保存一次撤销；编辑、发送、新建/切换会话、账号变化、卸载后丢弃旧结果及旧错误。一次撤销的版本规则见[数据模型](../data-model.md#润色临时状态2026-10-12-已实现)。

保留 `suggestion` 字段以避免接口迁移；收紧成功输出长度属于本功能约束修复，不修改问答上限。新旧前后端混合运行不作为验收成功，应在同一部署版本验证直接回填和长度保护。

## 来源解析与详情

- 回答完成后，来源解析接口接收有界文本和已知引文身份，从活跃物性定义、材料/别名、已批准论文公开关键词及引文中返回经当前数据验证的目标类型、显示文本和稳定 ID；无匹配、重名歧义和失效来源不返回可点击目标。实现时可批量解析，避免对每个词单独请求。
- `POST /api/rag/source-links` 返回单篇 `paper`、多篇 `papers` 或 `definition` 目标；多篇匹配时抽屉先展示可选择的论文。当前实现匹配已批准论文引文及其关键词、活跃物性定义和关联材料名/别名；不扫描任意自由文本片段猜测术语。
- `GET /api/rag/papers/{paper_id}` 继续提供已批准论文详情。
- `GET /api/rag/papers/{paper_id}/fragments` 列出当前版本片段摘要；`GET /api/rag/papers/{paper_id}/fragments/{chunk_id}` 仅返回该已批准论文当前 revision 的片段正文、页码和章节；不匹配返回 404。
- `GET /api/rag/definitions/{definition_id}` 只取当前活跃定义的公开解释；材料名没有解释字段时展示确切匹配的已发布关联论文，不生成虚构定义。

## 页面交互

- 默认布局为左侧历史和中央对话；右侧 Drawer 初始关闭。点来源目标后从右侧打开，关闭、Esc 或导航离开时恢复触发元素焦点，关闭时保持会话与滚动位置。
- 输入框为多行。星形按钮位于操作区靠近发送按钮，有可访问名称、忙碌态与禁用说明；空草稿、已有润色请求或问答生成中禁止重复润色。等待期间仍可编辑或主动发送当前草稿。
- 润色成功直接回填，不弹确认框、不自动发送；在输入区显示可键盘操作的一次撤销入口。失败使用输入区非阻塞错误提示。相同文本结果不制造无效果撤销；过期结果及错误不展示。
- 登录会话显示同步状态；访客本机历史标识“仅本机”；导入旧历史必须有显式动作。
