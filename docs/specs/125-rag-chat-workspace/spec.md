# 功能规格：RAG 对话工作区

**GitHub Issue**：[#125](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/125)

**创建日期**：2026-10-09

**状态**：代码已实现，本地验证通过；真实环境验收待核验

## 背景与目标

现有 RAG 页面以大标题、三列卡片和常驻证据栏占据主要空间，输入框狭窄。会话、消息和证据只保存在浏览器本地；回答中的论文标记无法打开站内详情。目标是参照用户提供的两张截图，将问答改为简洁的网页对话入口：左侧历史、中央对话和宽输入区，右侧默认没有栏目；只有点击有来源的词语或引文时，才临时显示文献详情或片段。

截图是视觉和图标位置参考，不作为交互或权限指令。页面需延续项目已有的导航、语言和模型配置能力，不要求逐像素复制第三方产品。

## 视觉与交互基线

- 左侧为贯穿工作区的历史导航，含清晰的新对话入口、当前项和最近会话。中央回答区限制阅读行宽，输入框固定在对话区域底部；移除现状截图中的大幅页面标题、三张重阴影卡片和固定右栏。
- 空态聚焦提问入口；有消息时用留白、字号和对齐区分用户与 AI，不以大块描边卡片包裹每段回答。来源和证据放在对应回答内部。
- 输入框采用可扩展的圆角多行编辑区，底部操作行放探索模式、星形润色和发送按钮；星形图标靠近发送按钮，位置参考第二张截图的红框。
- 右侧默认仅是页面留白或中央内容的自然延展，不显示“证据面板”标题、空态卡片或占位栏。临时详情打开时可覆盖或推开中央区域，关闭后恢复原布局。
- 窄屏时历史改为临时导航，输入区始终可见；星形、发送和详情关闭控件保持明确的点击与键盘焦点状态。

## 用户场景与验收

### US1：专注对话的入口（优先级：P1）

用户进入问答页，能立刻找到历史、新对话和宽输入框，阅读时不受空证据栏干扰。

**独立验收**：桌面与窄屏打开空会话和有消息的会话，默认右侧均无固定栏；输入和流式回答可正常使用。

1. **假如**用户打开空会话，**当**页面加载完毕，**那么**中央显示简洁引导和输入区，左侧可新建、选择历史会话。
2. **假如**会话已有多轮消息，**当**用户切换会话，**那么**消息顺序、滚动和输入状态保持可理解，回答中的来源留在对应回答内。
3. **假如**视口变窄，**当**用户打开历史或文献详情，**那么**内容以可关闭的临时层呈现，输入和消息不被永久挤压。

### US2：按账号保存和恢复历史（优先级：P1）

登录用户可在另一浏览器继续查看自己的问答历史，访客仍能使用原有问答入口。

**独立验收**：同账号跨浏览器恢复一段完整会话；另一账号无权读取、修改或删除该会话；访客问答不出现云端已保存提示。

1. **假如**用户已登录，**当**完成一次问答并刷新或换设备登录，**那么**会话标题、已完成的消息和来源信息从云端恢复。
2. **假如**另一账号持有会话标识，**当**其尝试读取、继续或删除，**那么**系统拒绝且不泄露内容。
3. **假如**访客打开问答页，**当**其提问，**那么**可继续得到回答，并清楚知道当前历史仅在本机。
4. **假如**浏览器已有旧版本地会话，**当**用户登录，**那么**旧历史不会被静默上传；用户可明确选择导入，重复导入不会产生重复云端会话。

### US3：星形按钮润色草稿（优先级：P1）

用户输入研究问题后，点击输入框操作区的星形按钮，请 AI 改写为更清楚的提示词，再自行决定是否采用。

**独立验收**：可预览原文与改写文；接受只替换草稿，取消或失败保留原文，整个过程不发送问答。

1. **假如**输入框为空，**当**用户查看星形按钮，**那么**按钮不可触发并说明需要先输入内容。
2. **假如**草稿非空，**当**用户点击星形按钮，**那么**系统使用当前可用模型生成润色候选，保留原意、科学符号和明确约束。
3. **假如**用户取消、模型失败或凭据不可用，**当**流程结束，**那么**原草稿仍可编辑且没有新问答消息。
4. **假如**用户接受候选，**当**回到输入框，**那么**只有草稿被替换，仍需用户主动发送。

### US4：在回答中探索有来源的词语与文献（优先级：P1）

用户阅读回答时，点击可识别的术语、材料或引文，从右侧临时查看数据库解释、文献详情或原文片段。

**独立验收**：点击有真实来源的目标显示正确内容；关闭临时层后回到原回答；无来源文字不伪装成链接。

1. **假如**回答包含当前已发布论文引文，**当**用户点击引文，**那么**临时层显示该论文的可访问详情和可用片段。
2. **假如**回答中的术语有数据库解释或关联文献，**当**用户点击它，**那么**临时层显示对应解释或文献匹配，并可继续查看具体片段。
3. **假如**引用的论文被撤回、版本变化或片段不可访问，**当**用户打开旧链接，**那么**系统提示内容已不可用，不展示旧的未批准内容。

## 边界与异常场景

- 云端会话写入或读取失败时，明确显示未同步或失败状态；不把未保存的消息标成云端已保存，不静默丢弃用户输入。
- 流式回答中断时，当前提问保留可重试；未完成的回答不成为已完成云端消息。跨设备同时操作同一会话时，不覆盖较新的轮次。
- 登录、登出或切换账号后，立即清理内存中的上一账号会话；访客本机历史与账号云端历史分开。
- 旧浏览器历史导入需用户明确操作；重复请求具备幂等性，导入失败不删除原本地数据。
- 润色处理中若用户继续编辑草稿，过期结果不能覆盖新输入；润色输出不可携带模型指令执行、自动发送或意外泄露凭据。
- Markdown、公式和引文仍可正常显示。只有经服务端验证、指向当前允许公开的数据才有可点击样式；词语重名时不得猜测来源。
- 文献详情抽屉必须可用关闭按钮、Esc 和焦点恢复关闭，且不会改变当前对话或发送内容。

## 功能需求

- **FR-001**：问答页必须以历史会话区、中央消息区和底部多行输入区组织；默认不得渲染常驻右侧证据栏。
- **FR-002**：工作区必须提供新对话入口；输入区必须提供发送、现有探索模式和靠近发送按钮的星形润色入口；空文本、加载中和错误状态必须可辨识。
- **FR-003**：桌面、平板和窄屏必须支持可关闭的历史导航与右侧临时详情，不得遮住用户无法恢复的输入内容。
- **FR-004**：回答正文必须直接呈现已有引文、来源归因和相关证据，保留流式、多轮和灵感探索行为。
- **FR-005**：登录用户必须能新建、列出、读取、继续和删除本人云端会话；列表按最近活动排序，打开后能恢复消息和必要来源元数据。
- **FR-006**：所有云端会话读写必须按当前有效账号隔离；不得接受客户端自报的所有者身份或将模型凭据写入会话。
- **FR-007**：访客必须能继续问答；本机历史须明确标识为未云端同步，登录后不得自动上传旧本地内容。
- **FR-008**：用户必须能显式导入旧版本地历史；同一旧会话重复导入只生成一份云端副本，导入失败后原数据保留。
- **FR-009**：云端持久化必须只把已完成问答标为完成；失败、断线和跨设备冲突须向用户提供恢复或重试路径。
- **FR-010**：星形润色只能处理非空草稿，生成结果必须可与原文对照、接受或取消；不得自动发送问答。
- **FR-011**：润色必须使用当前请求已选择的模型配置，保留材料名、公式、数值、单位及用户限定条件；无可用模型或生成失败时保留草稿。
- **FR-012**：润色结果必须与发起时的草稿版本绑定；用户后续编辑或切换会话后，旧结果不得覆盖当前草稿。
- **FR-013**：回答中的论文引文和数据库已确认匹配的关键词必须可点击；未匹配或重名歧义的普通文字不得制造虚假链接。
- **FR-014**：点击目标时必须从右侧临时打开详情，展示对应的数据库解释、已批准论文详情或当前版本原文片段，并标明来源。
- **FR-015**：详情与片段读取必须再次校验当前发布状态、论文版本和关联身份；无权限或目标失效时不得回显受限内容。
- **FR-016**：关闭临时详情后必须返回原会话、原滚动位置和触发元素焦点。
- **FR-017**：问答页新增文案与状态提示必须支持现有中英文切换及键盘操作。

## 关键实体

- **云端会话**：归属一个账号，有稳定标识、标题、创建时间、最近活动时间和有序轮次。
- **会话轮次**：一条提问及其完成的回答，含来源引用与展示所需的非敏感元数据；未完成生成不算完成轮次。
- **本机会话**：访客及旧版浏览器历史，独立于云端会话；只能经显式导入成为云端数据。
- **可点击来源目标**：经当前数据库验证的术语解释、材料、已发布论文关键词、论文或论文片段标识；只描述可访问目标，不保存模型臆造的事实。
- **润色候选**：当前草稿的一次临时改写，不构成问答消息或持久会话记录。

## 成功标准

- **SC-001**：空态、有消息、流式生成和窄屏四类页面验收场景下，默认右侧固定证据栏均为零，用户可直接找到输入框、历史与星形按钮。
- **SC-002**：同一账号在两个独立浏览器中完成“发送 → 重新登录 → 恢复 → 继续 → 删除”全流程；不同账号对该会话的读写请求全部被拒绝。
- **SC-003**：空草稿、接受、取消、失败、编辑竞态五类润色场景中，均没有自动发送；除接受且草稿未变化外，输入文本逐字保留。
- **SC-004**：已发布论文引文、已定义术语、无匹配关键词、失效片段四类场景中，可点击性和临时详情内容均与数据库当前状态一致。
- **SC-005**：现有普通问答、灵感探索、来源归因和模型切换的关键用户流程在改版后全部通过回归验收。

## 假设与依赖

- 暂按“访客可继续问答；登录后按账号云端保存”设计。该选择沿用当前公开问答入口，用户若另行指定登录门槛则调整权限与验收。
- 旧版本地历史迁移采用显式导入，避免在登录时无提示上传个人问答内容。
- 数据库目前有已批准论文、当前版本 `paper_chunks` 和部分带 `description` 的物性定义；并非所有词语都有解释。没有可验证目标时不展示链接。
- 复用当前认证、模型配置、流式问答和论文详情边界；服务端会话存储需要新增迁移和接口。

## 范围外事项

- 不新增常驻右侧栏目、术语百科编辑器、任意文本的 AI 猜测链接或第三方产品品牌素材。
- 不改变论文审核、发布、检索排序和 RAG 答案科学正确性的既有规则。
- 真实环境的数据库迁移、跨设备账号验收和外部模型调用需单独验证；本地代码与隔离测试结果见[验证指南](quickstart.md)。
