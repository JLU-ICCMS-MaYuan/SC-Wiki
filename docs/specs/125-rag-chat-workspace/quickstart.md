# 验证指南：RAG 对话工作区

**状态**：本地代码验证已执行；真实环境验收待完成。

**输入**：[Spec](spec.md) · [接口契约](contracts/rag-chat.md) · [任务](tasks.md)

## 前置条件

1. 在隔离测试环境运行主库最新 Alembic 迁移，并准备两个有效账号 A、B。
2. 配置可工作的问答模型及至少一篇已批准、已索引且有当前版本片段的论文；准备一条有解释的活跃物性定义。
3. 使用两个独立浏览器配置文件分别登录 A 和 B；另用无痕窗口作为访客。测试中不得使用真实敏感提示词。

## 自动化验证

实现对应测试后，在仓库根运行：

```bash
python -m pytest "backend/tests/test_rag_chat_conversations.py" "backend/tests/test_rag_chat_links.py" -q
```

在 `frontend/` 运行：

```bash
npm run build
npx vitest run "src/pages/RagPage.test.tsx" "src/lib/useStreamingChat.test.tsx" --config "../vitest.config.ts"
```

后端测试需覆盖主库真实事务边界、账号隔离、幂等和并发冲突；来源测试需覆盖已批准当前片段与撤回/旧版本拒绝。前端测试覆盖空态、星形按钮、候选预览、临时 Drawer、焦点和窄屏历史入口。模型可用性错误可用受控测试上游验证，不把真实密钥写入测试数据。

## 浏览器端到端场景

1. **布局**：访客打开空问答页，确认左侧历史、中央多行输入框和星形按钮可见，右侧无固定证据栏；调整到手机宽度后，历史与文献详情都能独立打开和关闭。
2. **本机与云端**：访客提问后看到“仅本机”；登录 A，显式导入一条旧会话并刷新，再在第二个浏览器登录 A，确认消息、来源和继续提问可恢复。重复导入不重复。登出后不显示 A 内容。
3. **账号隔离**：在 B 浏览器调用 A 会话的读取、继续和删除 API，均被拒绝；B 的列表不出现 A 会话。
4. **失败与并发**：模拟生成失败、浏览器断线、云端存储失败和两个浏览器同会话同时发送。未完成轮次不显示“已同步”，问题仍可重试；旧版本请求不能覆盖新轮次。
5. **润色**：空草稿按钮不可用；填写包含材料式、Tc 数值、单位和限定条件的问题，点击星形后比对原文与候选。取消、模型失败和在等待期间编辑草稿都保留当前输入；只有接受会替换草稿，均不自动发送。
6. **来源详情**：回答内点击论文引文和有解释的物性术语，确认右侧临时抽屉显示数据库当前内容；普通未匹配词没有可点击样式。关闭后光标与滚动位置仍在回答。撤回论文或切换 revision 后，旧片段链接不可读取。
7. **回归**：普通多轮问答、灵感探索、流式回答、来源归因和切换模型逐项执行；桌面与窄屏均检查中文、英文标签和键盘操作。
