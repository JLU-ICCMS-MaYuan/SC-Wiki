# 数据模型：RAG 对话工作区

**依据**：[Spec](spec.md) · [技术研究](research.md)

## 云端会话

建议表 `rag_chat_conversations`，存于主应用数据库。

| 字段 | 约束 | 用途 |
| --- | --- | --- |
| `id` | 不可猜测的稳定标识，主键 | 对话引用 |
| `owner_user_id` | 非空，外键 `users.id`，索引 | 所有权校验 |
| `title` | 非空，长度受限 | 左侧历史摘要 |
| `source_local_id` | 可空；与 `owner_user_id` 组合唯一 | 旧本地会话幂等导入 |
| `created_at`、`updated_at` | 非空 | 排序与审计时间 |

会话删除时在受所有权约束的事务中删除所属轮次。账号级权限以服务端身份为准，不接收客户端提供的 `owner_user_id`。空会话可创建，但列表优先展示已开始的会话；具体展示规则须与前端一致。

## 完成轮次

建议表 `rag_chat_turns`，存于主应用数据库。

| 字段 | 约束 | 用途 |
| --- | --- | --- |
| `id` | 主键 | 完成轮次标识 |
| `conversation_id` | 非空，外键并索引 | 所属会话 |
| `sequence` | 同会话唯一，严格递增 | 消息顺序与并发版本 |
| `request_id` | 同会话唯一 | 网络重试幂等 |
| `question`、`answer` | 非空，长度受限 | 完整一问一答 |
| `citations_json` | 仅非敏感来源身份、归因和显示摘要 | 回答内引文 |
| `display_meta_json` | 可空，有界，按白名单保存 | 灵感卡片等必要展示元数据 |
| `created_at` | 非空 | 历史顺序 |

轮次只在生成完成时一次写入。内部推理文本、模型 API key、完整请求头、临时润色候选和未批准文献原文不持久化。旧记录的来源可能失效，读取时可显示当时的引用摘要，打开详情仍需重新校验。

## 本机会话与导入

现有浏览器键 `rag_conversations`、`rag_meta_<id>` 是旧数据输入。新版访客本机会话须与当前登录账号隔离。导入只接受结构、长度、数量经过校验的消息和非敏感来源元数据；服务端由旧会话 ID 和账号形成幂等身份。导入失败保持本地原始数据。导入不等于重新验证答案或文献来源。

## 可点击来源目标

不为每次点击新增永久映射表。前端持有会话回答和已验证的短期目标描述：

| 类型 | 身份 | 点击时验证 |
| --- | --- | --- |
| 论文 | `paper_id` | 已批准且可公开读取 |
| 片段 | `paper_id`、`paper_revision`、`chunk_id` | 与论文当前版本和文件关联一致 |
| 物性定义 | `definition_id` | 当前活跃且含可展示解释 |
| 材料或别名 | 规范化名称和当前目标 ID | 唯一匹配且有已发布关联文献 |
| 论文关键词 | 当前已批准论文 ID 与关键词 | 关键词与论文当前公开元数据一致 |

不保存未验证的模型猜测映射。重名、多目标或无匹配时返回普通文本或待选择的明确候选，不默认指向某篇论文。

## 状态转换

```text
本机旧会话 --用户显式导入--> 云端会话
草稿 --用户发送--> 生成中 --完成并原子写入--> 完成轮次
                         └--失败/取消--> 可重试草稿
草稿 --点击星形--> 润色中 --有效结果且上下文未变化--> 新草稿与一次撤销快照
                  ├--失败/结果无效--> 保留当前草稿，非阻塞提示
                  └--上下文变化/请求过期--> 丢弃结果，保留最新输入
新草稿与一次撤销快照 --撤销且版本未变化--> 逐字恢复原草稿，清除快照
新草稿与一次撤销快照 --编辑/发送/再次润色/上下文变化--> 清除快照
```

## 润色临时状态（2026-10-12 设计，待实现）

只存于当前页面内存，不新增数据库表、浏览器持久化键或服务端会话字段。

| 状态 | 内容与约束 |
| --- | --- |
| 原始草稿 | 发起时未经 trim 的文本，用于逐字撤销；实际请求正文可沿用 trim 行为 |
| 请求身份 | 单调递增请求序号、草稿修订号、会话 ID 与账号上下文标识；不包含凭据 |
| 当前版本 | 每次编辑、发送、新建或切换会话、账号变化均递增/失效；即使字符串或最终 ID 相同，也不恢复旧版本 |
| 撤销快照 | 最近一次成功回填的原文、回填后的修订号及上下文；最多一份，不支持重做 |
| 处理与错误状态 | 上下文失效时立即清理当前请求的忙碌/错误状态；响应回调只有仍匹配当前请求序号时才能结束忙碌态，显示错误还须匹配草稿和上下文；卸载后不更新页面状态 |

回填前同时检查请求身份、当前草稿版本和当前上下文。发起下一次润色即清除旧撤销快照，下一次失败也不恢复旧快照。有效结果与当前文本完全相同时按完成处理，可非阻塞提示“无需修改”，不制造无效果撤销操作。发送使用当前输入；发送失败的恢复同样视为一次草稿变化，防止旧润色覆盖恢复内容。

编辑使当前结果失效时也立即清理其忙碌态，允许用户对最新草稿再次润色；旧网络请求即使未能取消，后续成功、失败及结束回调均不得改变新请求状态。相同有效请求尚在处理中时，重复点击不创建第二次调用。
