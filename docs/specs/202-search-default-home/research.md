# 研究与设计决策

## 默认首页归属

- 决策：`/` 继续使用 replace 跳转，目标改为 `/search`，品牌仍进入 `/`。
- 理由：保留规范搜索 URL 与现有检索参数，不在根路径复制检索状态。
- 备选：直接在 `/` 渲染 SearchPage 会引入第二个检索入口 URL；没有必要。
- 证据：`App.tsx` 现有根跳转、`searchNavigation.ts` 的 URL 构造、#178 导航契约。

## 按需加载边界

- 决策：将首屏直接 lazy 的 NewsPage 换为 SearchPage，并将 NewsPage 移至 LazyRoutes。
- 理由：维持原有首屏与其他页面分层；访问搜索不必加载 LazyRoutes 或诺奖和新闻页面代码。
- 备选：只改根跳转可实现视觉行为，但搜索仍多经过一次延迟路由加载，不符合现有首屏职责。

## 默认认证出口

- 决策：AppShell 退出及 AuthPage 三种无来源出口改为 `/search`。
- 理由：它们表达“默认首页”；合法来源、来源 query/hash 及新注册 `/account` 仍按原规则。
- 证据：`AuthPage.tsx` 的来源校验、`auth-page.test.tsx` 的跨标签页和恶意地址覆盖，#151。

## 验证边界

复用既有侧栏、认证与检索行为回归；真实浏览器使用生产构建和隔离 API 响应检查入口及导航，不操作当前本地服务、数据库或用户草稿。不新增镜像、依赖或部署动作。历史 #101/#151 文档保留原验收记录，当前行为写入本规格和 Overview。
