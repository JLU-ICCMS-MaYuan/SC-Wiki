# Feature 规格：社区问答、评论与弹幕

**GitHub Issue**：[ #106](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/106)
**创建日期**：2026-09-17
**状态**：代码实现与隔离验收完成；本地数据库已迁移，用户已确认当前账号在原页面发布成功。其他环境部署另行验证。

## 背景与目标

现有社区只有排行榜与 Tc 图表。研究者需要独立提问、回答，也需要在体系和论文详情交流，并能获知他人回复。

## 用户场景与验收

### US1：社区问答（P1）

用户从社区的“讨论”入口提问，其他用户各自回答；答案下可以评论和回复。价值是沉淀可检索的科研交流。

独立验收：两个正常账号完成提问、回答、评论、回复、点赞和取消，游客可以阅读。答案默认按点赞数排序，也可按最新时间排序；不设采纳。问题列表支持关键词搜索、最新发布和最近活跃排序。

### US2：体系与论文交流（P1）

从元素搜索进入 Hg 体系页，查看公开论文、发表评论；进入具体论文后可参与该论文自己的评论。

独立验收：不同论文共用 Hg 体系讨论；各论文评论独立，同一论文从搜索详情、图表抽屉和独立详情进入看到相同内容。论文版本修改不丢评论。

### US3：弹幕（P2）

用户在体系和论文的独立区域发送短消息，其他打开同一目标的用户数秒内看到。可以关闭动画或查看历史。

独立验收：两个浏览器验证约 3 秒同步、去重、切换目标、历史和断网重试。尊重减少动画设置，不遮挡正文操作。

### US4：通知与管理（P1）

用户获知问题的新答案、答案的新评论及评论回复；违规内容可举报，由管理员处置。

独立验收：通知可标记已读并定位目标；自己操作不通知自己。管理员填写原因隐藏、恢复内容或驳回举报，记录可追溯。

## 需求

- **FR-001**：社区导航必须展开排行榜、Tc~X 演变、讨论三个入口，旧图表与榜单行为保持可用。
- **FR-002**：支持问题、答案、答案点赞及问题搜索和排序，不区分讨论帖，不设采纳。
- **FR-003**：体系、论文、答案提供普通评论与回复，回复不得跨目标；所有回复在根评论下平铺。
- **FR-004**：体系使用稳定的元素组合身份，跨论文共享；论文互动跟随论文身份而非版本。
- **FR-005**：体系、论文提供独立纯文本弹幕、开关、历史与约 3 秒刷新。
- **FR-006**：正常且邮箱验证通过的账号可直接发布；游客仅阅读公开内容；论文互动始终继承论文可见性。
- **FR-007**：作者可编辑问题、答案、评论及删除自己的内容；弹幕可删除不可编辑。删除的评论保留占位和已有回复。隐藏的父问题/答案不可继续读取或写入后代。
- **FR-008**：问题、答案支持 Markdown、链接、代码、公式及预览；不执行原始 HTML、不渲染图片；评论和弹幕为纯文本。
- **FR-009**：新答案、新答案评论、评论回复触发站内通知，排除操作者自己；支持未读数、列表、单条及全部已读。
- **FR-010**：用户可举报，管理员与超级管理员可隐藏、恢复或驳回并填写原因；作者不得恢复管理员隐藏的内容。
- **FR-011**：限制正文长度、请求大小和操作频率，重复点赞幂等；封禁后写入被拒绝，注销身份匿名展示。
- **FR-012**：支持中文和英文界面、桌面与窄屏，以及加载、空状态、失败重试和内容不可用提示。

### 关键实体

问题、答案、评论、弹幕是不同内容类型；点赞只关联答案；体系讨论空间不属于某篇论文；举报、处理事件与通知关联具体内容。

## 成功标准

- **SC-001**：US1、US2 双账号完整流程均可完成，三个论文入口内容一致。
- **SC-002**：正常网络下弹幕在一个 3 秒轮询周期加请求耗时内可见，不重复播放；关闭或离开目标停止轮询。
- **SC-003**：权限矩阵、跨目标回复、隐藏内容、论文删除与注销身份验证中无受限内容泄漏。
- **SC-004**：通知正确指向内容、无自通知、已读数一致；举报处置可追溯。
- **SC-005**：Go 行为测试、隔离 MySQL/Redis 集成测试、前端交互测试、构建和双浏览器验收有真实记录。

## 假设与边界

体系按元素组合区分，例如 Hg 与 Hg-O 不共用讨论；无公开论文时允许合法元素组合拥有讨论空间。问题与答案不限制每人只能发表一条。评论回复平铺但标明回复对象。站内通知不发送点赞、邮件或浏览器推送。

论文权限变化后，互动和通知重新校验可见性；论文物理删除时清理关联互动。问题或答案删除后，其讨论不可访问；删除评论保留无正文占位。被隐藏的评论也保留无正文占位，但禁止继续回复。

范围外：图片附件、私信、关注、推荐算法、采纳答案、实时长连接。实际既有数据库迁移与部署和隔离验证分别记录。
