# 研究驱动力增量验收

关联 [Issue #66](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/66) 与 [Spec](spec.md)。

1. 运行研究驱动力生成的定向后端测试，核对全文输入、编号独立行、无依据留空和定向重试。
2. 用 H3S 已解析正文生成一份新草稿，对照原文背景、既有结构争议与作者明确的研究目的，
   检查每条均是研究开始前的动因，且逐行编号显示。
3. 打开上传校对页，确认可编辑多行内容；若论文已正式入库，在详情页确认换行保留。
4. 对截图对应旧草稿，先核对身份、版本、来源哈希和人工修改记录；保存私有快照后才允许
   定向更新。重读前后草稿及核对记录，确认只改变目标字段与对应依据。
5. 记录模型、来源、验证结果及无法执行的保护条件到本目录的验收记录；不可将本地代码
   测试写成旧草稿已经更新。
