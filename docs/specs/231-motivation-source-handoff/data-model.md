# 值、来源与处理状态

## 不变的数据归属

科学表单仍只有现有`paper.research_motivation`字段，#203版本和摘要不变，无新增表或迁移。当前工作稿决定值；缓存、模型候选和检查点不得覆盖人工值或所选来源。

候选保存其动因文本与本次窗口的`source_id`；来源目录保存实际文件、角色、片段/页码和完整原文。最终归纳时按目录回绑，不由模型重新抄写或由程序猜测引句。原始候选、归纳结果与理由作为既有私有解析证据留存，不冒充科学接受结果。

## 需要区分的逻辑状态

以下是待实施的处理语义，不是已新增的科学字段或数据库枚举。

| 情况 | 字段与处理要求 |
| --- | --- |
| 有依据的动因 | 既有英文编号格式、可定位来源，论文级核对保存 |
| 真实无可靠动因 | 原文阅读条件满足且有明确判定，空值和原因可交人工审核 |
| 缺少原文上下文 | 处理未完成，不得写成原文无动因 |
| 引句无效/非法编号 | 来源失败，保留候选与失败原因，不伪造引用 |
| 模型/传输失败 | 维持原运行器规则和未完成状态，保留已完成字段 |
| 格式问题 | 沿#66现有定向处理及人工边界，不增加固定轮次 |

检查点只能证明已完成的实际处理。旧版任意`absence_reason`生成的`source_absent`没有新的缺失证明力；定向恢复必须先核对当前值、字段归属、来源及任务版本，不进行批量后台回填。
