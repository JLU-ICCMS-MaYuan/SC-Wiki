## 背景与目标

公开资讯阅读页不再展示后台采集运行状态，避免来源告警和时间列表占用阅读空间。

## 用户故事与验收

### US1 阅读资讯而不看到来源运行面板（P1）

优先级理由：直接对应用户截图。独立验收：返回带失败/过期来源状态的真实结构响应，
三栏资讯仍显示，页面没有来源状态入口、错误码、更新时间或 Phys.org 订阅窗口说明。

边界：列表接口请求失败仍显示重试；后台采集失败不会因为隐藏面板而被清空或停止重试。
资讯作者、来源、分类标签、自然周、历史入口和详情行为保留。

## 功能需求

- FR-001：移除来源更新状态整块公开展示，包含折叠入口、关注提示、逐来源状态、错误码、最后成功时间和窗口说明。
- FR-002：清理面板专用状态、回调、辅助函数及中英文文案；不再以 sources 字段存在性验证资讯响应。
- FR-003：保留后台采集状态/API 契约、列表失败提示和既有资讯阅读行为。

## 成功标准

- SC-001：带失败来源的响应仍能显示资讯，但截图区域的任何文案或入口均不存在。
- SC-002：sources 缺失不影响有效资讯响应；现有资讯相关前端测试、生产构建通过。

## 假设、依赖与关键实体

沿用 #83/#153 资讯组件和既有 API；没有新增实体、字段、配置或迁移。
删除展示以用户截图为依据，不推断采集错误已经修复。

## 范围外与待确认决策

不新增管理页面，不修改后端状态接口、采集或重试，不更改其他任务的文件。无待确认产品决策。
