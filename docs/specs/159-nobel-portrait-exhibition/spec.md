## 背景与目标

快讯页当前用五条文字时间线呈现超导发展相关的诺奖里程碑。用户希望把它改成博物馆式的环形肖像展陈，让访客能逐一认识获奖者，并从肖像进入有引用来源的科研经历与获奖成果说明。第一步是实现可评审 Demo，Demo 使用的肖像文件应作为网站最终使用的同一套资产。

### 需求结论与变更取舍

用户随后明确选择“先看交互，最终漫画稍后制作”。当前阶段交付可运行的交互预览，允许使用已标注的线稿预览图；最终漫画、逐图来源核查和正式网站素材复用留在后续阶段。该选择不表示授权图片 API 调用，也不表示放弃最终素材要求。FR-003 和 SC-004 的最终漫画验收保持未完成，不阻断当前交互阶段交付。

最终人物范围以用户确认的图 1 名单为准，共 12 位：Onnes；Bardeen、Cooper、Schrieffer；Esaki、Giaever、Josephson；Bednorz、Müller；Abrikosov、Ginzburg、Leggett。早先回复中的“14位”与截图名单计数不一致；用户询问另外两人是谁后确认按图中 12 位继续，因此不得自行增补两人。

国家字段按获奖时的国籍或国家身份展示；多重身份或历史国别变化时需加简短说明，不把出生地直接等同于获奖时国籍。每位人物的生卒年份、身份、诺奖授奖理由和科研经历都须有逐项引用。内容须区分直接获奖贡献与更广泛的科学影响；例如 Leggett 的获奖贡献重点涉及超流氦-3 理论，不能写成因超导研究获奖。

漫画资产应从恢复的旧肖像加工而来，使用一致的手绘漫画方向，并保留源图到成品的映射。现有自动漫画滤镜样片呈强烈网点风，与参考图不够接近，不能作为最终资产。若无法在本地确定性处理中达到参考风格，应在交付 Demo 前说明限制并调整方案，不以临时占位图满足验收。

### 用户场景与验收

#### 用户故事 1：浏览环形获奖者展陈（P1）

访客在快讯页看到一圈获奖者漫画肖像，能够感受到缓慢旋转的展陈效果，并逐一看到姓名、年份、获奖时国家身份和获奖成果。

**优先级理由**：这是用户提出的主要页面体验，也是 Demo 评审的中心。

**独立验收**：在 Demo 页面中验证 12 张最终候选肖像可见、圆柱队列缓慢绕 Z 轴旋转、悬停会暂停并显示当前人物资料，移开后继续。

**验收场景**：

1. **假如**访客打开展陈 Demo，**当**页面加载完成，**那么**12 位人物肖像沿圆柱排列并缓慢绕中心 Z 轴运动。
2. **假如**访客将指针移到某个肖像，**当**该肖像进入悬停态，**那么**旋转暂停且该人物姓名、生卒年份、获奖时国家身份与获奖成果显示在肖像下方。
3. **假如**访客移开指针，**当**悬停结束，**那么**旋转恢复。

#### 用户故事 2：阅读有引文的获奖者科研经历（P1）

访客点击肖像后在新标签页阅读人物的科研经历、诺奖授奖理由和成果说明，并能打开支持这些陈述的可靠来源。

**独立验收**：对 12 位人物逐一检查详情页内容和引用；每一项事实叙述至少有一条对应的一手或权威来源，链接可访问且内容支持该陈述。

**验收场景**：

1. **假如**访客聚焦或点击某位人物肖像，**当**打开人物详情，**那么**详情在新的浏览器标签页打开，列出科研经历、明确的获奖贡献和逐条引用。
2. **假如**人物的贡献与超导并非完全重合，**当**详情描述获奖成果，**那么**文案清楚区分诺奖理由与其在超导发展中的关联，不扩大因果结论。

#### 用户故事 3：评审并复用 Demo 肖像素材（P1）

项目维护者能够评审完整 Demo，并确认其中的肖像资产就是后续网站使用的文件。

**独立验收**：Demo 全部 12 张肖像直接引用可复用的项目静态资产；清单记录源照片、处理方法、输出文件与校验值。

### 边界与异常场景

- 尊重 `prefers-reduced-motion`：减少动态或改为静态展陈；鼠标之外的键盘焦点也能暂停动画、查看资料并打开详情。
- 小屏幕下应能辨认肖像和资料；旋转容器不遮挡其他快讯内容。
- 对缺失来源、无法可靠识别或版权许可待核验的肖像和事实标记未核实，不编造来源。
- 详情页引用链接失效或来源不支持相应陈述时，该条内容不得标为已核验。

## 需求

### 功能需求

- **FR-001**：展陈必须包含图 1 明确列出的 12 位不同获奖者，并为每位人物单独呈现肖像。
- **FR-002**：展陈必须以围绕中心 Z 轴缓慢旋转的圆柱队列呈现人物；悬停时暂停，离开后恢复。
- **FR-003**：展陈肖像必须使用漫画风格的真实人物图像；Demo 与后续网站复用同一资产，不得以占位图片验收。
- **FR-004**：悬停或键盘聚焦人物时必须展示姓名、生卒年份、获奖时国家身份、相关说明和诺奖获奖成果。
- **FR-005**：点击或键盘激活人物肖像必须在新标签页打开其详情；详情包括科研经历、获奖贡献、与超导的关系及可核查引用。
- **FR-006**：引用必须链接到诺贝尔奖官方人物/奖项资料及能支持成果叙述的原始论文或权威学术来源；逐条核查来源内容，不以总参考列表替代事实引用。
- **FR-007**：Demo 必须有清晰的本地启动与评审入口；不改变快讯页现有生产体验，直至用户评审 Demo 并授权接入。
- **FR-008**：展陈必须支持减少动态设置、键盘访问、移动端阅读和新标签页安全属性。

### 关键实体

- **获奖者**：稳定标识、姓名、生卒年份、获奖时国家身份及说明、所关联诺奖年份、获奖理由、超导关联说明、源肖像、最终漫画肖像和参考文献。
- **引用来源**：来源类型、标题、作者或发布机构、发表日期、持久 URL/DOI、支持的具体陈述及访问核验状态。
- **肖像资产**：源文件路径与哈希、加工步骤、输出路径与哈希、裁切焦点和许可/归属核查状态。

## 成功标准

- **SC-001**：展陈准确覆盖 12 位确认名单，所有显示的姓名、年份、国家身份、获奖理由和科研经历均与其引用来源一致。
- **SC-002**：全部 12 张肖像均由非占位的漫画资产构成，圆柱旋转、悬停暂停/恢复和新标签页详情交互在 Demo 中可复现。
- **SC-003**：12 个详情资料的事实陈述均可通过逐项引用核查；来源不可访问或不支持时不将对应内容视为通过。
- **SC-004**：Demo 展示的最终候选肖像与项目复用的资产文件一致，清单可通过 SHA-256 验证。
- **SC-005**：用户可通过仓库说明启动 Demo；生产 `/news` 页面在 Demo 评审阶段保持现状。

## 假设与依赖

- GitHub Issue #159 是协作状态权威来源；本 Spec 与 Issue 双向关联。本地 Spec 远程链接待验证。

- 构造未被可靠来源支持的国籍、经历、诺奖理由或人物贡献。
- 在本 Feature 中改造快讯采集、新闻/论文信息流、站点语言体系或其他页面布局。

## 澄清记录

- 问：内置图像生成工具不可用时，是否使用图片 API 重绘？
- 需求结论：用户回复“先看交互，最终漫画稍后制作”。本轮交付交互预览，不调用图片 API；后续最终漫画仍需完成素材一致性要求。

- 问：图 1 只列出 12 位不同的人，早先确认中的“14位”应如何处理？
- 需求结论：用户回复“确认，按图中12位继续”。采用图中 12 人，不补充其他人物。
- 问：详情中“国家”按获奖时身份还是出生国家展示？
- 需求结论：用户回复“获奖时国籍/身份（推荐）”。按获奖时身份展示，必要时注明历史国别或多重身份。
