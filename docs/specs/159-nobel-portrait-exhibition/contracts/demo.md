# Demo 页面契约

- `/nobel-demo.html`：显示 12 位获奖者的旋转肖像展。
- `/nobel-demo.html?person=<id>`：显示唯一对应人物的科研经历和来源。未知 ID 当前回到展陈。
- 肖像链接使用 `target="_blank" rel="noopener noreferrer"`；打开后原标签页保持展陈。
- 悬停头像时暂停、移开恢复；键盘焦点和人物索引选择时将人物转到前方并定格，可通过“继续旋转”恢复。
- “减少动态效果”开启时关闭自动旋转，人物索引仍可展示全部 12 位。
- 概念上的竖直中心 Z 轴对应浏览器 CSS 场景的 Y 轴；第三轮采用有序循环相位的弧形展陈，不再使用会在侧缘压缩间距的 sin 横向投影；依然表现绕竖直轴的循环流动。
- 图片或最终漫画不达标时，页面和验收文档必须明确标注预览状态，不得通过标记文件存在来满足最终素材验收。

## 第二轮行为

- 页面沿用 SC-Wiki 主题的文字、主色和字体，内容背景纯白。去掉相框、黄色渐变和漫画滤镜。
- 展陈及详情都使用 `frontend/public/img/nobel/original/` 的历史原照，照片原始字节不变。展示边缘通过 CSS 遮罩淡入白底。
- 姓名、生卒年份、身份和成果嵌在每个人物容器中随之移动，移除静态下方资料卡。
- 按住时暂停自动运动，拖动超过 6px 后按水平位移控制角度；释放后遵循最后一次拖动方向。主动暂停或减少动态设置继续优先。
- 在原始点击元素捕获指针，拖动时转交舞台；触屏隐式捕获转交产生的冒泡 lostpointercapture 不结束手势。pointercancel 清理手势状态。
- 拖动的后续 click 被阻止，下一次正常点击可打开详情。
- 当前最前方人物最大，侧方连续缩小；背面不可点击，但12个人物始终可以通过索引选到前面。

## 第三轮行为：优先保证不遮挡

- `projection.ts` 根据人物显示宽度逐一计算中心间距，桌面预留36px、手机24px。照片自身的3D透视可能略微改变投影外沿，已额外在浏览器核验照片、容器和文字三者的联合边界。
- 主位比例1.10、两侧递减至0.42附近；照片侧向转角渐变至约48度，文字保持正向。
- 中心两个人物的相位插值确定原点，主位交接不跳动；循环折返点位于不可见范围。
- 此为可读性优先的弧形画廊，不承诺严格物理圆柱投影；白底、原照及既有交互保留。

## 正式页面接入（取代仅Demo边界）

- `/news#nobel-milestones` 嵌入同一 `features/nobel/NobelExperience.tsx` 展陈，不增加重复站点品牌。
- 正式详情为 `/nobel/:personId`，支持直接打开/刷新；未知ID给出未找到提示和返回展陈入口。
- Demo保留 `/nobel-demo.html?person=<id>&lang=zh|en`，复用正式组件/数据/布局。
- 正式页面通过LanguageContext切换中英文，Demo用查询参数；每个肖像成果后新增共同获奖句，详情显示官方份额与来源。
- 原照片由Vite构建至 `/assets`，匹配既有Nginx静态服务和Python的assets挂载；不增加后端接口。
- 样式局限于nobel类名及组件根内，不覆盖body、全局按钮/链接或页面背景。
