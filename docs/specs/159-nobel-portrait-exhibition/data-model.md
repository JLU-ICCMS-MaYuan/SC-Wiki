# 人物与肖像数据

本 Demo 使用静态 `NobelLaureate[]`，不写数据库。

| 实体 | 字段与规则 |
|---|---|
| 获奖者 | `id` 唯一；11 个展陈名单按用户最终确认固定。`name`、`englishName` 对应同一人；`years` 为生卒年份，在世者仅写出生年份和连接号。 |
| 国家身份 | `identity` 区分国籍与任职机构，`identityNote` 补充历史国家或多重国籍。不得以任职机构或出生地推定国籍。 |
| 叙述 | `career`、`awardReason`、`superconductivityLink` 分开表达科研经历、获奖理由与超导关联。 |
| 引用 | `sources` 保存标题、URL、支持范围；事实资料、传记、奖项文件依次为 1、2、3，存在原始论文时为 4。段落旁引用锚点指向对应资料条目。 |
| 肖像 | `image` 指向 `frontend/src/features/nobel/portraits/original/` 中历史原照；清单记录源图与输出哈希，最终重绘完成前禁止将其标为正式素材。 |

目前成果段落是经过官方资料初步核对的简要说明，不将链接可访问等同于全文科学审查完成。尚未核对完的国籍和图像归属继续记录为未完成任务。

第二轮动态状态为角度、主动暂停、悬停、拖动、减少动态偏好和舞台宽度。方向与指针会话存在 ref 中；人物深度、主位索引、位置、缩放由角度派生，不另建重复选择状态。

第三轮显示布局由 `projectGallery(angle, count, stageWidth)` 派生，包含循环偏移、缩放、显示宽度、水平位置、纵向偏移、照片转角与透明度。以整体人物容器的半宽累计间距保护文字，照片内部侧倾不改变姓名方向。不增加独立的主位位置状态。

正式接入后新增 `prizeShare` 字段，原始出处为各人官方facts页；同届共享者从同一个 `awardYear` 的已确认名单计算，不由研究合作关系推断。Onnes单独获奖，1973年三人的份额依次为1/4、1/4、1/2。中文原始资料在 `data.ts`，英文在 `en.ts`；`copy.ts`统一生成本地化名单和引用文案。完整科学史审校仍需后续核查。

当前紧凑版取消主动暂停状态，保留角度、悬停、焦点阅读、拖动、减少动态和宽度。新增人物未变换高度数组，由ResizeObserver更新，舞台高度从布局和可见人物高度派生。联系信息为四条姓名记录，其中三个有用户提供的邮箱，郭强不显示邮箱链接。

当前展陈记录与奖项历史拆开：`data.ts`/`en.ts`包含11人的展示内容，`awards.ts`包含原五届奖项的完整12名获奖者最小元数据。共同获奖说明从后者计算，展示过滤不能改变历史奖项份额。江崎在历史表中保留姓名、年份和1/4份额，无展陈资料或照片引用。
