# 人物与肖像数据

本 Demo 使用静态 `NobelLaureate[]`，不写数据库。

| 实体 | 字段与规则 |
|---|---|
| 获奖者 | `id` 唯一；12 个名单固定。`name`、`englishName` 对应同一人；`years` 为生卒年份，在世者仅写出生年份和连接号。 |
| 国家身份 | `identity` 区分国籍与任职机构，`identityNote` 补充历史国家或多重国籍。不得以任职机构或出生地推定国籍。 |
| 叙述 | `career`、`awardReason`、`superconductivityLink` 分开表达科研经历、获奖理由与超导关联。 |
| 引用 | `sources` 保存标题、URL、支持范围；事实资料、传记、奖项文件依次为 1、2、3，存在原始论文时为 4。段落旁引用锚点指向对应资料条目。 |
| 肖像 | `image` 指向 `frontend/public/img/nobel/comic/` 中当前预览资产；清单记录源图与输出哈希，最终重绘完成前禁止将其标为正式素材。 |

目前成果段落是经过官方资料初步核对的简要说明，不将链接可访问等同于全文科学审查完成。尚未核对完的国籍和图像归属继续记录为未完成任务。
