# 固定分隔线验证

日期：2026-10-23。Issue：#159。分支：`mayuan`。

## 原因和修复

上一版以当前angle派生的可见人物底边调整舞台高度，导致横线、姓名索引和联系人跟随旋转上下移动。现改为按所有人物完整周期的最大占用计算固定高度；保留ResizeObserver，仅在实际卡片高度因语言/字体/重排等改变时更新。

底边为64+0.42h+p(0.68h-64)，其中p∈[0,1]。对p线性，最大值可由端点得到。当前卡片远高于94.12px，最大值在主位，为1.10h；全部人物取最大，加顶部8px和底部12px。此公式与动画共用参数，不采样猜测，也不恢复任意850px高度。

## 验证

- 11项Vitest通过，其中新增数学测试覆盖不同卡片高度和完整正反两圈，所有底边都在固定高度内；最大卡片到达主位时只留必要余量。
- TypeScript及正式Vite构建通过；既有3Dmol eval及大包提示保留。
- [固定位置实测](assets/fixed-divider-validation/compact/browser.json)：中英文、1440/768/390px，每种121个位置，合计726相位；分隔线和联系人位置变化均为0px。
- 观测舞台高度：中文桌面/中屏661px、手机639px；英文桌面/中屏679px、手机657px。临界位置余量约11.77–13.37px；其他位置留白可能更大，这是容纳整圈最占空间人物所必需。
- 同一脚本验证默认自转及索引切换后横线位置不变，保留联系人、机构、引言和减少动态/键盘阅读行为。
- [Demo回归](assets/fixed-divider-validation/demo/browser.json)：拖动、触屏、取消、防误点击、新标签页及363相位无重叠通过。
- [正式页面回归](assets/fixed-divider-validation/production/browser.json)：11人详情、原照、份额、中英文、手机不裁切、样式隔离通过。
- [桌面截图](assets/fixed-divider-validation/compact/desktop.png)、[手机截图](assets/fixed-divider-validation/compact/mobile.png)。截图证明静止布局，动态稳定性以浏览器测量结果为准。
