# 验收与启动

源码及隔离验收已完成，目标环境仍需迁移和配套服务才能启用。先备份并按目标环境审批迁移；本任务仅对隔离测试库执行迁移。配置沿用服务端编号模型与 Redis。运行 python -m backend.community worker 启动专用两进程消费者，不安排定时问题。

验收：普通账号检查讨论、论文及体系只读；超级管理员手动提问与随机提问；至少两个隔离模型上游检查独立答案、来源一致与单模型失败恢复；编辑、下架与重生成竞争验证；刷新与 Worker 重启验证。具体执行结果写入 validation.md，未实际执行不宣称通过。
