# 设计依据

- 复用现有社区数据与 Go 读取，新增来源和修订信息；AI 作者允许空，不伪造真人用户，历史作者保持。
- 复用编号模型目录及默认配置，按端点和型号去重，保持目录顺序；浏览器个人配置不进入后台任务。
- 采用专用单次完整回答提示词，不调用会追问用户的 Mentor；各模型看到相同资料而看不到其他答案。
- 提问去重先规范化比较，再用提问模型对最相似的历史标题判别等义；最多三次候选生成。十类和提问模型分别均匀随机。
- 共用来源快照但每次生成发布及公开读取重新验证论文公开版本，禁止过期授权导致资料泄露。
- 整条答案受问题、答案版本控制，人工编辑和治理都增加版本；失败不会覆盖旧答案。修订记录后台可查。
- 使用独立 RQ 队列及全局两槽锁，不增加定时提问；恢复检查仅修正任务状态。
- 新迁移接现有 20261015_0094 头，不重写既有迁移；降级发现 AI 内容时拒绝破坏性清理。

- 实际 macOS 启动验证要求消费者位于可导入模块，并使用 RQ SpawnWorker，避免 Objective-C fork 崩溃；不修改系统环境或禁用安全检查。

- 本地实例没有 Embedding 密钥，且公开论文数为 0；在数据库确认空公开库后，无需先调用向量服务。存在公开论文时保留原检索与失败规则，不改变科学来源所有权。
- 实测 GPT 网关对非流式请求也返回 SSE。改为复用现有流式 complete_json，而不是复制协议解析或修改用户模型配置；两供应商真实回答均通过。
