# 目标1：减少不必要的人工核对

填写只是生成候选，系统还应核实来源、材料、压力、方法和数值配对。完成核实并保存后，用户不必逐项确认。

建议分工：

- 原文明确、关系确定：系统核实后自动通过，未变化的结果直接复用。
- 系统填错且答案唯一：自行纠正并核实，保护人工修改。
- 查完正文与附件仍有冲突：说明具体分歧，再交人判断。
- 处理或保存失败：标明技术失败，不能当作科学疑问。

维护与验证→结果保存、复用； 科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../221-scientific-field-sidebar/spec.md)，本处不再独立维护。

缺表迁移是另发现的运行环境故障，原三个目标未单独承接；本稿仅讨论分工，待确认。
