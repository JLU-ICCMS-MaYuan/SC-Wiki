## 实测发现并修复

1. 原生PDF提取阻塞时只关闭模型HTTP不能停止：增加定向RQ作业停止，保留检查点，不停止其他任务。
2. RQ使用压缩二进制，不能用decode_responses=True客户端读取：失败回归先检出，再改用队列二进制连接。
3. RQ主动stop不走普通失败回调：增加停止回调及读取时实际作业状态收敛，不能仅靠PID/超时判断。
4. 严格调用原先把400全部包装为结构错误：运行器保留原始上下文超限码，才能进入压缩，其他宿主保持旧行为。
5. LangMem实际传入消息列表，而不是固定PromptValue：直接库集成回归检出并修复。

6. 流式接收重复记录挤掉请求历史：固定反例检出5条接收记录而期望1条，修复后单次转换；完整JSONL过程记录可分页读取，后台轮询仍只带最近100条。
