## 已确认结论与验收

- 临时连接、限流和服务故障无限退避重试；请求成功不等于科学审核通过。身份、权限、参数和严格结构错误明确停止；上下文超限尝试压缩，无法缩减明确停止。
- 红框为唯一解析动态区：实际文件/页/动作/字段、简短依据、请求等待/接收/重试和脱敏错误。保留原始失败，不展示内部完整思维链，不额外调用模型制造过程。
- 原地等待占Worker；人工停止阻止新请求、使旧执行失效、保存恢复材料后释放Worker。继续同一任务，不重复上传和提交，不以半截输出拼接正式结果。
- 暂停保留到主动清理，计入100个活动任务上限；刷新不停止，服务中断明确展示可恢复位置。
- 完整历史留档；当前必要原文、图片、草稿值、引用与有效审核结果不由摘要替代。LangMem仅压缩旧过程，工具配对和用户/任务/步骤隔离。
- 保留失败重放、真实模型、停止恢复、权限/迟到回写/重复继续、四宿主字段表单和变异验证；继续Peng2017真实五阶段黑盒，未完成不能宣布完成。

## 功能需求

- FR-001：唯一解析动态区位于图1红框，展示实际阶段、请求次数、起点、接收、重试倒计时、脱敏错误与请求ID；历史可查。不新增科学核对来生成过程。
- FR-002：临时连接（含域名解析）/超时、无任何输出就结束且无明确拒绝或截断、429、暂时服务错误持续重试，遵守Retry-After与递增错峰；固定错误停止。每次失败留证；严格结构错误与科学疑点不因传输重试改变结果。
- FR-003：10个Worker原地等待；停止立即阻止新请求并使旧代次失效，关闭连接，保存后释放。无法保证上游停止或免计费。
- FR-004：持久保存输入身份、步骤、模型配置引用、请求、图片关联、工具历史、完整响应、检查点与草稿版本；不保存密钥。继续复用完整响应，仅重发未完成请求。
- FR-005：停止/继续幂等，检查权限及当前草稿/输入版本；迟到执行隔离。服务中断可显式继续，不自动重发已完成请求。
- FR-006：暂停保留到主动清理，计入现有100上限，不能由旧清理任务删除；刷新不停止。
- FR-007：直接接入LangMem滚动摘要，原始记录独立保留；先去重再压缩旧过程，近期工具调用成对保留。当前原文、图片、数值、引用、身份、审核及当前草稿不可用摘要替代。
- FR-008：预算提前压缩，明确超限可触发；分批限制摘要输入。摘要不缩减、必要证据超限、结构错误明确停止，不无限压缩；传输错误沿FR-002。
- FR-009：用户/任务/步骤隔离；相同版本有效审核复用，普通输入保存不调用模型；不改变科学字段键、材料归属及提交审核生命周期。

## 边界情况

无输出503与已输出断流分别留证；停止/响应保存竞态按先提交检查点判定；无有效配置、文件变更、草稿变更拒绝旧上下文；清理/送审与停止竞争按任务锁串行。旧任务只有实际保存的检查点可复用，不伪造历史进度。
