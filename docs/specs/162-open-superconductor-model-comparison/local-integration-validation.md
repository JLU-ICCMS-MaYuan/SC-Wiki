# 本地主站接入验收

日期：2026-10-26。用户要求暂停截图中的 SISSO · 81 样本，并将已能运行的模型接入 SC-Wiki 本地服务。目标为当前已确认的本机原生实时开发环境。

## 已实现范围

- 正式入口：[本地预测](http://127.0.0.1:5173/tc-predict)。使用主站 AppShell 和现有侧栏、主题；不是 iframe，也不跳转 Demo。
- 左侧“预测”下有常压 BCS 超导体／高压氢化物。常压组为 BETE-NET-CSO、Xie 2019；高压组为 Xie 2022、Tc assessment model。
- SISSO 81 已从主站模型目录、下载白名单及 Demo 可选列表移除；原研究资料和缓存保留。
- 已确认的自动结构解析、顶部模型、右侧短链接与整包下载、原模型同页上传、结果定高横条和展开功能保留。
- 正式源码位于 `frontend/src/features/prediction/`、`backend/prediction/` 和 `backend/api/tc_models.py`。运行路径不导入 `docs/` 内代码、不请求 Demo 的 5189／8192。
- 请求复用 Vite 5173 → Go 8080 → FastAPI 8000；无需新增常驻模型端口。BETE 请求按需派生独立解释器，结束后退出；轻量参数模型直接计算。原 `/api/tc-predict/` 算法文件未修改。

7. 缺 PDOS_H 返回 400，已有结果保留；分类支持浏览器返回。
8. 收起主站侧栏后仍可用菜单切换类别，不卸载结果区。
9. 从预测页离开至热点后，主站边距和布局无 CSS 污染。
10. 390px 真正访问主站，分类、POSCAR、真实计算及结果折叠均可用，无页面溢出。

## 运行隔离与失败边界

[真实并发记录](assets/local-integration-isolation.json)：一个 BETE 请求成功，另一个并发结构请求返回 429；同时健康接口返回 200，用时约 0.007 秒，SISSO 参数计算仍为 200。结构模型没有阻塞主服务事件循环。

后端 `backend/tests/test_tc_models.py` 七项检查通过，覆盖：暂停候选及未知下载、真实参数公式与非法输入、文件缺失／同长度篡改、独立解释器缺失、实际子进程超时／忙碌并释放槽位、任务取消后清理、制品缺失在导入作者代码前拒绝。生命周期测试使用真正的可控慢子进程验证清理，不把它们当作真实模型精度验证；真实权重推理由主站浏览器另外覆盖。

主站导入目录、API 和参数公式时不加载 Torch／e3nn；结构执行前校验固定提交、100 个权重、结构和作者代码的 Git 对象，运行结束不保留常驻 GPU／模型服务。依赖继续位于独立 venv，主站依赖未升级。
