# Demo 数据模型

## 模型

`demo/catalog.json` 定义稳定 ID、名称、家族、材料分组、输入模式、论文与代码网址、许可、适用边界和数据 ID。目录可包含资料候选，但候选不出现可运行按钮。BETE-NET、两版 SISSO 和原站估算的输入条件分别表达。

## 数据制品

数据文件 ID 只映射到受控缓存中的固定文件；保存文件名、原始网址、发布页、许可、固定版本、大小及 SHA-256。Xie 2022 未取得原包时以发布方 MD5 和大小作为恢复下载的校验依据；拿到文件前无本地下载入口。

原始训练输入、公开训练／测试全集和本站辅助材料打包分别标注。本页不提供数据预览，仅供应经核验的原文件。用户不能用请求参数指定服务器文件路径。

## 预测请求及结果

请求为结构文本／格式，或 λ、ωlog、ω₂、μ* 参数。结构不落业务数据库；结果在页面内按运行次数保留，最多八项。每项记录模型、输入标签、参数、Tc／谱、单位、方法和耗时；结果显示不等于实验事实或审核通过。

BETE 执行时对每个网络复制同一原始图，避免作者 forward 对节点输入的就地更新污染下一个网络。原作者参考输出仅由验收脚本读取，服务不会用参考表回答预测请求。

结构推理一次只允许一个请求；其他请求明确返回忙碌。参数错误或某个模型失败不清除已成功结果。没有新增 SQL 表、业务文件存储或用户账号状态。

Tc assessment model 保留内部 ID legacy，仅作为稳定标识；界面使用论文名称。上传使用浏览器 File／FormData，结构和 PDOS 不写入业务数据库；返回的解释特征按原字段保留。

BETE 的一个可见下载项关联同一发布版本的全部数据组成部分，不把这些部分当成不同数据集。外层 ZIP 由本站生成，SOURCE.json 保存每个原文件的路径和摘要，包内作者文件不改变。页面不展示元信息细节，发布版本和许可仍在数据目录及包内保留；“完整”仅限收齐当前公开的这些文件。
