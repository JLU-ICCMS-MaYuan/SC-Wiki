# 本地 SC-Wiki 主站接入计划

用户已明确暂时放弃截图中的 SISSO · 81 样本资料候选，并要求接入 SC-Wiki 本地服务。部署目标沿用本次操作已明确的本机原生实时开发，不涉及阿里云或 Docker。

## 实施范围与既有设计

将已逐项确认的预测页面接入 `/tc-predict`，复用主站 AppShell，移除 Demo 自带导航和外部端口链接。左侧“预测”提供常压 BCS 超导体／高压氢化物；顶部模型、等高来源卡、自动识别结构、短文字来源链接和定高结果展开行为保留。SISSO 81 从目录、下载白名单及主站入口移除，研究记录和原始缓存不删除。

启用 BETE-NET-CSO、Xie 2019、Xie 2022 和姜博文的 Tc assessment model。Xie 2022 原始数据存储不可用的状态仍明确显示，不能把接入成功写成原包已下载。

## 主路径与职责

- `frontend/src/features/prediction/`：正式页面与作用域 CSS，只影响预测页面，复用主站主题和主导航；类别写入 URL 查询参数，支持刷新与返回。
- `backend/api/tc_models.py`：主站 `/api/tc-models/` 目录、原始数据下载、示例和预测；经既有 Vite → Go → FastAPI 链路访问，不依赖 5189／8192。
- `backend/prediction/`：模型目录、数据完整性与纯参数公式；BETE 运算通过固定模块子进程在独立 venv 中执行，主网站不导入旧 e3nn／PyG，不升级主环境依赖。
- 原 `/api/tc-predict/` 保留，由同一页上传表单调用；无复制公式或数据库迁移。
- 复用已校验的 `.local/tc-model-demo/` 制品和隔离 venv（历史缓存名，不是对 Demo HTTP 服务的依赖）。目录可由显式服务端配置覆盖，用户请求不能指定文件路径／执行程序。
- 子进程有单并发限制、硬超时、退出与取消清理；制品缺失明确 503，非法输入 400，不影响主站其他 API。参数模型无需子进程。
- 准备入口转为 `scripts/prepare_tc_models.py`；重建及本地服务说明写入本 Feature quickstart 和 Overview，不安装全局包。

## 验证与完成边界

1. 主站真实浏览器验证分类切换、刷新／返回、自动 POSCAR、模型计算及结果横条。
2. 主站下载原包并核对摘要；移除候选与失效下载 ID、输入错误、缺制品、忙碌／超时等边界分别验证。
3. 不调用 Demo 端口；单独验证 5189／8192 不参与网站请求，主代码不引用 docs 内运行模块。
4. 作用域 CSS 不污染其他页面；侧栏角色与折叠回归、主前端构建及针对性后端测试通过。
5. 按任务路径自动提交，保留并行任务改动；未授权推送，远程文档链接与科学性能完整评测继续待验证，Issue 不关闭。

本计划仅推进已明确授权的本地主站集成；没有新增训练、结果持久化、模型数量承诺或独立科学精度门槛。
