## 摘要

用户明确要求本地实时开发 Demo、新增模型真实推理、模型旁原始训练数据下载及原始网址。以独立 React／Vite 页面和 FastAPI 服务交付，常压与高压分组，保留原站入口。当前 Plan 只覆盖这个授权增量，完整网站功能仍待后续评审。

## 技术上下文

- 语言：TypeScript／React 19，Python 3.12；前端复用仓库 Vite 5 和 TypeScript 5.6。
- 服务：本机回环地址 5189（Vite）、8192（Demo API）；现有 5173／8080／8000 服务保持运行。
- 依赖：独立 `.local/tc-model-demo/venv` 只读继承 sc-wiki 环境，额外安装 e3nn 0.4.2、PyG 2.0.2 及 CPU 扩展；不升级主环境。
- 数据：`.local/tc-model-demo/` 缓存作者固定对象与权重，不使用业务数据库。
- 首批：BETE-NET-CSO 原始 100 网络集成；Xie 2019／2022 解析模型。未接入模型只展示资料；原经验估算链接原站。
- 验证：真实作者样本的数值回归、合法新输入、非法输入、浏览器下载字节摘要、窄屏交互和旧页面可达性。
- 性能：CPU 单次集成可能较慢，前端显示运行状态；限制结构规模及并发，不虚构论文精度。

## 阶段与依赖

先取得并校验数据、结构、权重和依赖；随后复现模型与作者参考输出，再提供 API 与下载；最后完成页面和真实浏览器验收。下载上游暂不可用时保留精确错误，不能改用其他数据冒充。模型训练数据版本差异与无法验收项记录在 Demo 验证中。

必要复杂度限于独立推理环境和文件完整性校验：科学模型依赖及大型制品不混入正式网站环境，下载接口不读取任意路径。没有引入业务数据库、账号体系、任务队列或训练平台。

## 主题一致性修正

用户指出独立绿色样式与主站不统一。Demo 的 main.tsx 直接导入主站 theme.ts，将主色、背景、文字、字体及卡片阴影映射为 CSS 变量；成功／警告／错误沿用同一主题的语义色。品牌使用主站 SC 标识，按钮采用胶囊形，正文／说明恢复主站文字层级。样式修正不复制主站主题常量，后续主题变化可同步。浏览器从运行中的主站取计算样式与 Demo 比较，而非只检查源码色值。

## 右侧来源卡与原模型内嵌

按用户最新四项要求，右侧改为一个与模型卡片等高的来源卡，内部容纳论文、代码、引用说明和多个数据文件分区；取消外置标题和预览。原模型采用经论文第六页核查的 Tc assessment model 名称。Demo 的 Vite 将 /api/tc-predict 原样代理到现有本机 Go 8080，再由既有链路交给 Python；浏览器使用原 multipart 字段 contcar／pdos_files，避免复制公式或产生两套算法。

结果适配器保留 predicted_tc 和五项解释特征；使用合成结构与 PDOS 做真实接口一致性验证，不用该夹具证明科学准确度。全部交互留在当前页；参考截图及作者命名核查分别保存为用户证据和科学来源记录。

## 简化数据说明和整包下载

来源入口按作者仓库去重：同一个 GitHub 仓库的代码与数据共用“原始网站”，不同存储网站分别显示。页面只显示“论文链接”等文字，不渲染 URL、版本、许可详情或摘要；后台目录和下载文件的校验保留。

prepare.py 的 build_bete_dataset 收集固定版本的 database.json、structures、indices 和 LICENSE，逐文件验证原 Git blob 后生成确定性 ZIP，附本站 README 和 SOURCE 清单。模型目录只引用 bete-bundle；原来两个文件的接口暂保留供既有链接兼容，但不再出现在页面。SISSO 2019 只展示实际训练输入。server.py 每次请求读取小型元信息目录，使原生开发中的新下载包配置及时生效。
