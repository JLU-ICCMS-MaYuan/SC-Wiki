# 实施计划：本地真实推理与训练集下载 Demo

**Issue**：[#162](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/162)
**日期**：2026-10-26
**Spec**：[spec.md](spec.md)

## 摘要

用户明确要求本地实时开发 Demo、新增模型真实推理、模型旁原始训练数据下载及原始网址。以独立 React／Vite 页面和 FastAPI 服务交付，常压与高压分组，保留原站入口。当前 Plan 只覆盖这个授权增量，完整网站功能仍待后续评审。

## 技术上下文

- 语言：TypeScript／React 19，Python 3.12；前端复用仓库 Vite 5 和 TypeScript 5.6。
- 服务：本机回环地址 5189（Vite）、8192（Demo API）；现有 5173／8080／8000 服务保持运行。
- 依赖：独立 `.local/tc-model-demo/venv` 只读继承 sc-wiki 环境，额外安装 e3nn 0.4.2、PyG 2.0.2 及 CPU 扩展；不升级主环境。
- 数据：`.local/tc-model-demo/` 缓存作者固定对象与权重，不使用业务数据库。
- 首批：BETE-NET-CSO 原始 100 网络集成；Xie 2019／2022 解析模型。未接入模型只展示资料；原经验估算链接原站。
- 验证：真实作者样本的数值回归、合法新输入、非法输入、浏览器下载字节摘要、窄屏交互和旧页面可达性。
- 性能：CPU 单次集成可能较慢，前端显示运行状态；限制结构规模及并发，不虚构论文精度。

## 文档与代码结构

本目录保留 Spec、Research、来源清单及历史核验；新增 Plan、Tasks、数据契约、Quickstart、Demo 源码和验收记录。

`demo/server.py` 负责只读数据服务与预测 API；`demo/inference.py` 负责模型加载、结构构图和后处理；`demo/catalog.json` 保存来源元信息；`demo/scripts/prepare.py` 准备并校验制品；`demo/src/` 提供分组、模型卡、相邻训练数据及输入／结果交互；`demo/tests/` 保存真实数值和浏览器验收。

## 阶段与依赖

先取得并校验数据、结构、权重和依赖；随后复现模型与作者参考输出，再提供 API 与下载；最后完成页面和真实浏览器验收。下载上游暂不可用时保留精确错误，不能改用其他数据冒充。模型训练数据版本差异与无法验收项记录在 Demo 验证中。

必要复杂度限于独立推理环境和文件完整性校验：科学模型依赖及大型制品不混入正式网站环境，下载接口不读取任意路径。没有引入业务数据库、账号体系、任务队列或训练平台。
