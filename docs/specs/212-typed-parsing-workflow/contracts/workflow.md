# 流程选择与操作契约

## 判断输入输出

当前正文/SI有效原文分批及来源编号进入判断；普通结构附件和引用工作不能决定本文类型。输出文章类型、主要贡献、超导机制、中文理由、来源编号和基础题录。程序选择已登记流程，模型不能指定执行函数或表单。

## 状态与界面

公开判断结果和匹配绑定。needs_workflow停止轮询，仅显示通用结果、原文件入口与暂停原因，不提供专用编辑、送审或手动绕过。已匹配稿显示流程与表单版本；冻结历史只读。

`GET /api/upload-tasks/{task_id}/files/{file_id}/download` 沿现有任务所有者/已批准管理员权限返回原文件，不依赖科学表单；未声明文件返回404，其他用户返回403，临时存储不可用返回503。暂停页使用已有带认证的下载适配访问，不暴露物理存储路径。

## 操作保护与兼容

新策略任务缺少绑定、未登记流程或表单不一致时，专用操作返回明确409。整稿保存从服务端原稿继承绑定，局部接口不开放根级绑定。现有权限、工作稿周期、并发保护继续有效。

历史无绑定的既有稿沿原版本化路径；当前读取不写入迁移。未来复制流程只作开发起点，经过真实类型讨论、调试与验收后才登记支持；测试副本不能冒充实际支持项。
