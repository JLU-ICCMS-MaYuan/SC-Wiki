# Feature 规格：材料家族论文数量与年度发文统计

**GitHub Issue**：[ #115](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/115)

**创建日期**：2026-09-24

## 背景与目标

在社区排行榜的贡献榜下方，让访客和登录用户比较本站收录的不同材料家族论文规模，并点击查看年度分布。

## 用户场景与验收

### US1：比较各家族文献规模（P1）

优先级理由：提供核心统计入口，可独立检查各柱数量与已审核论文一致。

1. 假如已批准论文分别涉及铜基、铁基或两者，当用户进入排行榜，那么看到按篇数降序排列的全部家族，跨家族论文分别计数，同一家族不重复。
2. 假如目录包含零论文家族，当展示柱状图，那么仍显示该家族名称与零篇数量；缺少分类的论文进入“未分类”。

### US2：展开年度分布（P1）

优先级理由：直接满足用户查看研究体系发文变化的诉求。独立验收为点击家族并核对年度数据。

1. 假如年度区初始收起，当点击家族柱，那么高亮该家族并在下方展开其年度柱状图。
2. 当点击另一家族，那么在同一区域切换；再次点击当前家族或收起按钮则关闭。
3. 假如有效年份存在间隔，那么缺失年份补零；未知年份单独注明，年度数量之和加未知年份数量等于该家族总量。

### 边界与异常

空数据、全部年份未知、零篇家族均显示明确提示。刷新失败保留旧快照并提示失败，可重试；首次失败不伪造零统计。窄屏图表内部可横向滚动，页面不溢出。

## 功能需求

- **FR-001**：按现有材料家族目录展示所有家族，包含零篇家族及未分类，不限制 Top 20。
- **FR-002**：仅统计当前已批准论文及当前版本家族，每家族按论文去重，多家族分别计数；不依赖物性或 Tc 数据。
- **FR-003**：以发表年份统计，补齐最早至最晚有效年份之间的零值，并单列未知年份数量。
- **FR-004**：提供点击展开、切换、高亮及收起，初始不选中家族。
- **FR-005**：总量及明细使用一致快照，每小时自动更新，支持手动刷新并展示更新时间及加载、空、错误与重试状态。
- **FR-006**：访客及登录用户均可访问；中英文、窄屏和键盘操作可用，明确说明本站收录和跨家族计数口径。
- **FR-007**：公开接口只提供聚合数据；维持既有贡献榜及个人排名行为，增加后端和前端行为测试。

## 关键实体

论文、材料家族、家族年度统计。论文可属于多个家族；所有总量和年度计数共享同一论文集合。

## 成功标准

- **SC-001**：固定数据集中总量、各年、未知年份与人工去重结果全部一致，待审和旧版本计数为零。
- **SC-002**：展开、切换、收起三个操作均显示正确家族，无年度数据时不出现错误图形。
- **SC-003**：手动及小时刷新均更新完整快照，失败可恢复；匿名和登录视图一致且原贡献榜回归测试通过。

## 假设与依赖

复用已存在的家族目录及公开审批边界。有效年份遵循现有管理员校验的 1–9999 整数范围；同篇数按家族 ID 升序。零篇柱通过整列点击区及名称可选择。

## 范围外

外部采集、论文列表下钻、导出、常规/非常规维度切换、部署和推送。
