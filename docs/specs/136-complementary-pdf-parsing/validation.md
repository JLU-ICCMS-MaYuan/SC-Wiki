已完成 H3S 正文与补充的六次真实解析、四路同模型表单提取、带原 PDF 区域的 HTML 对照和独立评测。**首版互补没有证明准确度提升，反而发生压力归属退步，不满足接入生产默认流程的条件。**

## 同一下游条件与失败保留

四路均使用项目当前 `server:LLM1 / deepseek-v4-pro`，温度 0.1、输出上限 32768 token、输入预算 500000 字符；额外推理关闭。未保存 API Key、授权头或模型内部推理文本。

| 结果臂 | 输入 token | 输出 token | 本次调用 / 秒 |
| --- | ---: | ---: | ---: |
| Docling | 50017 | 22668 | 181.952 |
| MinerU | 54364 | 26844 | 208.078 |
| Marker | 41080 | 12749 | 103.197 |
| 互补 | 139919 | 13437 | 123.604 |

这些是供应商返回的真实 usage，只统计最终比较调用，不代表全部开发成本。互补输入为 Docling 单路的约 2.80 倍、Marker 的约 3.41 倍；没有证明按需执行成本降低。

早期 Docling 尝试默认开启额外推理，32768 输出 token 中约 20275 用于推理，响应以 `finish_reason=length` 截断。保存原始响应并记失败，没有补括号冒充成功；同配置的 MinerU 尝试被中断并留存。之后四路统一关闭额外推理。共同提示又补充了材料状态按压力拆分、Conditions 层级和非 Tc 代表标志约束，旧版本失败均保留，最终只比较同一个提示版本。

运行时还修复了两个 demo 适配问题：不能对 venv 的 Python 路径做符号链接 resolve，否则绕过隔离环境；不同 PDF 库的页尺寸有约百万分之一点的舍入差异，先在 0.01 pt 内确认等价，再使用包络页面尺寸保存原始块坐标。没有因这些问题修改原 PDF 或科学候选。

## 改善、退步与证据边界

独立清单涵盖四组 Tc、两组 λ/ωlog、四组 μ*、四项 k/q 网格、12 个显式晶胞参数、P1 带隙、Cccm 跨页行数、两行 S 坐标与两项 Wyckoff 标签。已目视核对正文 3、4、6 页和补充 4、5 页；原 PDF 黄色高亮是文件已有内容。

- 三个独立结果均把 130、200、250、300 GPa 分为独立状态，并提取 Tc=155–166、191–204、184、179 K。
- 互补结果把 184、179 K 放入 200 GPa 的 Im-3m 状态，没有独立的 250/300 GPa 状态；同时污染 200 GPa 的 Tc/μ* 候选组，并使高压两个 μ* 字段在正确状态下缺失。对应 Q002/Q003/Q004/Q010/Q011/Q012 六项退步。
- MinerU 将补充第 5 页 Cccm 的两行 `S(8l)` 写成 `S(8I)`；Docling、Marker 和互补保留小写 l。因此互补相较 MinerU 改善 Q032/Q034 两项，但同时退步六项。
- 所有四路均保留 Cccm 跨页 7 条独立原子行，顶部两行 S 没有误挂给 R3m。本检查不等于全部原子坐标已审完，也未验证可用 CIF。
- Docling/互补的部分晶胞角引句使用规范化希腊符号，而源块保留不同文本层字符，因此定位校验拒绝；不能因为角度值匹配便强行放行引句。
- 当前下游会返回 `predicted superconductor`、`predicted` 或 `hydride` 等超导体类别，实际表单只接受 conventional/unconventional/unknown；μ*=0.1–0.13 被完整保留为文本，现有数值控件不支持。这些是共同契约/表达问题，不是单个引擎质量排名。

首版互补对正文保留 361 个块、补充保留 771 个块和 6 个表格对象；共 192 个空间分组，134 组有文本差异，17 组是一对多不确定匹配。完整候选保留满足审计需要，却产生很大的重复输入。压力归属错误与输入膨胀同时出现，**单次运行不能证明因果**；应继续研究更小的内容取用单位与明确的状态归属约束，不能直接宣称三引擎组合更好。
