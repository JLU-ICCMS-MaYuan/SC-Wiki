# 界面与接口契约：研究材料右侧可折叠大纲

## 用户可见行为

- 研究材料改为右侧可折叠大纲，每个材料状态独立一项，按“#编号 · 空间群 · 化学式 · 压强”显示。
- 小三角展开/收起，长列表内部滚动；正文不再铺开长材料跳转表，窄屏保持可操作。
- 点击条目按稳定状态身份定位并展开目标；编号仅表示当前顺序，删除前项后不串位。
- 标题使用当前宿主的报告空间群、化学式及压力；零压有效，缺失明确提示，不推测科学数据。
- 覆盖上传、返修、两类审核和只读详情；保留来源标记和冻结稿自身数据，导航不触发保存或模型。

## 事实来源与约束

状态字段由当前宿主草稿/只读版本提供；state_key是定位身份，#编号只是展示；大纲折叠仅属于界面状态。

## 实现边界

PaperMaterialsSection复用materialStateSummary与locateMaterialState；桌面为右侧大纲留宽，来源侧栏位于更高层；按state_key在当前宿主定位，历史无key保留显式位置兼容。
此处记录原实现契约，没有新增接口或数据结构。与其他子项共用的接口参数、组件及返回值继续由原代码掌管；本项范围外行为见spec.md。

## 验证对应

FR-001～FR-005对应US1与SC-001/002，实际案例及原运行边界见[验收记录](../validation.md)。

## 2026-11-04 布局约束（历史方案，当前以下节为准）

展开目录顶部、底部各4px，桌面表单卡片与目录外框缝隙4px；外框不随条目多少收缩，条目区在剩余高度滚动。收起后保留箭头并释放正文留位。窗口高度变化及时响应，卡片样式与所有写入/审核契约不变。

## 后续覆盖：取消悬浮

采用最新确认：目录属于页面正常右栏，文件名／阶段横条不吸顶；两者随页面滚走。桌面两栏间距4px，目录折叠不遮挡正文，窄屏纵向排列。原固定顶底4px约束不再适用，材料卡片、定位身份、权限、来源及所有写入契约保持。
