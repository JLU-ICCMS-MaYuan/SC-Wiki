## 用户场景与验收

### US1：研究材料右侧可折叠大纲（P1）

目标：研究材料大纲展示、折叠展开、稳定跳转及五类宿主布局。
优先级理由：本项的主要用户路径，单独验收即可判断是否交付。
独立验收：逐条核对下列场景，并使用本项validation.md中列出的实际组件或存储用例。

1. 大纲显示#编号、空间群、化学式、压强，可收起与恢复，长列表内部滚动。
2. 点击折叠状态后展开并定位；删除前项和修改压力后，身份、序号及显示保持对应。
3. 0 GPa与未填写区分；只读和冻结稿不读取当前工作稿替代，不产生科学写入。

### 边界与异常场景

不修改研究材料科学汇总、标准键、材料归属、模型提取、审核规则或权限。普通保存、来源核对、权限、失败恢复、稳定身份及当前公开版保护继续遵守继承约束；本次文档拆分不扩大原实现范围。与其他子项共用的文件不归某一个Issue独占。

## 需求

### 功能需求

- **FR-001**：研究材料改为右侧可折叠大纲，每个材料状态独立一项，按“#编号 · 空间群 · 化学式 · 压强”显示。
- **FR-002**：小三角展开/收起，长列表内部滚动；正文不再铺开长材料跳转表，窄屏保持可操作。
- **FR-003**：点击条目按稳定状态身份定位并展开目标；编号仅表示当前顺序，删除前项后不串位。
- **FR-004**：标题使用当前宿主的报告空间群、化学式及压力；零压有效，缺失明确提示，不推测科学数据。
- **FR-005**：覆盖上传、返修、两类审核和只读详情；保留来源标记和冻结稿自身数据，导航不触发保存或模型。

- **FR-006**：材料目录保留在页面正常排版的右栏，取消独立悬浮；桌面两栏间距4px，目录高度随窗口高度变化，条目内部滚动，短目录保持同高。桌面目录在右栏内常驻，页面滚动时保持可见，不遮挡左侧正文；窄屏沿用纵向排列。
- **FR-007**：保留现有材料状态独立卡片、折叠/展开、稳定定位、来源入口与只读行为；收起目录回收正文留位，低高度窗口和窄屏可操作。

- **FR-008**：上传解析页文件名／阶段／操作横条取消吸顶，随页面滚走；任务信息、进度与草稿统一为右侧目录留宽，互不覆盖。窄屏顺序排列，保留目录折叠与跳转。

### 数据所有权

状态字段由当前宿主草稿/只读版本提供；state_key是定位身份，#编号只是展示；大纲折叠仅属于界面状态。

## 成功标准

- **SC-001**：US1列出的正常路径均满足FR-001～FR-005，对应实际案例可在validation.md和证据清单复查。
- **SC-002**：本项异常、只读或角色边界按原验收保持，拆分不改变已实现行为；邻接已知失败单列，不计入本项通过。
- **SC-003**：原始需求、对应图片、代码/用例哈希及验收归属完整；Issue指向本地Spec，远程链接在实际推送后另行核验。

- **SC-004（历史验收，现由SC-005覆盖）**：正式页面浏览器测量目录顶/底留白及桌面编辑卡片到目录缝隙均为4px（允许1px亚像素取整）；短/长目录、窗口变高变矮、收起/恢复、四编辑宿主及只读详情均覆盖，不新增科学写请求。

- **SC-005（取消悬浮阶段的历史验收，目录滚动行为由SC-006覆盖）**：真实浏览器验证完整上传处理中预览、可编辑上传、返修、两类审核和只读详情的正常分栏、4px间距、折叠恢复及页面滚动；处理中横条与目录同一起始行并能滚出视口，390px不新增水平滚动；导航无科学写请求。

- **SC-006**：桌面滚动及点击材料跳转后，右侧目录仍保持可见，展开时顶距4px、长列表可在内部滚动；收起后箭头仍可见、可恢复。两栏间距4px，文件名／解析阶段横条继续随页面滚走。覆盖上传预览、上传编辑、返修、两类审核及只读详情。
