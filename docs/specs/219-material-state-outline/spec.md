## 用户场景与验收

### US1：研究材料右侧可折叠大纲（P1）

目标：研究材料大纲展示、折叠展开、稳定跳转及五类宿主布局。
优先级理由：本项的主要用户路径，单独验收即可判断是否交付。
独立验收：逐条核对下列场景，并使用本项validation.md中列出的实际组件或存储用例。

1. 大纲显示#编号、空间群、化学式、压强，可收起与恢复，长列表内部滚动。
2. 点击折叠状态后展开并定位；删除前项和修改压力后，身份、序号及显示保持对应。
3. 0 GPa与未填写区分；只读和冻结稿不读取当前工作稿替代，不产生科学写入。

## 需求

### 功能需求

- **FR-001**：研究材料改为右侧可折叠大纲，每个材料状态独立一项，按“#编号 · 空间群 · 化学式 · 压强”显示。
- **FR-002**：小三角展开/收起，长列表内部滚动；正文不再铺开长材料跳转表，窄屏保持可操作。
- **FR-003**：点击条目按稳定状态身份定位并展开目标；编号仅表示当前顺序，删除前项后不串位。
- **FR-004**：标题使用当前宿主的报告空间群、化学式及压力；零压有效，缺失明确提示，不推测科学数据。
- **FR-005**：覆盖上传、返修、两类审核和只读详情；保留来源标记和冻结稿自身数据，导航不触发保存或模型。

### 数据所有权

状态字段由当前宿主草稿/只读版本提供；state_key是定位身份，#编号只是展示；大纲折叠仅属于界面状态。
