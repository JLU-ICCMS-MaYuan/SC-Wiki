# 本文研究对象与科学问题路由

本单元只定义运行协议，不新增标准科学字段或数据库表。

## 对象与来源

研究对象用已知material/state_key或提取阶段的稳定候选身份引用，关系为本篇实际研究、仅引用他人研究、尚未确定。每次判断保留实际file_id、原文件哈希、页/块或图表定位、来源版本和理由。引言不被整体屏蔽，同一材料后文存在本篇独立研究证据时不能因引言也提过而排除。

Tc范围、界限、可读具体点和未报告保持各自原表达；这些不再作为删除本文结构的条件。科学模型负责关系判断，程序负责身份、真实已读来源、字段/类型与完整性校验。

## 路由结果

| 元数据 | 含义 |
| --- | --- |
| kind | resolved、not_reported、human_required或technical_unfinished |
| reason_code | 科学冲突source_conflict、归属不明assignment_ambiguous、本文对象关系subject_ambiguous等明确原因；不以低信心直接代替 |
| target_refs | 稳定候选、状态、模块、记录和字段引用；各阶段只提供已存在的身份，不造正式科学记录ID |
| source_refs | 实际已读来源及双方矛盾；技术读取失败另记错误，不当作无来源 |
| checked_context | 已补读的相关原文/原页与仍未解决关系；不保存内部思维链 |
| requires_human | 仅需科学方向时为true，不由异常文本或未知状态自动推断 |

## 关系与校验

目标二只输出路由事实；问题ID、选项、队列和回答生命周期由目标三持有。技术失败没有通过人工选择豁免的路径；仅缺少可选字段而无事实冲突时保留空值，不人为制造问题。

使用本文/来源版本与稳定候选身份防止不同论文、条件或图表串位，不按化学式字符串推定科学关系。不批量改写旧稿；规则版本升级只使受影响的新请求/恢复范围重新核对，不能冒充旧结果为新提取。
