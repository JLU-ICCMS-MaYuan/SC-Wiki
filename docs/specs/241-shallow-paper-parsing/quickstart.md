# 验收操作：浅度解析

1. 登录后选择并上传正文及必要补充材料；上传完成后显示浅度／深度选择。
2. 选择浅度，完成论文级解析；确认没有材料状态、结构、物性或核对步骤。编辑论文信息并保存重开。
3. 点击“提交入库”，无需管理员操作；退出登录，在搜索页用标题／DOI或已提取研究材料的元素／化学式搜索并打开详情。
4. 指定压强或 Tc 条件时，该无科学数据论文不能命中；状态视图不产生假状态。
5. 另建深度任务，验证原解析、核对、送审及批准规则；已启动任务不得通过不同模式的 finalize 请求改路径。
6. 模拟提取、保存及提交失败，确认错误可见、草稿保留和重试幂等。

迁移只在独立测试数据库演练；本轮不操作本机业务或阿里云数据库。实际通过范围、命令和未完成项见 validation.md。
