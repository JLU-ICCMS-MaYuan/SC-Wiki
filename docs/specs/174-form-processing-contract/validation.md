# 实施与验证记录

2026-10-28；[Issue #174](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/174)。实施前基线 d8e42242，mayuan 分支，其他任务改动保留。

## 已实现的边界

- 材料卡片按自己的错误、核对路径和结构候选变化决定是否重绘；无关数组的新引用不再清空所有缓存。临时输入、上传/折叠、目录、语言及只读仍是实际依赖。
- 缓存事件读取最新宿主回调；删除前卡后会话内输入与提示随原状态移动，不因位置变化串位。
- 来源标记的节点定位和核对结果更新分离；状态、理由及当前值变化不重建全表定位，文字摘要变化只更新所属标签，新增/删除和身份变化仍重定位。占位入口点击时读取当前值，真实问题颜色继续更新。
- 编辑标记只读取本次受影响字段的科学值，集合变化保留必要重定位；保留未变化结果对象，避免所有消费者同步更新。
- 谱共享上下文复用相同业务内容，最新导航保存回调通过引用读取，不冻结旧草稿。
- AGENTS.md 记录全站继承要求；本地和 CI 使用相同检查入口。全站其他表单已有入口/数据归属/触发清单，未验收状态明确保留。

## 既有失败与范围限制

扩展运行旧的标记、#96、字段隔离和压强套件发现 19 项失败。分别将本次四个共享组件从 d8e42242 加载到独立测试转换器，得到相同的 4＋15 项失败名称；没有额外新增失败。清单见 [baseline-failures.json](assets/baseline-failures.json)。这些失败没有计为通过，也未为凑通过率修改科学规则或删除旧测试。

例如旧 #96 用例仍要求非法元素输入不进入草稿，而当前 #147 支持原始中间文本暂存；旧压强/侧栏用例仍寻找旧人工理由和核对入口。新检查保留真实提示、输入不丢、局部渲染和现行保存/审核契约。存在这些历史测试失败，因此不宣称仓库全部测试通过。

当前只完成四类科学表单及其受影响共享路径的本轮验收，其他页面仅登记共同规则与现状，未全面测量。没有修改真实草稿、后端、数据库或模型调用逻辑，没有部署、推送，也未运行 GitHub CI 或配置远端分支保护。Issue/Spec 远程链接待验证，Issue 保持开放。
