# 界面与验证契约

- DOM 字段身份与现有来源标签、侧栏三页签、待处理计数保持不变。
- 更新错误内容或核对字段归属时，只更新有实际依赖的卡片；仅改变数组外壳不得清空全部缓存。
- 删除状态后按既有稳定身份重定位；不增加主动排序。
- 未改变拓扑的输入不重建全表定位；新增/删除字段、改变身份或结构时必须及时更新入口。
- 上传、返修、管理员、超级管理员均运行完整宿主检查。四宿主单字段修改与异步来源更新不可用只测子组件替代。
- 本地脚本和 CI 使用相同检查入口；回退注入必须有非零失败用例，编译或环境加载失败不能算成功检出业务回退。
- 真实浏览器只使用隔离 API 和草稿副本，输出请求数、扫描次数和按键到画面更新的分布；不写真实草稿。
