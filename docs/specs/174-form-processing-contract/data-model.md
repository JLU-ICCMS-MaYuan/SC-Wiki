# 数据与更新边界

正式草稿仍由 UploadTaskEditor 或 AdminPaperEditPage 拥有。材料 state_key、module_key、record_key 和字段路径承担既有身份；位置仅作当前定位。无新增持久实体或 API。

卡片缓存保存 state 引用、该卡错误/核对路径内容、临时输入与候选引用，以及已有展开/上传状态。全局目录、语言和 readonly 变化是所有卡片的真实依赖；无关论文值不是。

来源定位缓存只保存当前 DOM 节点与字段身份，不存第二份正式科学值。核对记录发生变化时按 key 更新绑定；身份或节点结构改变时重新定位。占位记录在打开时读取控件现值，不将旧 DOM 值当成已保存值。

事件回调读取最新宿主状态，版本冲突、保存失败与旧响应保护沿用原流程；本次不改变模型审核或数据库事实。
