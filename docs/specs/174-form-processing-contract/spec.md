## 背景与目标

#96 已实现的局部渲染约束被后续表单集成破坏，现有组件级测试没覆盖父页面导致的缓存失效。建立适用于全站表单的共同处理规则、代码协作约束和可执行回归检查，首先恢复科学数据表单的局部更新与输入响应。

### 需求结论与取舍

采用用户选择的“全站立规矩，先把科学表单修好并验证”。其他页面列出适用规则和覆盖状态，不冒称全站全部验收。保留 #96、#102 的性能与提示正确性，继承 #147、#148、#169 的保存、来源和人工决定语义。当前不需要材料主动排序，不新增此功能；删除导致的位置前移仍不能串字段。

## 用户场景与验收

### US1：科学数据表单局部更新（P1）

用户输入论文标题或编辑单张材料卡片时，只有该字段、必要父级及有实际依赖的部分更新。优先级理由：当前输入卡顿已复现，违背既有约束。

独立验收：在完整上传、返修、管理员和超级管理员页面的五卡片场景，改标题不重绘材料卡片，改第一张卡片不重绘其余四张。不能只直接挂载子组件证明通过。

### US2：更新正确、保存可靠（P1）

用户修改后能看到真实值、错误提示和准确待处理数，保存重开一致，失败或冲突保留输入。优先级理由：不能以错误界面或丢值换速度。

独立验收：中文组合输入、中间数值、清空、侧栏应用、删除前一张卡片、异步来源返回、保存失败及版本冲突均保持当前值和对象身份；既有有效审核结论按真实变化处理。

### US3：后续功能不能绕过既有约束（P1）

开发者修改任何表单或共享逻辑前能找到适用规则和测试入口。优先级理由：避免本次回退重复发生。

独立验收：本地与 CI 运行同一回归入口；故意恢复“新问题数组清空全部缓存”的缺陷时测试失败。全站入口清单标明规则、数据所有者、请求触发及已验证／未验证范围。

### 边界与异常

- 空表单、目录加载、只读、字段增删、状态删除、错误定位和折叠均保持现有语义。
- 修改值、校验错误或来源结果真的改变时必须更新对应界面；不能永远复用旧缓存。
- 请求失败或旧响应迟到不得覆盖较新输入，也不能把失败当作科学审核不通过。
- 搜索、用户名可用性等必要输入请求保留明确触发条件；不把科学表单的零模型规则套到所有页面。

## 功能需求

- **FR-001**：全站表单遵守局部影响原则；无关业务区域不得因单字段编辑重复渲染、计算、校验或请求。必要父级协调和真实依赖更新允许。
- **FR-002**：相同内容不能因容器或回调引用变化引发全表缓存失效、DOM 扫描或核对刷新。明确依赖变化才使相关部分失效。
- **FR-003**：当前字段输入及时显示，保留输入法、光标和原始中间值；不得用只延迟显示或丢弃编辑的方式掩盖卡顿。
- **FR-004**：科学表单沿用现有输入、保存与审核分离；无变化的数据保存不写入，输入与自动保存不调用模型或刷新整篇核对。明确提交及审核动作遵守既有契约。
- **FR-005**：通过稳定对象身份绑定字段值、来源、结果和保存目标；删除导致位置前移时不串位。不新增材料状态主动排序。
- **FR-006**：保留待处理计数、来源入口、真实校验、并发保护、只读限制和失败恢复；真实变化及时显示，旧响应不能覆盖新编辑。
- **FR-007**：AGENTS.md 明确既有表单约束继承要求；新增字段或功能不自动授权牺牲性能或取消旧规则。受影响的原测试和完整宿主回归均须纳入验证。
- **FR-008**：提供本地及 CI 自动检查，覆盖实际生产组件组合，并通过注入已知回退证明检查有效；不靠静态代码字符串或全面模拟关键边界代替行为测试。
- **FR-009**：建立全站表单入口清单，记录规则、数据归属、输入／保存／提交触发及覆盖状态。先完成科学表单验收；其他表单未检查时明确标记。

### 关键实体

- 表单当前编辑值与已保存版本：沿用既有数据所有权；临时输入不能成为另一个互相覆盖的正式值来源。
- 稳定字段身份与实际依赖：决定局部更新及来源归属，界面行号只是当前位置。
- 验收清单：记录证据覆盖，不替代 GitHub Issue 的协作状态，也不创建独立任务状态库。

## 成功标准

- **SC-001**：四类科学表单宿主五卡片测试满足标题编辑无关卡片渲染为零、首卡编辑其他四卡渲染为零。（FR-001、002）
- **SC-002**：真实值、临时错误、待处理计数及来源入口随相关变化更新；删除、侧栏应用、只读、失败和冲突测试不丢值或串位。（FR-003、005、006）
- **SC-003**：连续输入期间无模型调用和全量核对刷新，无变化的数据保存写请求为零；实际变化按既有契约保存重载。（FR-004）
- **SC-004**：固定的大规模隔离草稿记录修复前后输入延迟、无关渲染、整页扫描和请求数量，证明不再由逐键无差别处理整表引起开销。记录环境与样本，不以机器绝对毫秒数作为唯一门槛。（FR-001–004）
- **SC-005**：本地与 CI 回归入口通过；已知数组引用回退注入后必失败，证明门禁能拦住本次故障。（FR-007、008）
- **SC-006**：当前全站表单入口清单可追溯到代码，科学表单附完整验证证据，其他入口如实标注覆盖；新增入口需同步清单与适用检查。（FR-009）
