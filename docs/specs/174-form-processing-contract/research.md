# 设计依据

- #96 的缓存没有被删除；df4e61de 的新问题数组和 5bff8b0a 的 reviewFields 投影每次返回新引用，而全局环境比较按引用清空全部卡片。完整宿主测试失败，单独挂载子组件不能检出。
- 不能仅冻结 reviewFields：真实计数变化必须显示，且其他卡片不应陪同重绘。因此在卡片边界比较该卡自己的错误与问题内容，公共目录／语言变化仍允许整体更新。
- 缓存复用增加后旧事件闭包可能暴露过期草稿风险；事件须读取最新宿主回调和结构候选，保留 readonly 与当前身份判断。
- 来源标记的定位依据是字段、状态、模块、记录和结构身份；状态/理由本身不改变控件位置。分离拓扑和结果后仍须处理动态节点增删、身份属性变化以及无后端记录的当前值入口。
- 谱 Provider 的新 value 会绕过卡片缓存通知消费者。只稳定业务内容相同的上下文，真实列表变化和最新导航保存回调不可遗漏。
- 不采用仅增加防抖：它不能防止周期性整表计算，还可能改变光标、输入法和保存时机；不采用删除校验或问题入口。
- 回归以生产宿主/共享组件为主体，渲染探针包装真实组件；仅隔离网络和必要重资源。独立注入旧缺陷证明测试能失败。
