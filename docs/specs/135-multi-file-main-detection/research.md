# 技术研究：文件角色识别与来源所有权

## 决策 1：不以上传顺序确定正文

#26 首文件默认 main 导致 La-Sc-H 的 SI 先上传时获得错误主文身份。使用文件名和提取内容联合判断；单独的 `SI` 文件名或 DOI 匹配都不足以决定。唯一文章式首页且其他文本具备 SI 信号才自动生效，否则暂停。

## 决策 2：高置信结论覆盖原手动角色

这是用户已选的交互：即使曾手动指定 main，只要正负信号足以唯一识别正文，系统直接纠正。原声明、有效角色和信号分别保存，UI 展示纠正记录；歧义时用户确认后不再循环自动推翻。

## 决策 3：统一来源，不为旧数据添加永久双轨分支

有效角色是当前任务的唯一来源。已有生成器排除 `attachment` 的行为不得各自复制；共用来源读取器按角色和文件种类过滤。旧 ready 草稿用 #120 的有界重算，缺凭据或人工改写时留待审，不扩大为每次读取都自动猜角色。

## 决策 4：在昂贵 LLM 前暂停

首页、章节和文件名足以形成可审计的确定性判断，角色检测不新增模型调用。文本层不足则显示歧义，避免用同一错误文件重复生成；后台状态保留提取产物并等待用户确认。
