## 已审定范围

建立版本化、机器可读的字段契约，固定键、类型、含义、单位和软件归属。论文通用21项、材料状态通用11项；理论计算型常规超导体保留超导、电子DOS、声子DOS和热力学稳定性。电子带隙退出新标准项目，历史记录保留。人工可主动扩展；模型不能自造键或伪造人工来源。

计算条件保留公共方法字段，软件参数分别为qe、epw、sscha。声子方法唯一使用calculation_conditions.phonon_method，删除对应阶段扩展写法。退出四个压力辅助键及method_scope，不混入VASP结构优化参数；依据每个字段原文核对适用性，不造替代字段。

本机127.0.0.1:3307/scwiki迁移包含当前工作稿和正式记录的格式转换；冻结快照、原PDF、历史带隙记录保持。先隔离演练备份恢复及迁移；冲突停止，不任选值。结构候选容器退出由后续结构Issue负责，不能先删断链。
