# 接口与读写契约

工作稿、内容快照、交接记录、公开批准引用分开。按用户新答复保留审核队列，首位开始处理的合法审核员在事务锁内接手；上传者不能自审，不增加指定审核员控件。其他审核员只能读正式收到的内容，不能看到当前经手人未交出的私稿。
正式交接在数据库事务中冻结规范内容、写幂等交接记录、结束旧工作稿并转移归属；写租约绑定工作稿周期，所有数值／证据／说明／候选／模型写回都检查，不能仅禁按钮。内容判等包括值、当前采用证据、理由和有效核对结果，排除操作人／时间／交接意见等流程元数据；同内容复用已有快照而每次交接保留记录。
当前字段状态和人工说明覆盖更新；停止新增逐字段事件、旧结果版本和中间回答历史。旧真实历史只读保留，不删除、不打开页面自动迁移。快照保持不可变来源引用和文件租约，删除工作稿附件不能损坏旧版本。
公开修订只改独立工作稿，正式已批准科学图在新版批准前不变。其他合法审核者正式交还后原上传者才能修订，不能自行撤回。批准提交科学图和公开引用在同一事务完成。
保留已确认demo的标题入口、新标签交接列表和新标签只读整稿；侧栏仅字段设置／来源核对。快照字段读取冻结资料，不能请求当前工作稿替代。

新接口明确schema_version／工作稿id／write_epoch／内容修订号。内容修订允许同经手人后保存覆盖；写租约只用于正式交接后的拒写和角色／周期隔离。列表仅分页元信息；字段及快照详情按需读取；不因查看或普通保存调用模型。
