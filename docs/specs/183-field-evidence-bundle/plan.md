# 实施方案：字段与采用依据

依据[规格](spec.md)、[调查](research.md)、[数据模型](data-model.md)及[接口合同](contracts/workflow.md)。

## 数据所有权与实现

以现有稿件JSON为科学值事实来源，字段资料只存稳定定位、当前结果、当前人工说明及证据使用关系，不建立第二份可修改科学值。新增内容寻址来源目录与逐字段使用关系，直接／共同／辅助上下文分开；完整validation_record只在请求当前字段时由当前稿件重建，不逐字段永久写入。
现有整条legacy_evidences作为旧上下文保留，不自动升级为直接证据。已采用共同依据通过引用共享，保留方法／点／表行范围；明确µ*—Tc配对矛盾不能因数字可定位而通过。快照冻结引用不可变来源目录，并保留所需文件引用。
