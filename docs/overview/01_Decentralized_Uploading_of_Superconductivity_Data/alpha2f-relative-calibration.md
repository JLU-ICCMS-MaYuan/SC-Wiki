# α²F 相对谱计算与论文 λ 幅值归一化

正式α²F使用当前保存曲线的源像素位置和幅值零基线，先独立计算ωlog，再以当前材料状态中同条件论文λ确定幅值倍率。幅值说明文本不是计算或保存条件；两类正式谱编辑器均无该输入项。

## 数值与参考的用途

像素幅值p是曲线相对当前幅值零基线的有向距离，不是图片全局坐标。历史λ轴的倍率不当作α²F幅值，但已保存的幅值零基线用于当前相对谱。相对像素的统一倍率在ωlog对数平均中抵消。

像素加权积分Ip=2∫p/ν dν；论文λ给出C=λ论文/Ip，归一化α²F=Cp。λ是归一化输入，结果标注“依据论文 λ 归一化”，不再以λ偏差作为独立准确度校验。ωlog只按当前频率和谱形计算，论文ωlog不用于反调频率、基线或曲线。

03显示ωlog计算值、同条件论文值、绝对偏差和相对偏差；另列论文λ、像素积分和C。相对偏差为绝对差除以参考绝对值，参考为0时显示相对偏差不适用。任何偏差均不控制编辑、保存或重算。该标量对比只作谱形参考，不等于整谱科学采纳。

## 独立可用性

- 缺少论文λ或参考存在歧义时，仍显示可计算ωlog；归一化独立说明原因。
- 缺少论文ωlog时，仍显示计算值及可用的C；不同方法/数值参考不会按结果接近程度挑选。
- 像素积分为0时，Ip显示0，ωlog和C分别标明无定义；参考输入保留。
- 频率、曲线或数值导致无定义/溢出时逐项返回状态，有限结果不会被非有限字段污染JSON。编辑保存不以这些结果或幅值说明作为通行条件。
- 高频末端核对保持取消。人工零频核对和首点必须为0的限制也已取消，按实际采样范围计算；连通、数学有效性与权限/材料/版本保护继续有效。

## 版本与展示

POST recalculate创建不可变新运行。源curves/manual_documents保留，归一化候选另存candidates.alpha2f_lambda_normalized，保存论文来源、对应曲线与基础run。再次计算始终读取当前源像素，不对旧归一化值再乘C。编辑保存按现有逻辑清除派生结果，旧run可追溯。

详情可以切换相对像素和归一化幅值刻度，图中像素几何保持；编辑器仍编辑源标定。内部旧amplitudeEvidence只沿用历史文本，不展示或要求填写，省略/空值不阻断有效保存。公开未采纳或限定频段结果不暴露完整归一化候选。

声子DOS只共享移除说明输入/必填规则，其积分和3N公式不变。Demo及插点功能保留；参数相等时允许核心边缘权重恰好等于截断值，工作区用户调参值不纳入功能提交。
