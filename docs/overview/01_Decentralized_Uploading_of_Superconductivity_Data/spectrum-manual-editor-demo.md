# 谱线人工编辑与联动调参

## 功能说明与边界

α²F 与声子 DOS 的人工编辑现已接入正式谱详情代码，通过有权限和版本校验的接口保存到现有谱运行表，保留旧版本；独立Demo继续保留供交互试用。两条路径分别保存，正式页面不读取Demo本机草稿。

正式谱集合、提取运行及审核流程见 [声子谱与提取质量](data-structure-and-form-mapping.md#声子谱与提取质量137)。本页注明正式与Demo的存储边界；整谱科学采纳不因人工保存自动通过。

## 正式保存与权限

当前、已归属且未过期的谱，在上传/返修草稿及有审核编辑权的正式论文详情中提供编辑按钮；历史和只读记录不可保存。编辑器读取鉴权原图与当前run的像素/标定；不同PhDOS分波按自身标定编辑，其他分波作为参照，单次保存一条曲线。

`GET /api/rag/spectra/{id}/manual` 取得版本化文档；`POST` 校验目标内容版本、集合版本和基础run，在事务中创建新SpectrumRun并更新当前运行。旧run、来源图、父运行、作者和操作保留，旧采纳撤回。发生409冲突时留在编辑器，不覆盖较新数据库结果；其他保存失败同样保留内容。

服务端按像素重新换算数值并生成零频报告，不信任客户端质量指标。人工修改后的旧积分/比较/候选失效；频率重复或回退的描线可以作为待核对版本保存，但不能直接采纳为单值谱。公开读取继续按采纳/频段过滤，内部编辑文档不公开；既有CSV增加像素、断边、人工状态和父运行字段。

无新增数据库表或迁移。当前已通过正式路由与隔离SQLite持久化、浏览器保存回读及前后端测试；MySQL隔离库创建失败，尚未完成该环境复验。未据此声明生产部署完成，详见[正式验收](../../specs/161-spectrum-manual-editor-demo/production-validation.md)。

## 当前编辑能力

- 从“02 · 原图与提取结果”的编辑按钮进入全屏工作区，默认允许 X/Y 两方向拖动，也可锁定为只改幅值。
- 编辑器和详情图窗均支持右键平移；工具栏/图例/说明在绘图区外，适应窗口完整包含子图和轴文字。按钮约5%步幅，滚轮按滚动量连续缩放，单帧合并更新，慢滚便于微调。
- 加点、删点、框选、坐标输入、缩放和平移共用原图像素坐标；新点自动选中，右侧显示频率、幅值、像素 X/Y 和距当前零频线的距离。
- 描线顺序与数值表的频率排序分开，补点连接附近线段或端点；删除保留断口，旧局部回折可以显式修正并撤销。
- 当前标定轴、已有识别刻度与人工零频标记分别展示。α²F 图的累计 λ 刻度只作参考，不用作 α²F 幅值；PhDOS 缺少数字幅值刻度时使用相对像素并标明边界。
- 撤销、重做、恢复原始样本和本机保存相互区分；旧草稿读取不会自动覆盖原存储。
- 编辑画布和详情图卡内容的左侧均有竖向原图不透明度滑条，范围0–100%、步长1%，只改变原图层。两处共用页面会话值，保存返回保持；隐藏原图时禁用，重新显示恢复原值。刷新回到100%，不写谱数据或撤销记录。

## 手动调整联动比例

正式调参入口是 [dragInfluence.ts](../../../frontend/src/components/spectrumEditor/dragInfluence.ts) 顶部的 `DRAG_INFLUENCE`；独立Demo继续使用 [Demo原文件](../../specs/161-spectrum-manual-editor-demo/demo/src/dragInfluence.ts)。每条运行路径的界面和拖动共用各自配置。正式初值复制用户已认可的2/.3/1/.1，Demo原文件的未提交修改未被覆盖或纳入正式接入提交。

| 参数 | 含义 | 怎么调整 |
| --- | --- | --- |
| `coreNeighbors` | 按描线顺序，每侧明显跟随的邻点数 | 正整数；减小后主要影响区更局部 |
| `edgeWeight` | 主要影响区最外侧邻点的跟随比例 | 在 `(0, 1]` 内；增大使附近点跟随更强 |
| `decayLength` | 核心区外的指数衰减长度，单位为点数 | 必须大于 0；减小则衰减更快，增大则影响更远 |
| `minWeight` | 极小影响的截断比例 | 大于 0 且小于 `edgeWeight`；增大后更远的点更早停止移动 |

以距离选中点的描线序号差 `d` 计：核心区权重为 `1 − (1 − edgeWeight) × d / coreNeighbors`，外侧为 `edgeWeight × exp(−(d − coreNeighbors) / decayLength)`。选中点始终 100% 跟随；低于 `minWeight` 的权重不再参与。断口和其他分波不参与当前曲线的联动。

2026-10-26 核对的**用户本地调参记录**为 `coreNeighbors=2`、`edgeWeight=0.3`、`decayLength=1`、`minWeight=0.1`。它不是仓库通用默认值，实际运行以当前文件为准。这组值使第 1、2、3 个邻点分别约跟随 65%、30%、11.04%，第 4 个开始停止；两侧都有足够连续点时最多移动 7 个点（包含选中点）。

调整前先保存页面里未保存的选点，再修改代码、保存并刷新 Demo。参数只影响以后的拖动，不自动改动已经保存的坐标。错误参数或过大的影响范围会报错；权重表仅在加载配置时生成，拖动中复用，不逐帧重新计算指数。

## 保存后的零频位置检查

点击“保存调整”成功后返回详情，程序会按本次保存的数据检查零频位置。正式路径使用服务端新运行生成的检查结果，刷新从数据库读取；Demo从本机草稿重新检查。结果与相应版本绑定，不沿用其他版本的通过标记。

| 状态 | 含义与下一步 |
| --- | --- |
| 零频位置核对完成 | 已有显式原图零频位置记录，且当前曲线的已确认点仍在该零频线上 |
| 尚未确认原图零频位置 | 仅有识别或蓝色标定线；对照原图后可点击“确认蓝色零频线与原图一致”，也可重新在图上标记 |
| 已有零频点，等待人工确认 | 数据中已有位于零频线的点；点击“继续核对”选中它，再确认该点，无需删除重画 |
| 缺少位于零频线上的有效点 | 显示最近点的频率和像素距离；需对照原图调整或补选，程序不自动补造零点 |

PhDOS 分别检查所有已有分波，全部完成才显示整体完成。图上原有标线与零频补点操作可直接作为依据，不要求重复确认。移动、删除已确认零点或修改标定后，下一次保存会重新判定；只改其他点不会无故使零频确认失效。

“继续核对”打开对应曲线并选中候选点或最近点。确认现有蓝线和现有点只记录用户明确操作，不改变坐标；这些操作可撤销，保存后正式路径生成数据库新版本、Demo写本机草稿。未完成不妨碍保存有效草稿；保存失败则留在编辑器，不报告新的完成结果。

完成只表示零频位置与选点的一致性，不代表整谱已采纳、幅值刻度正确、全频域完整或积分可计算。位置比较只容忍 `1e-4` 源像素的舍入误差，不会把普通近零点直接改成零点。



## 零频核对的具体步骤

1. 点击“编辑”，选择当前要处理的曲线，把原图不透明度调到100%，点击“适应窗口”看清原图。
2. 找原图频率轴的0刻度。本Demo这张图的频率沿竖轴，0频率对应图框底部的横线。
3. 蓝色零频虚线与原图0位置相符时，在右侧“坐标与零频核对”中点击“确认蓝色零频线与原图一致”。若不相符，向下滚动右侧面板到“零频边界”，点击“1 · 标记原图 0 频率位置”，再在0刻度对应的图框内位置点击。
4. 在这条零频线上确认当前曲线的数据点。已有点就选中它，点击“确认选中点为零频点”；缺点则到“零频边界”点击“2 · 补选曲线零频点”，在原图曲线与零频线的交点处点击。右侧应显示频率0、距零线0 px。零频率不要求幅值也为0；原图看不清时保留待核对。
5. 点击“保存调整”，返回详情检查结果。PhDOS的零频线只需确认一次，但La、Sc、H的零频点要分别处理，全部完成后才显示整体完成。
