# 超导数据去中心化上传

## 功能边界

该功能负责把研究者上传的 PDF/TXT/MD 论文与 CIF/POSCAR 结构附件转化为待审核的结构化论文记录：文件接收、正文提取、AI 分段阅读、AI 汇总草稿、用户校对和提交落库。它不负责审核决策（属 02）、不负责检索与问答（属 03/05）。

## 功能组成

```text
超导数据去中心化上传
├── PDF 解析管线（创建任务 → 提取正文 → AI 分段阅读 → AI 汇总草稿 → 用户校对 → 提交落库）
├── PDF 摄入（文件校验与摄入约束）
├── 上传数据结构与表单映射（材料状态 → 物性模块 → 独立记录）
└── 结构附件上传、审核与默认结构
```

## 关联关系

用户从前端 `/upload` 进入；当前本机实例的原文件使用私有 S3 对象键，解析运行态存 Redis，已核对草稿与结果持久保存到 MySQL，解析由 RQ worker 异步执行。Worker 按需把对象下载到本节点临时目录；提交后论文进入待审核队列，审核通过并发布向量索引后可被 03 检索与 05 问答使用。

上传与两个管理员工作台共享科学数据来源核对。有有效出处的语义疑点随提交进入待审，审核员在 02 的审核流程中逐条裁决；没有有效出处且未采用可用建议时保留草稿；明确采用通用知识推测可进入待审，管理员批准前必须逐项说明依据。

解析草稿进入 ready 后复用已有核对结果，仅对未完成项自动排队来源核对；打开校对页接续同一任务。上传页不再显示独立“AI 审核”按钮。失败保留草稿并显示重新核对入口；字段说明文字仍可定位和编辑建议，完成仅保存接受草稿，用户提交时应用，刷新可恢复。管理员独立审核入口仍保留。

上传页无论解析详情展开或收起，工作区距离左侧导航和视口右缘都各保留 8px；展开后的顶部常驻操作栏贴合视口顶边，以不透明背景覆盖滚动中的表单，并持续显示文件名、阶段和“收起解析”。收起后待上传文件仍保留。

共享核对侧栏在当前组保存成功后自动关闭，并保持原字段位置；失败保留输入，已接受项仍可重新打开查看和撤销。

共享材料状态表单支持压强连续输入、整组清空与原始条件编辑；显式空值不会被上传旧条件回填，数值零仍保留。

材料名位于化学式之前，两者至少填写一项；没有化学式不创建虚假材料实体。名称、条件和结构家族通过共用保存规则保留，详情与搜索显示名称及已有化学式。

来源核对区分未核对与无出处；连续输入合并保存、失败暂停重试。管理员可逐条说明推理或专业判断理由完成确认，永久记录独立人工来源；上传者不具备管理员裁决权限。

被拒绝论文的原上传者可从“我的论文”或详情进入返修，草稿长期保存在独立 MySQL 表；明确重新提交才使同一论文升版并回到待审核。详见 [已拒绝论文返修](pdf-ingestion.md#已拒绝论文返修)。

上传解析区分直接记载、论文推断和通用知识推测；通过类型与来源校验的推断、推测会直接补入主表单的空值，并保留简短 AI 理由与来源类别，不覆盖已有非空原文值。所有数据字段名（含空值、书目和只读结构参数）都可打开侧栏；侧栏不重复主表单值，已解决记录仍可查看，顶部不再堆放已接受列表。见 [#109 验收](../../specs/109-field-evidence-and-ai-suggestions/quickstart.md)。

## 统一物性编辑

[数据结构与表单映射](data-structure-and-form-mapping.md#四类性质的统一编辑与详情入口)记录四类性质的紧凑行、逐条扩宽补充字段、材料状态三元标题、分判据热力学稳定性与独立谱详情入口。上传、管理员和只读页面复用同一组件；谱后端是否已在目标环境就绪需沿 #137 单独验收。人工修改通过“保存并完成”保存当前值、说明和附件，禁用原因及正式核对边界见[论文与记录审核](../02_Decentralized_Maintenance_and_Verification/literature-and-record-review.md#人工修改保存与来源核对完成)。

超导、电子、动力学和热力学模块默认折叠，可独立展开查看或编辑；折叠保留当前输入，只读也可展开。详见[统一编辑规则](data-structure-and-form-mapping.md#四类性质的统一编辑与详情入口)。

物性模块已取消上下移动控件，保留既有顺序、折叠和空模块删除操作。

声子 DOS、α²F/累计 λ 的独立存储、原图回绘、分项质量和逐谱审核见[声子谱与提取质量](data-structure-and-form-mapping.md#声子谱与提取质量137)。本机谱表已迁移；其他环境须核验对应迁移与模型能力。
