# 超导数据去中心化上传

## 功能边界

该功能负责把研究者上传的 PDF/TXT/MD 论文与 CIF/POSCAR 结构附件转化为待审核的结构化论文记录：文件接收、正文提取、AI 分段阅读、AI 汇总草稿、用户校对和提交落库。它不负责审核决策（属 02）、不负责检索与问答（属 03/05）。

## 功能组成

```text
超导数据去中心化上传
├── PDF 解析管线（创建任务 → 提取正文 → AI 分段阅读 → AI 汇总草稿 → 用户校对 → 提交落库）
├── PDF 摄入（文件校验与摄入约束）
├── 上传数据结构与表单映射（材料状态 → 物性模块 → 独立记录）
└── 结构附件上传、审核与默认结构
```

## 关联关系

用户从前端 `/upload` 进入，原文件存文件目录、解析运行态存 Redis，已核对草稿与结果持久保存到 MySQL，解析由 RQ worker 异步执行；提交后论文进入待审核队列，审核通过并发布向量索引后可被 03 检索与 05 问答使用。

上传与两个管理员工作台共享科学数据来源核对。有有效出处的语义疑点随提交进入待审，审核员在 02 的审核流程中逐条裁决；没有有效出处时保留草稿。

上传校对提供独立 AI 审核按钮、字段说明文字定位与可编辑建议；完成仅保存接受草稿，用户提交时应用，刷新可恢复。

共享核对侧栏在当前组保存成功后自动关闭，并保持原字段位置；失败保留输入，已接受项仍可重新打开查看和撤销。

共享材料状态表单支持压强连续输入、整组清空与原始条件编辑；显式空值不会被上传旧条件回填，数值零仍保留。

材料名位于化学式之前，两者至少填写一项；没有化学式不创建虚假材料实体。名称、条件和结构家族通过共用保存规则保留，详情与搜索显示名称及已有化学式。

来源核对区分未核对与无出处；连续输入合并保存、失败暂停重试。管理员可逐条说明推理或专业判断理由完成确认，永久记录独立人工来源；上传者不具备管理员裁决权限。
