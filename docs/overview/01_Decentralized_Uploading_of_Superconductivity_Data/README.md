# 超导数据去中心化上传

## 功能边界

该功能负责把研究者上传的 PDF/TXT/MD 论文与 CIF/POSCAR 结构附件转化为待审核的结构化论文记录：文件接收、正文提取、主文识别、AI 分段阅读、AI 汇总草稿、用户校对和提交落库。它不负责审核决策（属 02）、不负责检索与问答（属 03/05）。

- [α²F 相对谱计算与论文 λ 幅值归一化](alpha2f-relative-calibration.md)

## 功能组成

```text
超导数据去中心化上传
├── PDF 解析管线（创建任务 → 提取正文 → AI 分段阅读 → AI 汇总草稿 → 用户校对 → 提交落库）
├── PDF 摄入（文件校验与摄入约束）
├── 上传数据结构与表单映射（材料状态 → 物性模块 → 独立记录）
└── 结构附件上传、审核与默认结构
```

## 关联关系

用户从前端 `/upload` 进入；当前本机实例的原文件使用私有 S3 对象键，解析运行态存 Redis，已核对草稿与结果持久保存到 MySQL，解析由 RQ worker 异步执行。Worker 按需把对象下载到本节点临时目录；提交后论文进入待审核队列，审核通过并发布向量索引后可被 03 检索与 05 问答使用。

上传与两个管理员工作台共享科学数据来源核对。有有效出处的语义疑点随提交进入待审，审核员在 02 的审核流程中逐条裁决；没有有效出处且未采用可用建议时保留草稿；明确采用通用知识推测可进入待审，管理员批准前必须逐项说明依据。

解析草稿进入 ready 后复用已有核对结果，仅对未完成项自动排队来源核对；打开校对页接续同一任务。上传页不再显示独立“AI 审核”按钮。失败保留草稿并显示重新核对入口；字段说明文字仍可定位和编辑建议，完成仅保存接受草稿，用户提交时应用，刷新可恢复。管理员独立审核入口仍保留。

上传任务条框的文件名、状态与空白区域会在新标签页打开 `/upload/tasks/:taskId`，原上传列表及待上传文件、多选状态保留；复选框、取消和清理继续独立操作。列表不再提供“查看解析／收起解析”或内联详情。详情按地址恢复任务，继续使用原有校对、保存、核对和提交功能；顶部常驻栏显示文件名、阶段与“返回上传记录”，关闭详情标签页或切回原页也可继续操作列表。重新获得焦点时列表刷新任务索引。列表和详情继续沿用全站窄边距。见 [#140 实施与验收](../../specs/140-upload-task-detail-page/validation.md)。

共享核对侧栏在当前组保存成功后自动关闭，并保持原字段位置；失败保留输入，已接受项仍可重新打开查看和撤销。

共享材料状态表单支持压强连续输入、整组清空与原始条件编辑；显式空值不会被上传旧条件回填，数值零仍保留。

材料基本区采用三行布局，结构家族固定高度并仅内部横向滚动；理论状态可填独立于声子近似的结构优化核处理，每卡只保存一份规范几何，其他晶胞／格式为派生表示。参见[数据结构与表单映射](data-structure-and-form-mapping.md)。材料名位于化学式之前，两者至少填写一项；没有化学式不创建虚假材料实体。名称、条件和结构家族通过共用保存规则保留，详情与搜索显示名称及已有化学式。

来源核对区分未核对与无出处；连续输入合并保存、失败暂停重试。管理员可逐条说明推理或专业判断理由完成确认，永久记录独立人工来源；上传者不具备管理员裁决权限。

被拒绝论文的原上传者可从“我的论文”或详情进入返修，草稿长期保存在独立 MySQL 表；明确重新提交才使同一论文升版并回到待审核。详见 [已拒绝论文返修](pdf-ingestion.md#已拒绝论文返修)。

上传解析区分直接记载、论文推断和通用知识推测；通过类型与来源校验的推断、推测会直接补入主表单的空值，并保留简短 AI 理由与来源类别，不覆盖已有非空原文值。所有数据字段名（含空值、书目和只读结构参数）都可打开侧栏；侧栏不重复主表单值，已解决记录仍可查看，顶部不再堆放已接受列表。见 [#109 验收](../../specs/109-field-evidence-and-ai-suggestions/quickstart.md)。

## 统一物性编辑

共用参数的字段绑定、旧关联失效和重新核对恢复规则见[来源关联与重新核对](source-association-review.md)，继续沿用现有前端页面。

计算条件区分电子结构理论（DFT、Hartree–Fock等）、交换关联泛函、软件和声子方法。DFPT／有限位移按声子方法保存，错误归入电子结构理论时，提取与来源核对均会提示类别错误；历史值保留供修正，不自动替换成DFT。见[方法字段规则](data-structure-and-form-mapping.md#计算方法的字段语义)。

泛函按对应软件的原文记录：VASP 的 PBE 不能推算成 QE 的 PBE，QE 未报告时留空免审。计算条件在软件、阶段、材料／物相、数值和完整来源均满足已确认规则时，可保留推断身份并自动核对通过，整篇论文仍需最终批准。见[QE 泛函按原文记录](data-structure-and-form-mapping.md#qe-泛函按原文记录)及[来源关联与重新核对](source-association-review.md)。

[数据结构与表单映射](data-structure-and-form-mapping.md#四类性质的统一编辑与详情入口)记录四类性质的紧凑行、逐条扩宽补充字段、材料状态三元标题、分判据热力学稳定性与独立谱详情入口。上传、管理员和只读页面复用同一组件；谱后端是否已在目标环境就绪需沿 #137 单独验收。人工修改通过“保存并完成”保存当前值、说明和附件，禁用原因及正式核对边界见[论文与记录审核](../02_Decentralized_Maintenance_and_Verification/literature-and-record-review.md#人工修改保存与来源核对完成)。

超导、电子、动力学和热力学模块默认折叠，可独立展开查看或编辑；折叠保留当前输入，只读也可展开。详见[统一编辑规则](data-structure-and-form-mapping.md#四类性质的统一编辑与详情入口)。

上传任务校对页顶部提供“全部折叠”“全部展开”，同时控制所有材料状态及其已有四类性质模块；入口常驻于“返回上传记录”左侧。操作保留输入和单项切换能力，空材料状态或只读时禁用。详见[批量折叠规则](upload-review-and-default-selection.md#上传校对批量折叠)。

物性模块已取消上下移动控件，保留既有顺序、折叠和空模块删除操作。

声子 DOS、α²F/累计 λ 的独立存储、原图回绘、分项质量和逐谱审核见[声子谱与提取质量](data-structure-and-form-mapping.md#声子谱与提取质量137)。本机谱表已迁移；其他环境须核验对应迁移与模型能力。

#154/#155 的新标签谱详情、单图三模式、提取历史和真实零频采样见 [正式详情、历史和零频采样](data-structure-and-form-mapping.md#正式详情历史和零频采样154--155)。历史业务谱不会自动重提取；缺失幅值与未确认标定仍需核对。

DOS 的相对面积、元素占比、按 3N 共同归一化与独立绝对积分见[谱详情计算规则](data-structure-and-form-mapping.md#正式详情历史和零频采样154--155)。缺少原胞 N 不再阻止有效像素面积计算，条件不足的派生项单独说明原因。

正式谱编辑器的[持续工具与按钮状态](spectrum-manual-editor-demo.md#持续工具与按钮状态)包括并列的联动/单点拖动、先选增加点工具再选起点、同钮退出与主题浅深色状态。
