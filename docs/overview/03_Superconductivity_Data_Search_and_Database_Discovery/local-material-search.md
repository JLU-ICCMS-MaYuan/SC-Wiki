# 本地材料检索

## 功能说明

从元素组合或化学式检索论文、材料状态与完整独立结构；访客及普通用户只查询已批准数据，已批准管理员和超级管理员可以按审核状态查询当前版本。检索结果默认按原始论文展示，可在同一页面右上方切换“按论文／按材料状态”。

## 进入与恢复

网站根路径 `/` 和 SC-Wiki 品牌入口默认进入 `/search` 的检索页面。科学字段右侧栏功能设计、原话及历史已迁移至 [#221](../../specs/221-scientific-field-sidebar/spec.md)，本处不再独立维护。


周期表“进入页面”和化学式“搜索”以新标签页打开结果，保留原标签页的输入和选择。结果地址保存元素／化学式、检索模式、筛选、view及两种视图和独立结构各自的页码。切换展示在当前标签页发生，保留查询条件；浏览器前后退、刷新和详情返回由地址恢复，重新读取最新数据。

元素组合、精确及包含三种模式保留原含义；化学式入口仍按提取到的元素集合匹配，不保证化学计量比严格相等。模式说明及周期表布局沿用[#150](../../specs/150-search-mode-description/spec.md)。

## 查询与展示单位

`POST /api/papers/search/results` 由 Go 直接查询主库。访客、普通用户及未获批准的管理角色只能查询 review_status=approved 且 approved_revision=content_revision 的论文当前版本，修改地址中的审核状态也不能扩大范围。已批准管理员和超级管理员可选择全部、待审核、已批准、已拒绝，缺省全部；仍绑定当前 content_revision，旧版本和排除结构不返回。权限来自服务端实际认证身份。

- 论文视图：每篇命中论文一项，显示标题、年份、期刊、DOI和匹配状态数。来源集合包含匹配状态及完整结构的来源论文，同一论文不重复。
- 状态视图：每个真实材料状态一项，显示化学式／材料名、压力、报告空间群号／符号和优化方式；同一压力的SSCHA与静态优化分开。同状态的多条Tc或其他物性不增加状态数量。
- 状态身份沿用论文revision下的state_key／id，不按显示字段跨论文合并。没有Tc也能检索；不要求有完整结构才显示状态。
- 匹配与去重在分页前完成，返回papers_total、states_total及当前视图total；默认每页20条。物性只通过相关存在条件限制实际收紧的Tc／图表筛选，不成为默认结果主体。
- 旧搜索Tc明细表和其局部记录详情已退役；正式论文详情与社区Tc图表保留。

## 筛选所有权

压力属于同一个命中状态或结构，年份属于来源论文，关键词匹配材料及论文字段；不能跨状态拼接组成与压力。材料家族选项从统一数据库目录读取双语规范名，例如“氢基超导体”，包含人工创建的正式家族；新查询提交 material_family_id，按当前论文 revision 的 paper_material_families 关联筛选。旧 superconductor_type 地址仍按目录编码／精确别名兼容，未知项不放宽为全部；不把该选项误用为 state_kind。目录失败可重试，不退回固定选项。

默认数值范围不额外过滤缺失值。“仅看有代表 Tc 的材料状态”要求同一状态存在代表 Tc；若同时设置 Tc 范围，同一条记录必须满足范围。这不等于社区图表的最终点集，后者还检查方法与坐标。独立结构不依赖 Tc，页面相邻说明该例外；独立结构请求不随 Tc／代表 Tc 条件或主视图切换重发。

审核状态控件只向已批准管理员、超级管理员显示，选择后同时用于论文、状态与独立结构查询。身份变化后清除上一身份结果并重新请求，旧响应不覆盖新身份结果。

## 独立结构与来源

独立区调用Python `POST /api/rag/structural-records/search`并启用independent_only，服务端在计数／分页前排除已关联状态的模型。普通用户只能发现当前已批准 revision 的 retained 完整 model；管理员查询遵守上述审核状态范围，仍只读当前 revision 的 retained 完整 model。资料按自身元素匹配，不依赖 Tc。

已关联模型在对应状态提供入口，独立伴随模型单列。没有状态的模型不会被虚构为材料状态，但其来源可进入论文视图；收录模型不等于已证实超导。缺原子位置的几何资料不生成完整模型入口。

“查看来源论文”和“查看结构与下载”均新标签打开，保留合法来源地址；结构详情继续提供晶胞切换、三维模型及CIF／POSCAR导出。没有完整模型时不复制其他压强或优化方式的坐标。

## 失败与权限

新结果查询不沿用旧Tc永久缓存。请求失败显示可重试错误，不伪装为0；快速切换或筛选时忽略旧请求响应。详情来源仅接受合法站内地址，直接访问或非法来源使用检索入口兜底，取消固定返回上传列表。
