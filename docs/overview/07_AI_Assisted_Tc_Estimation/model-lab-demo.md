# 本地模型实验室 Demo

## 功能说明

独立本地 Demo 按常压常规材料、高压氢化物展示模型；右侧等高来源卡提供“论文链接”“原始网站”和数据下载，不展示裸网址、许可／版本和校验码，不提供预览。代码和数据在同一仓库时合并网站入口；技术元信息仍保留在目录和下载包内。原站经验估算功能已接入当前页。

## 当前行为

- `127.0.0.1:5189` 页面经本地代理访问独立 `127.0.0.1:8192` API，采用 Vite／Uvicorn 原生热重载。
- BETE-NET-CSO 使用作者 100 个原始网络权重和当前公开结构的近邻归一化，输入 CIF／POSCAR／CONTCAR，输出平均 α²F、EPC 参数与可计算的 Tc。
- 结构默认按内容自动识别，上传和粘贴后恢复自动识别，结果标记实际格式；也可手动指定。选择的格式与内容不匹配时明确提示切换，不再把有效 POSCAR 按默认 CIF 报成无效结构。
- Xie 2019 与 2022 公开符号回归公式实际计算 Tc；2022 需要 λ、ωlog、ω₂、μ*，不是结构预测器。
- 姜博文等人的原模型使用论文称呼 Tc assessment model，当前页接收 CONTCAR／POSCAR 和多份电子 PDOS，通过本地 Vite 调用原 `/api/tc-predict/`；直接展示 Tc、E_couple（原 f₂）及所有返回特征，不跳转执行，也不复制公式。
- 结构模型结果可将同一组预测参数带入 SISSO；结果逐次保留，不自动平均，没有数据库持久化。
- BETE 以一个数据包下载，收齐当前公开的性质文件、806 个晶体结构和训练／测试名单，包内作者文件字节不变，另附许可和来源说明。SISSO 2019 默认提供实际使用的 29 条训练输入；81 样本候选数据也可下载。
- 网站入口为短文字链接；后台仍校验文件摘要，失败拒绝供应。候选数据可下载不等于候选模型已接入推理。BETE 整包范围是当前公开版本，不宣称补齐作者未公开文件。

## 工作流程

选择分组和模型 → 上传结构／PDOS 或填写参数 → 实际运行模型 → 当前页查看独立结果；相邻来源卡提供论文、代码、原文件和上游出处。桌面两卡顶底等高，窄屏自然堆叠。Tc assessment model 还需要现有本机 8080／8000 原站服务运行。

## 约束

结构推理一次运行一个请求，支持 1–80 个原子、三维周期结构；不支持分数占位。谱使用作者的 51 点网格和后处理约定。输入非法、公式不适用或模型失败时不返回假结果。

依赖与大型制品位于 `.local/tc-model-demo/`，未安装到主项目环境、未提交数据或权重。独立 venv 使用本机已验证的依赖版本；其他平台需重新验证。

## 已知边界

Xie 2022 的公开训练 ZIP 存储服务本次不可用，页面只有原始网址与失败状态，尚无本地下载；原有经验模型的校准数据也未核实。BETE 当前数据和作者参考输出数量不同，三个样本的近似数值回归不是完整论文指标复现；没有证明高压结构或非谐体系上的科学有效性。完整平台和其他模型接入状态以 Issue #162 为准。
